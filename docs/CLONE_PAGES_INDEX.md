## 先把站点跑起来

```bash
cd <仓库根>
npm install          # 首次
npm run dev          # 固定端口 4317
```

- 打开：`http://localhost:4317/`（这是**站点根目录**，也就是 LibTV 画布本身）
- 端口被占时用 `npm run dev:restart`（或 `npm run dev:restart -- 4387`）
- 停止：`npm run dev:restart` 脚本自带清理，或直接结束该进程

⚠️ **原型边界（先看这条，省得白等）**：本站**不接任何真实生成、账号、计费、上传或服务端持久化**。
生成/发布/会员/积分类入口点了只会给一条本地状态提示。

## 入口在哪（从站点根目录出发）

站点根目录 `/` 的顶栏左侧有一组**站点导航**（LibTV 芯片 ＋ 全部项目 ＋ 即梦画布 ＋ 克隆总览）：

| 目标 | 怎么点 |
|---|---|
| LibTV 画布（`/`） | 直接打开站点根目录 |
| FrameOS 画布 | 点顶栏最左的 **LibTV 芯片**（或直接开 `/frameos/canvas/demo`） |
| 全部项目 | 点顶栏「**全部项目**」芯片（源站原生的「项目菜单 ∨ → 全部项目」同样可达） |
| 即梦 AI 画布 | 点顶栏「**即梦画布**」芯片（或直接开 `/jimeng/canvas/demo`） |
| 克隆总览 | 点顶栏「**克隆总览**」芯片（`/clones`）—— 这一页列全了所有克隆页 |

> 💡 **别名路由**：`/frameos` 与 `/jimeng` 会重定向到对应的 demo 画布 ⇒
> 手敲它们和点芯片等价。

## liblib-canvas — LibTV 画布

- **路由**：`/`（站点根目录本身）
- **复刻对象**：liblib.tv/canvas（视频故事板画布）
- **怎么到达**：
  - 直接打开站点根目录 `http://localhost:4317/`
  - 从 `/project` 回到根目录：点 `/project` 页面左上角的「**返回**」按钮（它真的 `router.push("/")`）
  - ⚠️ **别走顶栏「项目菜单 ∨ → 回到主页」** —— 那一项在源站是回营销首页，
    而本站没有独立的营销首页，所以它**只给一条本地状态提示、不导航**
    （见 `scripts/verify-liblib-batch504.py` 钉住的那份契约）。
- **怎么交互测试**：
  - 画布空白处**双击** ⇒ 打开「添加节点」面板；点节点 ⇒ 看上/下两个浮层
  - 选中节点试 `⌘C` / `⌘V` / `⌘Z`；框选多个节点试成组与解组
  - 点顶栏「导演台」卡片上的「打开导演台」⇒ 进 3D 场景，可拖机位、拉时间轴
  - 打开「素材」抽屉看素材库；打开「分享」面板看原型态提示
  - 空白处**右键**看画布右键菜单；`⌘0` 恢复视图
- **mock 边界**：生成/发布/会员/积分入口都是原型态；画布数据只活在当前标签页内存，刷新即复位
- **手册**：[`docs/user-manual/libtv-canvas/README.md`](user-manual/libtv-canvas/README.md)

## liblib-projects — LibTV 全部项目

- **路由**：`/project`
- **复刻对象**：liblib.tv 的项目列表
- **怎么到达**：
  - 站点根目录 ⇒ 顶栏「**全部项目**」芯片
  - 源站原生路径：顶栏「项目菜单 ∨ → 全部项目」
  - 直接打开 `http://localhost:4317/project`
- **怎么交互测试**：
  - 点「新建项目」⇒ 列表多一张卡片 ⇒ 点卡片在**新标签页**打开画布
  - 删除一张卡片 ⇒ 进「回收站」⇒ 恢复 ⇒ 「剩余 N 天」按删除日期重算
  - 缩窄窗口 ⇒ 看左侧栏与卡片区的响应式排布
- **mock 边界**：项目只存在当前标签页内存 store 里（不持久化）；「创建新项目」是本地动作，不接账号
- **手册**：[`docs/user-manual/libtv-canvas/README.md`](user-manual/libtv-canvas/README.md)

## frameos-canvas — FrameOS 画布

- **路由**：`/frameos/canvas/demo`（别名 `/frameos` 会重定向过来）
- **复刻对象**：frameos.cn 的 AI 画布
- **怎么到达**：
  - 站点根目录 ⇒ 顶栏最左的 **LibTV 芯片**
  - 直接打开 `http://localhost:4317/frameos/canvas/demo`
- **怎么交互测试**：
  - 在 Prompt 编辑器里输入文字 ⇒ 点生成 ⇒ 看 mock 结果进画布
  - 画布空白处**右键** ⇒ 上下文菜单；点节点 ⇒ 浮动工具条 ＋ 右侧编辑面板
  - 打开「素材库」选素材 ⇒ 拖进画布；打开「帮助」看快捷键表
  - `⌘Z` / `⌘⇧Z` 试撤销与重做；框选多节点后试成组
  - 试「专注模式」「全屏文本」「图片灯箱」这几条浮层
- **mock 边界**：生成永远返回**本地 mock 结果**，不调用任何模型、账号或计费接口；独立 store，不与 LibTV/即梦共享状态
- **手册**：[`docs/user-manual/frameos-canvas/README.md`](user-manual/frameos-canvas/README.md)

## jimeng-canvas — 即梦 AI 画布

- **路由**：`/jimeng/canvas/demo`（别名 `/jimeng` 会重定向过来）
- **复刻对象**：jimeng.jianying.com 的 AI 画布
- **怎么到达**：
  - 站点根目录 ⇒ 顶栏「**即梦画布**」芯片
  - 直接打开 `http://localhost:4317/jimeng/canvas/demo`
- **怎么交互测试**：
  - 点节点 ⇒ 节点工具条；拖节点 ⇒ 跟随移动 ＋ 吸附辅助线
  - 点左侧 AI 按钮 ⇒ AI 对话抽屉 ⇒ 输入文字看引用与插入面板
  - 点顶栏「资产」⇒ 资产库；点节点图片 ⇒ 试裁剪、扩图、重绘面板
  - 新建「时间线」「主体」「导演台」节点 ⇒ 看各自的参数面板
  - 画布空白处**右键** ⇒ 画布右键菜单；`⌘K` / `?` ⇒ 快捷键面板
  - 试视频节点的播放、修剪、截取帧；试多选工具条与成组
- **mock 边界**：**所有生成类按钮只出「执行前一步」的本地状态**，不发起真实生图/生视频、不消耗积分；节点数据是 demo mock，刷新即复位
- **手册**：[`docs/user-manual/jimeng-canvas/README.md`](user-manual/jimeng-canvas/README.md)

## clone-index — 克隆总览

- **路由**：`/clones`
- **复刻对象**：本站自身的索引页（不是某个源站的复刻）
- **怎么到达**：
  - 站点根目录 ⇒ 顶栏「**克隆总览**」芯片
  - 直接打开 `http://localhost:4317/clones`
- **怎么交互测试**：
  - 点每张卡片右上角的「打开」⇒ 新标签页打开对应克隆页
  - 对照卡片里的「从根目录怎么走到」⇒ 看它描述的入口确实在根目录上
  - 改浏览器窗口宽度 ⇒ 看索引页的响应式排布
- **mock 边界**：纯索引，内容全部来自 `src/lib/clonePages.ts`，不含 mock 数据、不发起任何请求
- **手册**：本页自身

## 没进这张表的东西（别当成「已完成的页面」）

- `docs/research/tdcanvas-*`、`docs/research/beeftv-*`：**研究对象**，不是复刻页面 ⇒ 没有路由
- 源站的账户、充值、订阅、积分购买等页面：**不在复刻范围**
- 用户手册站点（`docs/user-manual/*`）：是**文档站点**，不是克隆页面 ⇒ 用各目录的 `build-site.sh` 构建
