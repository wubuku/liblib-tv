## 关键方法论沉淀

1. **React Flow 变换子树内的 `position: fixed` 会被劫持**——浮层需
   `createPortal` 到 `document.body`（Batch 195 实测 y=923 偏移）。
2. **390 断点**：预设构图铺满视口，pane 空白点用 `elementFromPoint`
   动态探测；卡内面板（660 宽）锚定出屏时先 Meta+0 fit-view。
3. **触发器贴近视口下缘**：模型菜单等 JS click 打不开，需 CDP
   `Emulation.setDeviceMetricsOverride` 抬高视口（batch 174/190 配方）。
4. **Tailwind 4** 将 `bg-white/[0.1]` 编译为 oklab——颜色断言按类名 +
   alpha 校验，不比较 sRGB 字面量。
5. **字体加载抖动**：面板相对 x 偏移随触发器文字宽度双峰（119/124.16），
   契约改用 CSS 保证的触发器相对偏移（-68/-60）。
6. **校验器要求显式 handle 方向**：程序化 `addEdge` 需带
   `sourceHandle: "source"` / `targetHandle: "target"`。
