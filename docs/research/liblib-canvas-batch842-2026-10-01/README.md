## 二、源站实测

### 2.1 ★★ batch 841 的 raw 为什么**不够**

841 那趟探针把右栏子树按 `y ≤ 833` 过滤了（只留首屏）⟹ ⟹ 眉眼页只留下**前 7 条**滑杆的完整结构。

但**不限 y** 的三个子集够用：

- `inputs`（32 条）⟹ 全部滑杆的**轨道**（宽 240 高 12）＋ `aria-label`；
- `leaves`（90 条）⟹ 全部**标签**、**数值**、**「i」标记**、H3、卡片名；
- `ctrls`（63 条）⟹ 11 张 **76×96** 的眼型卡。

⟹ ⟹ **30 条滑杆的四件套**全部能从 841 的 raw 里机器提取 ⟹ ⟹ 本批**不用**重跑源站就能对拍几何。

### 2.2 ★★ 更正 batch 841 的一个数字：**30 条，不是 32 条**

841 的 README 写「眉眼 32 条滑杆」⟹ ⟹ **错了**。那 32 个 `input` 里：

- 1 个是**「角色名称」文本输入框**（216×32）；
- 1 个是 **1×1 的复选框**；
- 剩下的 **30 个才是滑杆**（眼睛段 19 ＋ 眉毛段 11）。

⟹ ⟹ 本批更正（★ 旧批次的 README **不重写**，更正写在这里）。

### 2.3 眉眼页的完整结构（源站实测，top 一律相对右栏滚动区内容起点）

```
H3「眼睛」240×20 @top 20        （13px/500/行高 20/色 rgba(255,255,255,0.3)）
  └ 19 条滑杆：标签 top = 60 + 74.8·i（祛黑眼圈**带**「i」）
H4「眼神光」240×22 @top 1481    （14px/500/行高 22/**白**，**带**一枚「i」）
  └ 11 张眼型卡 76×96：3 列 × 4 行（步进 82／104）
      ＝ 76×76 媒体区（radius 16、底色 rgba(255,255,255,0.06)、1px 边框）
        ＋ gap 4 ＋ 名字（11／16）
      「无」那张**没有缩略图**（源站是一枚 18×18 的图标），其余十张是 74×74 的真图
H3「眉毛」240×20 @top 1947
  └ 11 条滑杆：标签 top = 1987 + 74.8·j
```

- 眼型卡（源站 `aria-label` 逐条照抄）：无／氧气／清澈／神采／秋水／灵动／水光／聚焦／透亮／星光／通透；
- 源站默认选中「无」（`aria-pressed="true"`，白边 ＋ 名字纯白；其余透明边 ＋ 名字白 60%）。

### 2.4 ★ 本批补跑的**只读**探针（只为了拿**计算样式**）

`probes/source842_brow.py` ⟹ raw 入库在 `raw/source-842-brow.json`。
★ 只点右栏的「眉眼」「妆造」两枚页签 ⟹ **不点**「确认生成／保存／智能调整」
⟹ ⟹ **不消耗** ⚡44（每次点击前后都核对那一颗积分：**44 → 44，全程未变** ✓）。

它补上了 841 那趟**采不到**的东西：H3／H4 的字号与颜色、卡片的圆角与底色、
「i」标记的**描边**、以及**妆造页**的 chip 与 tabpanel（留给下一批用）。

## 三、clone 的改动

### 3.1 分块布局

`CharacterEditorPanel.tsx` 里加了 `PanelBlock`（`h3` / `h4` / `sliders` / `cards`）
与 `TAB_BLOCKS["brow-eye"]`；`renderSlider` 多接一个**绝对 top** 参数
（原来只有「20 + i·74.8」这一种，⟹ 眉眼页各段的起点各不相同）。

### 3.2 ★★★ 「i」标记的外观之前是**错的**（本批顺手改正）

源站实测：`rounded-full border border-current text-[10px] font-medium leading-none`

⟹ ⟹ clone 之前写的是**填充底色**的实心圆（`background: rgba(255,255,255,0.12)`）
⟹ ⟹ **盒**一直是 14×14（所以旧门禁抓不到它）⟹ ⟹ **样子**是错的 ⟹ ⟹ 本批改正。

★ **通用形态**：**几何对齐 ≠ 外观对齐** ⟹ ⟹ 盒对了不代表样子对了 ⟹ ⟹
判据里要**另加**计算样式这一层（本批门禁的 S3 就是它）。

### 3.3 空态说明改成**逐页**写

「妆造」那页**没有滑杆**，它是 **11 个分类 chip ＋ 13 张妆容卡** ⟹ ⟹ 继续写
