# Batch 13 截图分析台账

> 识图日期：2026-08-25
> 用途：固化原站分镜模式的空间与内容结构；后续不重复识别同一张原站截图。

## 原站证据

文件：`docs/design-references/liblib-original-storyboard-2026-08-25.png`

### Viewport and zones

- 视口：`929x874`。
- 顶部浮动导航覆盖在页面上方，左侧包含 LibTV 标记、`画布 2`、模式按钮；右侧有分享和积分。
- 右侧 Agent 从约 `x=589` 开始，占剩余约 `340px`，标题为“新对话”。
- 左侧工作区从约 `x=16` 开始，主体被分成关键元素栏与故事板区。

### Left key-elements rail

- 顶部标题为“关键元素 · 全部”，右侧有下拉箭头。
- 下面有图片资源区，能看到 `图片4`、`咖啡` 等缩略卡。
- 下方有“文本”分区，至少有一个“剧本”资源项。
- 该栏是独立滚动/裁切区域，不是工作台 React Flow 节点本体。

### Storyboard body

- 主体标题为“故事板”。
- 至少有“图片”和“视频”两列，列标题右侧带排序/展开类图标。
- 图片列展示当前画布中的多张图片卡：`分镜 #2`、`图片4`、`咖啡` 和一张 `image_2026-...` 素材。
- 图片卡包含缩略图、标题、来源/尺寸信息；分镜卡还展示参考缩略图。
- 视频列展示当前视频素材；失败状态显示“生成失败，详情”一类状态入口。

### Agent relationship

- 分镜模式不是独立全屏 Modal；Agent 与故事板并列存在。
- 当前原站截图中的 Agent 包含推荐技能卡、输入框和底部操作区。
- Batch 11 已记录 clone 的 Agent 生命周期，本批只调整故事板主体，不重做 Agent 内容。

## 证据边界

- 上述布局、标题、列名、可见素材和 Agent 并列关系来自原站截图直接观察。
- 卡片点击后的具体导航、排序和展开命令未在本轮截图中确认。
- 本批只实现数据投影、选择态和返回工作台的可验证原型行为；不把这些 clone-only 行为写成原站事实。

## Clone 验证截图

### `liblib-clone-batch13-storyboard-desktop-929-2026-08-25.png`

- **来源**：本地 LibTV clone。
- **状态**：`画布 2` 分镜模式；右侧 Agent 打开；脚本卡被选中。
- **DOM/视觉事实**：左侧图片组 5 项、文本组 1 项；中间图片列 5 项；视频列 1 项并显示失败态；故事板卡片使用当前画布的本地图像。
- **空间事实**：Agent 右抽屉约 340px；关键元素栏与故事板主体并列；底部两组工具条仍位于页面底部。

### `liblib-clone-batch13-storyboard-empty-desktop-929-2026-08-25.png`

- **来源**：本地 LibTV clone。
- **状态**：切换到空的 `画布 1` 后进入分镜模式。
- **DOM/视觉事实**：图片、文本和视频分组均显示明确空态，没有残留 `画布 2` 的图片或视频卡。

### `liblib-clone-batch13-storyboard-mobile-390-2026-08-25.png`

- **来源**：本地 LibTV clone。
- **状态**：`390x844`，`画布 2` 分镜模式。
- **空间事实**：页面级 `documentElement/body` 无横向溢出；故事板主体在内部横向滚动，关键元素栏和图片列保持固定宽度。

## 一次性识图结论

- 不再重复打开 `liblib-original-storyboard-2026-08-25.png`，除非原站分镜模式发生变化或需要确认未覆盖的深层交互。
- 当前截图支持“布局与数据投影”验收，不支持排序、拖拽、发布或卡片深层导航的原站契约。
