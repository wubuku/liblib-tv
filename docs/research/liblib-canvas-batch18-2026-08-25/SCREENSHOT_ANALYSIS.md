# Batch 18 截图分析台账

> 识图日期：2026-08-25
> 用途：固化原站缩放菜单结构；后续不重复识别同一张截图。

## 原站证据

文件：`docs/design-references/liblib-original-zoom-menu-2026-08-25.png`

- 视口：`929x874`。
- 画布处于整理/适合后的 `28%` 构图。
- 底部画布工具条左侧约从 `x=32` 开始，缩放按钮显示 `28%`。
- 菜单位于缩放按钮正上方，约 `x=172, y=543, w=188, h=277`。
- 菜单为深色圆角浮层，没有全屏遮罩。
- 顶部状态行：
  - 左侧 `28`
  - 右侧 `%`
  - 浅一层背景
- 命令顺序：
  1. `放大`，右侧 `⌘ +`
  2. `缩小`，右侧 `⌘ -`
  3. `适合屏幕`，右侧 `⌘ 0`
  4. 分隔线
  5. `缩放至50%`
  6. `缩放至100%`
  7. `缩放至800%`
- 菜单截图中没有 `点阵网格`。
- 菜单打开时画布、节点、边和两个底部工具条仍可见。

## 证据边界

### Source fact

- 上述几何、文案、顺序、快捷键和无网格项由截图直接支持。

### 未确认区域

- 截图没有证明点击每个命令后菜单是否立即关闭。
- 没有保存 hover、外部点击或与其他 overlay 同时打开的状态。

## 复用规则

- 后续修改缩放菜单先读本文、`ZOOM_MENU.spec.md` 和 Batch 18 Playwright。
- 新截图只采样 clone 默认菜单、固定缩放和移动端状态。
