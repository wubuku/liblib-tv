## 三、clone 的改动

### 3.1 「编辑角色」不再是死按钮

`CharacterLibraryPanel.tsx` 里那枚 CTA 原本是个 `<span>` ⟹ 本批接上**角色大编辑器**：
`uiStore` 新增 `characterEditorId`，点 CTA ⟹ 打开；**保存** ⟹ 名字**落回角色**；
Esc ⟹ 关闭。标题值与角色名是**同一个 state** ⟹ 所以「保存」是真落库，不是画布上的假动作。

### 3.2 几何全走**普通 CSS**（不走 Tailwind 任意值）

★ 4317 的 Tailwind 扫描是**冻结**的 ⟹ 新增任意值类在 dev 根本不生成 ⟹
`.ce-*` 这一整套（约 500 行）全部写成**普通 CSS**，坐标也**不**依赖 Tailwind 类。

### 3.3 ★★★ Esc：靠**前台阻塞面**，不是组件本地状态

`libtvSelectionCommandContext.ts` 的阻塞面 union 加了 `"character-editor"`，
解析顺序**排在 `character-assets` 之前**（大编辑器比资产视图更靠前）。

★★ **Esc 有两条路径**，两条都要成立：
1. 焦点**不在**可编辑元素里 ⟹ 画布那套全局键盘契约看到 `character-editor` 这个面 ⟹ 关掉它；
2. 焦点**在标题输入框**里 ⟹ 全局那套对**可编辑目标**是**早退**的 ⟹ Esc 到不了 store
   ⟹ ⟹ 大编辑器**自己**处理 Esc（组件本地那层 ⟹ **不与**全局那层冲突，因为全局那层此时什么都不做）。

### 3.4 ★★ 图标：lucide **占位**，但**尺寸与位置**逐像素对齐

源站是 iconify SVG，**字形未采集** ⟹ ⟹ clone 用 lucide 占位（五段图标、首枚页签图标、
「确认生成」左侧那枚、撤销／恢复／按住对比、半身／全身、智能调整）。
★ 但**盒**全部按第⑤趟归档的 svg 盒对齐（18 × 18；「返回」16 × 16）。
