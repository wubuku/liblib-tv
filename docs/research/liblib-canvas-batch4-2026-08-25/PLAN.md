# LibTV 画布 Batch 4 计划：多选与分组

> 建档日期：2026-08-25  
> 原则：先按证据分层，再按用户价值和回归风险排序；没有实时证据的视觉行为不进入默认实现。

## 1. 缺口盘点

| 候选缺口 | 当前克隆 | 原站/当前代码证据 | 价值 | 本批决策 |
|---|---|---|---:|---|
| 框选 | React Flow 已开启 `selectionOnDrag`，但状态只支持单选 | 当前 `page.tsx` 的 `selectionOnDrag` 和 `SelectionMode.Partial` | 5 | 实现 |
| 多选 | `selectedNodeId` 强制单选 | 原站快捷键面板有成组；React Flow 原生支持多选 | 5 | 实现 |
| 成组 | 没有命令和数据关系 | 原站快捷键直接证据 `G`；原站有 group 节点 | 5 | 实现最小闭环 |
| 解组 | 没有命令 | 原站快捷键直接证据 `⇧G` | 4 | 实现最小闭环 |
| 合并分镜组 | 没有命令 | 原站快捷键直接证据 `⌥G`，但交互过程未保存 | 4 | 暂缓 |
| 连线快捷键 | 只能拖 Handle 连线 | 原站快捷键直接证据 `L`，起止端点选择流程未知 | 4 | 暂缓 |
| Option+拖动 | 未实现 | 原站文案证据，复制范围和拖动语义未知 | 4 | 暂缓 |
| 对齐辅助线 | 当前没有 | 当前 LibTV 没有直接证据；FrameOS 有独立证据 | 3 | 暂缓 |
| 视口 history | 当前不入 history | 原站当前证据不足，且会污染普通编辑撤销 | 2 | 不做 |

## 2. 实施范围

### P0

1. `selectedNodeIds: string[]` 与 `selectedNodeId` 主选中兼容并存；
2. React Flow 框选、多选和 `onSelectionChange` 写回 store；
3. `G` 对至少两个普通节点成组；
4. `Shift+G` 对选中的组或组内节点解组；
5. 成组/解组作为单个 graph history 事务；
6. `Delete` 批量删除当前多选节点；
7. 快捷键面板展示本批已经闭环的成组、解组。

### P1

1. 分组节点继承原站图片组的低干扰壳层；
2. 成组后的节点通过 React Flow `parentId` 建立父子关系；
3. 解组时把子节点转换回画布绝对坐标；
4. 选中多个节点时不显示单节点图片/视频编辑浮层。

## 3. 数据决策

- group 节点是普通 React Flow node，类型仍为 `storyboard-group`；
- group 节点创建在选中节点包围盒外扩 `32px` 的边界；
- 子节点位置转换为相对 group 的坐标；
- 子节点增加 `parentId`，不引入第二套 group store；
- 不把 group 节点和子节点的视觉细节写成原站事实；
- 新建 group 默认使用图片组壳层：`rounded-[20px]`、半透明背景、低 z-index；
- 成组后主选中节点为 group；解组后主选中节点为第一个恢复的子节点。

## 4. 不做

- 不实现嵌套组；
- 不自动推断“分镜组”与普通成组的业务语义；
- 不实现 `Option+G` 合并分镜组；
- 不实现跨画布分组；
- 不把 selection 写入 graph history；
- 不修改 FrameOS store 或 FrameOS route。

## 5. 验收标准

### Store

- 选择多个节点后，`selectedNodeIds` 保持顺序稳定；
- 单选时 `selectedNodeId` 等于唯一节点；
- 成组新增一个 group 节点，选中节点成为其子节点，边保持原端点；
- 解组删除 group 节点，子节点恢复到原画布坐标，边保持；
- 成组和解组分别可撤销、重做；
- 删除多选节点时所有关联边一次删除并可撤销。

### UI

- 框选区域能选中部分相交节点；
- 多选节点有一致的 selected 状态；
- 多选时不出现单节点上下编辑浮层；
- 分组壳层在节点后方，不遮挡节点和连线交互；
- `390px` 视口不出现横向溢出；
- 快捷键面板不宣传未实现的 `Option+G`、`L` 和 Option+拖动。

### 验证

- `npm run check`；
- Playwright 或现有浏览器自动化脚本验证桌面 `1440x900`；
- 移动 `390x844` 截图与溢出检查；
- 控制台错误数为 `0`；
- `/frameos/canvas/demo` 首屏和构建不回归。
