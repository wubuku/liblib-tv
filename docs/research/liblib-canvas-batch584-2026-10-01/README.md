## clone 合同（CLONE_DECISION）

1. **重排为七组解剖分组**，`DirectorPoseControlGroup` 增 `rows`
   （含 `side: left|right` 与子行标题），id 改为
   `body / torso / head / arm-shoulder / elbow / leg-hip / knee`；
2. **常驻展开**：去掉折叠按钮与骨骼链副标题，每组以标题 + 关节滑杆平铺；
3. **量程逐项对齐源站**（见上表），标签改用源站的纯关节名
   （前倾/扭转/点头/前举/前抬/弯曲…），不再带骨骼前缀；
4. **数字读数移入 `sr-only` output**，aria 为「{标签}角度」
   （对齐源站 `directorJointAngleAria` 键），视觉上与源站一致；
5. **内部关节只从 UI 隐去**：`body.offsetY`、手腕 ×6、脚掌 ×4 源站没有
   滑杆，但 clone 的 20 个源站对齐预设（蹲下/坐姿/抱臂/招手…）依赖这些
   取值，故保留在 `INTERNAL_POSE_CONTROLS` 参与
   `normalizeDirectorPoseControls` 钳制与预设应用，不进 UI；
6. **滑杆量程 ≠ 钳制量程**：源站 T型 预设的肩外展为 −70，落在源站滑杆
   下限 −10 之外，因此钳制仍用内部宽量程，滑杆只按源站区间呈现（越界时
   滑块贴边，与源站一致）。这一点若不分离，T型 预设会被源站下限截断。
