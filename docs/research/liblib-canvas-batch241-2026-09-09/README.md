## 关键新事实（`SOURCE_FACT`，m-HappyHorse1.1.png）

- **首帧态页脚紧凑变体**：工具行只剩 **+参考** 一个 pill（标记/特效/
  角色库/运镜消失）；页脚省略 doc-sparkle 图标；
- **参考槽悬停含「销毁」按钮**（槽图上深色 销毁 标签）；
- Happy Horse 1.1 默认 **1080P · 6s**（无比例段——部分模型设置芯片
  不含比例）；Happy Horse 1.0 默认 192 积分（6s×32/s？未受控）；
- 首帧态模式触发器带专属图标（非通用 Film 字形）；
- 部分模型（Happy Horse 系）切入后面板进入 首帧 紧凑态，此态下模型
  菜单无法再打开（当时疑似 首帧 态锁定模型选择器——**batch 242 已证伪**：
  首帧态菜单可正常打开，成因另查）。

## 方法笔记

- `ensure_panel`：面板意外关闭时重选节点恢复；
- 芯片读取失败率高的根因：各模型默认芯片分隔符/段落结构不一致
  （Happy Horse 无比例段），按「含 ≥2 个 ·」过滤会漏。
