### 5.3 ★ 本轮踩到的一个**真坑**：探针把模态**滚了 2px**

★ 现象：clone 探针的头一次读数里，右栏整体**比源站高 2px**
（源站 rel y=70，clone 读出 68）⟹ ⟹ 而 152 项几何里**全部**差 2px。

★ 根因：模态是 `overflow: hidden`，而它的内容**比它高 2px**
（底栏 672 ＋ 88 ＝ 760 > 758）⟹ ⟹ **`overflow:hidden` 的元素仍可被程序滚动**
⟹ ⟹ 探针点元素前的 `scrollIntoView({block:'center'})` 找不到更近的可滚动祖先时
⟹ ⟹ **把模态本身滚了 2px** ⟹ ⟹ 于是**整棵树**（三列 ＋ 底栏）**整体上移 2px**。

★ **这不是 clone 的缺陷**：★ **源站同样如此**（源站的底栏也是 672 ＋ 88 ＝ 760）
⟹ ⟹ 所以正解是**探针别去滚它** ⟹ ⟹ `click_box()` 现在在 `scrollIntoView` 之后
**把模态的 `scrollTop`／`scrollLeft` 复位**。

★ 附带结论：**「一轮的差」不能直接当因果**——同一批里第一次读数（68）
与后续读数（70）**不一样** ⟹ ⟹ 判据必须先证明读数**可复现**。

★ 教训二记（★ 阴性臂的变异**把代码改坏**了）：症状是「**等不到标记**」
而不是「判据没红」⟹ ⟹ 极易误判成「这条臂没生效」⟹ ⟹ 正解：只把**条件**换成恒真
（**结构一个字都不动** ⟹ ⟹ 编译得过）。★ 第一版写成
`{(cond ? (true) : (true)) && ( … ) : null}` ⟹ ⟹ 尾部那个 `: null}` 没有配对对象
⟹ ⟹ **整段 JSX 语法错** ⟹ ⟹ dev server 报错 ⟹ ⟹ 标记永远等不到。

★ 教训三记（★ **同一个串写两遍**）：迁移时把门禁里的键串 `「未实测」` 写成了
`「未实测》`（★ 错的是**右括号**）⟹ ⟹ 症状是**运行时报 KeyError**
⟹ ⟹ 而不是「判据红了」⟹ ⟹ 正解：把那个键提成**局部变量** ⟹ ⟹ 同一个串**只写一遍**。
★ 这与「**手打的标识符是输入，不是测量**」同族。
