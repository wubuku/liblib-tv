## 三、Q2：源站的关键帧**不是 DOM 按钮，是画在 canvas 上的**

打开源站时间线（`动画时间轴` → `aria-pressed` 变 `true`）后，泳道区是：

```
CANVAS  2212×115  @(322,871)  aria-label='动画时间轴播放头'
```

**整条泳道是一个 `<canvas>`。** 关键帧菱形画在里面，DOM 里查不到。

源站时间线 DOM 层面能读到的控件只有 8 个：

| 控件 | 尺寸 | aria-label |
|---|---|---|
| `播放` | 26×24 | `播放` |
| `自动帧` | 24×24 | `自动帧`（`aria-pressed='false'`） |
| `循环播放` | 26×24 | `循环播放` |
| 播放头位置 | INPUT 46×24 | `播放头位置`（`type=text`） |
| `新建轨道` | 82×24 | **`选中角色、道具或分组后建立轨道`** |
| `导出视频到画布` | 108×28 | — |
| `主机位` | DIV 60×19 | — |
| **`绘制轨迹`** | **86×24** | `绘制轨迹` |

**对平项**：
- `绘制轨迹` **86×24** ⟵ clone 的 `data-director-track-draw-trail` 也是 **86×24**，逐像素同尺寸
- `自动帧` 默认 `false` ⟵ clone 的 `autoKeyframe` 默认同
- 时间线总高 **182px** ⟵ clone `DIRECTOR_TIMELINE` 同（Batch 591/592 已记「182 → 88 最小化」）
- `新建轨道` 把状态说明写在 **`aria-label`** 里（「选中角色、道具或分组后建立轨道」）——
  clone 用 `disabled` + 旁注，这是两种表达

**差值项**：
- **源站 DOM 层面不存在「左侧轨道行=增删 / 泳道区=选中」这组语义** —— 那是 clone 自己的
  实现选择（把泳道区从 canvas 改成 DOM 后必须自己补的）。751 记的「两个同名同形菱形」
  是 **clone 独有的歧义**，源站没有这个问题。
- **源站没有「曲线编辑器」入口**。时间线工具条只有 `新建轨道` + `导出视频到画布` 两枚。
  clone 的 `data-director-open-curve-editor`（把 `editorMode` 切到 `curve`）是 **clone 独有的功能**。

点左侧树的「机位1」：

| 页签 | 源站 | clone |
|---|---|---|

| 截图 | BUTTON **50×28** | `="captures"` |

属性页完整结构（`SECTION` 逐块）：

`旋转 xyz` / `注视目标`（手动坐标·手动旋转·角色A）/ `注视坐标 xyz` / `视野角度 (FOV)` + 说明 / `相机截图`

**每轴的结构是三件套**（这是 clone 已经复刻了的）：

```
BUTTON 20×28  aria-label='左右拖动调整 X 轴'   ← 横向拖动调节
INPUT  80×28  type=number  step=…  value=…
BUTTON 20×28  aria-label='当前帧有关键帧' / '当前帧无关键帧'
```

⟹ 我核过 `src/components/director/DirectorInspector.tsx:125/162/1696`：
**clone 已经有「左右拖动调整 X 轴」和轴旁的关键帧开关**，
所以这不是缺口。位置 xyz 三个轴当前都是「**有关键帧**」、旋转 xyz 三个都是「**无关键帧**」——
这与 clone `AxisFields` 的 `onToggleKeyframe` 是同一套语义。

**解掉挂起项 ⑥「FOV 滑块可达集」**：
源站 `INPUT type=range min=15 max=90 value=50`（170×20），
clone `FOV_MIN/FOV_MAX = DIRECTOR_CAMERA_FOV_MIN/MAX`，
`DirectorInspector.tsx:88` 的 Batch 610 注释写「源站 range 实测 min=15 / max=90 / step=1」。
⟹ **本批是对 Batch 610 的独立复测确认，不是新发现。**

**时间线缩放滑杆 —— 已经对平，不是差值**：
源站 `INPUT type=range aria-label='时间轴缩放' min=0 max=100 value=44`（71×24），
clone `DirectorTimeline.tsx:1337-1346` 是
`<input type="range" aria-label="时间轴缩放" title="时间轴缩放"
 data-director-timeline-zoom min="0" max="100">` —— **aria、min、max 全一致**。

> 我第一版把这一条写成「clone 没有缩放滑杆」并当成差值。**错在 grep 时用了 `head -3`**：
> 搜 `时间轴缩放\|时间线最小化` 只回了三行，全是「时间线最小化」，
> 我就下了结论。**一次 grep 的 `head` 不能当全集。**
> 这是本批第三次犯「先断言 clone 没有，再谈差值」—— 前两次是「左右拖动调整 X 轴」

## 五、Q4：运动轨迹页签 —— **差值集中在这里**

/ 时长 / 位置 xyz / 旋转 xyz / 缩放 xyz / 统一缩放

| 项 | 源站 | clone | 判定 |
|---|---|---|---|
| 虚拟相机说明 | 「请保持手机和电脑在同一 **wifi** 下，用手机扫码连接」 | 同 | **对平** |
| `录制` | BUTTON **190×36** | `motion-record` | 对平 |

| **`预设运镜`** | BUTTON **248×36**，`aria-label='预设运镜'`，**无 ⟳ 前缀** | `⟳ 预设运镜`，**无 `onClick`** | **差值**：前缀；源站是否可点未验 |
| **`创建运动轨迹`** | **源站没有这个按钮** | `motion-create-path`，**无 `onClick`** | **差值：clone 自造** |

| `统一缩放` | 标签在（滑杆在折叠线以下，本轮未取到 range） | `UNIFORM_SCALE_MIN 0.1` / `STEP 0.05` | 待下一格 |
| 旋转 xyz | `type=number step=1` | 同 | 对平 |
| 缩放 xyz | `type=number step=0.05` | 同 | 对平 |

### 最重要的一条：`时长` 滑杆量程 —— **Batch 583 的存疑项有源站证据了**

`DirectorCameraMotionTab.tsx:38-39` 的 Batch 583 注释写着：

> 「时长」滑杆量程仍无源站交互证据，保留 0–10 并标注为待复核。

本批在源站直接读到 `<input type="range" min="0.1" max="10" value="0.1">`
⟹ **源站是 0.1–10，clone 的下界 0 是错的**（`MOTION_SLIDER_MIN = 0`，`:41`）。
上界 10 是对的。

### 第二条：clone 多出一个源站没有的按钮

clone 的「创建运动轨迹」在源站**没有对应物**。源站创建轨迹的入口是
时间线上的 `绘制轨迹`（86×24）⟹ **两条路各走各的，clone 多出来的那条是自造的**，
而且它恰好又是那个**没有 `onClick`** 的按钮。
