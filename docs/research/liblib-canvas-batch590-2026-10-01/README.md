## clone 合同（CLONE_DECISION）

- `ASPECT_GLYPH` 映射表逐项记录七卡示意框尺寸（`3:4`/`9:16` 同值照抄）；
- 画幅卡：104×72（`h-[72px]` + 栅格算出 104，允许 1px 亚像素）、`rounded-xl`、
  背景透明、文字两态同 `text-white/90`、选中 `border-white/[0.85]` /
  未选中 `border-white/10`；
- 网格 `gap-2 px-2 pb-3 pt-0` → 总高 324，与源站逐像素一致；
- 新增 `geometrySubmenu` 八项 + 展开态，点选项仅回显本地等效提示
  （上传文件复用既有本地模型导入管线）；
- 新增群众弹窗：三个数字输入按上表量程、`共N人` 实时计数（行×列）、
  取消不写入、添加按当前值提交 `addCrowdArray`。

### 过程中被 verifier 抓到的自身缺陷

1. 打开群众弹窗时 `setOpenFlyout(null)` 关掉了 flyout，导致「取消」之后
   再点「群众 (3x3)」找不到入口。源站的弹窗是并排出现、flyout 保持打开，
   已改为 `setOpenFlyout("add-character")` + 弹窗定位 `left-[294px]`。
2. 颜色断言最初直接比对 `rgba(255,255,255,0.9)` 字符串——源站序列化为
   `lab(...)`，clone（Tailwind v4）序列化为 `oklab(...)`，字符串永不相等。
   改为解析尾部 alpha 后比对（合同真正约束的是 alpha）。
3. 卡片宽度实测 103 而非 104（232 − 16 − 8 = 208 / 2 = 104，但浏览器落在
   103.5 CSS px），断言放宽 1px 亚像素。
