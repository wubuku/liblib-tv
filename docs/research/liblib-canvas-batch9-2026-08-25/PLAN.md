# LibTV 画布 Batch 9 计划：选中节点双浮层锚定

> 建档日期：2026-08-25
> 原则：先量当前 clone，再决定是否修改；通过测试也必须留下可重复的回归合同。

## 1. 缺口盘点

| 审计项 | 当前风险 | 原站证据 | 价值 | 本批决策 |
|---|---|---|---:|---|

| 图片顶部间距 | 容易把 flow 单位和屏幕像素混用 | 工具条底边距节点顶边约 `16px` | 5 | 自动测量 |
| 图片底部面板水平锚定 | 绝对定位、translate 和反缩放组合容易互相覆盖 | 面板与节点中心一致 | 5 | 自动测量 |

| 视觉内容细节 | 当前批重点是几何，不应借机重做生成器内容 | 已有 Seedance 专项证据 | 2 | 不扩项 |

## 2. 实施顺序

### 阶段 A：当前 clone 测量

1. 在 `929x874` 下整理画布到原站式 `28%` 构图；
2. 选择 `分镜 #2`：
   - 记录节点、顶部工具条、底部面板矩形；
   - 校验中心、间距和屏幕尺寸；
3. 选择靠左/靠下图片：
   - 确认浮层不做浏览器视口夹取；
4. 选择失败视频：
   - 记录 child 节点与生成面板矩形；
   - 校验中心、间距和尺寸；
5. 执行 parent drag、child drag、pan、zoom：
   - 每一步重新校验相同锚定公式；
6. 多选两个节点：
   - 确认大型工具条和编辑面板都隐藏。

### 阶段 B：按测量结果实施

- 若几何不满足：在最小组件范围修正定位；
- 若几何已满足：不改视觉实现，只新增稳定 selector 与专项测试；
- 若测试暴露 parent hierarchy 特有问题：只修 parented video 跟随，不扩散到 FrameOS；
- 更新陈旧的 `VideoNode.spec.md`，使其反映当前 Seedance 生成面板和就绪视频工具条。

### 阶段 C：验证与留档

- 新增 `scripts/verify-liblib-batch9.py`；
- 保存 `929x874` 图片选中、视频选中和拖动后的截图；
- 跑 Batch 7-Batch 9 与 `npm run check`；
- 更新本批实施记录、全局行为文档、组件规格和文档索引；
- 分关键进展 commit 并 push。

## 3. 不做

- 不用页面级 `position: fixed` 重写节点浮层；
- 不对原站没有的视口夹取或自动翻转做“体验优化”；
- 不修改 Seedance 模型、模式、积分或 Prompt 内容；
- 不实现真实生成后端；
- 不修改 FrameOS 的浮动工具条或 PromptEditor；
- 不把 clone 的“仅单选显示”表述为原站已实测事实。

## 4. 验收标准

### 图片节点

- 工具条中心与节点中心误差不超过 `1px`；
- 工具条底边到节点顶边为 `16px ± 1px`；
- 工具条屏幕尺寸约 `900.5x49`；
- 编辑面板中心与节点中心误差不超过 `1px`；
- 编辑面板顶边到节点底边为 `16 * zoom ± 1px`；
- populated 面板屏幕尺寸约 `660x274`；
- 靠左图片的面板允许 `x < 0`，不被夹回视口。

### 视频节点

- 生成面板中心与失败视频 child 中心误差不超过 `1px`；
- 面板顶边到节点底边为 `16 * zoom ± 1px`；
- 面板屏幕尺寸约 `660x274`；
- 拖动 parent 后 child 和面板获得相同屏幕位移；
- 拖动 child 后 parent 不动，面板仍锚定 child；
- pan 与 zoom 后锚定公式继续成立。

### 生命周期与工程

- 多选时每个节点的大型选中浮层都隐藏；
- 面板交互不触发节点 drag 或画布 pan；
- 控制台 error 为 0；
- Batch 7-Batch 9 自动化通过；
- `npm run check` 通过。
