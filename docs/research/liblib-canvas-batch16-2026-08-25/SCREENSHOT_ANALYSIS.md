## 原站证据

文件：`docs/design-references/liblib-original-canvas-menu-2026-08-25.png`

- 视口：`929x874`。
- 画布本体仍铺满视口，菜单是顶部浮动层，不推动或缩放画布。
- 左上导航从左到右可见：LibTV Logo、`画布 2` 下拉按钮、工作台/分镜入口。
- 展开菜单约位于左上导航下方，约 `224px` 宽、`196px` 高，深色圆角面板。
- 菜单内容按层级排列：
  1. `当前项目`
  2. `未命名项目`
  3. 分隔线
  4. `画布` 标题，右侧加号
  5. `画布 2`，右侧勾选，表示当前画布
  6. `画布 1`
- 活动画布使用勾选表达，不依赖高亮色块；项目名位于画布列表之前。
- 菜单打开时背景节点、连线、底部工具条仍可见，说明它是局部浮层而非全屏 Modal。
- 截图状态下顶部没有单独的“项目名”pill；项目名出现在画布下拉内部。

## 证据等级与边界

### Source fact

- 上述结构、文案、活动勾选、加号和浮层关系由截图直接支持。
- 原站总体审计另行记录画布下拉具备新建、切换、重命名、复制、删除动作。

### 未确认区域

- 截图没有展开行级更多菜单，因此重命名/复制/删除的菜单视觉不在本台账中。
- 截图没有证明刷新后的项目名是否由服务端恢复。

## Clone 复刻规则
