# batch 679 —— 中心口径**对「完全被挡」零漏检**，而它漏掉的那些**全都至少还有 60% 是清的**

## 一句话

678 把「探测点只取控件中心」的覆盖边界量化了：每格固定漏 26 枚 / 130 枚。
本批问那个决定后果的问题：

**678 揭出的那 26 枚，是「完全被挡」还是「只被挡一部分」？**

答案是：**中心口径一个全被挡的都没漏，而它漏掉的全都是至少 60% 还能点的。**
换句话说，那个覆盖缺口**这么多批都没被发现，是因为它在后果上是良性的**。

## 仪器

`scripts/verify-liblib-batch679.py`，**直接复用 678 的网格 JS**（同一台量具、同一批读数）。
667 自己的 6 格 × 130 枚控件 × 25 样本 = **19,500 次命中判定**；
其中 24 个控件-格完全落在视口外、无样本，单列第三态，剩 **756** 个参与统计。
跨批次一致性单列判据：**两次独立运行的中心/网格人口逐格吻合**。

## 1. 中心口径对「完全被挡」零漏检

两个布尔量：`centre`（中心样本被外人占据）、`fullyBlocked`（25 个样本**全部**被外人占据）。

| centre | fullyBlocked | 控件-格数 |
|---|---|---|
| False | False | 739 |
| **True** | **True** | **16** |
| **True** | **False** | **1** |
| **False** | **True** | **0** ← **空格** |

**最后一格是空的：中心口径一个全被挡的控件都没漏。**

而那 16 个全被挡的控件-格，去重后正好是 **6 枚**：

| data 键 | 可及名 |
|---|---|
| `data-director-rail-entry=help` | `帮助` |
| `data-director-scene-prompt-submit=true` | `发送` |
| `data-director-scene-prompt-upload=true` | `上传图片` |
| `data-director-scene-prompt-input=true` | `描述想搭建的场景` |
| `data-director-color-picker=object` | `颜色` |
| `data-director-hex-input=object` | `颜色 hex 值` |

**正是 667 / 672 / 677 一直在追的那 6 枚。** 四批的线索在这里合上了：
它们是这 130 枚里**唯一真正完全不可用**的控件。

## 2. 反向不成立，而且只差一条

`centre ⟹ fullyBlocked` 是 **16/17**。唯一那条例外是
**1366×1150 格的 `data-director-scene-prompt-input`（`描述想搭建的场景`）**：
**中心落在盖住区内，但盖住区只覆盖了盒的 80%。**

**一条中心样本回答不了「整盒是否可用」—— 这正是它作为完全性判据的边界。**

## 3. 遮挡比例是离散的六档，全部是 1/25 的整数倍

| 覆盖比例 | 控件-格数 |
|---|---|
| 0（完全不被盖） | 581 |
| 0.12 = 3/25 | 12 |
| 0.20 = 5/25 | 90 |
| 0.40 = 10/25 | 56 |
| 0.80 = 20/25 | 1 |
| 1.00 = 25/25 | 16 |

**没有一个中间值** ⟹ 盖住者全是轴对齐矩形，
**一个采样点都没落在边界抖动上** —— 这正是网格读数可信（而非有噪）的原因。

## 4. 结论：中心口径的盲区是良性的

**中心口径漏掉的 158 个控件-格，每一个都还剩至少 60% 的面积是清的**
（被盖 0.12 → 清 88%；0.20 → 80%；0.40 → 60%；被盖最多的那枚也只有 40%）。

反过来，**唯一真正「几乎全挡」的那枚（0.80）中心口径看见了**。

所以：**中心口径对「完全不可用」零漏检，对「部分不可用」完全无感 ——
而后者在本 clone 上恰好全是良性的。**

**这解释了为什么 676/677/678 三批挖出来的覆盖缺口，这么多批都没被任何断言抓到。**

## 5. 自记：一条预期被读数推翻

动手前我要断言「`centre ⟺ fullyBlocked`」。**读数说只有一个方向成立**：
`fullyBlocked ⟹ centre` 是 16/16，反向是 16/17（那 1 条就是 §2 的 `scene-prompt-input`）。

**对称的直觉是错的** —— 中心落在盖住区内，不等于整盒都在盖住区内。
判据因此拆成**两条单方向断言**，并把那条例外**指名记下来**，
而不是抹平成「基本成立」。
