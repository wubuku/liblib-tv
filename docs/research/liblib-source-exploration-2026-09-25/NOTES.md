## 5. 缩放与视窗行为（`11-zoom-menu-open.png`、`13`、`14`）

- 左下缩放标签点击 → 弹出：可输入数值框（"100 %"）+ 放大 ⌘+ / 缩小 ⌘- / 适合屏幕 ⌘0 / 缩放至 50% / 100% / 800%。
- Ctrl/⌘+滚轮缩放步进大（10%↔800% 间跳变，滚距 240/tick 约每次 ÷2 或 ×2，且 10% 为下限）。
- 视窗内无节点时出现 toast「当前视窗没有节点 → 返回节点」（瞬态）。
- ⌘Z/⌘⇧Z 撤销/重做覆盖节点创建；⚠️ 连续 ⌘Z 会撤销掉刚创建的节点（`13-nodes-gone.png` → ⌘⇧Z 恢复，`14-redo-restored.png`）。
