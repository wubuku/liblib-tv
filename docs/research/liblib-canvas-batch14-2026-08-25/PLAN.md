# Batch 14 计划：Agent 与分享面板的原站结构复刻

## 1. 缺口与价值

| 缺口 | 当前 clone | 原站证据 | 价值 | 决策 |
|---|---|---|---:|---|
| Agent header 错位 | 标题为 `Agent`，只有关闭按钮 | 原站为“新对话”及一组命令图标 | 4 | 实现 |
| Skill 推荐结构错误 | 3 个图标文字卡 | 原站 2×2 图片卡、`Skill 就位`、换一批 | 5 | 实现 |
| 浏览器通知提示缺失 | 无提示条 | 原站有蓝色通知横幅，可开启/关闭 | 4 | 实现本地状态 |
| Composer 是死控件 | textarea 与发送无状态 | 原站底部输入区含工具图标和提交按钮 | 5 | 实现本地提交反馈 |
| 分享文案不忠实 | 自行脑补 LibLib 社区说明 | 原站标题与两条说明可从截图直接读取 | 4 | 校准 |
| 分享命令无反馈 | 两个按钮 no-op | 原站是发布/分享入口；真实后端不在范围 | 3 | 实现本地状态反馈 |
| Agent 与顶部导航层级冲突 | 顶部 Agent 按钮覆盖抽屉 header | 原站 Agent 打开后顶部右控件避让抽屉 | 5 | 实现桌面避让 |

## 2. 实施步骤

1. 保持 `uiStore.isAgentOpen` / `isSharePanelOpen` 不变，只改内容组件。
2. 将 Agent 改为“新对话” header、Skill 推荐区、通知 banner、composer 四段结构。
3. Skill 卡使用 2×2 网格、现有本地图片缩略图、选中态和“换一批”本地切换。
4. Skill 点击把标题投影到受控输入框；发送按钮只产生明确的本地预览反馈。
5. 通知 banner 支持本地开启和关闭。
6. 分享菜单校准标题、说明和图标；点击命令展示本地未连接服务状态。
7. 增加专项 Playwright，覆盖 Agent 打开、Skill 选择、换一批、通知关闭/开启、发送、分享命令、桌面和移动端边界。

## 3. 事实边界

### Source fact

- Agent 抽屉宽度约 `340px`，标题为“新对话”，右侧有命令图标。
- 推荐区标题为“Skill 就位, ready when yo...”并有“换一批”。
- Skill 卡为 2×2，含图片缩略图、标题和 `/...` 路径样式副标题。
- 输入区上方有蓝色浏览器通知条，文案为“开启浏览器通知，及时获取最新消息”，含“开启”和关闭按钮。
- 分享弹层标题为“发布与分享”，两项为“在LibTV上发布”和“分享链接”。

### Clone-only decision

- Skill 切换、输入投影、发送反馈、通知开关和分享反馈都是本地原型状态。
- 本地素材只承担视觉缩略图角色；不模拟远端推荐、发布审核、链接权限或复制画布服务。

## 4. 验收

- Agent desktop 结构包含 header、4 个 Skill 卡、通知条和 composer。
- 点击 Skill 后输入框出现对应标题，发送按钮产生本地反馈。
- “换一批”改变推荐卡集合；关闭/开启通知条可逆。
- 分享面板尺寸约 `360x166`，标题和两项文案与原站截图一致。
- 分享命令有可见本地状态反馈，不生成虚假远端链接。
- Batch 11 overlay lifecycle、Batch 13 storyboard mode 和 FrameOS 路由不回归。
