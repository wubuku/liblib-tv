## 4. ★★★★ 工具链级发现：用 `127.0.0.1` 访问 4317 时**整页不 hydration**

★ **现象**：探针打开 `http://127.0.0.1:4317/`，页面**看起来完全正常**（200、布局对、
按钮都在），但**点任何按钮都没反应** ⟹ DOM 上**没有** `__react*` props ⟹ React 从没 hydration。

★ **根因**（dev server 日志里写着，我一开始没往那儿看）：

```text
⚠ Blocked cross-origin request to Next.js dev resource /_next/webpack-hmr from "127.0.0.1".
Cross-origin access to Next.js dev resources is blocked by default for safety.
```

Next 16 默认**只认 localhost**；用 `127.0.0.1` 访问时 dev 资源被判跨源并拒绝 ⟹
HMR 客户端起不来 ⟹ **整棵 React 树不 hydration**。

★ **为什么这条特别贵**：页面**不是报错**、**不是白屏**、**布局全对** ⟹
探针会拿着一份**静态 SSR HTML** 当成「活体读数」返回 ⟹
**门禁可以全绿，却一条交互都没测**。这正是已存那条「跑通了 ≠ 看到了」的最贵形态。

★ **修法**（两件事）：

1. `next.config.ts` 加 `allowedDevOrigins: ["127.0.0.1", "localhost"]` ⟹ 两个 origin 都能 hydration。
2. ★★ **本批门禁 S1 就是这条的闸门**：判据**先证明页面 hydration 了**
   （读 DOM 上的 `__reactProps$` 且 `onClick` 是函数），否则整轮读数一律作废。
   ⟹ 阴性对照 N1 把这个读数改成 `false` ⟹ S1 立刻翻红。

★ **另一条同族教训**：`npm run build` 会覆盖 dev server 正在用的 `.next/` ⟹
**build 之后 4317 会假死**（页面还能开、200，但不 hydration）⟹
**build 之后必须重启 dev server**（`npm run dev:restart`）。本批的排查过程里撞过一次。

★ **顺带查了**：全仓 665 个门禁脚本里，只有 **2 个**用 `127.0.0.1`（batch 626 / 709），
其余 663 个都用 `localhost` ⟹ 影响面很小；那 2 个已改用 `localhost` 并复跑确认
（626 ✔ 113 项；709 见 §4.1）。

## 6. ★ 本批抓到的**判据自身**的缺陷（以及本批对 826 §5.3 的更正）

### 6.1 ★★★ 更正 batch 826 §5.3：「祖先 opacity:0」是**错的**

★ 826 写的是「源站筛选选项的**祖先**是 `opacity:0` 的下拉层，于是按元素自身样式判断可见会给出假可见」。

★★ **本批实测证明那是错的**。真因（`source-827-details.json` 里那条完整祖先链作证）：

- 源站的筛选下拉是**原生 `<details>/<summary>`**；
- 收起时，子节点**仍在 DOM 里**，且它**自己**的 computed style 是
  `display:block / visibility:visible / opacity:1 / transform:none / clipPath:none /
  contentVisibility:visible` ⟹ **元素自身与整条祖先链都说「可见」**；
- **只有命中测试**（`elementFromPoint`）判得出「看不见」⟹ 命中的不是那个 `<label>`，而是下拉层本身。

⟹ ★★ 于是**按元素自身样式判可见**这件事，在 `<details>` 收起态上**本来就是对的**
（元素确实「可见」，只是被浏览器**不渲染**）⟹ 826 那条「祖先状态不会继承到子元素的
computed style」的结论在**这个场景**里用不上。

★ **连带的第二层更正**：**收起态的几何读数是失真的** ⟹ 要量下拉位置**必须展开后量**：

序 | 状态 | 面板读数 | 真值 |
| --- | --- | --- | --- |
| 1 | 收起（源站 & clone 一致） | y=**303** | 失真 |
| 2 | 展开（源站 & clone 一致） | y=**271** | 真值（= summary 顶 + 40 的 `top-10`） |

★ 同一个道理也适用于**判「收起」**：`<details>` 收起时**它的 panel 元素仍在 DOM 里**
⟹ 「panel 还在不在」**恒真** ⟹ 只能看 `<details>` 有没有 `open` 属性。
（112 / 146b 两个门禁第一版就踩了这个 ⟹ 判据自己错了，改成看 `open` 属性。）
