## 重大发现（`SOURCE_FACT`）

**「该模型不支持当前选入的音频素材」拒绝 toast**：

- 视频节点附挂音频素材（OmniHuman 探索遗留连线）时，点击
  **Style Video**（不支持音频的模型）→ 拒绝 toast 附着于该行 +
  **模型拒绝切换**；
- 这解开 Style Video 自 batch 240 以来五次切换失败的真实根因——
  非点击问题，而是**模型切换时的素材兼容性校验**；
- 同轮 Kling3.0 动作迁移 的行点击亦未切换（同样附挂音频）——两个
  BLOCKED 模型均为**音频不兼容模型**。

## 综合判定更新

- **音频素材兼容性校验**为新源站行为：附挂音频后，不支持音频的模型
  （Style Video 等）拒绝切换并 toast 提示；
- 33/35 模型已有费率数据点，Style Video 与 动作迁移 需先断开音频
  连线再采样——**音频连线成为新阻塞依赖**（BLOCKED_MANUAL）；
- clone 无音频素材连线机制，此校验场景 clone 不可达——无需对齐。
