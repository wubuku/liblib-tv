### ④ 子菜单的 `z-50` 现在只在 portal 容器**内部**生效

625 注释说「它写在类名里的 z-40 / z-50 从未生效」——**修好之后这句话要改读法**：
它们现在生效了，只是生效范围是 portal 容器内部。

### ⑥ 附带撞见：11 枚 `删除连线` 手柄 **`pointer-events: none`**

723 记过「11 枚连线手柄 8×8 **中心命中 0/11**」，当时没记成因。本批实测：

| | 读数 |
|---|---|
| 枚数 | **11** |
| 全部 8×8 | **11/11** |
| 全部 `pointer-events: none` | **11/11** |

**读屏用户能听到 11 个「删除连线」按钮，但鼠标点不到任何一个**。
