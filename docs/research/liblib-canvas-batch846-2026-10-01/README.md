## 三、★ 本批更正了**三处既存偏差**（batch 840 起就有）

### 3.1 页签行那条 240px 的底边框线**整条没画**

源站的页签行是**两层**：

```
外层 DIV  flex h-10 shrink-0 items-center px-6     （288 宽 @1273）
  └ 内层 NAV  ... items-center ... border-b          （**240** 宽 @1297）
```

⟹ ⟹ 那条 **240px 宽的底边框线**（`1px solid rgba(255,255,255,.08)`）
画在**内层**上 ⟹ ⟹ 它的横向范围是 **1297..1537**。

clone 之前把两层**合并**成一个 288 宽的 `.ce-tabs`（`padding: 0 24px`）
⟹ ⟹ **那条线整条没画**。

★ **像素证据**（改之前）：源站 y=270 那一行有 143 个非底色像素
（= 白 8% 的线），clone 那一行**全是底色** ⟹ ⟹ 这是实打实的偏差。

★ 改法：`.ce-tabs` 由「288 ＋ `padding: 0 24px`」改成
「**240 ＋ `left: 24px`**」＋ `border-bottom: 1px solid rgba(255,255,255,.08)`
⟹ ⟹ 内容区不变（1297..1537）⟹ ⟹ **既有几何断言不受影响**。

### 3.2 卡片**媒体区**的 `display`

源站实测：媒体区的计算 `display` 是 **block**（**不是** flex）⟹ ⟹
图是**普通流**里的一块 ⟹ ⟹ 源站那张图在 76×76 里是 **74×74 且偏移 +1,+1**
（等于居中）⟹ ⟹ clone 之前用 flex ＋ 绝对定位 ⟹ ⟹ 那是**既存偏差** ⟹ ⟹ 改成
block ＋ 普通流 ＋ 居中。

### 3.3 **色块**的 `line-height`

源站实测：那枚 swatch 的计算 `line-height` 是 **24.8px**（从正文继承下来的）
⟹ ⟹ clone 之前是 24px ⟹ ⟹ 那是**既存偏差** ⟹ ⟹ 改正。

★ 另有一处**源站内部就不统一**的地方（分开写才对得上）：
「自定义颜色」那枚 swatch 在源站是 **`display:flex`**（居中放 18×18 图标），
其余那些是 **block** ⟹ ⟹ clone 用 `.ce-swatch--custom` 单独写。

## 四、★ 探针踩过的坑：源站 raw 的 `chip` 是**混合数组**

846 主 raw 的 `读数.chip` 有 **35** 条 ⟹ ⟹ 而「发型 7 ＋ 妆容 7」只有 14 枚 chip ⟹ ⟹
**多出来的 21 条是色块**（35×35 的圆）⟹ ⟹ 源站这两个控件**共用了同一套胶囊类名**
⟹ ⟹ 探针的 chip 选择器**一并捞进来了**。

⟹ ⟹ ★ 这不是探针的错 ⟹ ⟹ 但**分不开就没法对拍** ⟹ ⟹
于是按**盒高**机械地分成两类（26 ⟹ chip；35 ⟹ 色块）⟹ ⟹ 判据可复现。

★ 教训：混合数组**看起来像**「clone 多渲了 21 个控件」⟹ ⟹
**先分清「这一条是什么」再比**，否则会照着一个错误分类去修。

## 四之二、★ 探针踩过的坑：点「口红」那十枚 ⟹ **点了空气**

这一段的滚动区高 **1312** 而可视高只有 **562** ⟹ ⟹ 「口红」那十枚色块在
rel y=**1266** ⟹ ⟹ **在可视区之外**。

⟹ ⟹ 探针第一版直接按元素的 `getBoundingClientRect()` 算坐标再 `mouse.click`
⟹ ⟹ 鼠标落在**生成遮罩**上 ⟹ ⟹ **点了空气**。

★ **危险之处**：读数上「点了空气」**只**表现为「选中态没变」⟹ ⟹
很容易被误判成「**clone 的交互坏了**」⟹ ⟹ 差点去改产品代码。

⟹ ⟹ 修法：点之前**先 `scrollIntoView({block:'center'})`** ⟹ ⟹
再重取盒（★ 滚动后坐标变了 ⟹ ⟹ 旧坐标是**过期的**）⟹ ⟹ 再点。
⟹ ⟹ 探针现在还把「★滚进可视区」记进读数 ⟹ ⟹ **点了空气**会**自证**出来。

★ 连带影响：**A 阶段的读数必须在任何滚动之前取** ⟹ ⟹
几何对拍（S2）只读 A 阶段 ⟹ ⟹ 滚动不会污染它。
