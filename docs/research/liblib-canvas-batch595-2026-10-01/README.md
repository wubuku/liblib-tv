验收：`scripts/verify-liblib-batch595.py`（10 项检查全过）

## 一、源站事实

源站的标尺是**一整块 `<canvas>`**（`width=4424 height=136`，2× DPR，CSS
2212×68 `@(322,1021)`，底色 `#212121`），没有 DOM 刻度元素。所以本批的做法是
**逐行/逐列扫描像素**把刻度结构量出来，而不是从 DOM 读。

### 1.1 细分恒为 0.1s，不随缩放改变

在两个缩放档位各扫一次整幅 canvas 的刻度列：

| zoom | canvas 宽 | 刻度数 | 主刻度间距 |
| --- | --- | --- | --- |
| 42 | 2124 | **100** | 211px |
| 100 | 5012 | **100** | 500px |

总时长 10s → 100 条刻度，两档一致。**只有间距随 zoom 线性放大**，细分粒度固定。
（对照：clone 原来固定每秒一条，缩放只改容器不改刻度数。）

### 1.2 竖直剖面（CSS px，y 以 canvas 顶为 0）

对一条主刻度列（x=6）与一条次刻度列（x=27）逐行取亮度：

```
主刻度  y 22.5 – 31.0   高 8.5px   rgb(135,135,135) = #878787
次刻度  y 27.5 – 31.0   高 3.5px   rgb(104,104,104) = #686868
标签带  y  5.0 – 13.5   字色直方图众数 157 = #9d9d9d
底色    #212121（= rgb 33,33,33）
```

主次刻度**底端对齐**（都在 y=31），次刻度从 y=27.5 起 —— 也就是主刻度的下半段
位置，视觉上是「长短刻度」而不是「上下两排」。

### 1.3 标签居中在主刻度上

zoom 42 时的标签与主刻度 x（canvas 内坐标）：

```
刻度   6.0    217.0    428.0    639.0 ...
标签   6.5..  212.0-222.5  422.5-434.5  633.5-646.0
```

`1s` 的两个字形横跨 212.0–222.5，中心 217.25 ≈ 刻度 217.0 —— **居中**。
（clone 原来是 `left-1`，即固定左移 4px、左对齐。）

标签字高 8.5px（数字 cap height），对应约 12px 字号。

### 1.4 轨道道没有网格线

扫描 canvas 的 34–130px 行带（也就是标尺以下的整条轨道区）：除播放头那一条
竖线外，**找不到任何竖直网格线**；行间也没有分隔线，底色恒为 `#2a2a2a`。

（clone 原来在每条轨道道里按「每秒一条 `border-l`」画网格，还带
`border-b` 行分隔线。）

## 二、clone 改动

`src/components/director/DirectorTimeline.tsx`

1. `ticks` 由「每秒一条」改为**每 0.1 秒一条**（`round(duration / 0.1) + 1` 条），
   每第 10 条是主刻度。
2. 刻度由「整行 `border-l`」改为**底部对齐的实心竖线**：
   主 `8.5px #878787`、次 `3.5px #686868`。
3. 标签由 `text-[9px] text-[#5e5e5e]` 左对齐改为
   `text-[12px] text-[#9d9d9d]` + `-translate-x-1/2` **居中**在主刻度上。
4. 标尺底色 `#191919` → `#212121`。
5. 轨道道：删掉逐秒 `border-l` 网格与 `border-b` 分隔线，底色改为 `#2a2a2a`
   （选中轨道的 cyan tint 保留 —— clone 能力）。
6. 新增 `data-director-ruler-tick="major|minor"` 供验收定位。

## 三、未取证 / 未验证（记录，不臆造）

- **标签的字体族与精确字号**。canvas 直接绘字，不暴露 font 信息；这里由 8.5px
  的字高反推出「典型 UI 字体下约 12px」，是推断。
- **标尺高度**。源站刻度底端在 canvas y=31，clone 保持 `h-7`（28px）—— 3px 差
  别，改了会把整条轨道道栈一起挪动，证据不足，不动。
- **源站在更高缩放下是否换更细的细分**。已测的两档（42 / 100）都是 0.1s，但
  更高档位没测（拖到 100 已是量程上限，所以实际覆盖了全量程）。
