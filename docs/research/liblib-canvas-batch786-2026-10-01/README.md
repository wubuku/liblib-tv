## ★ C786-3：互斥有**三种**机制，第一版把两种混成一种

| 机制 | 组 | 是什么 |
| --- | --- | --- |
| `cross-write` | `DirectorViewport.tsx` 三组 | **无条件**写另外两个 ⟹ 真交叉写入 |
| `cross-write+ladders` | `DirectorTimeline.tsx` 两组 | 既有无条件交叉写入、也有早退档 |
| ★ `early-return-ladder` | ★ `DirectorDesk.tsx:473` 的 Escape 阶梯 | 写 ≥2 个门状态，但**每一档后面都 `return`** ⟹ **一次按键最多走一档** ⟹ 两档**互相排斥**、**不是**交叉写入 |

★ 而 `DirectorDesk.tsx:473` 那组**第一版根本没报出来** —— 因为普查器用
「以 `;` 结尾」当类型标注判据，把 `:565` 那条**真的** `followTargetId` 写入
（`if (activeCameraId) updateCamera(activeCameraId, { followTargetId: null });`）
**一起杀了**。

★★★ **所以第一版的「5 组」是「数字恰好对、理由是错的」**：那一组本来是个
**假阳性**（阶梯各档互斥），被误杀之后计数正好落在 5。
⟹ 正确的判据是「类型标注里不会出现 `(` 或 `=>`」，不是「以 `;` 结尾」
（`open: boolean;` 与 `…{ followTargetId: null });` **都以 `;` 结尾**）。
