   音频/3D 节点真实渲染形态。
   ~~多选/编组工具条~~ → ✅ Batch 229 已采样并实现。
   ~~成组点击行为~~ → ✅ Batch 251-262 全链路闭合（创建/颜色/排列×3/拖拽/解组/
   重命名/右键菜单/批量连线端口/装饰手柄；见 liblib-frameos-batch25{1,2}-2026-09-27）。
   Batch 281 追加：多分组编号 组1/组2 实测与克隆一致；当日源站框选曾瞬态失效
   （数小时自愈，非功能移除）；小地图分组渲染不可判定（克隆保持仅节点渲染）。
3. 源站为滚动目标：每次源站更新后重跑 runner + 对照 §13-15 增量采样
   (2026-09-24 版本更新已按此流程完成一轮)。
