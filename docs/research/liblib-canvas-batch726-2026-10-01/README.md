## 我一开始把事情想复杂了

`validateLibTVGraphConnection`（`libtvGraphConnection.ts:135-160`）的检查顺序：

    normalize → DANGLING_ENDPOINT → DUPLICATE_NODE_PAIR（**无序**）
              → SELF_LOOP → DIRECTED_CYCLE

我先写下的推理是：「种子图里每一条会闭环的配对同时也都是无序重复对，
所以闭环只能用三个节点造」。**这是错的。**

实测：把「会闭环的配对」和「已有无序对」两个集合都算出来，相减得到 **8 对
「会闭环但尚未相连」**：

| 分镜组 | 图片 |
|---|---|
| `g-245IDFh8sB` | `i-1FQ9tErTcC` / `i-dnwoZQ7jsG` / `i-lBzmo67AHv` / `i-vxeeCnxySa` |
| `g-EFbbHpwq5w` | 同上四张 |

原因：`b-bTLLuU4w5q → g-245` 与 `i-1FQ → b-bTLLuU4w5q` 都已存在，
所以 `g-245 → i-1FQ` 一连上就是环，**而这两张卡之间并没有边**。

**⟹ `DIRECTED_CYCLE` 在种子上两节点直达可得，不需要造链。**

### 被拒落点是换颜色，不是没反馈

这是 725 第二个问题的答案，答案是「**有**」：

| | 合法落点 | 被拒落点 |
|---|---|---|
| 底色 / 边框色 | **`rgb(100, 217, 89)` 绿** | **`rgb(9, 202, 245)` 青** |
| class | `connectingto` + `valid` | `connectingto`，**无 `valid`** |
| 尺寸 | 7.66（38% 缩放下） | **7.66，完全相同** |

⟹ **`valid` 是机器可读的那一半，颜色是用户看得见的那一半。**
725 只读到 class 就说「只有没有 `valid` 这一处视觉」，是不完整的。

react-flow 侧**没有第三个「被拒」标记**：被拒落点同样拿 `connectingto`，
也**从不出现 `invalid`** —— 区分完全由 `valid` 的有无承担。

### 被拒的连线零记账

落点被拒后逐项读 store：`lastCommandResult` 恒 **`null`**，
画布选区 `getSelectionSnapshot()` 前后**逐字段相同**。

⟹ **重复对（725）与成环（本批）这两种拒绝，在 store 里一个字段都不留** ——
与 batch 700「`add-keyframe` 的 no-op 要不要补 NOOP 记账」是同一族。

## 不声称

- **不声称这套绿/青配色与源站一致**（源站未测）。
- **不声称只有环与重复对这两种拒绝** —— `SELF_LOOP`（自己连自己）与
  `DANGLING_ENDPOINT` 本批没有构造用例。
- **不声称「界面毫无反应」** —— 本批只读了 store，没看是否有 toast / 提示条。
- **不声称 8 对之外没有别的可闭环配对**（只算了种子图这一个状态）。

## 新增待拍板

1. **两种拒绝都零记账** —— 要不要给轻提示或 NOOP 记账，
   与 700 的 `add-keyframe` no-op 合并成一条「**被拒绝的操作要不要留痕**」。
2. **被拒落点只换颜色、不换形状** —— 要不要再加形状/描边差异，
   让不辨色的用户也能分辨（可及性）。
3. **`SELF_LOOP` 与 `DANGLING_ENDPOINT` 仍无用例。**

## 方法论

1. **规则有顺序，但「造不出用例」不等于规则不存在** ——
   我先假设「前 4 条会把所有用例都拦下」，于是设计了复杂的三节点链；
   **实测发现 8 对两节点用例现成可用**。
   **先量集合的差，再设计输入** —— 不要凭推理断定某个形状是必要的。
2. **无序判定让「二元环」不成立，但不阻止「新配对成环」** ——
   我把「无序重复」错误地推成了「所有会成环的配对都已被连过」。
   **无序判定只保证「这两个点之间已有边」被拒，不保证「这两点之间没有边」。**
3. **「有没有反馈」不能只看 class** —— class 是实现细节，
   **底色变了就是有反馈**。725 只读 class 得出的「只有一处视觉」不完整。
4. **零记账要读选区用真正的 API** —— 第一版读 `ui.selection` 拿到 `ABSENT`
   （字段名不对），差点写成「没有选区」；改用 `getSelectionSnapshot()` 才对。

## 探针返工两处

1. `drag()` 把 `page.evaluate(GRAPH)`（返回 `{edges:[…]}`）当数组用，
   `TypeError: string indices must be integers` 才暴露。
2. **三节点链的设计是多余的** —— 验收器第一版按链跑，判据 6 断言
   「会闭环的配对全等于已有无序对」直接失败，才看见那 8 对差集，
   于是把整条链删掉、换成两节点的直接用例。**失败的判据有时是最好的发现。**
