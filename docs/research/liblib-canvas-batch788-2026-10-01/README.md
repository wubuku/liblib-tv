## ★★ C788-2：**归因唯一**——是「加条目」这个动作，不是「开面板」

没有对照臂的话，「加条目后草稿消失」可以和「开模型库导致草稿消失」
「点任意东西导致草稿消失」**完全无法区分**。

★ 对照臂的逐步读数给出了决定性的那一步：

| 阶段 | ★ 对照臂（只开再关） | ★★ 处理臂（点条目） |
| --- | --- | --- |
| 造完草稿 | `true` | `true` |
| **开完模型库** | `true` | **`true`**（还活着！） |
| 关掉模型库 | **`true`**（仍然活着） | —— |
| 点「加入场景」 | —— | **`false`**（没了） |

⟹ 两臂在「点条目」那一步之前**逐步完全相同**（检查 S7 逐项断言），
差别**唯一地**落在最后那一步。
