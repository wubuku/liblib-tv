# batch 702 — 「objects 是派生视图」这句话是可以被证伪的 —— 而它没有被证伪

## 起点

701 测出 `playback` 会把插值结果回写进 `objects[*]`，并明确写下
**「不声称 `objects[*]` 被回写是 bug（那看起来是刻意的求值实现，未进一步取证）」**。

本批就去取那份证。

## ① 播放改了什么

拍平三样 —— **创作数据 `authoredObjects`**、**派生视图 `objects`**、**历史 `history`**。
真实点击启停一次，共 **10 个叶子**变：

| | 变了几片 |
|---|---|
| `authoredObjects`（创作数据） | **0** |
| `objects`（派生视图） | 9 |
| `history` | **0** |
| 其它 | 1（`currentTime`） |

⟹ **播放只动派生视图，不动创作数据，也不产生撤销条目。**

## ② `objects` 是不是纯函数

「派生视图」这个说法是可以被证伪的，检验方式只有一条：
**同一时刻，「从没播过」与「播过又退回」的派生值必须逐位相同。**

| 标尺比例 | 播放头（两臂读数相同） | 逐位相同 |
|---|---|---|
| 0.25 | 2 | **5/5** |
| 0.30 | 2.399999945109956 | **5/5** |
| 0.40 | 3.2000001097800883 | **5/5** |

**15/15 逐位相同。** ⟹ `objects` 是 `(authoredObjects, 播放头)` 的**纯函数**。

⟹ **701 那条「回写进 `objects[*]`」不是数据污染。**

## ③ 本批最值钱的一段：第一版对照是无效的

第一版做的是「播 → 停 → 把播放头点回标尺最左端 → 比对初始值」。
结果 **6 组值全部不复原**。看起来派生视图被破坏了。

**不是。** 它点的不是最左端那个像素，是**左端 +2px**，那里对应
`t = 0.008993184852104265`，**不是 0**。

| 点的位置 | 播放头读数 | 同刻两臂逐位相同 |
|---|---|---|
| 左端 `+0px` | **0** | **5/5** |
| 左端 `+2px` | 0.008993184852104265 | **5/5** |

两个位置上两臂都逐位相同 ⟹ **偏离量完全由像素偏移解释，没有别的。**
顺带把标尺的分辨率也量出来了：**每像素 ≈ 0.00450s**（`duration=8` 时）。

**这是 697 立的那条纪律（「非 0 读数不能被读成缺陷」）在我自己这批的新仪器上第三次生效。**
修法不是加一段解释，是**重做对照**：两臂只差「有没有播过」，并且**先断言两侧的播放头读数相同**，相同才比。

## 判据

| 判据 | 断言 |
|---|---|
| `playback-changes-only-the-derived-view` | 创作数据 0 变、历史 0 变，只有派生视图与 `currentTime` 变 |
| `objects-is-a-pure-function-of-authored-and-playhead` | 三个位置上两臂 15/15 逐位相同，且先断言播放头读数一致 |
| `playback-produces-no-undo-entry` | `historyLen` 前后都是 0，与「没有创作任何东西」自洽 |
| `the-first-control-was-invalid-and-the-deviation-is-fully-the-pixel-offset` | `+0px` 落在 t=0 且两臂 5/5 相同；`+2px` 落在非 0 且两臂也 5/5 相同 |

## 不声称

- 不声称 `objects` 的求值实现「好」或「坏」—— 本批只测出它是纯函数、不污染创作数据。
- 不声称 15/15 覆盖了所有播放头位置 —— 只测了 `f=0.25/0.30/0.40`，
  **都在标尺可视范围内**（可视范围约 `f ≤ 0.54`，更后面的没测）。
- 不声称源站有同样行为（**未取证，需授权点击**）。
- **不改 `src/`**
