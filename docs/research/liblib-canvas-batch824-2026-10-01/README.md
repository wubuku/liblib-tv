## 7. ★ 本批抓到的四处缺陷（四处都造出过假结论）

### 7.1 N12 的变异没进判据

见上。**阴性对照自己撒谎** ⟹ 「阴性 4/4」是假的。

### 7.2 ★★ 判据用了**两把不同的尺子**，数字碰巧相等

第一版 S9 拿 **clone 的「药丸→球」** 去比 **源站的「按钮→球」** ⟹ 两个不是同一个量（差一个药丸的右内边距 9px）
⟹ ★★ **两个数字碰巧都等于 14** ⟹ ★★ **判据绿灯，而 clone 实际离按钮 23px（源站 14px）**。

⟹ 修法：★ **两个量都量**（药丸→球、按钮→球），期望值**都从源站 raw 算** ⟹ 并加 N15 证明「按钮→球」这一路真在判据里。
⟹ ★★ 教训：**判据里出现的两个量，要确认它们指的是同一个东西**；★ 数字相等**不等于**量相等。

### 7.3 文字的「藏法」没读 ⟹ 差点把「有可见文字」当源站事实

源站 DOM 读数里 `textContent` 是「TV Director」⟹ 我据此做了「球 + 可见文字」⟹ ★★ **裁图放大才发现源站旁边是空的**。
⟹ 源站那段的真实读数是 **`width:0` + `opacity:0`**（矩形宽 0）⟹ S10 因此只认**矩形宽 + opacity**。

### 7.4 ★★ 「DOM 里有这个元素」**不等于**「它画出来了」

球芯那层用 Tailwind 任意值写渐变 ⟹ ★★ **4317 的 dev server 根本没编译那条类**（见第 8 节）⟹ 球芯 computed `background-image: none`、截图里**球是空的**。
⟹ ⟹ ★★ 探针读到「元素在、28×28、位置对」，**一切正常**，只有**截图**能看出它是空的。
⟹ 修法：S11 只认 **`background-image` 不是 none** ＋ 渐变里有源站那颗青 `rgb(0, 229, 255)`；并加 N16（改成 none 必须翻红）。

★ 另有一处判据写得不严：S8 原来用「`top-[` 不出现在文件里」来确保没写带小数的任意值 ⟹ ★ 结果**注释里**提到 `top-[23.5px]` 就把判据弄红了 ⟹ 改成只匹配**类名串本身**。

## 8. ★★★ 工具链级发现：4317 的 Tailwind 扫描是**冻结**的

★ 这一批最大的意外收获，与本批功能无关，但**影响所有人的读数**。

**现象**：4317 上那枚球的渐变不出现。逐层排查：

1. 探针读球芯 computed：`background-image` = `none`、`backgroundColor` = `rgba(0,0,0,0)` ⟹ 类没生效
2. 抓 dev server **真正 serve 的 CSS**（`/_next/static/chunks/…globals….css`）：★ **我那条类的规则一条都没有**（连标准类 `bg-radial` 都没有）
3. 但同一次抓取里：★ `ml-[6px]` **在**（那是我十分钟前刚写的类）
4. 再查磁盘：`.next/dev/static/chunks/Documents_…globals….css` 的 mtime 是 **2026-10-07**；★ 而 4317 上的 `next dev` 进程（`next-server (v16.2.1)`）**正是 10 月 7 日启动的**

⟹ ★★★ **结论：4317 的 dev server 自 2026-10-07 起就没重新扫描过 Tailwind** ⟹ ⟹ ★★ **任何新加的 Tailwind 类在 4317 上都不生效**，而 `npm run build` 的产物**照常生成** ⟹ ⟹ ★★ **同一个组件在 dev 上「没样式」、在 prod 上「有样式」**。

★ **同族症状**：★ `top-[23.5px]` 这种**带小数**的任意值在 dev 也被丢（prod 保留）⟹ 当初那 24px 的错位就是这么来的。

★★ **本批的处理**：★ **一个新增 Tailwind 类都不引入** ——
- 渐变与光晕走 **inline style**（对扫描器免疫；仓库里已有先例：`src/app/frameos/canvas/[id]/page.tsx:733`）
- 其余类全部**取仓库里早就存在的**（`ml-[6px]`、`top-1/2`、`left-full`、`size-7`、`w-0`、`opacity-0`、`hover:bg-[#383838]` …）⟹ 逐个对着 dev CSS 核过
⟹ ⟹ ★ **dev 与 prod 渲染完全一致**，本批的截图与读数在两边都成立。

★ **给后续批次**：★★ 在 4317 上量**新写的 Tailwind 类**之前，先确认这条类在 dev CSS 里存在（抓 `/_next/static/chunks/*.css` 找它）；★ 或干脆**重启 dev server**（`npm run dev:restart`）—— ★ 但 4317 是多人共用，**重启会打断别人正在跑的探针** ⟹ ★ 本批**没有重启**，只记录。
