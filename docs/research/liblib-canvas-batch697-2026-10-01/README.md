# batch 697 — 把 696 的失效**证伪**成程序化路径特有的现象

> 起点：696 钉出一条行为序列 —— **在右栏的 range 上按过一次键，紧接着切换到另一个
> 面板，新面板里的 range 收不到鼠标输入**。但 696 的复现走的是 `selectObject(null)`
> 这个 **store API**，而真人取消选中是「**点空白处**」。
>
> 696 因此留了一句限制：**「不声称这是一个用户能撞上的缺陷」**。
> 本批去把这句限制**兑现或推翻** —— **两种结果都有价值**。
>
> 验收：`scripts/verify-liblib-batch697.py`（4/4）　读数：`runtime-audit.json`

## ① 结果：第二种（证伪成立）

| 路径 | 取消选中的方式 | 刚按过 `End`？ | **`scene-scale` 鼠标可达** |
|---|---|---|---|
| **真人路径** | **点空白处** | 否（对照） | **11** |
| **真人路径** | **点空白处** | 是 | **11** |
| **真人路径** | **点空白处** | 是（再重复一次） | **11** |
| **程序化路径** | `selectObject(null)` | 是 | **1** |

⟹ **真人路径不复现，程序化路径复现。两条路径不等价。**

**所以 696 量到的是「测试怎么驱动这个 App」的性质，不是「这个 App 本身的性质」。**

**696 不被改写** —— 它当初写下的那句限制是对的，本批只是把那句
**从一句免责声明变成了一次测量**。

## ② 本批最贵的一课：「点空白处」这三个字本身是陷阱

我第一次取坐标 **`(640, 560)`**，自以为是画布空白。它不是。

**它选中了一张道具桌 `director-prop-table`** ⟹ 右栏渲染的是道具桌属性 ⟹
`scene` 控件**根本没进 DOM**（0 枚）⟹ 读数是 **`None`**。

**而 `None` 会被读成「不复现」** —— 那是一个**完全错误的结论**，
而且它长得和正确答案一模一样。

正确做法是**先测出哪些坐标真的是空白**：

- 扫 20 个坐标，逐个点完读 `selectedObjectId`
- **13 个坐标**能让它变成 `null`，例如 `(400, 300)`、`(400, 500)`、`(640, 700)`
- `(640, 560)` **不在其中**

**这和 695 那次「用 `[data-director-character-tab]` 去找机位页签」是同一个错误的
两种长相：我以为自己走的路径，不是我走的路径。**

两次的共同点值得单独立一条纪律：

> **一次静默的空操作，会伪装成一个负面结果。**
> 695 里那次「点击什么都没发生」，697 里这次「读数是 `None`」——
> **如果不做存在性检查，两者都会被写成「该控件/该路径不存在」，而那是一个假结论。**

## ③ 这条结论**不**等于「App 是对的」

本批证伪的是**可达性**，不是**正确性**。

- **不声称** 机制被追到了（697 换掉的是「用户能不能碰到」，不是「为什么会这样」）；
- **不声称** 真人路径在**所有**序列下都安全 ——
  本批只测了「姿态页签 → 按 `End` → 点空白」**这一条**；
- **但也不声称** App 存在缺陷 —— 支撑它的那条证据已经被证明**只在程序化路径上成立**。

**一条被证伪的缺陷线索，和一条没被证伪的缺陷线索，价值完全不同。**
本批把 696 那条从「可能」移到了「在测试路径上」。

## ④ 由此得到的一条可复用纪律

> **当一个 store 调用顶替了「用户会点的那个控件」时，那不是快捷方式，那是一个主张。**

`selectObject(null)` 顶替「点空白处」时，我默认了「这两件事对应用途的状态迁移相同」。
**本批证明它们不同。** 所以：

- 凡是能用真实控件驱动的，**优先用真实控件**；
- 非用 store 不可时，**在判据的 detail 里写明这一点** ——
  下一位读者需要知道这条读数是「程序化路径」的。

## 自记

- **「我以为的路径」必须被测量。** 697 和 695 各撞了一次同样的错，
  两次都是**静默的空操作**伪装成负面结果。**第三次遇到就该立成纪律**，
  而本批就是把它写下来的时候。
- **读数的第三态不能被当成否定。** `None` / `0 枚` / `missing` 都是
  **「我这一步没测到」**，不是「测了，没有」。
  695 已经为缺席控件立过纪律（先查存在性），
  **本批把它扩展成「先查存在的是不是我以为的那个东西」**。
- **证伪也是交付。** 这一批没有发现任何新功能特性，也没有发现新缺陷；
  它把一条**看起来快要变成缺陷报告**的线索收了回来。
  **把一条假线索追到底并写清楚为什么是假的，比发现一个真缺陷更省事。**

## 不声称

- **不声称** 机制被追到了（697 证伪的是**可达性**）；
- **不声称** 真人路径在**所有**操作序列下都不复现（本批只测了一条序列）；
- **不声称** App 因此是正确的（**没被证伪 ≠ 被证明**）；
- **不声称** 源站有同样现象（**未取证**；源站导演台关着，进入需点击、**需授权**）；
- **不改 `src/`**。
