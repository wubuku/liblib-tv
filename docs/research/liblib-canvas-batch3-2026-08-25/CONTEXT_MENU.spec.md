# 组件规格：Canvas Context Menu

## Overview

上下文菜单是本批的画布命令原型增强。它保留当前画布，不遮挡菜单本身之外的视觉内容；菜单根据右键目标切换命令。

## Node Context Menu

触发：节点上右键。

| 命令 | 行为 | 快捷键 |
|---|---|---|
| 复制节点和连线 | 创建偏移副本，并复制该节点的入边/出边端点映射 | `⌘/Ctrl+D` |
| 创建副本 | 只复制节点，不复制关联连线 | 无 |
| 删除节点 | 删除节点及其关联连线 | `Delete` |

右键节点时先选中该节点；菜单动作完成后关闭菜单。新副本自动选中。

## Pane Context Menu

触发：画布空白处右键。

| 命令 | 行为 |
|---|---|
| 添加文本 | 在右键位置创建文本节点 |
| 添加图片 | 在右键位置创建图片节点 |
| 添加视频 | 在右键位置创建视频节点 |
| 适应画布 | 调用当前 React Flow `fitView` |

添加节点使用 React Flow `screenToFlowPosition` 将屏幕坐标转换成画布坐标；因此在缩放/平移后仍落在指针附近。

## Geometry

- 菜单为固定定位，宽度约 `220px`；
- 距右侧/底部不足菜单尺寸时向内收拢；
- `390px` 宽视口下不使用横向滚动；
- `Escape`、点击菜单外区域、选择命令都会关闭；
- 菜单位于节点浮层和底部工具条之上，但不覆盖系统级对话框。

## Evidence Boundary

本项目已有 FrameOS 右键菜单实现和快捷键证据。本规格把该交互迁移为 LibTV 的前端原型能力；它不被记录为 2026-08-25 LibTV 原站的新实时实测。
