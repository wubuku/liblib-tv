# batch 664 —— 第三态（`not-measurable`）的塌缩普查：语料结构 + 代价量

## 一句话

663 找到**第 9 个盲区形状**：建在 `elementsFromPoint` 上的仪器，
在 `pointer-events:none` 元素上**不会失败，它会自信地作答**。
本批问两件事：**语料里有多少台仪器站在那个盲区上**，以及**那个盲区现在值多少钱**。
答案是：结构上 **26 个调用点、只有 1 台能拒绝**；代价是**一个量到的零** ——
但那 22 个盲区元素里有**播放头**。

## 1. 普查必须分两层（第一版一个都没找到）

第一版照 654 的做法只扫 Python AST，**命中测试调用点是 0**。

因为它们**住在 JS 字符串常量里**。654 的 AST 普查数的是 `.click()` 这种
Python 侧调用；而 `document.elementFromPoint` 是**载荷内部**的调用。

> **判据的仪器在字符串里，调用点普查就必须分两层**：
> Python 侧数「求值了几次」，JS 侧数「仪器里有几次命中测试」。

这条现在是一条**被检查的事实**（`pythonAstHitCalls == 0` 且 `jsLayerHitCalls > 0`），
不是一个故事。

## 3. 盲区人口：22 个元素，三视口恒定

导演台开着时，工作区里有 **22** 个 `pointer-events:none` 且**有面积**的元素，
其中 1 个 `opacity:0`，**13 个不带任何 `data-director` 属性** ——
连按名字指认都做不到。

压住活控件**中心点**的有 **27**（1280 宽两个视口）/ **30**（1920）枚，
占 132 枚活控件的 **20%–23%**。

**那 22 个是谁**（`byData`，三视口恒定）：

| 具名成员 | 是什么 |
|---|---|
| `data-director-playhead` | **时间轴上唯一表示「当前时刻」的图元** |
| `data-director-aspect-frame` | 16:9 画幅参考框 |
| `data-director-bottom-bar` | 底栏宿主（**带属性但不接点击**，只有子元素可命中） |
| `data-director-webgl-canvas` / `…-gizmo-webgl-canvas(-wrapper)` | 视口与 gizmo 画布 |
| `data-director-scene-prompt-status` | 提示条状态行 |
| `data-director-timeline-coachmark` | 时间轴引导 |
| `data-director-character-label` | 角色标签 |
| **13 个无属性** | 多数是 `span[aria-hidden].absolute.inset-0` 之类的装饰层 |

> **点击测不到 ≠ 屏幕上没有。** 播放头这一条有分量：
> 它是时间轴上唯一说明「现在在哪」的图元，而**任何基于命中测试的判据都看不见它**。

## 4. 代价：一个**量到的零**，而且它有作用域

这 30 枚里，命中测试要么返回控件本身（或是它自己的图标、632 记过的祖先容器），
要么该控件的遮挡**早已在案**。

「在案」是**跨批复核**出来的，不是本批写下的白名单：命中的元素既不是控件本身、
也不是它的后代或祖先时，判据去问 **658 的 `occludedKeys` 里有没有这个控件自己的
`data-director-*` 属性**：

| 控件 | 盖住者 | 谁在案 |
|---|---|---|
| `帮助` | `收起属性`（按钮） | **662** 的在案项 |
| `描述想搭建的场景`<br>`data-director-scene-prompt-input` | 检视器一根 **280px 宽、`rgba(0,0,0,0)` 的透明列** | **658** 在 720 与 1150 都记着它被遮，**659/660** 给了 `W ≥ 1510` 的闭式 |

**第二个几乎漏掉**：那根透明列**可命中、不可见** ——
所以任何**绘制类**读数（646/647 那一类）从来点不出它的名，
只有命中测试能看见它。**这正是 663 那个闸门存在的理由的另一个版本。**

**空集不算证据 —— 但「量到的零」和「没记录」不是一回事。**
本批把作用域写死（下一条），就是为了让它能被将来的批次推翻。

### 作用域

这个零**只覆盖「这里有什么」**。它**不覆盖**「这里**画**着什么」：
那 22 个元素对任何命中测试判据**全部不可见**，而它们里有播放头、画幅框、底栏宿主。
