> 探针 `probes/dbg795a.py` · 汇编器 `probes/mk795audit.py` · 验收 `scripts/verify-liblib-batch795.py`

## 一句话

793 遗留里写着「未测键盘方向键移动成员是否同样触发跟随」。**动手前先查源码，发现这条遗留的前提是错的**：
画布从来就没有键盘移动节点的能力。本批把它当成一个独立的可交互性缺陷修掉。

## ★ 前提被推翻的过程（可复核）

- `src/app/page.tsx` 的 `handleKeyDown` 分支只有 `Escape` / `Delete` / `Backspace` /
  `Tab` / `Cmd+0` / `Cmd+=` / `Cmd+-` / `Cmd+z` / `Cmd+d` / `g` …，
  **没有任何 `Arrow*`**（全仓 `grep Arrow* 四个方向键` 只命中 lucide 图标与导演台滑杆）
- `@xyflow/react` v12 **不内建**方向键移动；它内建的只有 `deleteKeyCode` 一类，
  而 `page.tsx` 里 `deleteKeyCode={[]}` 把它显式清空了
- store 里**没有** `nudge` / `moveNodeBy` 之类的 API

⟹ 不是「方向键移动了但框没跟随」，而是**键盘用户完全无法移动节点**。

## ★★ 两条臂的位移不同（1× vs 2×）——机制，不是 bug

| 臂 | 选区含 | `movingIds` | 每按压绝对位移 | 3 次实测 |
| --- | --- | --- | --- | --- |
| 移**成员** | 只有成员 | 只有成员（组由收口重算） | 成员 +1、组 +1 | **+3** |
| 移**组** | 组 | 组 **和它的成员**（store 显式塞 child） | 两者 `position` 各 +1，成员绝对 = 自身 + 父组 ⟹ **+2** | **+6** |

★ 我第一版把组臂的期望值也写成 3 ⟹ 实测 6 时判红。**是我的断言写错了，实现是对的**：

★ 不变式「组与成员绝对位移**相等**」（6 == 6）仍然成立 ⟹ 成员没掉出框。

## 修法

- store 新增 `nudgeSelectedNodes(delta)`（`canvasStore.ts:3394`）：
  组与它的成员**一起**搬（`movingIds` 同时含两者），并**过 793 的收口**、**记历史**
- `page.tsx:166` 一张四项的 `ARROW_NUDGE` 表；`:1397` keydown 里一个分支

★ 三条刻意边界：① 不抢 `Cmd/Ctrl/Alt+方向`（留给浏览器切标签页）
② 没选区时**不** `preventDefault`（方向键仍能滚别的面板）③ `Shift` 按住时 10 像素、否则 1 像素

## ★ 一个真实的 UX 代价（如实记账，不当缺陷修）

3 次按压 ⟹ `past 1→4` ⟹ **一次按压记一条历史** ⟹ 撤销要按 **3 次**才回到原位。

★ 这与桌面画布（Figma / FigJam）惯例一致 ⟹ 保留现状。但必须记账，
否则下一批读到 `past 1→4` 会误判成「重复记历史」。验收器把它写成 S9 显式断言。
