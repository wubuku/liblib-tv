# batch 801 —— `duplicateGraphSelection`：副本应该只是原节点**整体平移**

> 结论先行：这个函数**是对的**。本批是**纯测量批次**（`src/` 一行没改），
> 目的是把 800 那句「读源码看起来对」升级成**行为证据**。
> 偏移 40、父子重映射、嵌套结构逐层保持、成员脱管提升为顶层——全部实测成立。

## 一、起点：静态结论不能当验收结论

800 顺带读了 `duplicateGraphSelection`（`canvasStore.ts:841`），逻辑看起来对：
父也被复制时保持 `position` 只改 `parentId`（`:888`）；父没被复制时提升为顶层、
用**绝对位置 + 40**（`:891`）。但 794 留过一条教训：`removeNode` 那处只有静态证据，
报告**不许**说「两处都验过了」。所以本批去取行为证据。

## 二、判据

- **不变量 C1（平移）**：每个副本节点的**绝对**位置 = 其原节点的绝对位置 + 同一个偏移。
- **不变量 C2（结构）**：复制**组**时父子关系与**深度**逐条保持；
  复制**组内一个成员**时副本应**脱管**、提升为顶层。这是**故意的**结构变化，
  按臂分开判——混成一条会把「正确」判成「错误」。
- **不变量 C3（阳性）**：副本 id 与原 id 全不相交，且副本数 = 预期。
- **不变量 C4（父重映射）**：副本的 `parentId` 必须指向**副本集合内部**，
  否则副本成员会挂回**原组** ⟹ 两份成员挤在一个框里。

### 偏移 40 **不写死**（798 的教训）

先用配对算出每个副本的偏移，再要求**所有副本完全一致**——那个共同值才是偏移。
实测三方（汇编器与验收器各自算）都得到 `(40,40)`。

## 三、三条臂

| 臂 | 复制什么 | 怎么触发 | 结果 |
| --- | --- | --- | --- |
| 单层组 | 组 + 2 个成员 | **纯 UI**：`G` 造组 → `Cmd+D` | 3 个副本，父子与深度保持 |
| 嵌套整组 | 整个嵌套结构 | 注入 + store | 5 个副本，**逐层**保持 |
| 组内一个成员 | 只有成员 | 注入 + store | 1 个副本，**脱管**、深度 0 |

★ 第一条是纯 UI 用户路径（`page.tsx:1381` 的 `Cmd+D`），不需要注入。

### 一个必须钉死的机制事实

`Cmd+D` 复制单层组时，**副本成员的父是副本组**，不是原组：

```
副本 storyboard-group-…-i9gi0q  abs(188,-45)  ← 副本组
副本 image-…                    abs(212,353)  父=storyboard-group-…-i9gi0q  ★ 不是原组
```
