# batch 751 — 把三族剩下的 25 种按门分五组打开；关键帧编辑器在**泳道区**不在轨道行；曲线**默认就是启用的**

## 起点

750 走的是**一条**链（选 camera 轨道 → 建 line → 开曲线编辑器），三族从 2 种涨到 27 种，
静态 52 种里**仍缺 25 种**，并把它们列了出来。749 的说法是「运动路径族只从源码守卫
表达式推断、无运行时读数」—— 750 兑现了一半，751 兑现另一半。

本批把那 25 种按门分五组各走一遍。全部读数来自 clone，**源站导演台关着，一次没碰**。

## 五组门

| 组 | 门 | 带出 |
|---|---|---|
| 1 运动页签 | 选中机位 → 相机页签 `motion` | **6 种**顶层 |
| 2 路径菜单 + 绘制态 | 选中轨道 → `create-motion-path` → 选工具 | **4 + 4 种** |
| 3 锚点类型 | 建路径 → **选中一个锚点** → 锚点类型改「对称」 | **2 + 3 种** |

| 5 朝向 | 角色 transform 轨道 + 建路径 → 只点「沿路径朝向」 | **1 种** |

## 组 1：运动页签（门未开时）

进页签只带出 6 种顶层（`vcam`/`qr`/`record`/`retry`/`preset-button`/`create-path`），
**滑块 0 个、关键帧编辑器不存在**。

这不是「滑块没实现」—— 源码里它们和关键帧编辑器在**同一段守卫**后面：

```
DirectorCameraMotionTab.tsx:232
{selectedKeyframe && selectedTransform ? ( …关键帧编辑器 + 时长/统一缩放滑杆 + 位置/旋转/缩放三组… ) : null}
```

**一个门挡着 5 种**（`motion-keyframe-editor` / `-keyframe-field` / `-keyframe-axis` /
`motion-slider` / `-slider-value`）。

## 组 2：路径菜单 + 绘制态

菜单带出 4 种（`-path-menu` / `-free-draw` / `-draw-tool` / `-preset`），
选「钢笔路径」后面板出现、再带出 4 种（`path-drawing` / `-drawing-tool` /
`-drawing-complete` / `-drawing-cancel`），面板上两个按钮是

## 组 3：锚点类型 → 贝塞尔手柄

| 步骤 | 带出 |
|---|---|
| 建 line 路径 | — |
| 点第 2 个锚点（`path-anchor-option`） | `path-anchor-position` / `path-anchor-type-option`（**2 种**） |
| 锚点类型改「**对称**」 | `motion-path-handle` / `path-anchor-handle` / `path-anchor-handle-axis`（**3 种**） |

锚点类型三档是 **顶点 / 对称 / 非对称**，都 enabled。改完之后：

```
in  = x −0.896   y 0   z −0.308
out = x +0.896   y 0   z +0.308      ← 严格相反，对称成立
```

sr-only 层同步变成：锚点 0 = `vertex`（`handles: []`）、
锚点 1 = `symmetric`（`handles: ["in","out"]`、`selected: true`）。

## 组 4：关键帧编辑器 —— **我点错了地方**

这一组是本批最重要的发现。

**左侧轨道列表里那个菱形不是「选中关键帧」**，它是增删 toggle：

```js
DirectorTimeline.tsx:1794-1798
if (keyframe) { deleteTimelineKeyframe(keyframe.id); }
else          { addTimelineKeyframe(track.id); }
```

**`selectTimelineKeyframe` 全项目只有一个调用点** —— 时间线**泳道区**的
`<button data-director-keyframe-id>`（`:1999`），它同时
`setTimelineTime(keyframe.time)` 把播头 seek 过去。

| | 位置 | 作用 |
|---|---|---|
| 左侧轨道行 | `DirectorTimeline.tsx:1775-1812` | **增删**当前帧的关键帧 |
| 时间线泳道区 | `:1988-2001` | **选中** + seek 播头 |

两条路、两个图标含义、都叫「关键帧」，但只有后者能打开编辑器。

### 泳道区实测

6 个菱形（角色 transform 与 camera 各 3 个，时刻 t = 0 / 4 / 8），每个 **11×11**，
`aria-label` 是 `机位01 · 对峙中景 · 机位 00:04.00 关键帧` 这种完整形式。

点 camera 轨道 t=4 那个 ⟹ 编辑器标题 **「关键帧 4.00s」**（与被点的时刻一致）。

字段是 **9 个平铺的 input**（3 字段 × 3 轴）：

| 字段 | X | Y | Z | step |
|---|---|---|---|---|
| 位置 | 4.1 | 2.3 | 5.4 | 0.1 |
| 旋转 | 0 | 0 | 0 | **1** |
| 缩放 | 1 | 1 | 1 | 0.1 |

`aria-label` 齐全（「位置 X」「旋转 Y」「缩放 Z」）。滑杆 2 个，宽 180：

| 滑杆 | min | max | step | value |
|---|---|---|---|---|
| 时长 | 0 | **10** | 0.01 | 0 |
| 统一缩放 | 0.1 | 10 | 0.05 | 1 |

> 「时长」量程 0–10 是 Batch 583 留下的存疑项（源站无交互证据），本批只复读了显示值。

## 组 5：**曲线默认就是启用的**

我第一版去点「启用曲线」想打开它，读到的是：

```
点之前   aria-pressed = "true"     ← 它本来就是开的
```

点完反而**关掉了**。同 745/746 的坑：**静态断言取值前必须先读一次实际值**。

而这个按钮的 **label 恒为「启用曲线」**，`title` 也是「启用曲线」，
**不随 `aria-pressed` 变** ⟹ 曲线已开时，界面上仍然写着「启用曲线」。

### 朝向这一格：提示是兑现的

只点「绑定对象沿路径朝向」（`pressed` 从 `false` → `true`）⟹ 提示出现，
带出 `data-director-motion-path-rotation-hint`：

| | 值 |
|---|---|
| 文案 | 「**已开启沿路径朝向，Y 轴旋转由运动轨迹控制**」 |
| 颜色 / 字号 | `rgb(114, 152, 162)` / 10px |
| 盒子 | 248 × 16 |

关键在于**它真的兑现了**（`pathControlsRotationY` 的三个与条件：
轨道 `kind === "transform"` + `selectedPath.enabled === true` + `path.orientToPath`）：

| 通用 rotation 三轴 | x | y | z |
|---|---|---|---|
| 朝向前 | 0 | **18**（enabled） | 0 |
| 朝向后 | 0 | **71.03**（**`disabled`**） | 0 |

Y 轴真的被禁用，值也从 18 变成 71.03。

> 我第一版读到的「三轴 `disabled` 全 false、提示像在撒谎」是**查错了组件**：
> 我查的是 `data-director-path-transform-field`（路径检查器专用，
> `DirectorInspector.tsx:873`），而带 `disabledAxes` 的是**通用**的
> `data-director-transform-field`（`:179`，`:2493` 传
> `disabledAxes={pathControlsRotationY ? [1] : []}`）。

### C8/C9/C10：「走完还缺 24 种」是没有意义的读数

| | 种数 |

**一种属性该记在哪一步，要看它的守卫条件挂在哪个状态上。**

## 探针与判据返工（全是我自己的错）

1. **组 4 点的是左侧轨道行的按钮** —— 那是增删 toggle，点下去等于把种子里两个关键帧删了
   （一次性浏览器页，无持久影响）。`selectTimelineKeyframe` 只在泳道区。
2. **组 5 我去点「启用曲线」** —— 它默认就是 `true`，我点完反而关掉了。
   **静态断言取值前必须先读一次实际值**（745/746 同款）。
3. **关键帧字段读成 9 条但每条 `inputs` 都是空** —— 我按「容器含子元素」读，
   而 `data-director-motion-keyframe-field` 与 `-keyframe-axis` 挂在**同一个 input** 上
   （`DirectorCameraMotionTab.tsx:268-269`）。**属性是平铺的，不是一棵树。**
4. **rotation 三轴 `disabled` 全 false，看着像提示撒谎** —— 查源码才发现查错了组件
   （路径专用 `:873` vs 通用 `:179`）。同 746/747：
   **找那个有 X 的元素不能按名字找，先确认它在哪个节点上。**
5. 探针里一段 `document.querySelector` 的 JS 报 `SyntaxError`，重写一次就好，
   同一写法在别处能跑通，没查到底因。
6. 验收器自己的 `lines()` 助手漏了 `nth` 关键字参数（750 那个版本有），第一次直接 TypeError。
7. **判据自己错了四处**：C1 写 `len(selectCallSites)==3`（以为把 `useDirectorStore` 的解构
   也算进去，实际该正则只命中真调用点 1 处）—— **数一个模式有几处命中之前，先确认匹配规则本身**；
   C4 把两个中文按钮按语序写成 `[完成, 取消]`，但 `sorted()` 按码位排，「取」U+53D6 < 「完」U+5B8C
   —— **拿中文字面量写断言时，先想一遍排序规则**；C6 标签只剩一个 `%d` 却传两个参数；
   C9 拿单链在场种数当「已覆盖」（见上）。
