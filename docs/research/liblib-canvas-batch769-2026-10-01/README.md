# Batch 769 — 协议 v2：只换「焦点落点」这一个变量

## 选题

768 结论是「关闭 disclosure 浮层时焦点归还 **0/6**」，但它自己留下一条 FAIL
判据（J10）说**有 2 个浮层根本没测到**：

> 协议是「把焦点放进浮层的**第一个**可聚焦控件」，而这两个浮层的第一个
> 可聚焦控件是 `INPUT[type=number]` ⟹ `DirectorDesk.tsx:487` 的 `isEditable`
> 早退先把 Esc 吞掉、**浮层压根没关** ⟹ 焦点还在原地，焦点去向无从观察。

本批就补这一问。**只换一个变量**：焦点落点的类别。

| 臂 | 焦点落点 | 作用 |
| --- | --- | --- |
| `editable` | 浮层里第一个**输入框**控件 | 768 的原协议落点，顺带当**可复现性对照** |
| `noneditable` | 浮层里第一个**非**输入框控件 | **本批新协议** |

其余协议与 768 逐字相同：每格都从重载页面开始、全程不点外点、只点 6 个触发器。

## 新缺陷

### D12（低，新增）模型库面板的第一个可聚焦控件是一个 `sr-only` 的 1px 文件输入框，且零可访问名

面板挂载时第一个孩子就是：

```jsx
<input
  ref={localModelLibraryInputRef}
  data-director-model-library-local-input
  type="file"
  accept=".fbx,.obj"
  multiple
  onChange={(event) => void handleLocalModelLibraryChange(event)}
  className="sr-only"        // ← 1px×1px + clip，视觉隐藏但仍可聚焦
/>
```

没有 `aria-label` / `aria-labelledby` / `title` / `id`，也不在任何 `<label>` 里
（面板内 1 个 `<label>`，在它后面）⟹ **可访问名为空**。

**实测**：`editable` 臂的落点就是它 —— `INPUT[type=file]`、`pickedIndex=0`
（面板共 15 个可聚焦控件），2/2 轮；换到 `noneditable` 臂时落点变成 index 1 的按钮。
**键盘用户 Tab 进模型库，第一站是一个看不见、也没有名字的文件选择器。**

**★ 它与 765/762 记的那个隐藏 file input 不是同一个。** 那个用 `display:none`
——**不可聚焦**，当时据此判它「不构成缺陷」，那条判断对那一处成立。
`sr-only` 是 **1px 但有布局盒、仍可聚焦**，**根本不在那次的扫描范围内**。

**严重度低**：焦点不可见且无名字，键盘用户不知道自己在哪；但仍在对话框内、
Esc 还能关掉面板，不会「卡住」。与 765 的 D4 同级。

**修法**：①给 `aria-label`（例如「上传本地模型」）——更小；②或者改用真正的
`<button>` 触发文件选择器，把 `<input type="file">` 彻底藏起来而不是让它当
第一站 —— 更对。

## 扩宽与加强的四个缺陷

### D11 焦点归还：仍是 0/6，但**真测到的从 2 个变成 3 个，3 个全错**

非输入框落点下，导出面板 / 虚拟相机 / 模型库**全部把焦点丢到 `body`**；
另 3 个按 Esc **关掉整个导演台**、触发器随之卸载 ⟹ 仍然没有可归还的对象。
**「没测到」这一桶已清空**（768 那里还有 2 个）。

### D4 关闭后焦点掉到 body：导出面板这一例得到**独立复现**

本批**没有新增成员**，但把 765 最初发现的那一例用**另一套协议、另一个探针**
重测了一遍：768 因 D3 遮住没测到，本批落在画幅按钮上测到，2/2 轮。
同一个缺陷在两个批次、两个探针、两套协议下都出现 ⟹ **D4 从「单点观察」
升级为双协议确认**。

### D3 成员没变（2/6），但作用域与耦合都量清了

①**作用域**：`isEditable` 早退**只对两类浮层有效** —— 「靠导演台阶梯关」的
（导出面板 `:557`）与「根本没有 Esc 处理」的（添加群众阵列）。
**模型库面板的落点同样是 `INPUT`，Esc 却照样关掉了面板** —— 因为它自己的
window **捕获**监听（`DirectorViewport.tsx:2748`）在 DirectorDesk 的**冒泡**
处理器**之前**就 `stopImmediatePropagation()` 了。⟹ **那道早退不是全局防线。**

②**耦合**：添加群众阵列的「没关」与「导演台没了」是**同一个 `if` 的两面**。

### D8 成员没变（3/6），但群众阵列这一个成员现在有了**双臂**读数

- 焦点在**数值输入框**上按 Esc ⟹ **什么都没发生**（`isEditable` 早退吞掉）；
- 焦点在 **cancel 按钮**上按 Esc ⟹ **整个导演台没了**。

⟹ 它「有时不丢工作区」**不是安全，只是被 D3 的早退挡住了**。

**★ 修法顺序（这条从 768 的推理升级为实测）**：
**先修 D8，再修 D3。** 顺序反了，就会在「给 `isEditable` 开特例」的那一刻
把群众阵列面板的「按 Esc 丢工作区」直接打开。

## 方法论

### ★ 协议等价的判别式是「落点」，不是「臂名」

6 个浮层里 **3 个一个输入框都没有**（预设运镜 0、创建运动轨迹 0、虚拟相机 0 个
可编辑控件）⟹ 它们的 `editable` 臂**必然**失败。若按臂名去配 768 的读数，
这 3 个会被误判成「复现失败」—— 而它们实际上复现得最干净。

按落点（`tag`+`type`）配对之后：**6/6 逐格复现**。

探针在「那一类控件为 0」时**如实报出两类控件各多少个并拒绝退化成交取第一个** ——
退化会让读数看着有、其实答非所问。

### ★ 「换个变量」把一个看不见的耦合照了出来

同一个浮层、同一颗 Esc，焦点类别从输入框换成按钮，结果从「什么都没发生」
变成「整个导演台没了」。**只测一个落点就会把这个耦合完全漏掉** ——
768 那一次就漏了（它把「浮层没关」当成结论的终点）。

### ★ 产物里标着「机制推断」的判据是欠账

768 那句「群众阵列此刻没丢工作区，靠的正是 `isEditable` 早退」当时是对的、
也如实标了推理，但**没有读数支撑**。本批只换一个变量就把它测成了读数。
**推理与读数的距离，有时只差一个变量。**

## 探针教训

- **R81 ★ 协议等价的判别式是「落点」，不是「臂名」。** 某个臂「失败」可能是
  结构事实而不是探针坏了；按落点配对才不会把「那一类控件不存在」
  误判成「复现失败」，进而误判成「新一批数据不可信」。
- **R82 ★ 一道「守卫」的作用域必须单独量。** `isEditable` 早退看起来像全局
  防线，实测只对「事件能到达导演台」的路径有效 —— **「有守卫」不等于
  「有防线」**。否则会把守卫当成修复的安全垫，而它恰好在要修的那个路径上失效。
- **R83 ★ 产物里标着「机制推断」的判据是欠账，下一批就去测它。** 推理留在
  产物里久了会变成「已知事实」被后续批次引用，越传越硬。
- **R84 ★ `sr-only` 与 `display:none` 是两回事。** 查「不可见控件」时要先把
  「不可见」分成两族（`display:none` / `visibility:hidden` vs
  视觉隐藏但有盒子）—— 否则一个同族缺陷会被「已排除」的说法盖住两批。
- **R85 ★ 在 JSX 上用 `[^>]*>` 切标签会停在 `=>` 的那个 `>` 上。** 我给 D12 取
  标签时用了 `<input\b[^>]*data-…[^>]*>`，匹配到「到 `onChange={(event) =>`
  为止」，后面的 `className="sr-only"` 被切掉，断言「不是 sr-only」炸了出来。
  **形状完全对、语义完全错**（R72 的同族）。改法：按标记位置取固定窗口 +
  一条形状断言（**最近的 `<input` 必须比最近的 `>` 更靠后**）。
- **R86 ★ 阴性对照要改「决定分类的那个字段」。** 我写了「把 768 的
  `crowd/inside` 焦点改成 `isTrigger`」来破坏 6/6 复现，结果那条对照**永远
  漏放** —— 那一格的分类是 `panel-stuck`，而分类函数**先看面板还在不在**，
  焦点字段轮不到读。改 `panelPresent` 才拦得住。这是 R80 的第二例：
  **无效的阴性对照不会报错，只会永远「漏放」。**

## 不声称

- 无源站对照：本批全部结论只针对 clone 自身的行为自洽性。
- ★ **本批只换了焦点「类别」，没换焦点「位置」**：焦点在浮层**外面**（对话框
  别处）时按 Esc、焦点在**第三个**控件上，都**没测**。
- ★ **「可聚焦但不可编辑」的其他类型没普查**：本批只碰到模型库面板的
  `INPUT[type=file]`（`sr-only`）。同族是否还有别处，**未测**。
- **没有测 6 个浮层里的 Tab 围栏**（765 只量过导出面板与对话框级，767/768
  连续两批列为不声称）。
- **没有测打开状态下再点一次触发器**（toggle 关闭 vs 报错）。
- **没有测多个浮层同时开着会怎样** —— 每格都从重载页面开始。
- **没有测虚拟相机在录制中的 Esc**（`DirectorPhoneVcamPanel.tsx:292` 有
  `if (!recording) onClose()`）。
- **只测了 1440 桌面一档视口**。
- **没有改 `src/`**：所有结论都是读数 + 源码现算，修法列在缺陷条目里等拍板。
