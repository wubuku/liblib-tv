## 四之二、★★ 本批在**判据自己身上**抓到的两个问题

### 4.2.1 建键维度 ≠ 取值维度 ⟹ 判据恒 False

S3 第一版长这样：

```python
widths = {t["id"]: t.get("w") for t in tabs}          # ★ 按 **id** 建键
want_widths = {a: b["w"] for a, b in exp[page]["页签盒"].items()}   # ★ 源站侧按 **aria** 建键
s3["★%s_宽度与源站逐条相等" % page] = (want_widths == widths)     # ⟹ 键集不同 ⟹ 恒 False
```

⟹ 两侧**键集不同**（`nose` vs `鼻子`）⟹ 整字典比较**永远 False** ⟹ 这条断言**从写下起就没测过任何东西**，
而**对照轮照样是绿的**。

⟹ ⟹ 正解：**判哪一枚被选中用 `id`**（页面 id），**跟源站比宽度用 `aria`**（源站 raw 的页签盒就是按中文标签建的键），
两侧**同维度**才叫「比」。

★ **通用形态**：**建键维度必须与取值维度一致**；写完先问一句
「这个字典比较的两边，是同一套键吗？」。

### 4.2.2 ★ 断言只钉了一半 ⟹ 「每枚都带文字」能蒙混过关

S3 原本只钉了「**选中那枚**带文字」，**没钉**「**其余五枚没有文字**」
⟹ ⟹ 一个把文字渲染在**所有**页签上的实现，能照样通过。

⟹ ⟹ 本批**补上**：`★只有选中那枚带文字`（`sum(带文字的页签数) == 1` 且就是本页）。
⟹ ⟹ 补上之后，阴性对照 N3（把文字渲染到每一枚）就**精确地红在 S3 上**了。

★ **通用形态**：**规则类断言要钉住「全集」**，不能只钉「被点名的那一个」——
少钉的那一半，通常正好是**别的实现能蒙混过关**的那一半。

### 4.2.3 阴性对照：N1–N6，各翻一条 ⟹ **6/6**

「对照轮全绿」**不能**证明某条断言有牙 ⟹ ⟹ 每条臂**只翻它自己那一条**，看它**精确地红在指定那一条上**。

| 臂 | 注入的缺陷 | 红在 |
| --- | --- | --- |
| N1 | 「鼻梁」→「鼻背」（**同字数** ⟹ 盒宽不变 ⟹ 不会顺带翻 S2） | S1 |
| N2 | 滑杆行整体下移 6px（> ±1px 容差） | S2 |
| N3 | 页签**每枚都渲染文字** | S3 |
| N4 | 滑杆更新量 `Number(...) % 1` ⟹ 拖动后永远是 0 ⟹ 控件成了摆设 | S4 |
| N5 | 未实现的页签渲染一枚**假滑杆**（必须带 `data-character-editor-slider`，否则探针数出来还是 0 ⟹ S5 不会红） | S5 |
| N6 | README 里的 **mock** 标注全部删掉 | S6 |

⟹ 6/6 每条都**只**红一条 ⟹ ⟹ **六条判据都有牙**。
⟹ ★ 全部臂跑完后**按 SHA-256 字节级复原**，再跑一次门禁 ⟹ 必须**回到 6/6**（产物 `negative-audit.json` 里记着这一条）。
