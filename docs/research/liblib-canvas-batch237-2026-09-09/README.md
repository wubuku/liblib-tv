- **Escape 会取消节点选中并关闭整个面板**——此前多轮「触发器探测失败」的
  根因；菜单需用触发器**再次点击**（toggle）关闭。

  并非恒 2.5（对照 batch 158 的 clone 默认 2.5 决策——账号态/项目态混合，
  维持 clone 2.5 不翻转）。

## 实施（`VideoGenerationPanel.tsx`）

1. `MODEL_RESOLUTIONS` 表：2.5→3 项 / 2.0 VIP→4 项含 4K / 2.0 Fast VIP→
   2 项；缺省 3 项；栅格 ≥4 项时 4 列。`selectModel` 通用钳制：目标列表
   不含当前清晰度 → 落到**不高于原选择的最高项**（4K→2.5 得 1080P，
   1080P→Fast VIP 得 720P；钳制规则 `CLONE_DECISION`）。
2. 积分公式加 Fast VIP Auto 速率 22：`(ratio === "16:9" || model !== "2.5"
   ? (model === "2.0 Fast VIP" ? 22 : 27) : 46)`；注释升级为模型平价率
   结论（证据级推断）。
3. 首帧生成视频芯片 → `setMode("first-frame")`（新增 `VideoMode` id +
   `inMenu:false` 查找项，模式触发器显示 **全能参考**）+ Auto + 5s。
