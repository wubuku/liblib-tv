各 46×24、12px 居中、`border-width: 0`、**`readOnly=false`**，且连体：

值随单位切换（点击单位钮实测，s → ms 再 → s 双向验证）：

| 模式 | 播放头位置 | 总时长 | 按钮文本 | 按钮 aria |

即 **s 模式两位小数、ms 模式整数毫秒**，按钮宽度随之 31 → 33（文本驱动）。

## clone 原状与本批改动（CLONE_DECISION）

clone 原先把读数显示成 `mm:ss.ss`、时长是**只读 span**、没有单位切换钮、
自动帧排在循环播放**之后**。

1. 新增 `TimelineTimeField`：连体可编辑文本框，46×24 / 12px 居中 / 无描边，
   左框 `rounded-l-lg`、右框 `rounded-r-lg`；值格式随单位切换；回车或失焦
   提交，无法解析时回滚（沿用 588 已在源站实测通过的读数行同一模式）。
2. **store 新增 `setTimelineDuration`**：源站的「总时长」可编辑，时长因此
   必须可写。钳制规则源站未实测（改数值会写入用户真实项目），取两条不臆造
   也不丢数据的下限——**正数**、且**不早于最后一个关键帧**（否则关键帧会被
   甩到时长之外）；播放头随之夹回新时长内。规则写进代码注释，不藏在文档里。
3. **单位切换钮** `s` / `ms`，aria 逐字随模式翻转。
4. **自动帧前移**到循环播放之前，工具栏前七项与源站逐位一致。
5. **新建轨道 aria 改为源站逐字** `选中角色、道具或分组后建立轨道`；
   clone 更完整的 `title` 禁用提示（含 coachmark 指引）保留为 tooltip。
6. **上一/下一关键帧**移到源站顺序前缀**之后**：源站工具栏没有这两个按钮
   （实测七项如上），但它们是 clone 既有能力且被 batch 36 / 42 按
   `role+name` 点击。放在前缀之后，既让前七项与源站对齐，又不删功能。

### 有意保留的差异

- **上一 / 下一关键帧**：源站无，clone 有（见上）。
- **重复的 `+ 轨道` 按钮**：clone 工具栏下方还有一个无 aria 的 `+ 轨道`
  （走 `addTimelineTrack()`），与源站的 `新建轨道` 并存。batch 553 用
  `.first` 取前者，未受影响；未取证前不删。
- **顶栏的「导出视频到画布」**：源站在时间轴右侧，clone 在顶栏。两处功能
  都在，本批只对齐时间轴工具栏的控件顺序，不搬迁入口。

## 刻意不臆造

- 源站对「总时长」提交时如何钳制未实测（改数值会写入用户真实项目）；
- 源站 `时间线最小化` 的收起后形态未取证（点它会改变浮层状态），本批未实现；
- `播放头位置` 提交后是否也走 ms 解析未验证（clone 按当前单位解析）。
