## clone 合同（CLONE_DECISION）

1. **变换组上提**：把 `data-director-scene-transform` 整段（场景缩放/平移/旋转）
   移到场景面板顶部，与源站行序一致。clone 独有的行（场景名称、显示地面/
   网格、背景颜色、地面颜色、画布环境、场景机位）保持原相对位置不动。
2. **轴片拖动**（本批最大增量）：场景平移/旋转的每轴新增
   `SceneAxisScrub` 轴片，aria 逐字沿用源站 `左右拖动调整 {轴} 轴`，
   按住横向拖动连续改值。源站未暴露步进量，clone 取数值框 step 的 1/4
   像素当量作为拖动灵敏度（记录为 CLONE_DECISION）。
3. **量程对齐**：场景缩放 `0.5–3` → **`0.1–10`**（百分比读数保留，源站同形态）；
   球形半径 `10–100 step 1` → **`10–500 step 10`**；地面高度 step `0.1` →
   **`0.05`**。
4. **地面行序与读数**：透明度移到高度之前（源站 920 < 992），并补两位小数
   读数 `0.40`；透明度滑杆宽度与高度行统一（此前 0.4 透明度是 28 宽、
   无读数的孤立形态）。
5. **天空颜色 hex 读数**：取色器左侧补 `#060608` 文本读数（源站 y=457）。
6. **FOV 帮助默认展开**（batch 581 遗留修正）：源站该说明默认展开
   （innerText 直接含文案），581 实现成默认收起，本批改回默认展开。
