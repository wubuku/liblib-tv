## 二、源站实测（只读，⚡44 未变）

raw：`raw/source-845-body.json`（结构）＋`raw/source-845-pixels.json`（像素）
＋`raw/source-845-visual.json` ＋ `raw/source-845-sliders.png`（截屏原件）

### 2.1 结构

- 这一段**没有标题行** ⟹ ⟹ 右栏**第一层就是滚动区**（`pt-3`）
  ⟹ ⟹ 内容起点 ＝ 右栏顶 + **12**（与第二段同 ⟹ ⟹ 比「脸部精修」段高 48px）
- **18 条**滑杆，每条 ＝ LABEL(240×55)：
  - 标签行 240×22（名字 14px／22px／**纯白** ＋ 可选的「i」 ＋ 右端数值 11px／16px 等宽）
  - 轨道 240×12 ＝ 标签 +36
  - 标签行 top ＝ 段内 **12 + 74.8·i**
- 滚动区高 **1418** ＝ 12(pt-3) ＋ 18×54.8(块) ＋ 17×20(space-y-5) ＋ 80(pb-20)
  ⟹ ⟹ **不是手打常数** ⟹ ⟹ 由块数与步进**算**出来

### 2.2 量程（逐条实测）

- **5 条**是 **−100..100**：丰胸／瘦身／瘦手臂／美臀／肩膀宽度
- 其余 **13 条**是 0..100；step 全是 1、初值全 0

### 2.3 「i」标记

**6 条**带「i」：驼背／瘦脖子-左／瘦脖子-右／天鹅颈-左／天鹅颈-右／全身美型

### 2.4 ★ 外观是**像素**实测的，不是推理

`probes/pixels845.py` 从截屏里**机器提取**：

| 事实 | 实测值 | 怎么测的 |
| --- | --- | --- |
| 轨道厚 | **2px** | 「不是底色」的像素行数 |
| 已填充段 | **#fff**（纯白） | 轨道行上、圆钮左侧的像素 |
| 未填充段 | ≈ rgba(255,255,255,.08)（面板底 #242424 上是 53） | 轨道行上、圆钮右侧的像素 |
| 圆钮 | **14×14 纯白** | 圆心那一列的竖向跨度 |
| 圆心点 | **2×2 ＝ #464646**（灰阶 70） | DOM 给出 2×2 盒 ⟹ 取那四个像素 |
| 圆钮行程 | 中心 ＝ 轨道左端 + **7** + ratio·**226** | 由**两条**滑杆**解**出（ratio 0 与 ratio 0.5） |

★ 教训记一笔：第一版提取脚本按「行内最长连续亮段」取圆钮 ⟹ ⟹ 取到了**填充段**
（填充段 113px 远长于圆钮 14px）⟹ ⟹ 改用**二维**判定（按列统计近白高度）才分得开。

### 2.5 ★★ 源站与 clone 的**像素级对照**（`probes/pixeldiff845.py`）

门禁 S3 比的是**计算样式**，而**轨道与圆钮是伪元素**（`::-webkit-slider-runnable-track`
／`::-webkit-slider-thumb`）⟹ ⟹ 计算样式**量不到它们** ⟹ ⟹ 门禁看不到
「轨道是不是 2px」「填充段到没到圆钮中心」「圆钮是不是 14px 白圆」。

⟹ ⟹ 唯一的办法是**把同一片区域截下来逐像素比**。
★ 源站与 clone 的角色编辑器模态**同在视口 (361,161)** ⟹ ⟹ 同一个 clip
（1285,235,260×175）在两端截到的是**同一片 UI** ⟹ ⟹ 可以直接相减。

结果（`raw/pixel-diff-845.json`）：

| 项 | 值 |
| --- | --- |
| 总像素 | 45500 |
| **完全相同** | **45396** |
| 差 1～2 / 3～4 / 5～8 | 84 / 18 / 2 |
| **差 > 8** | **0** |
| **最大通道差** | **7** |

⟹ ⟹ 残差只是抗锯齿的舍入 ⟹ ⟹ **这一片区域在像素级与源站一致**。
（★ 这也反过来证明第三节那三处外观偏差**确实**是偏差 —— 改之前这里差得满屏都是。）

## 四、★ 探针踩过的坑：「点空气」

第一趟源站探针**点空了** ⟹ ⟹ 读到的是**皮肤页**的 6 条滑杆 ⟹ ⟹ 差点把错数据入库。

修法：改用**前缀匹配** ＋ 限定在**左列**的按钮里 ＋ **自证**：
读数的第一条滑杆**必须**是「丰胸」，否则**当场停**、这份读数**不许**入库。
（★ 这条自证已经写进 raw：`★读数_是目标段` ＝ true。）
