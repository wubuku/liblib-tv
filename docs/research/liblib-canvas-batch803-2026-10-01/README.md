# batch 803 —— 导演台撤销/重做入口：**先量几何**，结果量出「这事被卡住了」

> 结论先行：本批是**纯测量批次**（`src/` 一行没改）。要回答的是 750 留的待拍板 ③
> 「撤销/重做要不要给按钮（151 个可交互节点里 0 个入口，鼠标用户无路）」。
> 量完的结论不是「做」或「不做」，而是：**三个候选位置每一个都有已记录的否决理由**，
> 而**否决它们的理由我原先都不知道** —— 包括我自己写下的那句前提。

## 一、我自己那条待办的前提是错的

我在待办里写过：「导演台缺撤销/重做入口 —— 画布右键菜单已有现成范本；但导演台
header 右列 280px **已塞满**，需先量几何」。

★ 「已塞满」这个**方向**对，但真正的账我算错了：

| | 子元素数 | 余量 |
| --- | --- | --- |
| 我静态估的 | 3 | 约 176px |
| **实测** | **5** | **7.328125px** |

差在哪：漏数了对象名 `SPAN`（88.67px）和「尚无构图」`DIV`（56px）两个元素，
也漏了 `gap-2` 是 **4 段**不是 2 段。⟹ **我就是那个「没量就下结论」的样本**，
这条差值本身就是「先量再动」的全部理由。

## 二、右列到底装不装得下（算出来的，不是估的）

右列容器 `280px` / `box-sizing: border-box` / 左右 `padding 12px` ⟹ 内宽 **256**。
五个直接子元素（两轮逐位相同）：

| 序 | 元素 | 宽 | 高 | 身份 |
| --- | --- | --- | --- | --- |
| 序0 | `SPAN` | 88.671875 | 22.5 | `data-director-header-object-name`，文本「角色01 · 陈默」 |
| 序1 | `DIV` | 56 | 15 | `data-director-capture-status="empty"`，文本「尚无构图」 |
| 序2 | `DIV` | 32 | 32 | **匿名包裹层**（`div.relative`），内层按钮 aria「导出导演台项目」 |
| 序3 | `BUTTON` | 32 | 32 | aria「导入导演台项目」 |
| 序4 | `DIV` | 8 | **0** | `data-director-project-io-feedback`（aria-live） |

`used = 88.671875 + 56 + 32 + 32 + 8 + 4×8 = 248.671875` ⟹ **余量 7.328125**。

**两个按钮需要多少**：`2 × 32 + 2 × 8 = 80` ⟹ **缺 72.671875px**。

★ 那个 `32` **不是写死的常量**：验收器拿右列里**现成的 BUTTON 实测宽度**当参照
（取最小那枚 = 最保守），`gap` 也从读数里取。规则是「**不预设常量**」。

### ★ 但「放不下」有前提，如实记账

对象名 `SPAN` 是 `min-width:0` + `overflow:hidden` ⟹ **它可以被压缩**。阴性对照
N1 把它压窄 80px，S2 立刻翻红。⟹ 「放不下」的真实含义是：

> **在不牺牲对象名可读性的前提下放不下。**

这是个**设计取舍**，不是物理不可能。不能写成「技术上放不下」。

⟹ **750 的待拍板 ③ 不该按「要不要给按钮」来拍**，它缺一个前置问题（见第六节）。

## 四、独立复核 750：0 入口这条成立

136 个可交互元素（`button,[role=button],a[href],input,select,textarea,[tabindex]`），
按 `撤销|重做|undo|redo|回退|恢复|复原` 筛，命中 **0**。查询覆盖文本、`title`、
`aria-label`、属性名、`data-*` 的值，**五条路全查**，且逐条记录「命中了哪个字段」
（不是只给一个布尔）。

★ 750 记的是 **151** 个，本批数出 **136** 个。方向一致，**数量不同**。
可能的选择器集合或当时的 DOM 状态不同 —— **本批不追这个差异**，如实记账。

## 五、★★ 本批撞出来一条新事实：文档持久化，历史栈不持久化

这条是**撞出来的**（见第七节），撞出来之后单开一格专门去测，四个问题：

| 步骤 | 读数（`path-count`） |
| --- | --- |
| 起点 | 0 |
| 建一条运动轨迹 | 1 |
| ★ **格内**按 `Cmd+Z` | **0** ⟹ 撤销在这一格**确实是活的** |
| ★ 按 `Cmd+Shift+Z` | **1** ⟹ 重做也是活的 |
| **重载页面**再打开导演台 | **1** ⟹ **文档存活** |
| 重载后连按 `Cmd+Z` ×3 | **1、1、1** ⟹ **撤销失效** |

两轮逐位相同。★ **格内阳性对照不可省**：没有那两步，「重载后撤销失效」同样可以
由「这一格导演台整体都坏了」造成。⟹ 这是**变化**，不是恒态。

⟹ **导演台持久化的是文档，不是 `history.past` / `history.future`。**

### 它直接冲击 750 那条待办

750 的理由是「功能已完整，151 个可交互节点 0 个入口，**鼠标用户无路**」。
但实测说明：**重载之后，按钮和快捷键一样是死的**。

⟹ 加一个按钮**并不能**解决「鼠标用户无路」，它只把一条死路换成另一条死路。
真正的前置问题是：**历史栈要不要跨会话持久化** —— 那是产品决策，而且需要
源站对照（本批没有）。

## 六、给 750 待拍板 ③ 的重新表述

> ~~撤销/重做要不要给按钮~~ → **先决定历史栈跨会话要不要持久化，再决定入口放哪。**
> 在这之前不加按钮，理由是三个表面各有一条**已记录的**否决，不是「没想好」。
> 若仍要做，唯一不破坏源站已记录几何的路径是**独立于 header 的浮层**
> （例如仿画布的右键菜单），而不是挤 header。

## 八、判据与阴性对照返工五处

| # | 现象 | 教训 |
| --- | --- | --- |
| 序1 | S3 要求每个子元素**自身**可命名 ⟹ 被一枚匿名包裹层打红（`div.relative` 装导出按钮，自身既无 `aria-label` 也无文本） | ★ 「点名」必须允许**内层**。探针因此补记 `nested` |

| 序3 | S3 里 `any(own)` 用了 `json.dumps(k["data"])` | ★ 空字典返回字符串 `"{}"`、**恒为真** ⟹ 那一项永远通过。改 `bool(k["data"])` |
