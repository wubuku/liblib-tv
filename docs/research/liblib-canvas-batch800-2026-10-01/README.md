# batch 800 —— 取消分组（`ungroupSelectedNodes`）：**东西不该跳**

> 结论先行：解除分组时成员会**跳位**，跳掉的量**恰好是沿途祖先的偏移**。
> 同一类坐标系错误在 799 修过的那处**之外**还有第二处：`ungroupSelectedNodes`
> 把「父的**相对**位置」当成了「父的**绝对**位置」。单层组没有祖先 ⟹ 两种写法
> 不可区分 ⟹ 键盘 `G`→`Shift+G` 这个**真实用户路径**一直没暴露它。

## 一、起点：799 的姊妹缺陷

799 查出 `fitStoryboardGroupsToChildren` 写回组框时用了错的坐标系。本批先按
799 留下的线索去普查其它写点，**没打开 UI 就先在源码里看到第二处**：

```ts
// ungroupSelectedNodes 内，约 3580 行（修之前）
node.parentId === groupId
  ? withoutParent(node, {
      x: group.position.x + node.position.x,   // ★ 只加了一层
      y: group.position.y + node.position.y,
    })
  : node,
```

解除分组要把成员的**相对**坐标转成**绝对**坐标（`parentId` 删掉之后
`position` 就是绝对的）。而这段代码写的是「组的 `position` + 成员的 `position`」
—— 那假设「组的 `position` 就是组的绝对位置」，**只在组没有父节点时成立**。
嵌套时沿途所有祖先的偏移被丢掉。

## 二、判据：取消分组**不该**让任何东西移动

> **不变量 U**：取消分组**前后**，每个成员的**绝对**位置必须**逐位相同**。
> ——「我只是取消了分组，东西不该跳」。

这条与坐标系语义无关，只看用户看得见的位置。写死任何坐标都不行，全部从 raw 现取。

## 三、三条臂里藏着**两个**阴性对照

| 臂 | 怎么造分组 | 沿途有祖先吗 | 角色 |
| --- | --- | --- | --- |
| 键盘往返 | 选 2 个散节点 `G` 造组，再 `Shift+G` 取消 | 没有 | 阴性对照：**纯 UI 用户路径** |
| 取消**外层** | 注入嵌套数据，取消顶层组 | 没有 | 阴性对照：**同一个操作**在无祖先时的样子 |
| 取消**内层** | 注入嵌套数据，取消嵌套组 | 有一个 | 缺陷臂 |

★ 前两条与第三条是**同一个操作**（取消分组）在不同祖先深度下的表现 ⟹
两者的**差**就是缺陷本身，不需要另找对照。

★ 键盘臂额外证明：缺陷**不在**真实用户路径上——`page.tsx:1412` 的 `Shift+G`
分支跑的是完全相同的数据形状（组没有父节点），结果是对的。缺陷只出现在
**注入出来的嵌套结构**上，而嵌套结构 UI 造不出来（792 遗留，799 复核仍成立）。

★ 阳性对照：解除后成员的 `parentId` 必须**确实变成空**。没有它，
「操作什么都没发生」也会让不变量 U 成立 ⟹ 假绿。

### 机制钉死

只说「跳了」不够。汇编器与验收器都独立算了一遍：

```
内层组 g-inner： 相对 position (40,40)   绝对位置 (240,190)
丢掉的那段      = 绝对位置 − 相对 position = (200,150)
实测跳位        = (−200,−150)
恰好相反        = True      ← 四个成员、两轮，逐位成立
```

⟹ 「跳位」不是巧合，就是**沿途祖先的偏移被整段丢掉**。

### 修复（post）

`取消内层` 两条：`n-m1 (280,230)→(280,230)`、`n-m2 (680,230)→(680,230)`，**不动**；
另外两条臂读数**逐位不变**。

### 独立重算

脱管之后 `position` 就是绝对坐标 ⟹ 它必须等于**用 before 的 `parentId` 链**
沿路求和算出来的值。汇编器与验收器**各自**算了这条链（不读源码公式）：

- post 侧**全部吻合**；
- pre 侧**对不上**（n-m1 重算 `(280,230)`、实测 `(80,80)`）⟹ 缺陷就在这。

## 五、修复

```ts
const nodesById = new Map(currentCanvas.nodes.map((node) => [node.id, node]));
const nextNodes = currentCanvas.nodes
  .filter((node) => node.id !== groupId)
  .map((node) => {
    if (node.parentId !== groupId) return node;
    const absolute = getAbsoluteNodePosition(node, nodesById);
    return withoutParent(node, { x: absolute.x, y: absolute.y });
  });
```

- 改一个函数，不新增 API、不动 UI。
- `nodesById` 必须在**旧**的节点集合上建（要含组本身，链才走得通）。
- 对「沿途无祖先」是**恒等变换** ⟹ 阴性对照两条臂 pre/post 读数**逐位相同**
  （S7 钉死），这是无回归的最强证据。
