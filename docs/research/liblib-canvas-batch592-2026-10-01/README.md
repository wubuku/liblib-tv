## clone 合同（CLONE_DECISION）

- 时间轴高度 196 → **182**（源站实测值），并新增 `时间线最小化` /
  `展开时间线` 切换：收起态 **88px**、隐藏轨道区、工具栏保留，按钮可及名
  随状态翻转；
- prompt 占位与可及名改为源站逐字 `描述想搭建的场景`；
- 提交钮 aria/title 改为 `发送`、尺寸 28 → **32px**、保持全圆。
  空态底色沿用 clone 原有的 `disabled:bg-white/[0.08]`——与源站实测的
  `rgba(255,255,255,0.08)` 一致，无需改动。

### 刻意不改的部分

源站输入区是 contenteditable，但**其 Enter 是提交还是换行未取证**
（`aria-multiline="true"` 暗示换行）。为避免臆造交互语义，clone 继续用
`<input>` + Enter 提交，只对齐文案与几何。这条记入待确认。
