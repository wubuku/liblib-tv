# batch 653 —— 按 652 的判据**重测 648 那 4 个导演台抽屉**：滚动 offset 全为 0，648/649 的读数**追溯性地干净**

## 一句话

652 把「探针副作用」的污染面在 626 的 11 条打开路径上量完了（**11 分之 1**），
但自己写了「不声称」：**648 那 4 个导演台抽屉走 `locator.click()`，本批没重测。**
而 652 同时量出一条关键事实 —— **同一个 `locator.click()` API 下，
「最小滚动」与「滚到末端」两种语义都出现过**。
既然语义会在同一 API 内分叉，那 4 条 click 路径就**不能靠「它们是 click」推定干净**。
本批复测：**4 条路径 × 3 个窗高 = 12 格，滚动 offset 全为 0。**

## 1. 为什么这条「不声称」必须被关掉

652 的结论是「污染面 = 11 分之 1」。这句话只覆盖它**量过**的 11 条。
剩下 11 条浮层的打开路径里，还有 648 的 4 个抽屉、649 的 7 个画布页浮层 ——
后者的打开机制是 **store 动作**，结构上不可能触发浏览器的滚动，**天然免疫**；
前者是 `locator.click()`，**与被污染的那条同属一个 API**。

651 的因果链是：`hover()` 滚到容器末端 → 浮层贴着被滚动的元素定位 → 读数随探针漂移。
`locator.click()` **有没有可能走出同一条链？** 不测就不知道。
「它是 click 所以它干净」与「它没报错所以它通过」是同一类话：**都是用缺席当证据**。

## 2. 读数（1280 宽 × 720 / 900 / 1150，12 格）

| 抽屉 | 触发 | 滚动 offset | 横向盒位（三个窗高） |
|---|---|---|---|

| `model-library-panel` | `模型库` | **0** | **390** 恒定 |

**四条路径、十二格，滚动 offset 全为 0。**

第四条是本批的重点：它是四条里**唯一含悬停**的路径，
**也正是最可能落进 651 那类的一个**（651 的元凶就是一条 hover）。
它也干净 —— 因为那张卡**在已打开的面板里、天然可见**，探针没有东西要滚。

**横向盒位在三个窗高上全部恒定**，这是「什么都没被滚」的第二个独立佐证：
抽屉是宽度锚定的，若有东西动了它，x 不可能不动。

## 3. 由此得到的那句话

**648 与 649 那两批的抽屉读数，从未被滚动污染过。**

区别在于这次的说法：

* 648/649 当时的说法是「**没记录到**滚动」—— 那是**没在找**；
* 653 的说法是「**滚动 offset 被断言为 0**」—— 那是**量出来的**。

**「没有怀疑」不是证据，「量到的零」才是。** 这条区别被写成
`648s-and-649s-drawer-readings-were-never-scroll-contaminated` 断言，
而不是留在 README 里当叙述。
