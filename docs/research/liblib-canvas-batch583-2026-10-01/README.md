## 本批结清的两个悬案

1. **统一缩放真实量程 = `0.1–10 step 0.05`**（实测，非推断）。
   batch 580 当时只有截图，按滑块位置推断为 `0–10`，**已更正**；与 582 的
   场景缩放 `0.1–10` 同为倍率滑杆，读数形态也一致（一位小数 / 百分比）。
2. **轴片不只属于场景面板**：对象变换三行（位置/旋转/缩放）每轴都有
   `左右拖动调整 {轴} 轴` 按钮。582 的「待后续」项就此确认并在本批推广。

## clone 合同（CLONE_DECISION）

1. **轴片进 AxisFields**：`SceneAxisScrub` 提升为共享轴片，渲染在
   `AxisFields` 每轴数值框左侧（不可用轴回退为静态字母，保留 575 的
   关键帧菱形徽标位）。aria 逐字沿用源站。拖动灵敏度取该行 step 的
   1/4 像素当量（源站未暴露，记为 CLONE_DECISION）。
2. **步进对齐**：缩放 `0.1` → **`0.05`**（源站实测）；位置 `0.1`、
   旋转 `1` 不变。
3. **统一缩放属性行**：对象属性面板在「缩放」之后、「颜色」之前新增
   `统一缩放`（`range 0.1–10 step 0.05` + 一位小数读数），编辑时三轴
   同写 `scale`。这是 583 相对 clone 的最大新增能力——此前统一缩放只
   存在于运动轨迹页签的关键帧字段组。
4. **颜色行归位**：颜色控件从顶部「可见/未锁定/颜色」按钮行移出，作为
   独立行放在统一缩放之后，并补 hex 文本读数（源站行序 481）。顶部按钮
   行保留 clone 独有的 可见 / 未锁定 两枚按钮。
5. **运动轨迹页签同步**：统一缩放滑杆量程改为 `0.1–10 step 0.05`
   （与 580 的更正一致）；时长滑杆仍为 `0–10`，无源站交互证据，保留标注。
