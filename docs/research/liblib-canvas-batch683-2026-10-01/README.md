# batch 683 —— **12 个窗高下只有一枚控件的尺寸会变**；而 `帮助` 有**两种**互不相同的失效模式

## 一句话

682 在普查里撞见一条读数：`帮助` 在 H=300 时的盒是 32×20，不是 32×32。
本批把这条**意外**推成一条新轴：不问「谁被盖住」，问 **「谁的盒在矮视口下变形」**。

## 仪器

`scripts/verify-liblib-batch683.py`，2 宽度 × **12** 个窗高
（180 / 240 / 300 / 400 / 500 / 600 / 720 / 850 / 1000 / 1150 / 1400 / 1700）= 24 格。
**故意不在这里剔除零尺寸** —— 恒定零尺寸本身是 671 记的盲区，要留下来说话。

## 1. 控件总体在十二格**一格不变**

每格都是 **132 枚**。**布局既不增也不减控件**，无论视口多矮。

## 2. 那 2 枚零尺寸是**恒定**的，不是矮视口造成的

`data-director-viewport=true` **两枚**，盒恒为 `[0, 0, 0, 0]`，二十四格全同。

**这正是 671 记的「恒定零尺寸是普查盲区」** —— 它与窗高无关，
**不能读成「矮视口把它压没了」**（那会是 682 犯过的同一个错）。

## 3. 唯一随高度变形的一枚：`帮助`，阈值正好是 **H = 336**

| 窗高 | `帮助` 的盒 | 相对视口底 |
|---|---|---|
| H ≤ 300 | **`[8, 316, 32, 20]`** | **−156 / −96 / −36（整枚在画布外）** |
| H ≥ 400 | `[8, y, 32, 32]` | **恒为 +8** |

阈值不是我猜的，是从左栏容器量出来的：它的**内容高 284**，`clientHeight = H − 52`，
两者相等处即 **H = 52 + 284 = 336**。

**682 采样的是 300 与 400 —— 跨过了阈值，却没有落在它上面。**
（`scrollHeight` 本身会跟着 `max(284, clientH)` 走，所以它只在真正溢出时才读作 284。）

## 4. 为什么是「掉出画布」而不是「被裁掉」或「能滚动」

左栏容器的 `overflow-y` 在**每一格都是 `visible`**。

所以内容溢出时是**画出盒外**，既不裁也不滚 ⟹
矮视口下 `帮助` 被推出视口下沿，**成为「不在画布上」，而不是「在画布上但点不到」**。

## 5. 两种失效模式，此前只见过一种

| 模式 | 条件 | 681 见过？ |
|---|---|---|
| **被更高的 z 盖住**（`z-40` 底栏压 `z-30` 左栏） | H ≥ 336 | **是**（681 只测了 H ≥ 720） |
| **被推出画布下沿**（`overflow: visible` + 内容 284 > 248） | H < 336 | **否** |

**同一个控件，两种完全不同的失效模式，而 681 的采样区间整段落在第一种。**

## 6. 顺带一条**尺寸侧的异类合并**

两条轨道的 `data-director-track-label` 键，在**每一个高度下都有两种尺寸**：
`24×24` 的导航钮里夹着一枚 `36×18` 的。**这与窗高无关**（十二格恒定），
是**同一个 data 键下两种尺寸的控件** —— **673 那条「异类合并」的尺寸版**
（673 是名字版的：9 枚 20×28 轨道片 + 2 枚 24×24 检视器钮）。

**「随高度变形」与「同一键两种尺寸」是两种异质性，不能混进彼此的统计。**

## 7. 自记：同一个错，本批犯了**三次**

**「跨高度取并集」≠「逐高度比集合」，而我在本批把前者当后者用了三次：**

1. **探针**用 `setdefault` 把每条轨道的 3 枚导航钮折叠成一枚 ⟹ 报「只有 1 个键变形」。
   **这是有 bug 的路碰巧给出了正确答案。**
2. **验收器第一版**改用「跨高度取并集」判变化 ⟹ 报「3 个键变形」——
   因为那两条 `track-label` 键**在每个高度下就有两种尺寸**。
3. **「两个宽度是否一致」那条判据**也用了并集 ⟹ 并集必然含两种尺寸，判据必然失败。

**探针对、验收器错**这件事本身就说明：**答案对不等于路对**，
所以判据里必须写死「逐高度」，并且把 `multi`（同键多尺寸）单列成一条。

## 8. 不声称

- **不声称** H = 336 是源站的行为（**未取证**；这是 clone 的读数）；
- **不声称** H < 336 时 `帮助` 一定「不可点」—— 它在画布外，
  `elementFromPoint` 在视口内**采不到它**；
  这与「采得到但被盖住」是**两种读数**，本批不把前者说成后者；
- **不声称** 12 个窗高覆盖了所有布局临界（本次只测了高度方向的一个临界）。
