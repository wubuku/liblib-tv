- CDP 视口覆盖三档直采（每档重建视频节点后 JS 点角色库 pill）：
  - 1920 → 模态 **1280×720 @ (320, 90)**
  - 1680 → 模态 **1280×720 @ (200, 90)**
  - 1440 → 模态 **1280×720 @ (80, 90)**
- **规则**：模态恒 1280×720，水平居中（x=(vw−1280)/2），顶部 y=90。

- 采样方法学：较窄视口下需**重建视频节点**（面板随节点走，pill 才在
  DOM 内）再 JS 点角色库。
