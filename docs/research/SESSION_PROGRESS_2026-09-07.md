## 2. 采样方法学（重要勘误与结论）

- **「源站会话降级」根因为背景窗口渲染节流**：Chrome 窗口被遮挡时 rAF 冻结，
  floating-ui/Mantine 类浮层（模型菜单、参数菜单、角色库模态）不挂载，展开中
  的面板动画冻结在中间态（如添加面板容器实测 39px，目标态 196px 与 clone 一致）。
  DOM 取证不受影响。详见 batch149/151/153 记录。
- `visibilityState=visible` 不等价于未被遮挡限流；`tell application id
  "com.google.chrome.for.testing" to activate` 可短暂请求前置（System Events
  路径会挂起）。
- 脚本全量扫描**不得**加 `timeout` 前缀（coreutils 的 x86_64 二进制会把 venv
  CPython 带进 Rosetta，Pillow arm64 `.so` 加载失败造成批量误报）。
- 源站 Seedance2.0 承诺书为账号级法律同意，采样时**未代用户同意**，仅点
  「不同意」恢复原状；素材库实际内容因此未采样。
