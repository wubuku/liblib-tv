# 界面与功能参考

画布界面的分区、菜单文字、节点类型与关键规则的速查参考。操作步骤见 [10-tasks/](10-tasks/create-first-node.md) 各分页。

## 界面分区

| 分区 | 内容 |
|---|---|
| 顶部面包屑 | 作品 / 项目 / 画布 三级下拉（如“测试作品 / 测试项目 / 画布 1”） |
| 顶栏右侧 | **使用教程**（外链）、**撤销**、**重做** |
| 左栏（自上而下） | **添加节点**、**查看项目资产**、**从素材库选择**、**本地上传**、**帮助** |
| 左下工具条 | **画布小地图**、**缩小**、缩放百分比、**放大**、**适应画布**、**搜索节点**、**一键整理 · 网格整理**、**选择整理方式** |

## 节点类型

通过“添加节点”菜单或双击空白处弹出的“选择节点类型”菜单创建：

- 文本、图片、视频、音频、3D模型、3D导演台、视频剪辑台；
- “添加资源”组另有**上传文件**；
- 空画布的中央入口提供：文本、图片、视频、音频、3D导演台、上传文件。

节点默认命名为“类型 + 序号”（如“文本节点1”）；副本命名为“原名（副本）”。

## 节点右键菜单

- **复制 ⌘C**
- **复制图片**（无图时禁用）
- **创建副本 ⌘D**
- **重新生成**（禁用）
- **删除 ⌫**

## 画布空白处右键菜单

添加节点、上传文件、粘贴 ⌘V、整理、重置 ⌘0（该菜单项为第一轮观察记录，功能语义与顶栏 / 快捷键一致）。

## 图片节点提示词面板（选中时）

- 工具行：**聚焦**、**故事版**、**参考**；已连接的文本节点显示为引用芯片；
- 面板图标：**删除连线**、**替换参考**、**全屏编辑**、**高级设置**；
- 提示词占位文字：“描述你想要的图像，@引用素材”；
- 模型与规格示例：Seedream 5.0 Pro、2K · 16:9；面板同时显示积分消耗与折扣信息（如“60”“30”“5 折”）；
- 点击生成会触发真实生成并消耗积分，使用前确认面板上的积分提示。

## 文本节点浮动工具条（选中时）

- **全屏查看**
- **下载**

文本节点没有提示词面板；编辑文字请双击文本区域，点击画布空白处提交。

## 搜索

- 入口：左下**搜索节点**按钮或 `⌘F`；
- 占位文字：“搜索节点名称”；
- 无匹配提示：“无匹配节点”；
- 点击结果：选中节点并缩放聚焦。

## 整理方式

| 方式 | 说明（逐字） |
|---|---|
| 按连线横向 | 沿连线从左到右分层 |
| 按连线纵向 | 沿连线从上到下分层 |
| 网格整理 | 保持相对位置去重叠对齐 |

## 项目资产面板

- 分类：角色 / 物品 / 环境；
- 搜索占位：“搜索资产名称...”；
- 空态：“暂无已生成的资产图”。

## 素材库（选择素材对话框）

- 副标题：“从素材库选择图片或视频作为生成参考”；
- 筛选：全部 / 图片 / 视频 / 音频 / 3D、收藏、创建者、创建时间；
- 操作：批量操作、+ 本地上传；
- 空目录提示：“暂无数据”；
- 文件类型：图片、视频、音频，另支持 .txt、.docx、.pdf；图片 / 视频 / 音频素材可多选。

## 连接点与连线

- 每个节点左右各有一个圆形连接点；
- 连线标识格式为“源节点：右侧输出点 → 目标节点：左侧输入点”（内部命名为 `text_out` / `prompt_in`）；
- 在空白处松开拖拽即取消本次连接。

## 持久化与历史

- 刷新后内容保留；撤销 / 重做历史清空；
- 撤销可恢复被删节点并连带恢复连线；
- 初始状态下“撤销”“重做”均为灰色。
