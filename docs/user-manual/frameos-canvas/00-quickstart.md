# 快速上手：创建前两个节点并连成一条线

本页带你用最短路径完成一次画布创作闭环：创建一个文本节点、输入内容、创建一个图片节点，并把两者连接起来。完成本页后，你可以继续阅读 [10-tasks](10-tasks/create-first-node.md) 中的分任务详解。

## 适用角色与前置条件

- 角色：已登录的画布创作者。
- 前置条件：已登录帧界，并打开一个画布（地址形如 `#/canvas/…/…`）。空画布会显示“选择一种方式开始创作”。

## 步骤

1. 在画布空白处**双击**，弹出“选择节点类型”菜单；点击**文本**。画布上出现“文本节点1”，节点自动处于选中状态，“撤销”按钮变为可用。
2. 在“文本节点1”上**双击**节点中的文本区域，文本变为可输入的编辑框；输入你的内容，例如“开场画面：咖啡馆门口”。
3. **点击画布空白处**。编辑框消失，节点上显示你输入的文本——内容已提交。
4. 再次**双击**画布空白处，在“选择节点类型”菜单中点击**图片**。画布上出现“图片节点1”并自动选中，下方展开图片提示词面板。
5. 把鼠标移到“文本节点1”右侧的圆形连接点上，**按住拖到“图片节点1”左侧的圆形连接点上**松开。两个节点之间出现一条连线。
6. 点击左下工具条的**适应画布**，让所有节点进入视野。

## 成功判据

- 画布上有两个节点、一条连线；
- 文本节点显示你输入的内容；
- “撤销”按钮可用（说明以上操作都进入历史，可逐步撤回）。

## 出问题了？

- 双击节点没进入编辑：先单击选中节点，再双击其中的文本区域，见 [10-tasks/edit-selected-node.md](10-tasks/edit-selected-node.md)。
- 连线拖不上去：必须从节点边缘的圆形连接点拖到对方节点边缘的圆形连接点，松开前移出画布空白会直接取消本次连接，见 [10-tasks/connect-nodes.md](10-tasks/connect-nodes.md)。
- 其他问题见 [90-troubleshooting.md](90-troubleshooting.md)。
