# 画布核心概念

解释帧界画布的几个设计概念，帮助你理解各操作背后的统一逻辑。本页不含操作步骤。

## 节点是内容的最小单位

画布上的一切内容都放在节点里：文字在文本节点、画面在图片节点、视频在视频节点。节点默认按“类型 + 序号”命名（文本节点1、图片节点2），序号只增不减，删除节点不影响其他节点的名字。

节点的类型决定它的编辑方式：

- 文本节点在画布上直接双击改文字；
- 图片 / 视频 / 音频等媒体节点选中后在下方面板中填写提示词、选择模型参数；
- 副本节点是完整的内容拷贝，但不继承连线。

## 连线表达“输入从哪来”

连线把一个节点的输出接到另一个节点的输入。每个节点左右各有一个圆形连接点：右侧是输出、左侧是输入。以文本节点 → 图片节点为例，连线承载的是文字到画面描述的引用关系，图片节点的面板中会以引用芯片的形式显示来源。

拖拽连线但松开在空白处，等于取消；已建立的连线通过选中节点后的“删除连线”移除。删除节点时，它与外界的连线一并移除。

## 选中是大多数操作的开关

单击节点选中它：节点出现蓝色边框、露出连接点，并按类型出现对应的工具条和面板。删除（⌫）、复制（⌘D）、编辑内容等操作都作用在“当前选中的节点”上。`Esc` 或点击空白处取消选中。

## 撤销是会话内的安全网

创建、移动、编辑、连线、删除都会进入历史。撤销 / 重做可以逐步回退或重做，其中撤销“删除节点”会把节点连同连线一起恢复——误删并不可怕，当场撤销即可。

历史只存在于当前会话：刷新或重新打开画布后，内容仍在，但撤销 / 重做历史被清空。需要“保存某个版本”时，不能依赖撤销栈，应在删除或大改前想清楚。

## 视野与内容相互独立

缩放（放大 / 缩小 / 适应画布 / ⌘0）只改变“你看画布的方式”，不改变节点位置和大小；整理（网格 / 按连线分层）才真正移动节点位置，因此整理进入撤销历史，缩放不进入。

“聚焦”有两种含义，注意区分：搜索结果点击会把视野缩放聚焦到目标节点；图片节点工具行的“聚焦”按钮则是进入局部框选模式，与视野无关。

## 手册的证据边界

本手册区分三类内容，正文中均有标注：

1. **已验证**：在真实产品中实际执行并确认结果的步骤；
2. **产品声明**：来自内置帮助面板的快捷键与手势，未逐一实测；
3. **未验证**：上传、生成、面包屑层级切换等会触发副作用或超出安全边界的能力，只描述入口，不描述结果。

遇到手册与实际界面不一致时，以实际界面为准，并可通过 [90-troubleshooting.md](90-troubleshooting.md) 的“使用教程”外链查阅官方文档。
