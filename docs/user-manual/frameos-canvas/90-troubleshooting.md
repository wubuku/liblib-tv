# 排障手册

按症状查找画布常见问题的原因与解决办法。

## 编辑文字后内容“丢了”

**症状**：在文本节点里输入了新内容，但节点上显示的还是旧文字。

**原因**：输入过程中编辑尚未提交——只有让编辑框失去焦点，内容才会生效。

**解决**：点击画布空白处。编辑框消失、节点显示新文本即提交成功。

**注意**：按 `Esc` 不会提交也不会取消编辑；提交后可用顶栏**撤销**回退。见 [edit-selected-node.md](10-tasks/edit-selected-node.md)。

## 双击节点没有进入编辑

**症状**：双击文本节点没有出现输入框。

**原因与解决**：先**单击**选中该节点，再双击节点内的文本区域。若仍无响应，检查是否点在其他节点或浮层上——新建节点会自动选中并可能遮挡旧节点，把上层节点拖开再操作。

## 点不到被挡住的节点

**症状**：一个节点压在另一个节点上面，点不到下层。

**解决**：拖动上层节点挪开；或用**搜索节点**（`⌘F`）点击结果直接选中目标节点。长期整理可使用**一键整理 · 网格整理**，见 [organize-and-search.md](10-tasks/organize-and-search.md)。

## 连线拖不上去

**症状**：从一个节点拖到另一个节点，松手后没有连线。

**原因**：连线必须从节点边缘的**圆形连接点**开始、到对方节点边缘的圆形连接点结束；拖动中在画布空白处松开会直接取消本次连接。

**解决**：对准左右圆形连接点重新拖拽。见 [connect-nodes.md](10-tasks/connect-nodes.md)。

## 误删了节点或连线

**解决**：立即点击顶栏**撤销**（或 `⌘Z`）。删除节点时连带移除的连线会一起恢复。

**注意**：如果已经刷新过页面，撤销历史会被清空，无法再恢复——删除前请确认（见下一条）。

## 刷新后“撤销”变灰

**症状**：画布内容都在，但撤销 / 重做按钮是灰色的。

**原因**：撤销历史不跨会话。刷新或重新打开画布后内容保留，但历史清空。

**解决**：这是正常行为。之后的操作会重新进入历史。见 [duplicate-delete-history.md](10-tasks/duplicate-delete-history.md)。

## 搜索不到某个节点

**症状**：在搜索框输入名称后显示“无匹配节点”。

**原因与解决**：搜索按节点名称匹配。确认关键词与名称一致（例如“图片节点1”）；副本节点名称带“（副本）”后缀，输入更短的关键词（如“图片”）更容易命中。

## 想取消当前的拖拽 / 弹层

- 连线拖到一半：在画布空白处松开即取消，不会留下半截线；
- 各类面板与对话框：点右上角 ×、“取消”，或按 `Esc`；
- 选中状态：按 `Esc` 或点击空白处。

## 图片节点进入“聚焦模式”后想退出

**症状**：点了图片节点工具行的**聚焦**，节点提示“请选择一张图像进行「局部框选」操作”。

**解决**：点击顶部条的**退出**或按 `Esc`。“聚焦模式”用于在已生成的图片上框选局部区域，画布视野并没有变化。

## 素材库 / 资产面板是空的

**症状**：项目资产面板显示“暂无已生成的资产图”，素材库目录显示“暂无数据”。

**解决**：资产图来自项目内已生成的内容；素材库当前目录没有文件时先用**+ 本地上传**上传，或切换到有文件的目录。上传入口见 [canvas-context.md](10-tasks/canvas-context.md)。

## 还是解决不了

- 点击顶栏**使用教程**查看官方完整文档；
- 把问题现象、操作步骤和截图反馈给项目管理员。
