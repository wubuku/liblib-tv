# 帮助与快捷键

打开画布内置的快捷键帮助，掌握常用快捷键，并了解“使用教程”外链。

## 适用角色

已登录的画布创作者。

## 前置条件

已登录并打开一个画布。

## 打开与关闭帮助

- 点击左栏的**帮助**按钮，左侧滑出“快捷键”面板；
- 点击面板右上角 × 关闭；`Esc` 亦可关闭。
- 画布顶栏的**使用教程**会打开外部网页版教程（飞书云文档），用于查阅完整产品手册。

![帮助面板：快捷键总览](../screenshots/18-help-shortcuts.png)

## 使用建议

- 先记住三个高频键：`⌘Z` 撤销、`⌫` 删除、`⌘F` 搜索。
- 手势类操作（触控板、滚轮、空格拖动）在不同设备上表现可能不同，以实际效果为准。
