# 移动画布视野并控制缩放

调整画布视野：放大查看节点细节、缩小总览全局、一键让所有内容回到视野中。

## 适用角色

已登录的画布创作者。

## 前置条件

已登录并打开一个画布。

## 入口

画布左下工具条：**画布小地图**、**缩小**、当前缩放值（如 100%）、**放大**、**适应画布**，以及右侧的**搜索节点**、**一键整理 · 网格整理**、**选择整理方式**。

![左下画布工具条](../screenshots/03-navigate-canvas-toolbar.png)

## 原子步骤

### 放大与缩小

1. 点击**放大**或**缩小**。每点击一次，缩放值约变化一档（实测从 112% 到 98% 再到 85% 的步进幅度）。
2. 观察工具条中央的缩放百分比，它实时反映当前视野。

### 让所有内容回到视野

1. 在任意缩放状态下点击**适应画布**。
2. 缩放自动调整、视野自动平移，直到所有节点可见（实测把 273% 的聚焦视野一键恢复为 100%）。

### 重置视图

1. 按 `⌘0`。缩放恢复为 100%。

### 小地图

1. 点击**画布小地图**：左下角的小地图隐藏（按钮为开关）。
2. 再次点击：小地图重新出现。小地图中的缩略块表示各节点的相对位置。

### 整理布局（与视野配合）

内容排布混乱时，点击**一键整理 · 网格整理**：节点位置小幅归位、视野自动适配（实测缩放从 100% 调整为 112%）。整理属于历史操作，可用**撤销**回退。三种整理方式的差别见 [organize-and-search.md](organize-and-search.md)。

![网格整理后的布局与视口适配](../screenshots/13-grid-organize.png)

## 成功判据

- 缩放百分比按预期变化；
- “适应画布”后所有节点在当前窗口内可见；
- 小地图随开关出现/消失。

## 手势说明：已验证与产品声明

下表区分两类内容：**已验证**为本手册在真实产品中执行过的操作；**产品声明**来自帮助面板，供参考。

| 操作 | 状态 | 说明 |
|---|---|---|
| 放大 / 缩小按钮 | 已验证 | 步进缩放 |
| 适应画布按钮 | 已验证 | 全部内容入画 |
| `⌘0` 重置视图 | 已验证 | 恢复 100% |
| 小地图开关按钮 | 已验证 | 显示 / 隐藏小地图 |
| 双击节点聚焦 | 产品声明 | 帮助面板写明“双击节点聚焦填满视口” |
| 鼠标滚轮 + ⌘ 滚轮缩放 | 产品声明 | 未逐项验证 |
| 空格拖动、左键拖动、中键 / 右键拖动、滚轮平移 | 产品声明 | 注意：实测按住左键拖动画布空白处**不会**平移视野，移动视野请优先使用小地图或“适应画布” |
| 触控板双指捏合缩放 / 双指平移 | 产品声明 | macOS 触控板手势，未逐项验证 |

## 恢复

- 缩放乱了：点**适应画布**，或按 `⌘0`。
- 整理后布局不满意：顶栏**撤销**。
