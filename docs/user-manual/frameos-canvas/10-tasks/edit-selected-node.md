# 编辑选中的节点

选中节点后修改它的内容：编辑文本节点里的文字，或为图片节点填写提示词、选择模型参数。删除连线、替换参考等与“连接”相关的操作见 [connect-nodes.md](connect-nodes.md)。

## 适用角色

已登录的画布创作者。

## 前置条件

画布中已有至少一个节点（创建方法见 [create-first-node.md](create-first-node.md)）。

## 入口

直接在画布上**单击**节点。选中后：

- 节点出现蓝色边框，左右两侧露出圆形连接点；
- 文本节点上方出现“全屏查看”“下载”两个图标按钮；
- 图片节点上方出现工具行，下方展开提示词面板。

![文本节点选中态：边框、连接点与浮动工具条](../screenshots/08-select-text-node.png)

## 编辑文本节点

1. **单击**选中文本节点。
2. **双击**节点中的文本区域。文本变为可输入的编辑框，光标在框内。
3. 输入或修改内容。此时节点上显示的还是旧文本——内容尚未提交。
4. **点击画布空白处**。编辑框消失，节点显示新文本，编辑已提交。

![双击进入 textarea 编辑态](../screenshots/04-edit-selected-node.png)

成功判据：编辑框消失、节点显示新文本、顶栏“撤销”变为可用。

注意：

- 按 `Esc` **不会**提交也不会取消编辑——想让内容生效，请点击画布空白处。
- 编辑提交后可用顶栏**撤销**回退。

## 图片节点的提示词面板

1. **单击**选中图片节点。下方展开面板：工具行有**聚焦**、**故事版**、**参考**；提示词输入框显示占位文字“描述你想要的图像，@引用素材”。
2. 与文本节点相连时，工具行会显示该文本节点的引用芯片，可通过芯片上的移除按钮断开引用。
3. 在输入框中填写画面描述后，可在下方切换模型（如 Seedream 5.0 Pro）与规格（如 2K · 16:9），或打开**高级设置**。
4. 面板右侧的**全屏编辑**可展开更大的编辑区。

![图片节点选中面板](../screenshots/09-image-node-panel.png)

注意：点击生成按钮会触发真实图片生成并消耗积分，这超出本手册的记录范围，请按产品内的积分提示自行确认。

## 聚焦模式

选中图片节点后点击工具行中的**聚焦**，节点进入“聚焦模式”：在已生成的图片上框选局部区域作为聚焦范围，顶部条提供“返回节点”与“退出”，按 `Esc` 也可退出。节点还没有生成图片时，浮层会提示先选择一张图像。

![聚焦模式提示与“选择节点类型”菜单](../screenshots/19-focus-mode-and-addmenu.png)

## 取消与恢复

- 取消选中：按 `Esc`（已验证）或点击画布空白处。
- 编辑内容回退：顶栏**撤销**；撤销后再**重做**可恢复。
