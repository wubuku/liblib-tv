# 复制、删除并恢复节点

复制已有节点快速产出同类内容，删除不需要的节点，并利用撤销 / 重做在误操作后恢复画布。

## 适用角色

已登录的画布创作者。

## 前置条件

画布中已有至少一个节点。

## 入口

在节点上**右键**，打开节点菜单：

- **复制 ⌘C**
- **复制图片**（无图可复制时为灰色禁用）
- **创建副本 ⌘D**
- **重新生成**（灰色禁用）
- **删除 ⌫**

![节点右键菜单](../screenshots/11-node-context-menu.png)

## 创建副本

1. 在节点上**右键**，点击**创建副本 ⌘D**（或选中节点后直接按 `⌘D`）。
2. 画布出现一个新节点，命名为“原名（副本）”，位置在原节点右下方一点，并自动选中。
3. 副本不携带原节点的连线——需要连线请重新拖拽（见 [connect-nodes.md](connect-nodes.md)）。

对副本再次创建副本时，名称会在“（副本）”后继续追加。

## 删除节点

1. 选中要删除的节点。
2. 按 `⌫`（或在节点上右键点击**删除 ⌫**）。
3. 节点从画布消失，同时它上面的连线一并移除。

## 用撤销 / 重做恢复

- 顶栏**撤销**（或 `⌘Z`）：回退上一步操作。撤销“删除节点”时，节点和它的连线一起恢复（已验证）。
- 顶栏**重做**（或 `⌘⇧Z`）：把刚撤销的操作重新执行。
- 撤销后“重做”才会亮起；没有可撤销的操作时“撤销”是灰色。

成功判据：误删后按一次撤销，节点与连线重新出现在原位置。

## 持久化边界（重要）

- **刷新或重新打开画布后**：节点、连线、文本等内容都还在；
- 但撤销 / 重做历史会清空——刷新后两个按钮回到灰色，无法再撤回刷新之前的操作。

因此：删除关键节点后不要依赖“刷新再来”，先当场用撤销恢复。

## 尚未验证的能力

以下能力在帮助面板中有声明，但本手册未能逐一实测，请以实际产品为准：

- **复制 ⌘C / 剪切 ⌘X / 粘贴 ⌘V**：跨位置的节点复制粘贴；
- **拖拽复制（按住 ⌥ 拖动节点）**。
