# 创建节点

在画布中创建文本、图片、视频、音频、3D模型、3D导演台或视频剪辑台节点。这是画布创作的基本动作：任何画布内容都从一个节点开始。

## 适用角色

已登录的画布创作者。

## 前置条件

- 已登录并打开一个画布。
- 空画布直接显示“选择一种方式开始创作”；已有内容的画布请使用下方任一入口。

## 入口（三选一）

1. **空画布中央 CTA**：空画布上直接点击“文本”“图片”“视频”“音频”“3D导演台”“上传文件”之一。
2. **左栏“添加节点”按钮**：点击后弹出菜单，分“添加节点”（文本、图片、视频、音频、3D模型、3D导演台、视频剪辑台）和“添加资源”（上传文件）两组。
3. 双击画布空白处（早期版本的源站支持；**当前版本已移除该入口**，请使用左栏 添加节点 菜单）。

![添加节点菜单](../screenshots/06-add-node-menu.png)

## 原子步骤

1. 打开上述任一入口。
2. 点击需要的节点类型（例如**图片**）。菜单自动关闭。
3. 观察画布：新节点出现在画布中，命名为“图片节点2”这样的“类型 + 序号”格式，并自动处于选中状态。
4. 若是图片节点，节点下方会同步展开提示词面板，可直接输入画面描述；文本节点则无此面板。
5. **拖动节点主体**可以把节点移动到合适位置，拖动结束后节点保持选中。

![创建图片节点后自动选中并展开面板](../screenshots/07-create-image-node-result.png)

## 成功判据

- 画布上出现新节点，命名遵循“类型 + 序号”；
- 节点呈选中态（蓝色边框）；
- 顶栏“撤销”按钮变为可用——说明创建已进入历史，可随时撤回。

## 取消与恢复

- 创建错了类型：点击顶栏**撤销**（或按 ⌘Z，见 [help-and-shortcuts.md](help-and-shortcuts.md)），节点即被移除；撤销后再点击**重做**可恢复。
- 节点互相遮挡时，拖动上层节点挪开即可点到下层节点。

## 已知边界

- 节点序号按同类型节点递增，删除中间节点不会让后续节点改名。
- “上传文件”与素材库上传流程见 [canvas-context.md](canvas-context.md)；本页不涉及触发图片或视频生成。
