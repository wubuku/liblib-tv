# 搜索节点并整理画布布局

节点很多时，按名称快速定位某个节点，或让画布自动整理布局。

## 适用角色

已登录的画布创作者。

## 前置条件

画布中已有节点；搜索按节点名称匹配（节点默认命名为“类型 + 序号”，例如“图片节点1”）。

## 入口

画布左下工具条：**搜索节点**、**一键整理 · 网格整理**、**选择整理方式**；搜索也可用快捷键 `⌘F`。

## 搜索节点

1. 点击**搜索节点**（或按 `⌘F`）。工具条上方弹出搜索框，占位文字为“搜索节点名称”。
2. 输入名称关键词，例如“图片”。下方实时列出匹配的节点（带类型图标）。
3. 点击结果中的某个节点：该节点在画布上被选中，视野自动缩放聚焦到它（实测从 100% 聚焦到 273%）。
4. 没有匹配时，结果区显示“**无匹配节点**”。
5. 完成后按 `Esc` 关闭搜索框。

![搜索“图片”命中三个节点](../screenshots/12-search-nodes.png)

成功判据：点击结果后目标节点呈选中态且位于视野中央附近。

## 一键网格整理

1. 点击**一键整理 · 网格整理**。
2. 节点位置自动归位、视口自动适配（实测缩放随之从 100% 调整到 112%）。
3. 对结果不满意时，顶栏**撤销**即可回到整理前。

![网格整理后的布局](../screenshots/13-grid-organize.png)

## 选择整理方式

1. 点击**一键整理 · 网格整理**右侧的**选择整理方式**箭头。
2. 菜单中三种方式的名称与说明逐字为：
   - **按连线横向**：沿连线从左到右分层；
   - **按连线纵向**：沿连线从上到下分层；
   - **网格整理**：保持相对位置去重叠对齐。
3. 点击其中一种即切换默认整理方式；当前方式在菜单中带勾标。之后再点**一键整理**按钮就按所选方式执行。

![整理方式菜单](../screenshots/14-organize-options.png)

## 恢复

- 整理是历史操作：顶栏**撤销**可完整回退。
- 聚焦后视野乱了：**适应画布**或 `⌘0`（见 [navigate-canvas.md](navigate-canvas.md)）。
