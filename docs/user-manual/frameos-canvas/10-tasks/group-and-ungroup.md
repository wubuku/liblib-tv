# 成组、排列与解组节点

把多个相关节点编成一个"组"，统一移动、统一换色、一键整齐排列；不再需要时解组还原。

## 适用角色

已登录的画布创作者。

## 前置条件

画布中已有至少两个节点。

## 入口

**左键拖动画布空白**框选至少两个节点，选中集合上方出现**成组工具条**：

- **成组**
- **批量下载**

## 创建分组

1. 框选要编组的节点。
2. 点击工具条上的**成组**。
3. 画布出现一个包住全部成员的**分组框**，左上角自动命名为"组1"（再建一组就是"组2"，以此类推），节点本身的选中态取消、分组框呈选中态。
4. 分组框四周出现四个角点；同时工具条展开为分组工具条：
   **切换背景色**（色点）、**排列方式**、**整组执行**、**存为模板**、**解组**、**批量下载**（悬停提示"打包下载 N 个文件"，N 为组内有图片/音频等文件的成员数）。

成功判据：拖动分组框时，组内所有节点跟随一起移动，组外节点不受影响。

![成组后分组框与展开工具条](../screenshots/21-group-created-toolbar.png)

## 更换分组颜色

1. 选中分组，点击工具条最左侧的**切换背景色**色点。
2. 在弹出的色板中点一种颜色（共 10 种；当前颜色带蓝色描边）。
3. 分组的填充、边框和四个角点立即换成所选颜色，色板自动收起。

![分组背景色板](../screenshots/22-group-color-popover.png)

## 一键排列组内节点

1. 选中分组，点击**排列方式**。
2. 在菜单中选择：
   - **宫格排列**：按方形网格排布（3 个节点排 2+1，4 个排 2×2）；
   - **水平排列**：排成一行；
   - **垂直排列**：排成一列。
3. 组内节点按各自当前位置从上到下依次排序重排，间距统一，分组框自动收缩到恰好包住新布局。

成功判据：点"水平排列"后，组内节点顶边对齐、横向间距一致，无重叠。

## 解组

1. 选中分组，点击**解组**。
2. 分组框与角点消失，组内节点留在原地（位置不变），恢复为普通节点。

## 边界与说明

- **撤销/重做（`⌘Z`）不覆盖分组操作**——解组后无法用撤销找回分组，需要重新成组。
- **本原型为内存态演示**：刷新页面后画布回到初始示例数据，分组与节点位置不会保留（与源站的服务端持久化不同）。
- **批量下载**：逐个下载组内有媒体的节点文件，并提示"已开始下载 N 个素材"。
- **整组执行**：对应源站的付费生成入口，本原型中按钮存在但点击无效果。
- **存为模板**：点击提示"已存为模板 (mock)"，不会真正保存模板。
