# 创建画布项目并认识工作区

- **适用角色**：所有 TDCanvas 用户（无需登录，本地使用）。
- **目标**：创建一个画布项目，认识编辑页的工作区布局，并学会回到项目列表。
- **前置条件**：TDCanvas 已启动（桌面客户端，或本地 Web 版）。
- **入口**：首页「新建画布 →」按钮；或首页顶部导航「我的画布」。

## 步骤

### 1. 打开首页

启动 TDCanvas 后默认进入首页 `我的画布`。首次使用时页面显示：

- 大标题「从一张画布开始」与紫色「新建画布 →」按钮；
- 「最近画布」区（首次为空，显示「还没有画布」）；
- 右上角实时预览窗（当前为空时显示占位）。

![首页空态](../screenshots/01-create-canvas-project-empty-home.png)

> 顶部导航还可以前往：ComfyUI 本地、提示词库、我的资产、配置；右上角提供 Agent 面板、中/EN 切换与明暗主题切换。完整清单见 [00-quickstart.md](../00-quickstart.md) 的「顶部导航都有什么」。

### 2. 新建画布

点击「新建画布 →」。TDCanvas 会立即创建一个新项目（自动命名，如「TDCanvas 1」；再新建会是「TDCanvas 2」，编号自动递增），并直接进入画布编辑页。

**关于编号**：首次安装时编号从 1 开始。如果你的第一个项目叫「TDCanvas 2」，通常是之前删除过项目留下的递增计数——不影响使用。

### 3. 认识编辑页工作区

![新建后的空画布](../screenshots/01-create-canvas-project-empty-canvas.png)

这是一张**无限画布**：你可以把窗口想象成俯视一张无限大的纸，拖动画布就是在纸上平移视角。

| 区域 | 内容 |
|---|---|
| 顶栏 | 主页（返回首页）、画布菜单、项目标题（双击可改名）、本地 Codex 面板、配置、中/EN、明暗主题、快捷键 |
| 中央 | 无限画布；空画布时提示「双击画布，自由创作」，下方一排快捷芯片：文字创作、图片创作、视频创作、音频创作、上传素材 |
| 左侧 Dock | 新建（+）、搜索节点、资产、提示词库、历史（撤销/重做）、上传资产、画布外观、（**仅单选时**出现）删除选中、快捷键 |
| 左下缩放 Dock | 打开小地图、隐藏连线、网格吸附、重置视图、5%–500% 缩放滑杆 |

### ★ 左侧 Dock 上的按钮全是纯图标，但停上去都有名字

上面两张表列的那些名字，**在 Dock 上一个都看不到**。2026-10-03 逐个实测主列 8 个按钮：**可见文字 0 个、`title` 属性全部是 `null`**。整条 Dock 上不悬停时能看见的文字只有两处：「＋」按钮上方那个「**新建**」小徽标，和缩放滑杆旁的**百分比读数**（如 `91%`）。

![画布左侧的悬浮按钮条，从上到下只有一排没有任何文字标注的图标，加号、放大镜、文件夹、星形、时钟、上传箭头、调色板和一把剪刀，加号右上角有一个写着「新建」的小徽标](../screenshots/00-dock-icon-only.png)

**但把鼠标停上去，每个按钮都会弹出名字**——本手册此前说这里有 9 个按钮连悬停都没有提示，**那是错的，已订正**（见下方引用块）：

![同一条左侧按钮条，「历史」那一格被点亮、右侧弹出一个写着「历史」的圆角标签，底部的剪刀按钮是红色的，加号右上角仍挂着「新建」徽标](../screenshots/00-dock-hover-tooltip.png)

| 停上去弹出的名字 | 按钮长相 | 位置 |
|---|---|---|
| 添加节点 | ＋ | 主列第 1 个（唯一的大号圆钮，40×40） |
| 搜索节点 | 放大镜 | 主列第 2 个 |
| 资产 | 打开的文件夹 | 主列第 3 个 |
| 提示词库 | 星形 | 主列第 4 个 |
| 历史 | 时钟 | 主列第 5 个 |
| 上传资产 | 上传箭头 | 主列第 6 个 |
| 画布外观 | 调色板 | 主列第 7 个 |
| 清空画布 | 剪刀（**红色**） | 主列最下面一个 |
| 删除选中 | 垃圾桶 | **只在单选时出现**，插在调色板和剪刀之间 |

> ⚠️ **订正：本手册此前写「悬停提示只有 6 个、9 个完全没有提示」，那是错的。**
> 2026-10-03 用「悬停前后全页可见文本取差集」重测，**主列 8 个按钮（含单选时出现的「删除选中」）的悬停提示一个都不缺**，浮层里写的名字与上表逐字一致。
> **读错的原因**：Dock 的浮层是自研组件，类名是 `pointer-events-none absolute left-[calc(100%+8px)]`，**里面没有 tooltip / tip 任何字样**；而同一区域里左下角那 4 个视图控制按钮用的是 antd 原生浮层 `div.ant-tooltip`。此前只按 `tooltip` 字样找浮层，**就只抓到了后者，把前者整批读成了「无提示」**。
> **教训**：同一块界面里并存两种浮层实现时，按类名找浮层必然漏掉一半。**这是量具的毛病，不是产品的毛病。**

**还有一个订正**：本手册此前把「**主页**」列进了 Dock 那张「悬停有名字」表里。**主页不在 Dock 上**——它在顶栏最左边（`x=20`），而 Dock 的「添加节点」也在 `x=20`（`y=325`），两个按钮**横坐标完全一样**，按位置粗筛极易混为一谈。实测 Dock 容器里只有上表这 8 个按钮，「主页」是顶栏那 1 个。

**记不住就停一下**：这套按钮**位置固定、顺序固定**，从上到下永远是「＋ / 放大镜 / 文件夹 / 星形 / 时钟 / 上传箭头 / 调色板 /（选中时）垃圾桶 / 剪刀」。认图标不如记顺序，但**停一下看名字最快**。

### ★ 顶栏也有两个按钮是真的认不出来

顶栏一共 11 个可点的东西。2026-10-03 逐个实测，**9 个停上去有名字**（或本身印着字），**只有 2 个什么都不给**：

![画布顶栏左侧，鼠标停在青色的主页方块上、下方弹出「主页」标签，而它右边那个三横线的汉堡按钮停在原地、什么提示都没有](../screenshots/00-topbar-two-blank.png)

| 认不出的 | 它在哪、长什么样 | 你只能靠什么认出它 |
|---|---|---|
| **画布菜单**（俗称汉堡按钮） | 顶栏最左，主页按钮右边，三条横线 | 位置——它永远是画布名左边那个 |
| **右侧面板拖动把手** | 贴窗口右缘的一根竖条，Agent 面板打开时移到面板左缘 | 位置——就是那条能拖宽窄的分隔线 |

> **认不出来不是你的问题。** 这两个按钮停上去**既没有悬停提示也没有原生提示**，界面上任何地方都不会显示它们叫什么。好在它们都是这条边上**唯一**的东西——三横线只出现在画布名左边，拖把手是那条竖线，位置认比长相认可靠。

其余 9 个分别是：主页（停上去显示「主页」）、项目标题（**双击可改名**，停上去写「双击修改画布名称」）、本地 Codex 状态灯（停上去写当前连接状态）、配置、语言切换（按钮上印一个「**中**」字，停上去写「切换到 English」）、明暗主题、版本号（印着 `v0.14.0`，停上去写「查看版本更新」）、快捷键、Agent。

> **「切换到浅色主题」按钮里藏着一个看不见的字**：它确实有一个写着「切换到浅色主题」的文字节点，但那个节点只有 **1×1 像素**——占不了地方，等于没有。**只有浏览器自己弹出的原生提示在起作用**（本应用里叫 `title` 属性）。这类「明明有字却看不见」的节点在应用里不止一处，Agent 面板顶部那排图标按钮里的文字更极端，是 **0×0**。

**两个容易踩的坑**：

**① 「清空画布」和「裁剪」是同一把剪刀。** 选中一个**已经放了图**的图片节点时，节点上方工具条里有一个「裁剪」，左侧 Dock 里有一个「清空画布」——**两者的图标逐字相同**（都是 `lucide-scissors`），而且**它们会同时出现在同一屏上**。

> **注意前提**：图片节点**刚建出来、还没放图**时，工具条上**没有「裁剪」**（那时只有 4 个按钮：信息、删除、编辑、上传图片）。**所以你得先放一张图，才谈得上「两把剪刀同屏」这回事。** 对照表见 [edit-nodes.md 的工具条一节](edit-nodes.md#悬浮工具条-每个节点类型都不一样)。

![画布整屏，左侧是一条常驻的竖排图标按钮条，选中的图片节点上方浮出一条横排工具条，右侧是打开着的 Agent 面板，三处都能看到成对出现的相同图标，但彼此相距很远](../screenshots/04-icon-reuse-same-screen.png)

> ⚠️ **但别把这条读成「你分不清哪个是哪个」**（本手册此前就是那么写的，2026-10-02 已订正）。实测两把剪刀的横向距离是 **931 像素**（Dock 的在 `x=32`、工具条的在 `x=963`），**一个在常驻的左边竖排、一个在跟着节点走的横条上，位置差别一眼可见**，再加上 Dock 那个是红色且点了会弹确认框。**真正的提醒只有一句：这两处剪子功能完全不同，别顺手点到错的那把。**

### 图标会被复用，认按钮要靠位置不要靠长相

这不是 Dock 独有。2026-10-02 把**全应用 36 个可见图标**（在画布空白、选中节点、打开 Agent 面板三种状态下各扫一遍）按类名分组，发现 **9 个图标被用在了不止一个功能上**：

| 图标 | 用在哪些功能上 | 会不会同屏 |
|---|---|---|
| `sparkles` 星形 | 顶栏**主页** · Dock **提示词库** · Agent 面板**技能** | 不同屏 |
| `plus` 加号 | Dock **添加节点** · Agent 面板**新对话** | 不同屏 |
| `scissors` 剪刀 | Dock **清空画布** · 工具条**裁剪** | **同屏，相距 931 px** |
| `upload` 上传箭头 | Dock **上传资产** · 工具条**替换图片** | **同屏，相距 815 px** |
| `trash2` 垃圾桶 | 工具条**移除节点** · Dock **删除选中** | **同屏** |
| `message-square` 对话气泡 | Agent 面板**对话** · 工具条**编辑** | **同屏** |
| `bot` 机器人 | 顶栏 **Agent** 按钮 · 面板内另一个 | — |
| `plug-zap` 插头 | 面板顶栏**连接设置** · 连接状态指示 | — |
| `copy` 复制 | 多处复制按钮（同一个功能，合理） | — |

> **所以：认按钮要靠位置，不要靠长相。** 四处按钮区的顺序都是固定的（左侧 Dock 见上文清单、节点工具条见 [edit-nodes.md](edit-nodes.md) 的按钮表、Agent 面板见 [use-agent.md](use-agent.md)、顶栏见上文那节），**记住顺序比认图标可靠得多**。实在认不出就悬停一下——**这四处里，除了顶栏那两个按钮（画布菜单、右侧面板拖动把手），停上去都有名字。**

**② 「删除选中」只在单选时出现，多选时它就没了。** 实测：未选中时 Dock 15 个按钮 → 单选后 16 个（多出垃圾桶「删除选中」）→ **再按住 Shift 多选，垃圾桶又消失，回到 15 个**。所以**要一次删掉多个节点，别指望用 Dock 的垃圾桶**，走画布上的右键菜单（那个多选时仍然有「删除」）。

中央那排快捷芯片是**快捷入口**，不是必走的流程——等画布已有内容后它们会消失，此时用左侧 Dock 的「+」按钮（弹「添加节点」菜单）或直接双击空白处创建节点。

![左侧 Dock 的「+」按钮打开添加节点菜单](../screenshots/30-concepts-add-node-menu.png)

画布内容会**自动保存**在本机，无需手动保存。这意味着关掉页面不会丢东西，但也意味着**删掉的项目不会自动找回**——重要项目请用首页的导出功能留一份 zip 备份。

### 4. 回到项目列表

点击顶栏「主页」按钮回到首页。「最近画布」区现在会显示项目卡（标题、节点数与连线数、更新时间），点击卡片即可重新进入画布。

![首页项目卡](../screenshots/13-project-management-home-with-card.png)

卡片上的「N 个节点 · M 条连线」能让你在进入前就大致判断这个项目的复杂度——节点很多的项目通常加载稍慢。

## 成功判据

- 浏览器地址为 `/canvas/<项目ID>`，顶栏显示项目标题；
- 首页「最近画布」出现该项目卡片，卡片显示正确的节点计数与更新时间。

## 取消与恢复

- 误建了空项目：回到首页，将鼠标悬停在项目卡上使用删除（有确认弹窗）；首页多选模式下可批量删除。
- 项目标题想改：见 [project-management.md](project-management.md)（双击顶栏标题或首页卡片重命名）。
