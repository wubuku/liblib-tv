# 管理我的资产

- **适用角色**：所有 TDCanvas 用户。
- **目标**：把常用的提示词、参考图片等素材存进「我的资产」，随时检索、编辑、导出和备份。
- **前置条件**：已启动 TDCanvas 并登录本机工作区。
- **入口**：顶部导航的「**我的资产**」。

「我的资产」是独立于画布项目的**素材仓库**：画布项目存节点和连线，资产库存可复用的文本与图片。两者互不影响，资产保存在本机。

![资产页空态与工具栏，右上角高亮「新增资产」按钮](../screenshots/14-manage-assets-add-entry.png)

## 新增一个文本资产

1. 点击右上角「**新增资产**」，弹出「新增资产」窗口。
2. 「类型」选「文本」（默认）。
3. 「标题」填写便于检索的名字——必填。
4. 「封面 URL」可留空；需要缩略图时粘贴图片地址，或点「上传」选择本地图片。
5. 「标签」输入后按**回车**逐个添加（如「摄影」「产品」）。
6. 「来源」可填「手动添加 / 画布 / 提示词库」等字样；「备注」为可选项。
7. 「文本内容」填写正文——文本类型必填。

![新增资产窗口，标题、标签、来源与文本内容均已填写](../screenshots/14-manage-assets-add-form.png)

8. 点「**保 存**」。窗口关闭，右上角出现「资产已保存」提示，卡片出现在列表中。

![保存后的资产卡片，底部有编辑、复制、删除三个操作](../screenshots/14-manage-assets-card.png)

## 搜索与筛选

- **搜索**：在搜索框输入关键词，匹配**标题、内容、标签或来源**四个字段。输入即过滤，标题右侧的 `当前 / 全部` 计数同步变化。
- **类型筛选**：点「全部 / 文本 / 图片 / 视频」切换。实测只有一个文本资产时，选「图片」或「视频」会显示 `0 / 1` 与空态「没有找到资产」。

> **2026-10-01 M100 复测：把计数语义钉死（此前的证据跑在退化状态上）**。手册原来记的是「有一个资产时看到 `1 / 1`」——**只有一条数据时，`1 / 1` 同时符合好几种解释**，它证明不了分母到底是不是"全部资产"。本批先手动录入 3 条文本资产再逐项读数：
>
> | 操作 | 计数 | 空态 |
> |---|---|---|
> | 「全部」筛选 | `3 / 3` | 否 |
> | 「文本」筛选 | `3 / 3` | 否 |
> | 「图片」筛选（一条图片都没有） | `0 / 3` | **是** |
> | 「视频」筛选（一条视频都没有） | `0 / 3` | **是** |
> | 搜索「摄影」（命中标题与标签各一条，实际 1 张卡） | `1 / 3` | 否 |
> | 搜索一个不存在的词 | `0 / 3` | **是** |
>
> **两个值得记住的点**：① **斜杠右边永远是"全部资产数"，不随筛选或搜索变**——所以 `0 / 3` 的意思是"当前一条都没匹配上，库里一共 3 条"，不是"库里空了"；② **搜索与筛选是叠加的**，分母也**不跟着搜索结果变**。每次读数都**连读两次确认一致**才采信（见下方教训）。
>
> **顺带记一条方法论教训（来自 M99）**：M99 出了一次"结论其实错了但看起来很有依据"的事故——根因是**读到了写盘尚未落定的旧值**。本批因此给所有计数读数加了**连读两次、取一致值**的前置条件，六次读数**全部两次一致**，没有再出现陈旧值。**判据选对了不等于读数可信；跨页读持久化数据时，先确认它已经落定。**

![搜索关键词后仅剩匹配的一个资产卡片](../screenshots/14-manage-assets-search.png)

## 批量下载

「批量下载」这个名字有点误导：**点它不会下载任何东西**，它只是把你切换到**勾选模式**。真正的下载动作在下一步的工具栏里。

1. 点工具栏「**批量下载**」进入勾选模式。每张卡片右上出现圆形勾选框，**卡片底部的操作条会整条隐藏**（避免误点编辑/删除），工具栏变成「已选 N 项 / 全选当前结果 / 下载 ZIP / 取消」。
2. 点「**全选当前结果**」勾选当前筛选出的全部资产。注意「当前结果」四个字——它跟着筛选走：先按「图片」筛选再全选，就只会勾中图片，不会把文本一起打包。
3. 点「**下载 ZIP**」打包下载；点「取消」退出勾选模式。

![批量下载选择模式，工具栏显示已选 0 项与全选当前结果、下载 ZIP、取消](../screenshots/14-manage-assets-batch.png)

**一个容易卡住的地方**：「下载 ZIP」在没有勾选任何资产时是**不可点**的。它不是坏了，是还没到能下载的状态——先勾选或全选，它才会变亮可点。

> **两个和「看起来」不一样的地方**（2026-10-03 实测）：它**真的是禁用态**（`disabled=true`，不是仅仅画得灰），而**背景色本来就是紫色** `rgb(117,107,255)`——**没勾选时它一直是紫的**，只是 `opacity` 只有 0.4，半透明的紫在深色主题下看着偏灰。所以别去找「那个灰色的按钮」，它从来不是灰的。
> 另一半更坑：**光标在禁用时仍然是手型**（`cursor=pointer`）。鼠标扫过去会亮起一个可点的手势，**点下去什么也不会发生**——这不像坏了，更像卡住了。

> **★ 两端都实测过了**（2026-10-03 M189 补上此前一直没验到的第二态）：「未勾选 → 已勾选」是一次**变化**，两端都得读到才算数。实测勾选前 `disabled=true` / `opacity=0.4`，**勾选一项后 `disabled=false` / `opacity=1`**，背景色与光标两端不变。勾选后**真的点下去也真的下载到了文件**（不是只看见按钮亮了）——这一条此前一直挂着「未测到」，本批结清。

![刚进入批量模式、尚未勾选时，右上角的下载 ZIP 按钮呈灰色不可点状态](../screenshots/14-manage-assets-zip-disabled.png)

勾选后点「下载 ZIP」，页面顶部弹出成功提示，形如「**1 个资产已保存为 TDCanvas.zip**」，并**自动退出勾选模式**、工具栏恢复原样。

> **提示里的文件名不一定叫 `TDCanvas`**：它跟着这批资产的**来源画布名**走，取不到才叫 `TDCanvas`（见下文「为什么两个 zip 名字不一样」）。**以提示里写的那个名字为准。**

![下载完成的顶部提示为 1 个资产已保存为 TDCanvas.zip，工具栏已自动退出批量模式恢复为批量下载、导出资产、导入资产、新增资产](../screenshots/14-manage-assets-zip-done.png)

> 提示语里直接写出了 ZIP 的文件名，**这是确认产物名最快的办法**——不用去翻系统下载目录。

## 带走资产的三条路

资产页能"把东西带走"的地方有三个，它们产出的文件**互不通用**，用错会导致还原不回来：

| | 导出资产 | 批量下载 → 下载 ZIP | 卡片上的「下载」 |
|---|---|---|---|
| 适用类型 | 全部 | 勾选的任意类型 | 仅图片 / 视频 |
| 作用范围 | **全部资产**（忽略当前筛选与勾选） | 仅勾选的资产 | 单个资产 |
| 落地文件 | 一个 zip | 一个 zip | 单个原始文件 |
| zip 文件名 | `我的资产.zip`（固定） | `<画布名>.zip`，取不到则 `TDCanvas.zip` | — |
| 含元数据（标题/标签/来源） | ✅ | ❌ | ❌ |
| 能用「导入资产」还原 | ✅ | ❌ | ❌ |
| 适合 | **备份、换机迁移** | **分享给不装 TDCanvas 的人** | 存单张图/视频 |

一句话记法：**「导出」是给自己搬家的，「下载」是给别人寄东西的。** 只有前者是往返的（导出 → 导入），后者是单向的。

## 导出与导入

- **导出资产**：把**全部**资产打包为 `我的资产.zip` 下载到系统下载目录。它不看当前筛选也不看勾选状态——在「图片」筛选下点它，导出的仍是全部资产。无资产时点击会提示「暂无资产可导出」。
- **导入资产**：点它**直接弹出系统文件选择器**（中间没有二次确认页），选择此前导出的 zip 压缩包导入，成功提示「已导入 N 个资产」；文件无效时提示「导入失败，请选择有效的资产压缩包」。

![导入资产按钮高亮，列表显示刚从压缩包恢复的两个资产，计数恢复为 2 / 2](../screenshots/14-manage-assets-import.png)

### 两个 zip 里到底装了什么

2026-10-01 实测拆包对比（一个文本资产「赛博朋克雨夜」）：

```text
导出资产 → 我的资产.zip                批量下载 → TDCanvas.zip
├── assets.json                       └── 赛博朋克雨夜.txt
│   ├── app / version / exportedAt        内容仅为「文本内容」那一段
│   ├── assets[]  ← 完整元数据
│   └── files[]   ← 媒体文件清单
└── files/
    ├── image_xxx.png
    └── media_xxx.mp4
```

- **「导出资产」的 zip 是一份自描述的存档**。`assets.json` 里有 `app`、`version`、`exportedAt` 三个头部字段，加上资产数组（标题、封面、标签、来源、备注、正文、时间戳）和一份媒体文件清单。导入时正是靠这个清单把二进制放回原位。
- **「下载 ZIP」的 zip 只是一堆裸文件**，一个资产对应一个文件（文本落成 `.txt`，图片视频落成原格式），包内**没有任何元数据**，也**没有目录层级**。同名资产会自动改名为「xxx (2).txt」避免互相覆盖。

> 拿「下载 ZIP」的产物去点「导入资产」，一定会得到「导入失败」——因为它压根没有 `assets.json`。这正是两条路径的分工。

### 为什么两个 zip 名字不一样

`我的资产.zip` 是写死的固定名（界面文案里就叫这个），而批量下载的 zip 名是**猜出来的**：程序会先看选中资产是不是都来自**同一个画布项目**，是的话就用那个画布的名字；不是（或者压根不来自画布，比如手动添加的资产）就退回"最近打开的画布名"；连这个都没有，才落到硬编码的 `TDCanvas`。

所以截图里那个 `TDCanvas.zip` 并不是 bug，而是**这条兜底链走到底的样子**——那批资产来源是「手动添加」，前两级都没取到名字。想换个名字，唯一办法是让这批资产来自同一个画布项目。

> **★ 三级兜底链现在每一级都有实测了**（2026-10-03 M189 补上第一级）。此前的证据只有**兜底那级**（手动添加的资产 → `TDCanvas.zip`）。本批的资产是从**画布节点**用工具条「加入资产」存进去的，走的是**第一级**：实测下载到的文件名为 **`改过的项目名.zip`**，而那个画布当时正叫「改过的项目名」。
> **所以第一级是通的**——**资产来自画布时，zip 名就跟着那个画布的名字走**。
> 这一点值得单独记一笔，因为它反直觉：**名字跟的是画布，不是你给这个资产起的标题。** 从画布 A 存一个提示词、给标题叫「我的文案模板」，下载出来的 zip 仍叫「画布 A」——**想改名字只能去改画布名**。源码对应 `assets/index.tsx:174` 的 `projectTitles.length === 1 ? projectTitles[0] : recentCanvasTitle`。

### 导出不会下载远程封面

导出只打包**存进本机**的图片和视频（源码里按本地存储键去找二进制）。如果某个资产是用「**封面 URL**」粘贴的**远程地址**，那串 URL 只会作为文本躺在 `assets.json` 里，**图片本体不会进 zip**。换机后如果那个链接已失效，这个资产的封面就没了。

> 想让图片真正随备份走，走「**图片内容**」的上传（本地文件）而不是「封面 URL」。

2026-09-30 实测的完整还原流程：

1. 新建两个文本资产（带标签），确认列表计数为 `2 / 2`；
2. 点「导出资产」，得到 `我的资产.zip`；
3. 逐个删除两个资产，页面回到「没有找到资产」；
4. 点「导入资产」并选择该压缩包；
5. 两个资产全部恢复，计数回到 `2 / 2`，标题、正文、标签、来源均与删除前一致。

> 导入是**追加**而非覆盖：与现有资产同名时会产生新的条目，导入前建议先清空或重命名可能冲突的资产。

## 删除资产

1. 点击卡片底部的「**删除**」，弹出确认框「删除资产」，正文为「确定删除「<资产名>」吗？删除后会从我的资产中移除。」
2. 点「删 除」确认，或「取 消」放弃。

![删除资产确认框，提示将移除指定名称的资产](../screenshots/14-manage-assets-delete.png)

> **删除不可撤销**，也没有回收站。误删后只能重新录入，建议先「导出资产」留一份备份。

## 不同类型的卡片操作

| 资产类型 | 卡片底部可用操作 |
|---|---|
| 文本 | 编辑、复制、删除 |
| 图片 | 编辑、下载、删除 |
| 视频 | 下载、删除（**无「编辑」**） |

三种卡片并排时，视频卡明显少一个按钮——这不是加载失败，是类型决定的：

![我的资产页并排三张卡片：图片卡的底部是「编辑 下载 删除」，视频卡只有「下载 删除」，文本卡是「编辑 复制 删除」](../screenshots/14-manage-assets-card-actions.png)

> **2026-10-01 逐张实测**，方法是把三种资产同时放进资产库，再对每张卡片取「删除」按钮的父元素作为操作条容器、逐条枚举其按钮：图片 `["编辑","下载","删除"]`、视频 `["下载","删除"]`、文本 `["编辑","复制","删除"]`——与上表逐字一致。（视频资产因界面无创建入口，是通过「导入资产」放入的，媒体文件本身不参与本次验证。）

这组差异不是随手排的，它由**类型决定**：

- **「编辑」排除视频**——视频资产只有来源地址和存储键，没有可编辑的正文表单，改不了字段。
- **「复制」只给文本**——它复制的是「文本内容」字段里的**纯文本到系统剪贴板**（复制成功提示「文本已复制」），不是复制整个资产。想把文本资产搬到提示词库里，得先点「复制」再手动粘贴。
- **「下载」只给图片和视频**——文本没有可下载的媒体文件，文本要带走请走上面的「批量下载 → 下载 ZIP」。

> 顺带一提：进入批量模式时**整条操作条会被隐藏**（见上文截图），这是防止你在勾选状态下误触编辑或删除。

## ⚠️ 视频资产既不能编辑，也建不出来

上面第三行不只是"少个按钮"，它连着一个**必须提前知道的坏消息**：

| | 文本 | 图片 | 视频 |
|---|---|---|---|
| 筛选器里有这一项 | ✅ | ✅ | ✅ |
| 卡片有「编辑」按钮 | ✅ | ✅ | ❌ |
| **「新增资产」表单能选** | ✅ | ✅ | ❌ |

**「新增资产」的类型下拉里只有「文本」和「图片」两项，没有视频。**

![新增资产弹窗的类型下拉已展开，只有「文本」「图片」两项；而同一画面右侧的类型筛选器里却有「视频」一项](../screenshots/14-manage-assets-new-form-kinds.png)

> 2026-10-01 实测：展开该下拉，选项元素逐条枚举为 2 项；源码里这组选项同样只写了 `text` 与 `image` 两条。**同一画面右侧的类型筛选器却是「全部 / 文本 / 图片 / 视频」四项**——筛选器认视频，创建表单不认。

**这意味着视频资产的标题一旦写错，无法修正**：

- 改不了——卡片上没有「编辑」；
- 重建不了——「新增资产」没有视频选项；
- 删了更糟——删除不可撤销、没有回收站，**而且删掉之后就再也建不回来了**。

**所以唯一可行的做法是：添加视频资产时就把标题想清楚。** 真到了要改标题的地步，导出资产 zip、在 `assets.json` 里改掉那个视频条目的 `title` 字段、再导入回去——这条路走得通（`importAssets` 读的就是这个结构），但属于手工改数据，不建议日常使用。


## 成功判据

- 保存后右上角出现「资产已保存」，且列表计数 `0 / 0` → `1 / 1`；
- 编辑后卡片标题即时变为新值；
- 搜索或筛选后计数与卡片数量一致，无匹配时显示「没有找到资产」；
- 导出后系统下载目录出现 `我的资产.zip`；
- 批量下载后顶部提示「N 个资产已保存为 XXX.zip」，且工具栏自动退出批量模式；
- 删除后卡片消失，回到空态。

## 已知限制

- 视频资产**不能编辑**，只能下载或删除；**而且也建不出来**——「新增资产」的类型下拉只有文本和图片。**所以不要用"删掉重建"来改视频的标题，那条路走不通，删了就是永久丢失**（详见上节「视频资产既不能编辑，也建不出来」）。
- 删除无撤销与回收站。
- 资产与画布项目是两份独立存储；删除资产不会影响画布节点，反之亦然。
- 「封面 URL」填的**远程图片不会随导出打包**，换机后可能失效。
- 「下载 ZIP」的产物**无法用「导入资产」还原**（缺元数据），它只适合单向分享。
- 批量下载的 zip **名不跟随你输入的标题**，而是取自资产来源的画布名，取不到就是 `TDCanvas.zip`。
