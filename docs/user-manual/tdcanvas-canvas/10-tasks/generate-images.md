# 发起图片生成并理解任务状态

- **适用角色**：已配置 Aitudou API Key 的 TDCanvas 用户。
- **目标**：以图片节点为中心发起 AI 生图，理解任务状态与结果组织。
- **前置条件**：右上角「配置」中已填写并保存 Aitudou API Key（未配置时点击生成会失败）。
- **入口**：选中图片/文本等节点 → 节点下方的生成面板。

> ⚠️ **费用提示**：生成调用 Aitudou API 按量计费。本页为流程说明；开始生成前请确认模型与参数。

## 发起生成

1. 选中图片节点（或通过[连线引用](connect-references.md)把参考素材接到节点上——「从画布连线后会自动带入参考素材」）。
2. 在节点下方生成面板的描述框输入画面描述。
3. 按需调整：模型（默认按引用自动匹配，如 Seedream V5 Pro）、比例与分辨率（1K/2K）、数量。
4. 点击发送按钮开始生成。

## 生成中与结果

- 生成中：节点显示进度遮罩，相关连线出现流动动效。
- 完成后：
  - 数量为 1 → 结果直接回填当前节点；
  - 数量大于 1 → 当前节点成为**主图**，右侧堆叠生成子图节点（可展开/收起/设为主图）；
  - 每次生成的历史保留在节点的**图片历史**中（最近 24 个版本，可随时切换回某一版）。

## 任务状态与异常

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 排队中 / 生成中 | 任务已提交，正在执行 | 等待；可刷新页面，任务状态会恢复 |
| 完成 | 结果已写入节点 | 通过图片历史切换版本 |
| 部分成功 | 批量中部分失败 | 查看失败原因，重试失败项 |
| 失败 | 请求被拒或出错 | 查看节点错误详情，修正参数后重试 |
| 等待补充参数 | 平台要求补充信息 | 按平台提示处理 |
| 已停止 | 你停止了本地轮询 | **远端任务可能仍在执行并计费**，请到平台确认 |

- 「停止」只停止本地等待，不会取消远端任务。
- 提交过的任务即使刷新页面也能恢复状态（本地任务日志）。
- 同一节点有未完成任务时不允许重复发起（防止重复计费）。

## 快捷路径

- 文本节点右上角「**生图**」：在右侧自动创建图片节点并连线，把文本作为提示词。
- 图片节点悬浮工具条「**反推提示词**」：创建反向推导提示词的文本节点（付费）。
