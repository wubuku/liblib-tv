# 发起图片生成并理解任务状态

> **本页编写中**（任务 `generate-images` 状态见 [../task-inventory.yml](../task-inventory.yml)）。
> ⚠️ 生成动作调用 Aitudou API **按量计费**——本页流程描述来自官方文档与源码取证，
> 运行时回走只到「点击生成之前」；手册不引导读者执行未确认的付费操作。

大纲要点（成稿依据：SOURCE_OBSERVATIONS §7 + 调研包任务状态机）：

- 前置条件：配置页填写 Aitudou API Key；未配置时生成入口不可用
- 入口：媒体节点下方生成面板的运行按钮 / 文本节点「生图」/ 错误卡「重试」/ 反推提示词
- 面板参数：模型（自动匹配变体）、比例/分辨率/数量、参考素材区
- 任务状态：排队中 → 生成中（进度玻璃遮罩）→ 完成 / 部分成功 / 失败 / 等待补充参数 / 已停止
- 停止轮询 ≠ 取消远端任务（远端可能继续执行并计费）
- 刷新恢复：提交过的任务会写入本地日志，重开画布时恢复状态
- 批量生成：主图 + 子图堆叠，图片历史保留最近 24 个版本
