# 快捷键与帮助

- **适用角色**：所有 TDCanvas 用户。
- **目标**：查看画布全部鼠标与键盘操作。
- **入口**：顶栏键盘图标，或左下角 Dock 的「快捷键」按钮。
  > ⚠️ **左下角那个入口在默认状态下点不到**（2026-10-05 M257 实测，R110）：
  > 左侧节点面板开着时，它把左下缩放条盖掉了 5 项，**「快捷键」是其中之一**（只有「打开小地图」还能点）。
  > **用顶栏那个键盘图标，它不受影响**；或者先把左侧面板收起来。

> ⚠️⚠️ **比上面那条更容易撞上的一条：只要焦点在左侧面板里，画布快捷键全部失灵。**
> **左侧节点面板一开就是一直开着**（它默认收起，**你开过一次之后就一直开着**，R114），
> **而你在那儿点一下任何一行或按钮，焦点就留在里面了**——
> 于是 `Delete` / `Backspace` / `Esc` / `Ctrl / Cmd + A` / `Ctrl / Cmd + C / V` / `Ctrl / Cmd + Z`
> **一个都不响应**。
> ★ **症状长这样**：节点**确实变成选中态**（节点工具条出来了、左侧 Dock 也多出垃圾桶），
> **但按 Delete 什么也没发生**——**看上去像应用卡死了，其实只是焦点不在画布上。**
> ★ **机制**（2026-10-05 M261 实测 + 源码核对）：快捷键的处理器挂在 `window` 上
> （`pages/canvas/project.tsx:1805`），但它**第一件事就是早退**——
> 事件目标落在 `[data-canvas-no-zoom]` / `[contenteditable]` / `[data-canvas-shortcuts-ignore]` 里就直接 `return`
> （`:1739-1740`），**在任何键分发之前**。
> 而**侧面板自己就带 `data-canvas-no-zoom`**（`canvas-side-panel.tsx:115`）——
> **所以「焦点在面板里」= 「所有画布快捷键失效」**，而**面板一开就是常态**（R114）。
> ★ **实测对照**（同一个节点、同一组键，只换焦点）：

  | 键 | 焦点在画布 | 焦点在左侧面板 |
  |---|---|---|
  | `Ctrl / Cmd + A` | 选中 1 → **4**（全选生效） | 选中 1 → **1**（没生效） |
  | `Esc` | 选中 4 → **0**（生效） | 选中 1 → **1**（没生效） |
  | `Delete` | 画布元素 **4 → 3**（删掉了） | 画布元素 **4 → 4**（没删） |

> ★ **这条不止左侧面板**（M263 订正，R115）：**生图面板**（整个根节点带这个标记）、
> **Agent 面板**、**模型下拉**、参数弹层、提示词弹窗里点过之后**同样全哑**——
> **而 `Esc` 连弹层本身都关不掉**，因为 `Esc` 正是被吞掉的那个键。
> ★ **但持久面板与弹层不一样**：**左侧面板 / Agent 面板关不掉快捷键也不会自己恢复**（要点画布）；
> **而生图面板这类弹层一关掉，焦点回到画布，快捷键立刻自动恢复。**
> 完整清单与实测见 [排障页](../90-troubleshooting.md#快捷键按了没反应)。
>
> ★ **修复只有一个动作**：**点一下画布**（空白处或节点上都行），焦点就回来了，所有快捷键立刻恢复。
> **预防**：**在左侧面板里选完节点，要动手删或复制之前，先点一下画布。**

## 弹窗里的十三条（逐字抄录）

下表与**顶栏那个**弹窗内容一致，它共 **13 行**（实测：弹窗边界框 520×749，内部无滚动容器，13 行全部可见，没有被视口裁掉的隐藏行）。
★ **⚠️ 2026-10-06 M280 订正：画布上其实有两个不同的快捷键弹窗，本表只对应其中较大的那个**——
★ **左下角 Dock 那个问号圆按钮打开的是另一个，只有 6 行、520×293**。详见下面「[两个入口不是同一个弹窗](#两个入口不是同一个弹窗)」一节。

| 键位 / 方式 | 弹窗标注的作用 |
|---|---|
| 拖动画布 | 平移视图 |
| 滚轮 | 缩放画布 |
| 缩放滑杆 | 精确调整缩放 |
| `Ctrl / Cmd` + 拖动 | 框选多个节点 |
| `Shift / Ctrl / Cmd` + 点击 | **追加选择节点** |
| `Ctrl / Cmd` + `A` | 全选节点 |
| `Ctrl / Cmd` + `C / V` | 复制 / 粘贴节点，或粘贴**剪切板**文本/图片 |
| `Ctrl / Cmd` + `Z` | 撤销 |
| `Ctrl / Cmd` + `Shift` + `Z` | 重做 |
| `Ctrl / Cmd` + `Y` | 重做 |
| `Delete / Backspace` | 删除选中 |
| `Esc` | 取消选择并关闭浮层 |
| 拖入图片 / 视频 / 音频 | 上传到画布 |

> **多选之后能做什么（实测，别抱太高期待）**：选中两个及以上节点时，**悬浮工具条会整个消失**，右键菜单也还是单选那两项「复制 / 删除」——**这个版本没有批量编辑**。多选真正能省事的只有三件事：**整组一起拖动**、**一次 `Delete` 删掉全部**（`Ctrl / Cmd + Z` 也是一次全恢复），以及 `Ctrl / Cmd + C / V` **复制粘贴全部选中的节点**。想批量改名字或尺寸，只能一个个来。详见 [edit-nodes.md](edit-nodes.md#选中多个节点时-工具条会消失)。

> ⚠️ **多选时右键「复制」有个陷阱：它只复制你右键点到的那一个。** 菜单不会告诉你现在是多选（和单选长得一模一样），但复制的结果是**单数**——实测选中 2 个节点后右键「复制」，画布上只多出 1 个副本（2 → 3），而且副本是**右键命中的那个**，不是选中的两个。**要一次复制全部选中，请用 `Ctrl / Cmd + C` 再 `Ctrl / Cmd + V`**（实测 2 → 4）。详见 [edit-nodes.md](edit-nodes.md#多选时右键「复制」只复制右键的那一个)。
>
> ★ 换过去之后**副本标题的规则也换了**：`Ctrl / Cmd + C / V` 复制同一个节点两次会得到**两个同名节点**。原因见本页「[弹窗没写、但确实能用的三条](#弹窗没写、但确实能用的三条)」一节末尾的对照表。

三个容易看岔的细节：

- **「重做」在弹窗里占两行**（`Shift+Z` 和 `Y` 各一行），不是一行写「或」；
- 弹窗用的是「**剪切板**」不是「剪贴板」——整个应用五处文案（右键菜单、提示词库、画布右键菜单）都写「剪切板」，你在界面上找「剪贴板」三个字是找不到的；
- 弹窗只说「**追加**选择节点」，没说「取消」。想取消选中，点空白处或按 `Esc` 更稳。

## 弹窗没写、但确实能用的三条

下面这三条**在弹窗里不存在**，但操作是真的（均已实测）：

| 操作 | 方式 | 说明 |
|---|---|---|
| 重命名节点 | 双击节点**标题** | 标题是节点边框**上方**那块带虚线下划线的文字，位置比节点框高 40 像素。★ **注意：因为它浮在节点外，所以两个节点摆得近时标题可能被压在下面那个节点底下——这时双击点到的不是标题、而是压着它的那个节点**（见下方实测） |
| 编辑文字 | 双击文本节点**内容区** | 内容区就是节点框本身，里面写着「双击编辑文字」 |
| 复制 | 节点右键 →「复制」 | 副本向右下偏移 **+36, +36** 像素。**多选时只复制右键点到的那一个** |

> ⚠️ **★ 「双击标题改名」点不到时，先怀疑标题被别的节点盖住了**（2026-10-06 M275 实测）。
> ★ **这不是偶发**：标题那块渲染在**节点框上方 40 像素**的位置（★ **上表那句「比节点框高 40 像素」就是它的几何**），
> ★ **而那一块不属于节点的框内区域——它伸到画布的别处去了，于是完全可能落在另一个节点的下面。**
> ★ **实测四类节点逐个双击，判据是「双击点上到底是谁」**（用 `elementFromPoint` 反查，不看位置猜）：

> | 节点 | 标题中心那个点命中的是 | 双击的结果 |
> |---|---|---|
> | 图片 | 标题自己 | ✅ **进入改名**，编辑框 **166×32** |
> | 视频 | 标题自己 | ✅ **进入改名**，编辑框 **166×32** |
> | 音频 | ★ **上层那个视频节点的 `<video>`** | ❌ **没改名**，弹出的是**视频查看器** |
> | 文本 | 标题自己 | （本批有一次没进编辑态、换一次顺序又正常，★ **未查清，如实记下**） |

> ★ **出路很简单**：★ **把两个节点拉开一点，或者先把画布缩放到标题露出来的那一块再双击**。
> ★ **顺带一个正结论**：★ **改名编辑框是 166×32**，★ **与本手册写的数逐字相符**；
> ★ **它也是画布坐标**（实测 `÷k` 之后 100% 与 50% 两档恒为 **166×32**，见 [30-concepts.md](../30-concepts.md)）。

> ⚠️ **★★ 还有第二种「点不到」：左侧面板本身**（2026-10-06 M278 A/B 实测，六对六）。
> ★ **面板开着的时候，它会盖住落在它横向范围内的那一片节点标题**——
> ★ **实测同一个动作（双击文本节点的标题）各做六次**：
>
> | 左侧面板 | 六次里进编辑态 | 落点实际命中的是 |
> |---|---|---|
> | **开着** | **0 / 6** | ★ **面板自己那个节点列表条**（每个节点在面板里都有一行可点的条目） |
> | **收着** | **6 / 6** | 标题自己 |
>
> ★ **所以「双击标题没反应」有两种完全不同的原因**：★ **被别的节点压住（上一段那条）**，或者 ★ **被左侧面板盖住（这一段）**。
> ★ **两者的解法也一样——把碍事的东西挪开**：★ **节点之间拉开，或者把面板收起来再双击**。
> ★ **顺带**：★ **面板里那一行条目本身是可点的**（点它会把视野跳到那个节点），
> ★ **所以「双击没反应」时你还可以直接点面板里那一行——效果是跳过去，不是改名**。

**两个「双击」别搞混，这是最容易点错的地方**。2026-10-01 逐个验证过它们的落点——判据是双击后**焦点落在哪个元素**上：

| 双击哪里 | 双击后 `document.activeElement` | 结果 |
|---|---|---|
| 标题（「文本」那块） | `INPUT`，值为「文本」 | 进入**重命名**，输入框里已填好现标题 |
| 内容区（节点框中央） | `TEXTAREA` | 进入**编辑正文**，是能换行的多行框 |

> 节点正文区是 `TEXTAREA`、标题是 `INPUT`，两者不是同一个控件——所以标题永远只有一行，正文能敲回车分段。

**复制还有一件手册没细说的事：副本标题会变。但「复制」有两条路径，规则不一样。** 最容易踩的正是这个差别——因为本页下面推荐的「一次复制多个选中」走的是**后者**。

| 你走的是 | 副本标题 | 副本位置 |
|---|---|---|
| 节点右键 →「复制」 | **每次都追加一个 ` Copy`**，一路叠下去 | 右下偏移 **+36, +36** 像素 |
| `Ctrl / Cmd + C` 再 `Ctrl / Cmd + V`（或画布右键「粘贴」） | **只追加一次**。标题已经以 ` Copy` 结尾的，**原样照抄** | 摆在**画布中心**，不按 +36/+36 偏移 |

![五个文本节点沿对角线排开，标题依次是「文本」「文本 Copy」「文本 Copy Copy」「文本 Copy Copy Copy」「文本 Copy Copy Copy Copy」](../screenshots/11-shortcuts-help-copy-titles.png)

> 上图是**右键「复制」连按四次**的结果，**不是**快捷键的结果。2026-10-01 实测坐标：`(540,350)` → `(576,386)` → `(612,422)` → `(648,458)` → `(684,494)`，**每级偏移都是 +36 / +36，恒定不变**；标题同步变成「文本 Copy」→「文本 Copy Copy」→「文本 Copy Copy Copy」→「文本 Copy Copy Copy Copy」。**连点右键复制就会叠加出一长串 Copy**，这不是故障。想让标题干净，就双击标题改掉。

> ⚠️ **走 `Ctrl / Cmd + C / V` 复制同一个节点两次，画布上会出现两个一模一样的标题。** 2026-10-04 实测：先右键复制两次做出「文本 Copy Copy」，选中它按 `Ctrl / Cmd + C` 再 `Ctrl / Cmd + V`——新节点**仍然叫「文本 Copy Copy」**，同名节点变成 2 个。原因在源码里写得很直白：快捷键那条路径只在标题**不以** ` Copy` 结尾时才追加，撞上了就不加。
>
> **怎么选**：想要「一路叠成 `文本 Copy Copy Copy`」并且副本位置固定偏移，就用**右键「复制」**；想一次复制多个选中节点，就用 `Ctrl / Cmd + C / V`（它复制的是**选中的那几个**，位置会摆到画布中心），但**记得自己双击把标题改掉**，否则画布上分不出哪个是原件。

**右键菜单本身只有两项**：对节点右键弹出的是「**复制**」「**删除**」，没有第三项（画布上三个右键菜单各不相同，见 [connect-references.md](connect-references.md#管理连线)）。

**为什么弹窗不收这三条**：它们是「双击」和「右键」这类鼠标手势，不是快捷键——弹窗的体裁是键位表，只列键帽。但你把它们当键位记却又找不到，会以为自己记错了。

> **画布上没有缩放类快捷键**。放大缩小只能用滚轮或左下角的缩放滑杆——这是与大多数设计工具不同的地方，也是新手最常问的键位。滚轮缩放以**鼠标指针位置**为锚点，也就是说指针在哪，缩放时那个点就固定在原地。

## 键位记不住怎么办

不用背。上表就是弹窗内容的完整抄录，随时可以对照；更省事的办法是**用鼠标菜单**：

| 想做什么 | 不记键位的做法 |
|---|---|
| 撤销 | 左侧 Dock「历史」→ 面板里的「撤销」 |
| 删除节点 | 选中后点悬浮工具条红色「删除」 |
| 取消选择 | 点画布空白处，或按 `Esc` |
| 复制副本 | 节点右键 →「复制」。**多选时它只复制右键点到的那个**；要一次复制全部选中，用 `Ctrl / Cmd + C` 再 `Ctrl / Cmd + V`。**两条路径的副本标题规则不一样**，照上面那张对照表选 |

**这四条在 2026-10-01 全部实测过**，逐条结果：

- **撤销**：清空 5 个节点的画布后，「历史 → 撤销」把 5 个全带回来了（详见 [undo-persistence.md](undo-persistence.md)）。
- **删除**：选中节点后工具条出现，点红色「删除」——3 个节点变 2 个，**不需要任何确认弹窗**。那个按钮的计算色是 `rgb(248, 113, 113)`（玫红），确实是红的。
- **取消选择**：`Esc` 与点空白**两种都行**，实测都让悬浮工具条消失（按钮数 4 → 0）。

> **单击空白 ≠ 双击空白，这两个别混。** 单击空白**只是取消选择**，什么都不会弹出来（实测点击前后 `.td-canvas-flyout` 数量都是 0）；**双击**空白才会弹出「选择节点」创建菜单。所以"取消选择"随便点，不担心手抖点出东西；想建节点才需要双击。

**能用鼠标完成的操作都有对应入口**，快捷键只是省时间。

## 快捷键不生效的常见原因

- **光标在输入框里**：正在输入文字时 `Cmd/Ctrl + Z` 是「撤销输入」而不是「撤销画布操作」。先点一下画布空白处让焦点离开输入框。
- **在浏览器里被截胡**：某些浏览器会把 `Cmd/Ctrl + N`、`Cmd/Ctrl + T` 等保留给自己；TDCanvas 用到的键位通常不冲突。
- **按了 `Esc` 以为会删除节点**：`Esc` 只是取消选择和关闭浮层，删除要用 `Delete` / `Backspace`。

## Esc 在各个流程里分别是什么

`Esc` 这个键在画布上出现在**好几个不同的流程里，而它的效果并不一样**——
查手册时最容易被「别处也这么写」带偏，所以这里逐条列出来。
**下表五行 2026-10-03 全部实测过**：第 1 行此前只有一次旧读数（工具条按钮 4 → 0），
本批重新测得「工具条 1 → 0」；第 5 行的结论来自早前那次，本批又复测了一次。

| 你正处在 | 按 `Esc` 会 | 实测 |
|---|---|---|
| 节点**被选中**、工具条浮着 | 取消选择，工具条消失 | ✅ 工具条 1 → 0，与本页表格一致 |
| 某个**弹窗**开着（快捷键、版本号等） | 关闭弹窗 | ✅ 可见 dialog 由 1 个变 0 个 |
| 「添加节点」**菜单**开着 | 关掉菜单，**不会误建节点** | ✅ 节点数 0 仍为 0 |
| **双击节点标题**改名、正在输入 | **整个取消**，名字回到改之前 | ✅ 打字期间存储里仍是旧名 |
| **双击节点正文**编辑、正在输入 | **撤不回**——只退出编辑态，文字已落库 | ⚠️ 与上面第 4 行**语义相反** |

**为什么第 4 行能撤、第 5 行不能**：**改名是「提交才写」**（敲的字只在输入框里，`Esc` 一按就丢），
**编辑正文是「边打边存」**（每敲一个字就写进本机存储了）。
**同一个物理按键，在两个输入通道里效果相反**，原因在写入时机而不在按键。
误删了正文要找回，**用撤销（`Cmd/Ctrl + Z`），不要按 `Esc`**。

> 顺带一条常被想当然的：**64 字符那个上限只管节点名，不管正文**——
> 文本节点的正文文本框实测**没有长度上限**（改名输入框是 64）。
> 详见 [edit-nodes.md 的重命名一节](edit-nodes.md#重命名节点)。

## 打开帮助弹窗的两种方式

- 顶栏右侧键盘图标「快捷键」；
- 左下角缩放 Dock 最右侧「快捷键」按钮。

### 两个入口不是同一个弹窗

★ **⚠️ 本手册此前写「两处打开的是同一个弹窗」，那是错的，本批已订正**（2026-10-06 M280 实测 + 源码双证）。
★ **画布上确实有两个快捷键弹窗，而它们的标题与按钮提示文字完全一样**——★ **所以肉眼和 `aria-label` 都分不出来**。

| | 顶栏键盘图标 | 左下角 Dock 问号圆 |
|---|---|---|
| 弹窗尺寸 | **520 × 749** | ★ **520 × 293** |
| 弹窗内正文区 | 472 × 677 | 472 × 221 |
| **行数** | **13 行** | ★ **6 行** |
| 源码位置 | `canvas-top-bar.tsx:147` | ★ `canvas-zoom-controls.tsx:103` |

★ **★ Dock 那个只有 6 行**（逐字抄录）：

| 键位 / 方式 | 弹窗标注的作用 |
|---|---|
| 拖动画布 | 平移视图 |
| 滚轮 | 缩放画布 |
| `Ctrl / Cmd` + 拖动 | 框选多个节点 |
| `Shift / Ctrl / Cmd` + 点击 | 追加选择节点 |
| `Ctrl / Cmd` + `C / V` | 复制 / 粘贴节点 |
| `Delete / Backspace` | 删除选中 |

★ **★ 对照上面那张 13 行表**：★ **Dock 版少了 7 条**（缩放滑杆、`Ctrl / Cmd + A` 全选、`Ctrl / Cmd + Z` 撤销、
`Ctrl / Cmd + Shift + Z` 重做、`Ctrl / Cmd + Y` 重做、`Esc`、拖入素材上传）；
★ **而且少掉的这 7 条里没有一条是「被折叠」或「要滚动」**——★ **它就是另一个更短的弹窗**。
★ **另有一处连文字都不一样**：★ **`Ctrl / Cmd + C / V` 那一行**，★ **顶栏版写「复制 / 粘贴节点，或粘贴剪切板文本/图片」，
★ **Dock 版只写「复制 / 粘贴节点」**——★ **所以 Dock 版连「都是 13 条的子集」都不成立**。

★ **所以要查完整那份键位表，请点顶栏那个**：★ **本页第二节那张 13 行表只对得上顶栏**。

> **两个弹窗的尺寸都不是窗口的函数**（2026-10-06 M280 三档窗口高度 700 / 900 / 1200 逐档实测）：
> **520×749 恒为 520×749、520×293 恒为 520×293**，★ **它们由内容行数决定，不随窗口高度变**。

> **弹窗的横坐标会跟着窗口宽度走，别当成漂移**：它水平居中，所以 1280 宽的窗口量到 `x=380`（(1280−520)/2），1440 宽则量到 `x=460`。纵坐标也随窗口高度走（垂直居中）。

![快捷键弹窗浮在画布之上，遮住中间区域，底部的缩放条与左侧 Dock 仍可见](../screenshots/11-shortcuts-help-modal.png)

> ⚠️ **「仍可见」不等于「还能点」——弹窗开着的时候，左侧 Dock 和左下角缩放条是看得见、但点不动的。** 这是 antd 弹窗自带的一层**透明遮罩**（`.ant-modal-wrap`，铺满 1440×900 整个视口，`background: rgba(0, 0, 0, 0)` 完全透明，`pointer-events: auto`），它视觉上什么都不挡，却把下面的点击全吃掉了。实测弹窗打开时，Dock 那 8 个按钮和缩放条那 4 个按钮的 `visibility` / `opacity` 一律不变（仍可见），但逐个用 `elementFromPoint` 打点，**12 个点无一命中按钮本身，全部落在遮罩上**；实点左侧「清空画布」也没有弹出确认框，**这一下只是把快捷键弹窗关掉了**。所以看见 Dock 还亮着就伸手去点，是白点。

> **弹窗里没有的两个入口**：画布空白处右键菜单里的「**复制所有节点**」和「**粘贴**」在快捷键弹窗和本页表格里都没有。实测「复制所有节点」复制的是画布上**全部**节点（不看当前选中了哪些），随后「粘贴」把整份复制到鼠标位置——2 个节点的画布粘贴后变成 4 个。
>
> **它和 `Ctrl / Cmd + C / V` 不是一回事**：后者复制的是**当前选中的节点**。实测一个 4 节点的画布上只选中其中 2 个，`Ctrl / Cmd + C / V` 的结果是 4 → 6，只多出被选中的那 2 个的副本；另外 2 个没被选中，也就没有副本。想用快捷键达到「复制所有节点」的效果，得先 `Ctrl / Cmd + A` 全选再 `Ctrl / Cmd + C / V`。
>
> **两处菜单的快捷键标签不一致**：顶栏汉堡菜单把撤销写作 `Ctrl / Cmd + Z`（Mac 上正确），而右键菜单只写 `Ctrl+Z`——界面上没提示 Mac 需要换成 `Cmd`。**以本页表格和顶栏菜单为准。**
