# 连线引用与无线引用

- **适用角色**：所有 TDCanvas 用户。
- **目标**：把上游节点（图片/视频/音频/文本）作为参考，接到下游节点上参与生成。
- **前置条件**：画布中已有至少两个节点（见 [create-nodes.md](create-nodes.md)、[upload-materials.md](upload-materials.md)）。
- **入口**：节点左右两侧的圆形端口；画布外观 flyout 的「画布输入模式」。

## 方式一：拖线连接（连线模式）

1. 鼠标移到节点上，左右两侧出现圆形**端口**（左侧输入、右侧输出）。
2. 从上游节点的**输出口**按住拖动，出现虚线连线。
3. 拖到目标节点附近松手——连线以贝塞尔曲线生成，两端节点高亮。

![拖线到空白处的生成菜单](../screenshots/07-connect-references-drop-menu.png)

## 方式二：拖线到空白处，直接创建下游节点

把连线拖到画布空白处松手，会弹出「利用画布节点生成」菜单（按上游类型提供 文本生成 / 图片生成 / 视频生成 / 音频参考 等项）。选择一项后：

- 在松手位置自动创建新节点；
- 新节点与上游自动连线；
- 生成面板自动打开（生成动作本身需要已配置 API Key，见 [generate-images.md](generate-images.md)）。

## 引用的作用

下游节点生成时会**自动读取所有上游**：文本拼入提示词，图片/视频/音频作为参考素材传入。因此「连线 = 让上游参与下游生成」。

## 方式三：无线引用（objects 模式）

不想让画布上出现连线时：

1. 左侧 Dock「**画布外观**」→「画布输入模式」→ 切换为「**无线模式**」。
2. 此时改用对象引用方式组织输入（连线隐藏，原有连线关系保留但不显示）。
3. 切回「连线模式」即恢复连线显示。

## 管理连线

- 删除连线：点击连线选中后按 `Delete`，或右键连线选择删除。
- 引用版本：图片节点有多版本历史时，引用可固定（pinned）到某一版，或跟随最新版。

## 成功判据

- 连线生成后，下游节点面板的参考素材区出现上游条目（如「图片 1」）；
- 删除上游节点时连线一并消失；「历史 → 撤销」可恢复。
