# 使用提示词库

- **适用角色**：所有 TDCanvas 用户。
- **目标**：了解「提示词中心」的用途、当前可用状态，以及提示词与「我的资产」的关系。
- **前置条件**：已启动 TDCanvas。
- **入口**：顶部导航的「**提示词库**」。

## 当前版本的实际状态（重要）

**v0.14.0 全新安装后，提示词中心是空的**，页面显示「当前共 0 条提示词」和「没有找到匹配的提示词」。

这不是故障，而是当前版本的设计：提示词中心的内容**全部来自外部「提示词来源」**，而内置来源列表为空（源码 `prompt-source-presets.ts` 中 `DEFAULT_PROMPT_SOURCES` 为空数组），也没有向用户暴露添加来源的界面——实测在 `/canvas`、`/assets`、`/prompts`、`/config` 四个页面中均未出现「提示词来源」「新增来源」等入口。

![提示词中心空态：标题「提示词中心」旁显示当前共 0 条提示词，左侧分类与标签筛选，列表区提示没有找到匹配的提示词](../screenshots/15-prompt-library-empty.png)

**为什么值得知道这件事**：很多用户第一次打开这个页面会以为软件坏了，或者以为自己漏配了什么。实际上当前版本既没有内置内容，也没有配置入口——等待和反复刷新都不会让提示词出现。

因此在当前版本中：

- 想用提示词中心，需要先有可用的提示词来源配置；
- 若你看到空列表且没有任何配置入口，属当前版本限制，不是操作错误；
- 需要沉淀提示词时，请改用「**我的资产**」自行录入（见 [manage-assets.md](manage-assets.md)），该路径在当前版本完全可用。

## 那我该怎么做

**推荐路径：用自己的资产当提示词库。**

1. 打开顶部导航「我的资产」。
2. 点「新增资产」，类型选「文本」。
3. 标题写一个好检索的名字（如「人像摄影-侧逆光」），正文粘贴提示词，标签分类（如「摄影」「人像」）。
4. 保存后随时可搜索、编辑、复制、导出备份。

![资产管理页的新增资产入口](../screenshots/14-manage-assets-add-entry.png)

这样得到的提示词库完全在本机、可检索、可导出，**不依赖任何外部服务**——比等一个尚未开放的来源系统更实际。

## 有内容时的操作（供来源可用后参考）

以下为页面在存在提示词数据时的交互，标签取自当前版本界面与源码：

- **按标题搜索**：在搜索框输入关键词，匹配标题、内容或标签。
- **按分类筛选**：左栏「分类」中选择，右侧计数随之变化。
- **按标签筛选**：左栏「标签」胶囊可多选，「全部」表示清除标签筛选。
- **查看详情**：点击卡片打开详情弹窗，可复制完整提示词。
- **复制提示词**：卡片与详情弹窗均有复制操作，成功后提示「提示词已复制」。
- **加入资产**：卡片上的「加入资产」按钮会把该提示词存为**文本资产**（来源标注为「提示词库」），之后可在「我的资产」中检索编辑，详见 [manage-assets.md](manage-assets.md)。
- **加载更多**：列表滚动到底部时自动加载，底部文案在「继续向下滚动加载更多」与「已经到底了」之间切换。

## 成功判据

- 页面标题为「提示词中心」，标题右侧显示「当前共 N 条提示词」；
- 有数据时列表出现提示词卡片，且 `已显示 / 总数` 计数随筛选变化；
- 无数据时显示「没有找到匹配的提示词」，计数为 `0 / 0`。

## 已知限制

- 内置无提示词来源，需外部来源配置才有内容；
- 当前版本界面未提供添加/管理提示词来源的入口；
- 顶部导航称「提示词库」、页面标题称「提示词中心」，名称不统一。
