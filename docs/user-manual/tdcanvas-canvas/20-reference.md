# 参考：键位、限制、状态与设置

> 全部条目取自 TDCanvas `v0.14.0` 真实界面与快捷键弹窗。

## 鼠标与键位

| 操作 | 键位 / 方式 |
|---|---|
| 平移视图 | 拖动画布空白处 |
| 缩放画布 | 鼠标滚轮（5%–500%，以指针为锚） |
| 精确缩放 | 左下角缩放滑杆 |
| 重置视图 | 左下角「重置视图」按钮（有选中时聚焦选中节点） |
| 框选多个节点 | `Ctrl / Cmd` + 空白处拖动 |
| 追加/取消选择 | `Shift / Ctrl / Cmd` + 点击节点 |
| 全选节点 | `Ctrl / Cmd + A` |
| 复制 / 粘贴 | `Ctrl / Cmd + C` / `V`（可粘贴剪贴板文字或图片） |
| 创建副本 | 节点右键 → 制作副本（偏移 +36,+36） |
| 撤销 / 重做 | `Ctrl / Cmd + Z`；`Ctrl / Cmd + Shift + Z` 或 `Ctrl / Cmd + Y` |
| 删除选中 | `Delete` / `Backspace` |
| 取消选择并关闭浮层 | `Esc` |
| 编辑文字 | 双击文本节点内容 |
| 重命名节点 | 双击节点标题 |
| 上传素材 | 拖入图片/视频/音频文件 |

## 素材格式与限制

| 类型 | 格式 | 单文件上限 |
|---|---|---|
| 图片 | JPG / PNG / WebP | 50MB |
| 视频 | MP4 / MOV / AVI / MKV | 50MB |
| 音频 | MP3 / WAV / FLAC | 50MB |

- 节点尺寸范围：最小 220×160，最大 1600×1200；图片/视频默认锁定宽高比。
- 图片节点历史版本上限 24 条。

## 生成任务状态

| 状态 | 含义 | 可撤销？ | 费用 |
|---|---|---|---|
| 排队中 / 生成中 | 任务执行中，节点显示进度遮罩 | 可停止本地轮询 | 已计费 |
| 完成 | 结果写入节点（数量>1 时堆叠子图） | 历史可回退节点，图片历史保留 24 版 | 已计费 |
| 部分成功 | 批量中部分失败 | 重试失败项 | 按成功项计费 |
| 失败 | 请求被拒或出错 | 重试 | 通常不计费 |
| 等待补充参数 | 平台要求补充信息 | 按平台提示处理 | 视平台 |
| 已停止 | 本地停止轮询（**远端可能继续执行并计费**） | — | 可能已计费 |

## 连线与其他限制

- 同一节点对之间的连线不会重复（已有同向连线时再次拖线会被忽略）；
- 节点不能连接自己；组节点不参与连线；
- 一条非多选输入口只接受一条入线（占线后再拖入会被忽略）；
- 连线一旦建立不会自动消失，除非上游/下游节点被删除或连线被手动删除；
- 项目标题最长 64 字符；文本节点重命名同样最长 64 字符；
- 文本节点字号可调范围 10–32。

## 图片历史

- 每个图片节点保留最近 **24 个版本**；
- 从节点右上角「历史」入口切换版本；引用该节点的下游可「固定（pinned）」某一版。

## 画布设置（画布外观面板）

| 设置 | 选项 | 默认 |
|---|---|---|
| 画布输入模式 | 连线模式 / 无线模式 | 连线模式 |
| 主题模式 | 浅色 / 深色 | 深色 |
| 网格样式 | 点阵 / 线格 / 空白 | 点阵 |
| 图片信息 | 开 / 关 | 关 |
| 网格吸附（缩放 Dock） | 开 / 关 | 关 |
| 对齐辅助线 | 开（拖动时自动出现） | 开 |

## 数据与存储

| 数据 | 位置 | 说明 |
|---|---|---|
| 画布项目（节点/连线/视口/外观） | 本机 IndexedDB | 自动保存，无需手动保存 |
| 上传的素材文件 | 本机 IndexedDB | `storageKey` 稳定引用 |
| API Key | 本机配置 | 不会上传到画布仓库 |
| 导出包 | zip（projects.json v3 + 素材） | 首页多选导出 |
