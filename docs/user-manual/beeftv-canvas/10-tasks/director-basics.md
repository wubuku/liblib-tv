# 导演台入门：镜头、运镜与检查器

> 适用角色：所有用户 ｜ 白膜导出为本地渲染，不产生云端费用。

> 运行时实证（v1.6.13 构建实测）：入口已解禁（v1.6.7+ 移除「正在开发」），本篇流程与面板均经真实走查；**摄影机模式右栏**表现为 FOV 直输（见下）。镜头检查器里的「焦距/光圈」并未消失，只是移到了另一处——两处并存，本篇一并说明。

## 目标

在三维导演台里摆放镜头、选择运镜，用检查器精确控制画面。

## 进入与就绪（v1.6.13 实测流程）

1. 「添加节点」菜单点「导演台」（v1.6.13 起无「正在开发」标）；
2. 弹出**「选择镜头模板」**：空场景（摄影机+布光）/ 单人对白（1 演员·中近景）/ 双人对话（2 演员·对话机位）/ 人物走位（3 演员·广角）/ 产品/道具镜头（产品+背景板·长焦）；
3. 选定后在画布创建**「镜头 N」节点**：空态卡提示「在3D空间中搭建场景并进行多视角截图」，带「打开导演台」按钮与「场景描述」输入（支持通过参考图创建）；
4. 点「打开导演台」进入 3D 工作台；模板可连续选择、一次创建多个镜头节点。

## 工作台总览

![导演工作台（摆场模式）](../screenshots/33-director-workbench.png)

- 顶栏：场景名称（可直接改名）· 撤销/重做 · **摆场 / 姿态 / 动画 / 摄影机**四模式 · 已保存状态 · 预览画质 · **导出白膜** · **应用到镜头**；
- 左栏：场景树（主摄影机、主光/轮廓光/环境光三点布光，均带删除钮），底部快速添加（添加角色/添加机位/全景图/选择画幅比例/素材）；
- 视口：顶部是取景模式切换与方向球，底部是视口工具条（明细见下两节）；
- 右栏随模式切换：3D 场景（缩放/平移/旋转、全景背景、天空颜色、全景球水平旋转与半径）或对应检查器；
- 首次进入有 **6 步**上手引导：添加演员 → 移动 → 调姿 → 轨迹 → CAM → 应用（可跳过，可「重新开始引导」）。

### 视口底部工具条

工具条分四组，中间用细竖线分隔：

| 组 | 按钮 |
|---|---|
| 变换 | 一个**下拉**（不是三个独立按钮）：移动 `V` / 旋转 `R` / 缩放 `F`，按钮本身显示当前模式 |
| 视口 | **截图**（视口尚未加载时禁用，提示「视口加载中」）、**动画时间轴**（按下即展开，再按收起） |
| 增删对象 | **添加演员**、**添加立方体**、**添加灯光**、**添加摄影机**、**摄影机对齐当前视图** |
| 渲染视图 | 构图预览 / 彩色白膜 / 骨骼视图 / 深度视图 / 法线视图——**实际显示哪几个由当前模式决定**，见下表 |

::: tip 「添加灯光」点开是四种，不是一盏
| 类型 | 用途 | 放下时的默认位置 / 强度 |
|---|---|---|
| 方向光 | 平行光，全场一个方向，适合打底 | [4, 6, 4] / 2.4 |
| 点光源 | 从某点向四周发散 | [2, 3, 2] / 1.5 |
| 聚光灯 | 带锥形范围的定向光 | [2, 4, 2] / 2 |
| 环境光 | 无位置的概念光，均匀提亮全场 | [0, 0, 0] / 0.65 |

选中任意一盏灯后，右栏出现灯光检查器，五个字段：**类型 / 位置 X·Y·Z / 颜色 / 强度（0–20，步长 0.1）/ 投射阴影（开关）**。环境光落在原点是正常的——它本来就不靠位置起作用。

::: warning 渲染视图按钮会随模式增减，不是固定五个
这是最容易找不到按钮的地方——**不同模式下底部工具条末尾的渲染视图按钮数量不同**：

| 顶栏模式 | 可用的渲染视图 |
|---|---|
| **摆场** | 构图预览、彩色白膜 |
| **姿态** | 构图预览、彩色白膜、**骨骼视图** |
| **动画** | 构图预览、彩色白膜、**骨骼视图** |
| **摄影机** | 构图预览、彩色白膜、**深度视图**、**法线视图** |

也就是说：**骨骼视图**要到「姿态」或「动画」模式才出现，**深度/法线视图**只有「摄影机」模式才有。摆场模式故意不给这些高级视图——先把人和物放对位置。切换模式时按钮会自动增减，**不是按钮坏了**。
:::

### 四模式的能力差异

顶栏四个模式不只是换个右栏，它们各自开放的功能也不同：

| 模式 | 时间轴 | 关键帧 / Auto Key | 骨骼 | 机位面板（跟随/注视/FOV） |
|---|---|---|---|---|
| 摆场 | — | — | — | — |
| 姿态 | — | — | ✅ | — |
| 动画 | ✅ | ✅ | ✅ | — |
| 摄影机 | — | — | — | ✅ |

**动画**是唯一显示时间轴、允许录关键帧与 Auto Key 的模式；**摄影机**是唯一展开机位面板的模式。

::: warning 「机位面板」不等于「运镜」
最后一列说的是**跟随目标 / 注视目标 / 视野角度**这一组机位参数，它只在摄影机模式展开。
但**景别**与**运镜**属于镜头检查器（下节「摄影机模式与检查器」），**四个模式都改得了**——
在摆场/姿态/动画模式下，先在视口里点空白处取消选中，右栏就会回落到同一个镜头检查器。
所以「只有摄影机模式能设运镜」是个常见误解。

### 一级模式 ≠ 取景模式

导演台有两组正交的开关，很容易混：

- **一级模式**（顶栏，摆场/姿态/动画/摄影机）决定「**能改什么**」；
- **取景模式**（视口顶部「导演视角 / 机位视角」+ 方向球）决定「**从哪只眼睛看**」。

取景模式有 7 个：3D（自由视角，可拖拽环绕）/ CAM（按当前镜头摄影机取景）/ TOP 俯视 / FRONT 正视 / BACK 背视 / LEFT 左视 / RIGHT 右视，另有「重置视角」。

除 3D 外，其余六个都**锁定环绕**——拖拽会破坏取景，所以它们会阻止你自由转动视角。取景只改变观看角度，**不修改场景内容，也不会产生一条撤销记录**。

## 摄影机模式与检查器（v1.6.13 重构后）

![摄影机检查器](../screenshots/34-camera-inspector.png)

摄影机模式下右栏顶部是**摄像机**面板，下方分**属性 / 截图**两个页签。「属性」页签里其实**叠了两层**：上层是机位参数，下层是镜头参数。

### 上层：机位面板（仅摄影机模式）

| 参数 | 说明 |
|---|---|
| 名称 / 切换机位 | 机位命名与下拉切换（如主摄影机） |
| 位置 X/Y/Z | 数值直输 |
| 跟随目标 | 下拉选择跟随的角色或「不跟随」（v1.6.13 相机跟随） |
| 注视目标 | 下拉选择注视对象，或「手动坐标」（出注视坐标）/「旋转」（出旋转角） |
| 视野角度 (FOV) | 滑杆 + 数值直输（拖动范围 15–90，模板入口默认约 54.4） |

### 下层：镜头检查器（四个模式都有）

这一层是**镜头本身**的参数，**摆场/姿态/动画/摄影机四个模式都能改**——非摄影机模式下，在视口点空白处取消选中，右栏就回落到它。

| 参数 | 可选值 |
|---|---|
| 景别 | 6 档：大远景 / 远景 / 全身景 / 中景 / 近景 / 大特写 |
| 帧率 | 24 / 25 / 30 fps |
| 运镜 | 10 种：固定 / 推进 / 拉远 / 左摇 / 右摇 / 上摇 / 下摇 / 左环绕 / 右环绕 / 手持 |
| 时长 | 0.5–60 秒，步长 0.5 |
| 镜头意图 | 自由文本（人物表演、动作、叙事目标…） |
| 焦距 | 12–200 mm |
| 光圈 | f/0.7–f/32，步长 0.1 |
| 焦点距离 | 0.1–200 m，步长 0.1 |

**焦距与 FOV 是联动的**：在这一层拖焦距，上层 FOV 会跟着换算；反过来在上层拖 FOV 滑杆，这里的焦距也会同步。两者是同一枚硬币的两面，不是两套互相独立的参数。

> 走「选择镜头模板」进来时，FOV 初始值就是由模板的 35mm 焦距换算出来的（约 54.4），两者天然一致。
> 但如果你是用视口底栏的「**添加摄影机**」直接加的，初值是 FOV 50 配焦距 35——这对数字按换算并不吻合（35mm 应当对应约 54.4）。
> 不用管它：随便动一下上面任意一个数值，两者立刻按 35mm 全画幅重新对齐。

::: tip 摄影机模式下少了两项，不是有 bug
切到摄影机模式，上层机位面板已经给了「切换机位」，所以下层镜头检查器里的**「摄影机」下拉**和**「摄影机位置 / 焦点」坐标**会自动隐藏，避免出现两个机位入口。
**景别、运镜、焦距、光圈、焦点距离则始终保留。**
:::

### 选完运镜之后
下层的「**按运镜生成轨迹**」会按你选的运镜把摄影机位置写成一条轨迹；「记录摄影机关键帧」则**只在动画模式**出现（其它模式没有关键帧可录）。

## 三个关键按钮

| 按钮 | 行为 |
|---|---|
| 摄影机对齐当前视图 | 把镜头摆到你当前看到的视角 |
| 应用到镜头 | 把工作台状态写回画布上的镜头节点 |
| 导出白膜 | 本地渲染导出白模视频（不产生云端费用） |

另外镜头检查器里还有「按运镜生成轨迹」和「记录摄影机关键帧」两个按钮，见上节「选完运镜之后」。

## 其他

- **H 键**在导演台是「显隐切换」，与画布的抓手平移不同；
- 网格、地面与环境光自动就位；
- 会话中断（如页面刷新）后有恢复流程：能力恢复 → 重新注册 → 必要时提示重建场景。
