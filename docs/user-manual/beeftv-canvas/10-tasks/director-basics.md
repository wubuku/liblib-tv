# 导演台入门：镜头、运镜与检查器

> 适用角色：所有用户 ｜ 白膜导出为本地渲染，不产生云端费用。

> 增量注记（v1.6.13）：导演台工作台大幅扩展——新增**场景控制**（场景检查器/场景搜索/可见性开关）、**相机跟随**、**画幅框**（宽高比取景框）、**截图与全景生成历史**（截图画廊）、统一缩放与舞台调色板等；场景封面会被保留，重新打开画布不会因迟到上传/截图被覆盖。本篇以下按既有面板描述，新面板按入口名对应。

## 目标

在三维导演台里摆放镜头、选择运镜，用检查器精确控制画面。

## 进入与就绪

从「添加节点」菜单点击「导演台」（标记「正在开发」，功能逐步开放）。视口就绪后页面会携带真实就绪信号（供自动化在触发 context loss 前确定监听器已安装）；加载失败时仅视口区域显示错误与重试，**导演台其余面板仍可使用**。

## 镜头与检查器

摄影机模式下右栏固定为 **ShotInspector（镜头检查器）**：

| 参数 | 范围 |
|---|---|
| 焦距 | 12–200mm（实时换算 FOV） |
| 光圈 | f/0.7–32 |
| 焦点距离 | 0.1–200m |
| 时长 | 0.5–60s（步进 0.5） |
| 帧率 | 24 / 25 / 30 |
| 景别 | 大远景 / 远景 / 全身景 / 中景 / 近景 / 大特写（6 档） |
| 运镜 | 静态 / 推近 / 拉远 / 左摇 / 右摇 / 上仰 / 下俯 / 左环绕 / 右环绕 / 手持（10 种） |

## 三个关键按钮

| 按钮 | 行为 |
|---|---|
| 摄影机对齐当前视图 | 把镜头摆到你当前看到的视角 |
| 按运镜生成轨迹 | 按所选运镜自动生成首尾关键帧对（不同运镜有预设位移偏移） |
| 记录摄影机关键帧 | 在当前播放头记录关键帧（需关键帧能力开启） |

## 其他

- **H 键**在导演台是「显隐切换」，与画布的抓手平移不同；
- 网格、地面与环境光自动就位；OrbitControls 限制距离 0.6–80；
- 会话中断（如页面刷新）后有恢复流程：能力恢复 → 重新注册 → 必要时提示重建场景。
