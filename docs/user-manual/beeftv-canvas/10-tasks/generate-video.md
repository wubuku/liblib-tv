# 发起视频生成与素材限制

> 适用角色：所有用户 ｜ **视频生成计费显著高于图片**，提交前请确认参数。

## 目标

从视频节点发起生成，理解「素材限制」校验，避免提交后被拒。

## 前置条件

- 视频节点已连接参考素材并配置好渠道（不同渠道/模型能力不同）。

![视频节点与生成 composer（模型 2.0，720P·1:1·6s）](../screenshots/09-image-node.png)

选中视频节点后，底部弹出生成 composer：输入「描述你想要生成的画面内容，@引用素材」，右侧选择模型与参数（如 720P·1:1·6s），点发送提交。

> 实测（模型芯片行为）：composer 左下为当前模型芯片（如「2.0」）；**模型清单由已配置渠道驱动**——未配置任何渠道的新实例上点击芯片会直接跳转「模型配置」页引导接入（源码 `model-picker.tsx`：打开时无候选即触发 onMissingConfig）。先在「模型配置」接入渠道，芯片才会展开可选项。空提示词时「生成」按钮为禁用态。

## Seedance 任务模式（2.0/2.5）

不同的任务模式决定哪些参数可自定义：

| 模式 | 素材角色 | 比例 | 时长 |
|---|---|---|---|
| 文本或语义参考生成 | reference_image/video/audio | 可设置 | 可设置 |
| 首帧、首尾帧 | first_frame/last_frame | 自适应（跟随首帧） | 可设置 |
| 编辑视频 | 参考视频及其他素材 | 自适应 | -1（跟随原视频） |
| 延长视频 | 参考视频及其他素材 | 自适应 | 可设置 |

- 2.0 与 2.5 的约束不同；明确的素材角色与所选模式会被保留发送（首帧任务显式发自适应比例，普通参考视频不会因含视频就被改成编辑/延长）；
- 画布专业模式可明确选择「参考生成」或「首尾帧」；界面只显示当前渠道已声明支持的模式；
- **首帧/编辑/延长跟随源媒体**（v1.6.7 起）：这类模式的界面会明示比例与时长随源视频、不可自由设置；首帧不兼容时会给出可操作的错误指引。

> **付费风险确认（v1.6.7 起）**：在受影响渠道上对 Seedance 2.0 标准版 / 2.5 发起参考视频生成时，若请求的画幅比可能不被遵守，提交前会**先弹确认**——这是「可能白花钱」的保护，请看清提示再决定。生成完成后若实测画幅比与请求不符，视频仍会保留并附带提示。

## 三层限制：提交前后分别核对

1. **模型能力**：模型版本、任务模式、素材种类/数量/时长/尺寸/分辨率；
2. **接入合同**：方舟原生 API、BeefAPI、第三方中转的字段与默认值分别核对，不能互相代替；
3. **内容审核**：输入与输出的审核结果**不等同参数错误**——修改尺寸解决不了版权审核失败。

## 素材限制：提交前就会校验

点击生成时，系统会按**当前模型的能力配置**校验参考素材：

- 参考图片的**尺寸、宽高比、文件大小**；
- 音频/视频的**时长**与**尺寸**（v1.6.8 起：时长已知也会读取视频实际尺寸；不可读或超范围的视频提交前即被拒绝，本地与内联视频以实际文件为准而非旧元数据）；
- 参考视频的**帧率**（v1.6.10 起：素材转换路由会检查普通、分片与混合 MP4）；
- 参考素材的**数量上限**与**类型**（v1.6.11 起：不支持的参考类型/数量提交前拒绝）。

不符合限制的素材会在提交时得到明确错误提示（而不是静默丢弃或偷偷降级）；像素超限类错误会**指明是哪个参考、实际尺寸与允许范围**（v1.6.8 起）。看到限制类报错时：更换/裁剪素材，或切换到能力匹配的模型。

> 增量注记（v1.6.11）：经 BeefAPI 提交 Wan 3.0 视频任务时本地参考图被误拒的问题已修复——本地素材可正常作为参考。

## 提交后

- 任务进入与图片一致的徽章/耗时/浮层跟踪（见 [generate-images.md](generate-images.md)）；
- **网关超时（524）等「提交不确定」情形不会自动重试**——请先看该节点的状态徽章确认实际结果，再决定是否重发，避免重复扣费（没有「任务中心」页面，`/tasks` 已退场；「生成历史」只列已成功的结果）。

## 视频节点工具条上到底有什么

有内容的视频节点被选中后，浮在节点上方的那条工具条**只有这四项**（源码 `canvas-node-toolbar.tsx` 的 `isVideo` 分支）：

| 位置 | 入口 | 做什么 |
|---|---|---|
| 菜单 | **视频处理 ∨** | 视频剪辑（进入剪辑台）/ 画面裁切 / 深度动作捕捉 |
| 按钮 | **音视频分离** | 拆出音频节点，保留原视频声音 |
| 菜单 | **关键帧截取 ∨** | 截取当前帧 / 截取首帧 / 截取尾帧 |
| 按钮 | **预览**、**下载** | 放大预览、下载文件 |

::: tip 找不到「字幕」「保存为素材」「删除」是正常的
工具条的注册表里确实登记了这些工具，但**视频节点不会渲染它们**：

- **字幕**：视频节点没有字幕按钮。要编辑字幕，得走「视频处理 → 视频剪辑」进时间线，再点 S 轨字幕片段上的「精细编辑」——完整四步见 [subtitle-highlights.md](subtitle-highlights.md)。
- **保存为素材**：视频节点工具条上不提供，改用「下载」把文件存到本地。
- **删除**：工具条上**本来就没有**删除按钮。删除节点用 `Delete` / `Backspace`，或右键菜单里的「删除节点」。可回收的删除见 [undo-history-versions.md](undo-history-versions.md)。

这些工具在**图片 / 文本 / 音频**节点的工具条上是正常的——只有视频节点走的是另一套精简渲染。
:::

## 失败后取回原结果（v1.6.16 起）

视频任务失败时，**先别重发**。任务详情里会出现「查询原任务并取回视频，不会重新生成。」的说明和「**取回结果**」按钮，点它会用原任务去上游查结果并下载——**不产生第二次计费**：

- 取回到画布：「视频已取回并放回画布，未重新生成」；
- 上游还在处理：「原任务仍在处理中，请稍后再取回结果」，过一会儿再点即可；
- 节点已不在画布：「视频已取回，请在生成历史中查看」。

该按钮只在任务支持向上游查询时出现。下载环节断线造成的失败，后台会做**有界恢复**尝试。

画布上失败节点上的「**查看原任务**」按钮、以及批量子节点上的同名按钮，都会打开同一个任务详情。

> 报障前记得点失败提示里的「**复制排查信息**」——复制出来的结构化文本（含任务 ID、请求 ID、上游代码）比截图有用得多，详见 [90-troubleshooting.md](../90-troubleshooting.md)。

## 任务 ID 只证明创建成功

部分 Seedance 2.5 任务要到消费阶段才返回参数错误。遇到 `InvalidParameter.TaskTypeConstraint` 时，核对最终发送的 `ratio`、`duration` 和每个素材的 role（包括省略的字段）；外层包装错误（如 `fail_to_fetch_task`）不能覆盖内部的具体参数原因。
