# 发起图片生成：任务状态、批量与重试

> 适用角色：所有用户 ｜ **本页操作涉及按量计费**，请先确认渠道配置与额度。

## 目标

从一个图片节点发起生成，看懂任务状态徽章，掌握批量出图与失败重试。

## 前置条件

- 图片节点已连线上游参考（或提示词中已 @mention）；
- 管理员已配置可用的生成渠道（见 [plugins-management.md](plugins-management.md)）。

## 发起生成

1. 选中图片节点，在提示词面板填写提示词（参考 [prompts-and-mentions.md](prompts-and-mentions.md)）；
2. 设置份数（count>1 时自动创建 root + N 个子节点，首张成功后回填为主图）；
3. 点击生成。**同一节点用完全相同的提示词、模型、参数和参考再次提交时，会弹出「可能再次消耗积分」的确认**——这是防重复扣费的保护，确认才会继续。

![文本节点工具条：文本生成 / 放大编辑 / 生图 / 文本调整，「生图」入口在工具条第三项](../screenshots/04-text-node.png)

### 可选参数（随模型能力档案变化）

和视频一样，图片参数也是**跟着模型走**的，不同模型给的档位不一样。

| 项 | 可选值 |
|---|---|
| 质量档 | **1K / 2K / 4K** |
| 比例 | 1:1 · 16:9 · 9:16 · 4:3 · 3:4 · 3:2 · 2:3 · 4:5 · 5:4 · 21:9（**10 档**，比视频多 2:3、4:5、5:4） |
| 实际像素 | 每个比例在每个质量档下都有对应像素，例如 1:1 依次是 1024×1024 / 2048×2048 / 2880×2880 |

::: tip 记不住也没关系
面板里**只显示你当前模型支持的那些档**，不会把全部选项都摆出来。换个模型，比例与质量档会跟着变——**以面板里实际出现的为准**。
:::

> 想看某个模型到底支持什么：先在「模型配置」接入渠道，模型芯片才会展开可选项。视频侧的参数清单见 [generate-video.md](generate-video.md)。

## 任务状态

进行中的节点显示徽章、spinner、阶段文案与**已耗时**；右上角任务浮层列出当前活跃任务（最多 5 条），2 秒/10 秒自适应轮询，窗口聚焦即时刷新。

> 任务详情实时刷新（v1.6.14 起）：打开任务详情后，**进度、日志与开始/完成时间**在任务运行期间持续同步；任务完成后自动停止详情轮询，关闭或切换任务会取消未完成的读取；详情暂时刷不出来时会显示重试提示。

| 状态 | 含义 |
|---|---|
| 排队/运行中 | 任务已提交，等待或生成中 |
| succeeded / failed / cancelled | 终态 |
| 提交不确定（如 524 网关超时） | 结果未知，系统**不会自动重试**——先看该节点的状态徽章确认结果再手动操作，避免重复扣费（没有「任务中心」页面，`/tasks` 已退场） |

## 刷新与恢复

页面刷新后，系统按 taskId 与服务端任务列表**对账恢复**：仍在运行的任务继续跟踪；没有任务身份的孤立「加载中」节点会被标记为本地中断，不会覆盖已完成结果。

## 失败与重试

- 失败时**旧结果不会被清空**；
- 因「输入未变」被审核类规则拒绝的任务不会自动重试；
- 手动重试会重建上下文：从最初生成的节点恢复引用；引用已丢失时会拒绝并提示；重试使用幂等 id，不会重复扣费。

## 失败提示里的三个按钮

生成失败时，提示条上会按情况给出：

| 按钮 | 何时出现 | 作用 |
|---|---|---|
| 查看详情 / **查看原任务** | 状态不确定（如 524）时显示「查看原任务」 | 打开任务详情，看真实进度与日志 |
| **复制排查信息** | 有可复制的诊断内容时 | 复制结构化排查文本（原因/下一步/类别/上游代码/任务 ID/请求 ID/模型/时间），报障时整段贴出即可 |
| 重试 | 该失败允许重试时 | 走上面的重试流程 |

「复制排查信息」自 **v1.6.15** 起升级到版本 2：新增**请求 ID** 与**上游代码**，并保留错误来源与请求证据（上游 HTTP 响应 / 上游业务响应 / HTTP 错误 / 传输或读取失败），所有文本经脱敏。同一时期，**丢失提交回执会被记为「未确认」而不是静默重发**，所以不会再出现系统替你重复提交的情况。

视频任务还有一条专用的「取回结果」恢复路径，见 [generate-video.md](generate-video.md)。
