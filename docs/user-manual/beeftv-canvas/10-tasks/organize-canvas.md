# 整理画布、Frame 分组与外观

> 适用角色：所有用户。

## 目标

让画布保持整洁：一键整理、用 Frame/文件夹分组、按喜好切换主题与网格。

## 底部工具条

底部居中的工具条是画布视图的操作中心，从左到右：

| 入口 | 作用 |
|---|---|
| 添加节点 | 在画布中心新建节点 |
| 移动 | 切换到移动工具（也可按 V） |
| 资产管理 | 打开素材管理抽屉 |
| 画布外观 | 打开外观面板（见下节） |
| 生成历史 | 打开生成历史弹窗，可复用历史结果 |
| 画布快捷键 | 打开快捷键中心 |

左下角一排是**视图开关**：资产管理入口、**隐藏节点连线**、**切换小地图**、**网格吸附**、**适合屏幕**、**自动整理节点**，以及缩放百分比。

## 自动整理

| 操作 | 入口 | 行为 |
|---|---|---|
| 自适应整理画布 | 空白右键（多选时）→「自适应整理画布」 | 保持相对布局并加大边距 |
| 自动整理 | 底部工具条「自动整理节点」或 Alt+Shift+F | 有选区时只整理选中项；无选区整理全部顶层节点；至少需要两个可整理节点 |

整理按**媒体类型分类**排布——执行后会提示「已按媒体分类整理画布」。锁定（locked）的节点、frame 本体、隐藏的批量子节点不会参与整理。

::: tip 整理前先散开
节点互相重叠时，先点「自动整理节点」再点「适合屏幕」，才看得清每个节点的位置。
:::

## Frame 与文件夹

- 从「添加节点」菜单创建**背板**（Frame，6 款样式）或**文件夹**；
- 把节点拖进 frame 即加入分组（显式成员关系，拖入即归属）；
- **折叠** frame：子节点随之隐藏，连线自动改道到 frame 边缘；
- **文件夹折叠后显示为封面卡**（内容缩略图）；
- 折叠/展开按钮带无障碍标签「折叠背板 / 展开背板」。

## 画布外观

底部工具条「**画布外观**」打开面板，四组设置：

![画布外观面板：主题模式三选一、空间网格点线空白三态、网格吸附 16px 与显示连线开关](../screenshots/44-appearance-panel.png)

| 分组 | 选项 |
|---|---|
| **主题模式** | 浅色 / 深色 / 自定义；选「自定义」后可挑背景色，并显示基底是「浅色界面」还是「深色界面」 |
| **空间网格** | **点**（点阵）/ **线**（网格线）/ **空白**，三选一 |
| **网格吸附** | 开关，标注 **16px**——开启后拖动按 16px 对齐 |
| **显示连线** | 开关——节点多时关掉连线，视野更干净 |

> 自定义皮肤的具体色板由管理员配置；浅色模式自 v1.5.8 起可用。切换主题只影响显示，不改变任何素材或生成结果。

## 找东西

- **切换小地图**：左下角开关，打开后画布一角显示缩略图，节点密集时用来定位；
- **画布快捷键**：底部工具条进入快捷键中心，完整键位表见 [shortcuts-help.md](shortcuts-help.md) 与 [20-reference.md](../20-reference.md)；
- **搜索画布节点**：按 **⌘F**（Windows 为 Ctrl+F）打开，按名称或内容搜索并定位节点；
- **素材管理**：底部工具条「资产管理」打开抽屉，可按媒体类型浏览与插入（见 [upload-materials.md](upload-materials.md)）。
