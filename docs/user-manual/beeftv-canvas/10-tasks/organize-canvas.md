# 整理画布、Frame 分组与外观

> 适用角色：所有用户。

## 目标

让画布保持整洁：一键整理、用 Frame/文件夹分组、按喜好切换主题与背景。

## 自动整理

| 操作 | 入口 | 行为 |
|---|---|---|
| 自适应整理画布 | 空白右键（多选时）→「自适应整理画布」 | 保持相对布局并加大边距 |
| 自动整理 | Alt+Shift+F | 有选区时只整理选中项；无选区整理全部顶层节点；至少需要两个可整理节点 |

锁定（locked）的节点、frame 本体、隐藏的批量子节点不会参与整理。

## Frame 与文件夹

- 从「添加节点」菜单创建**背板**（Frame，6 款样式）或**文件夹**；
- 把节点拖进 frame 即加入分组（显式成员关系，拖入即归属）；
- **折叠** frame：子节点随之隐藏，连线自动改道到 frame 边缘；
- **文件夹折叠后显示为封面卡**（内容缩略图）；
- 折叠/展开按钮带无障碍标签「折叠背板 / 展开背板」。

## 外观

- **主题**：浅色 / 深色 / 自定义（自定义皮肤由管理员配置；v1.5.8 起支持浅色模式）；
- **画布背景**：默认点阵（dots），支持切换；
- 入口：顶栏「画布外观」面板。
