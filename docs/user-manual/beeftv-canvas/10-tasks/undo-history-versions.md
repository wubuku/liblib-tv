# 撤销重做、版本历史与回收站

> 适用角色：所有用户。
> **版本提示**：本页的「导入画布」按钮是 **v1.6.22 恢复**的入口（v1.6.16 源码里项目库只有「回收站 / 新建文件夹」）。**你的版本若低于 v1.6.22，这个按钮不存在**——那时只能用「导出」先存成 zip 文件。

## 目标

放心地改：弄错的操作能撤销，重要的状态有版本可回，删除的项目能找回。

## 撤销与重做

| 快捷键 | 行为 |
|---|---|
| Ctrl/Cmd + Z | 撤销 |
| Ctrl/Cmd + Shift + Z 或 Ctrl/Cmd + Y | 重做 |

- 撤销栈按**实体差异**记录（哪个节点/连线改了什么），连续的小改动会在 180ms 内自动合并成一步；
- 拖动节点过程中暂停记录——拖完算一步；
- 注意：**画布撤销不会取消已经提交的生成任务**（提交审批时的警告文案已明示）。要停止任务请用任务取消。

## 版本历史

入口：画布顶栏 → 版本记录。

![版本记录侧栏：本机备份条目（v1.6.6 重摄）](../screenshots/07-version-history.png)

- **云端 / 本地** 双标签页——本地标签在云端部署下叫「**本地草稿**」，纯本地项目下叫「**本地历史**」；
- 纯本地项目的条目显示为「**本机备份**」，带「基于 vX」角标与「N 个节点 · M 条连线」计数（云端版本条目同样显示节点/连线计数）；
- ::: tip 含绘图的历史只剩预览
  预览旧版本时若有绘图节点，会提示「**绘图仅保留已上传的预览，不含本机历史笔画**」——手绘笔迹不会进历史，需要的话请单独保存。
  :::
- 每条历史可**只读预览整张画布**，确认后再恢复；
- **恢复前自动备份**：点恢复时会先备份当前云端内容（版本原因标记为「恢复前备份」，区别于「自动保存」），**并保留本地草稿**；恢复本身会生成一个新版本，画布的项目归属保持当前设置——所以恢复操作本身也可撤销。

![项目列表页与「回收站」入口](../screenshots/16-project-list.png)

![项目卡操作菜单：六项操作](../screenshots/27-project-ops-menu.png)

> 端到端实测（v1.6.14 运行时走查）：「删除项目」→ 项目立即从列表消失并进入回收站（无二次确认弹窗）；「回收站」中条目带删除时间，勾选前「恢复 / 彻底删除」均为禁用态；勾选后点「恢复」→ 弹窗关闭、项目回到列表。全链路与源码行为一致。

## 画布备份：导出与导入

项目列表页右上角有两个相邻的入口，成对使用：

| 入口 | 位置 | 作用 |
|---|---|---|
| **导出** | 先勾选要保存的项目，操作栏出现「导出」按钮 | 把选中的画布打包成 **zip** 文件下载到本地 |
| **导入画布** | 操作栏常驻按钮（v1.6.22 起） | 从本地 zip 文件把画布恢复到项目库 |

- 文件选择框只接受 **`application/zip` / `.zip`**，选别的格式会被直接过滤掉。
- 两个按钮在**页面刚加载完之前是灰的**（等本地存储就绪），刷新后即可点。
- 导出失败时提示「**画布不存在，无法导出**」——多半是你勾选后画布已被删除或移动。
- 导入成功后提示会告诉你**导进来几个画布**：「已导入 N 个画布」；若云端同步没跟上，会追加一句「**云端同步未完成，将自动重试**」，这不等于导入失败。
- 一个 zip 里可以装**多个画布**，导入后全部进库。
- 导入**不会覆盖同名画布**——每次导入都生成新的项目 id，所以重复导入同一个文件会得到多个副本。

> **注意版本差异**：「导入画布」是 **v1.6.22 恢复**的入口。**v1.6.16 及更早版本的项目库里没有这个按钮**，
> 那时只能导出、不能在界面里导回来。手册的取证基线是 v1.6.16（见 [参考：快捷键全表、路由与端点](../20-reference.md)），
> 所以本节描述的是上游后续版本的行为。

- 删除的项目进入回收站，保留**最近 200 条完整快照**；
- **恢复**：勾选后点「恢复」（图标 ↩，恢复到项目列表）；恢复是幂等的——同名项目已存在时不会产生副本；
- **彻底删除**：点「彻底删除」（红色）→ 弹出「确认彻底删除？」二次确认 → 确认后不可恢复；
- 支持「全选」与「已选择 N 项」批量操作；确认弹窗点击遮罩即可取消。

::: warning 这里说的回收站和素材归档不是一回事
画布库这个回收站装的是**你删掉的画布**，保留最近 200 条、由你手动清理。而**素材归档**是另一套机制：被删掉或到期清理的素材文件进那里，**默认部署 30 天后由后台自动彻底清除**（不是 200 条，是按天算）——**但本地部署的保留天数是 0，清理任务会直接返回、也就是永远不会自动清**，删掉的素材得你自己处理（见 [账号存储、容量与配额](storage-quota.md)）。

也就是说：**画布删了能找回，素材删了最多等一个月**。两者的配额与行为见 [账号存储、容量与配额](storage-quota.md)。
:::
