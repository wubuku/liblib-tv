# 云端 Agent：发起任务、审批与插话

> 适用角色：Agent 用户 ｜ Agent 执行中的生成操作涉及按量计费。

> 状态注记（v1.6.14 源码核查，Batch 33）：旧桌面 Agent 的交互面板组件在当前版本**未挂载**（`canvas-creative-interaction.tsx` 无任何引用点，属「旧桌面 Agent 退场」后的遗留）；后端 Agent API（`POST /agent/runs` 等）在位，等待新入口接入。本篇按后端契约与历史面板结构成稿，入口开放后回走。
## 目标

用自然语言让云端 Agent 替你操作画布；在关键节点审批，随时插话补充。

## 发起与对话

1. 打开云 Agent 面板，输入目标发起运行；
2. Agent 按「行为策略 + 你的目标 + 参考事实」执行，过程中可以**继续发消息**（多轮续聊）；
3. 运行中可以**插话**：插话不会打断正在执行的操作，在下一步生效（可先插话排队）；
4. 状态：排队 / 运行中 / 等待审批 / 已完成 / 异常 / 已停止 / 已拒绝。

## 审批

- 需要审批的操作会先展示**预览**：目标节点、操作类型、修改字段、名称变化与连线两端——不需要你猜内部 ID；
- 首次出现 ≥2 项的待办清单会先请你确认；`auto` 模式直接建立；
- 画布写入使用内容快照哈希校验，未批准不会落盘；
- 画布 Agent 的写画布操作走「8 种封闭操作 + 事后事实复核」——每次操作后系统会核对结果（例如「资源物化才算完成」），失败会如实报告。

## 上下文与预算

- 历史上下文有预算（约 192KB），较旧的内容会按轮省略并**明示**「上下文整理说明」，不会假装记得；
- 单轮工具结果与上下文超限（约 384KB / 96k token）会**直接硬失败**并提示缩小下一步范围——已完成的操作会保留。

## 取消

运行可随时取消（15 秒超时保护）；取消后已完成的操作保留。
