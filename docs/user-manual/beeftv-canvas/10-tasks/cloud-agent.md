# 云端 Agent：发起任务、审批与插话

> 适用角色：Agent 用户 ｜ Agent 执行中的生成操作涉及按量计费。

> **当前状态（v1.6.22 源码核查）**：云端 Agent 的**前后端都已退场**。界面侧：旧桌面 Agent 的交互面板组件 `canvas-creative-interaction.tsx` 在当前版本没有任何引用点；后端侧：**没有注册任何 `/agent/*` 路由**，上游用 `agent_retired_test.go` 以真实 HTTP 路由图固化了这条边界，命中时服务端提示「Agent 能力已下线，请在画布中手动创建节点并生成」。下面写的是**历史机制**（曾如何设计），不是你现在能点到的操作——请先看文末「现在能做什么」。

## 目标

用自然语言让云端 Agent 替你操作画布；在关键节点审批，随时插话补充。

## 发起与对话

::: warning 这一节写的是**历史机制**，当前版本没有这个面板
下面四条是**曾经**的操作方式（面板、发起、多轮续聊、插话）。**云端 Agent 的前后端在 v1.6.16 已整体退场**（页面顶部写明了依据）——你**在当前版本里找不到「云 Agent 面板」**。本节留在手册里，是因为同一套交互设计与审批模型在别处仍有参考价值；**但它不是你现在能照做的操作**。
:::

1. 打开云 Agent 面板，输入目标发起运行；
2. Agent 按「行为策略 + 你的目标 + 参考事实」执行，过程中可以**继续发消息**（多轮续聊）；
3. 运行中可以**插话**：插话不会打断正在执行的操作，在下一步生效（可先插话排队）；
4. 状态：排队 / 运行中 / 等待审批 / 已完成 / 异常 / 已停止 / 已拒绝。

## 审批

- 需要审批的操作会先展示**预览**：目标节点、操作类型、修改字段、名称变化与连线两端——不需要你猜内部 ID；
- 首次出现 ≥2 项的待办清单会先请你确认；`auto` 模式直接建立；
- 画布写入使用内容快照哈希校验，未批准不会落盘；
- 画布 Agent 的写画布操作走「8 种封闭操作 + 事后事实复核」——每次操作后系统会核对结果（例如「资源物化才算完成」），失败会如实报告。

## 上下文与预算

- 历史上下文有预算（约 192KB），较旧的内容会按轮省略并**明示**「上下文整理说明」，不会假装记得；
- 单轮工具结果与上下文超限（v1.6.14 走查时约 384KB / 96k token）会**直接硬失败**并提示缩小下一步范围——已完成的操作会保留。**⚠️ 这两个数字在 v1.6.16 源码里已检索不到对应常量**，且入口未开放、无法运行时复验；**把它们当作 v1.6.14 时期的观察值**，实际报错以你看到的那条为准。

## 取消

运行可随时取消（v1.6.14 走查时约 15 秒超时保护）；取消后已完成的操作保留。**⚠️ 该 15 秒在 v1.6.16 源码里同样检索不到对应常量**——当前实现用的是「调用状态标记为 cancelled」的显式取消语义，不是定时器超时，所以**以实际行为为准**。

## 现在能做什么

入口没开放，但这几件事**都已在 v1.6.14 上走查过**，可以立刻用：

| 你想做的事 | 用这个（已验证） |
|---|---|
| 让系统帮你写提示词 | 提示词面板的**提示词优化器**——返回正向/负向提示词、关键变化、待确认假设与候选变体，见 [提示词与 @mention](prompts-and-mentions.md) |
| 调整生成结果 | 失败任务的「**重试**」不额外计费；满意后再决定是否重新生成（会按量计费） |
| 批量处理素材 | 画布上的**批量连接**（选中 ≥2 个节点后按 ⌥L） |
| 找回误操作 | 顶栏「**版本记录**」恢复，或 ⌘Z 撤销，见 [撤销重做、版本历史与回收站](undo-history-versions.md) |
| 排查问题 | 失败提示里的「**复制排查信息**」，见 [故障排查](../90-troubleshooting.md) |

入口开放后，本页会补上完整的操作步骤与截图。
