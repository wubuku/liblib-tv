# 快捷键与帮助中心

> 适用角色：所有用户。

## 打开帮助

按 **?**（Shift+/）打开快捷键中心：支持**搜索**、按四个分类筛选（常用 / 视图与导航 / 选择与连接 / 编辑与文件），每类显示条目数。快捷键以 ⌘/⇧/⌥ 书写（Windows 对应 Ctrl/Shift/Alt）。

![画布快捷键中心：搜索、四分类与条目列表](../screenshots/05-shortcuts-center.png)（v1.6.14 重摄）

中心显示「共 24 个快捷键」，分类计数：常用 4 / 视图与导航 7 / 选择与连接 6 / 编辑与文件 7。

全表见 [20-reference.md](../20-reference.md)。

## 高频快捷键速查

| 快捷键 | 行为 |
|---|---|
| Ctrl/Cmd+F | 搜索节点（+Shift 进入专注模式） |
| Ctrl/Cmd+S | 保存画布 |
| Ctrl/Cmd+Z / Shift+Z / Y | 撤销 / 重做 / 重做 |
| Ctrl/Cmd+C / V | 复制 / 粘贴 |
| Ctrl/Cmd+D | 创建参数变体 |
| Delete / Backspace | 删除（先连线后节点） |
| Alt+L | 批量连线（>1 选中） |
| Alt+Shift+F | 自动整理画布 |
| V / H | 移动工具（空白左键拖即框选）/ 抓手工具 |

## V 键语义说明

快捷键中心对 V 键的文案为「切换移动工具」——行为即：切到移动工具后，**空白处左键拖动默认就是框选**（Shift 追加、Ctrl/Cmd 切换、Alt 移除选择）。旧版本曾存在面板文案与代码不一致，v1.6.14 实测文案与行为一致；H 为抓手工具（拖动平移画布）。
