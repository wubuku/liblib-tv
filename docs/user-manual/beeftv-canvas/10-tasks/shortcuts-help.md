# 快捷键与帮助中心

> 适用角色：所有用户。

## 打开帮助

按 **?**（Shift+/）打开快捷键中心：支持**搜索**、按四个分类筛选（常用 / 视图与导航 / 选择与连接 / 编辑与文件），每类显示条目数。快捷键以 ⌘/⇧/⌥ 书写（Windows 对应 Ctrl/Shift/Alt）。

全表见 [20-reference.md](../20-reference.md)。

## 高频快捷键速查

| 快捷键 | 行为 |
|---|---|
| Ctrl/Cmd+F | 搜索节点（+Shift 进入专注模式） |
| Ctrl/Cmd+S | 保存画布 |
| Ctrl/Cmd+Z / Shift+Z / Y | 撤销 / 重做 / 重做 |
| Ctrl/Cmd+C / V | 复制 / 粘贴 |
| Ctrl/Cmd+D | 创建参数变体 |
| Delete / Backspace | 删除（先连线后节点） |
| Alt+L | 批量连线（>1 选中） |
| Alt+Shift+F | 自动整理画布 |
| V / H | 框选工具 / 抓手工具 |

## 已知文案差异（以实际行为为准）

快捷键中心里 V 键的文案写的是「切换移动工具」，实际 V 是**框选工具**、H 才是抓手——这是上游已知的文案与代码不一致，本手册以实际行为为准。
