# 插件管理

> 适用角色：管理员与进阶用户。

## 六个内置插件

| 插件 | 能力 |
|---|---|
| RunningHub 工作流 | 接入 RunningHub 工作流（图片/视频/音频三类能力） |
| AI 审美批改 | 画布节点，对图片给审美反馈 |
| AI 提示词优化器 | 提示词面板优化（五字段结构化输出） |
| Eagle 素材库 | 接入桌面 Eagle 资料库 |
| 媒体转换节点 | 灰度 / Canny / AI 线稿 / 深度 / 姿态（本地模型，不加载 SD 重绘管线） |
| 剪辑工作台 | 时间线八面板宿主 |

内置插件随应用发布，可在插件页启停；AI 审美批改和剪辑工作台属于「应用型插件」，与系统协议插件区分。

## 模型渠道配置（运行时实证）

侧栏「模型配置」（`/settings?section=channels`）打开「本地模型渠道」页：**新增渠道**按钮 + 渠道分区（如 BeefAPI：OpenAI 兼容 · 已保存 N 个模型）。生成渠道在此配置后，画布生成节点即可选用。

## 安全模型（了解即可）

- **前端永远不执行第三方代码**：上传的插件只能是**声明式协议**（JSON 模板 + 引擎执行）；
- 直连宿主 API 的绑定保留给随应用发布的插件；
- 插件节点创建受「插件已启用」硬门禁；尚未开放的沙箱渲染器会显示「插件节点等待隔离运行时」。

## Eagle 素材库接入

1. 管理员在插件设置填写 Eagle Base URL（默认 `http://127.0.0.1:41595`）并读取文件夹；
2. **浏览器不直接访问 Eagle**：所有读取/搜索/下载/写入经站点后端转发（library / items / thumbnail / file 四个代理端点）；
3. 可把 Eagle 素材写回（POST items）或下载导入站点资源存储。
