# 提示词与 @mention

> 适用角色：所有用户 ｜ 生成操作涉及按量计费。

## 目标

在生成节点上写好提示词，并用 @mention 精确控制哪些素材参与本次生成。

## 两种引用模式

| 模式 | 触发 | 行为 |
|---|---|---|
| 自动引用 | 未写 @mention | 所有连线的上游资源按连线顺序成为参考 |
| composer 模式 | 提示词中出现 `@图片1` 或 `@[node:节点id]` | 只按 mention 集合取素材，忽略连线自动引用 |

- mention 写法支持「@ + 节点显示名」；无法解析的 mention 会直接报错，不会静默忽略；
- `composerContent` 与 `prompt` 是两个独立字段，系统分别保存，不会互相覆盖。

## 提示词优化器

1. 在提示词面板点击优化（AI 提示词优化器插件）；
2. 优化器返回五个字段：**优化后正向提示词**、**负向提示词**（无则空字符串）、**关键变化**（相对输入的改动列表）、**假设**（对模糊需求的假设，无则空数组）、**候选变体**；
3. 逐项确认后应用。

## 常见问题

- 为什么我的参考没有生效？→ 检查是否误写了 @mention（composer 模式会忽略连线引用）；
- 提示词里的「图片1」字样失效了？→ 富引用依赖 mention 语法，直接手改文字不会更新引用，请用 mention 或重新连线。
