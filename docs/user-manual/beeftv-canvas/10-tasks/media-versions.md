# 媒体版本族与重试

> 适用角色：所有用户 ｜ 重新生成涉及按量计费。

## 目标

理解 BeefTV 的「版本族」：同一节点的多次生成结果如何组织、如何切换主版本。

## 版本族是什么

对同一节点重新生成时，新结果不是覆盖，而是创建一个**兄弟节点**：

- 兄弟节点共享 `versionOfNodeId`，形成一组版本；
- 每个版本有 "A"、"B"、"C"… 的版本标签；
- 其中一个版本带 **primary（主版本）** 标志，参与下游连线的就是它；
- 重新生成成功后自动切换 primary。

## 日常操作

| 我想…… | 做法 |
|---|---|
| 回看某个版本 | 在画布上直接查看对应兄弟节点 |
| 切换主版本 | 在对比弹窗中「设为主版本」（只翻标志，不删节点） |
| 就用第一版 | 无需操作，切换 primary 即可 |

每个版本都是独立节点，可以单独连线引用——想让下游改用旧版本，把连线指过去即可。
