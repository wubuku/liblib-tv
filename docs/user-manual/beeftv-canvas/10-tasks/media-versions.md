# 媒体版本族与重试

> 适用角色：所有用户 ｜ 重新生成涉及按量计费。

> **当前状态**：本页的「版本族」机制来自 v1.6.16 源码核查，**尚未在真实界面上走查验证**——触发它需要真实发起一次付费生成，本手册的取证红线止于付费边界前一步，所以没做。下面写的是机制本身；界面上你实际会看到什么，请以本页末尾「现在就能用的替代做法」为准。

## 目标

理解 BeefTV 的「版本族」：同一节点的多次生成结果如何组织、如何切换主版本。

## 版本族是什么

对同一节点重新生成时，新结果**不是覆盖**，而是创建一个**兄弟节点**：

- 兄弟节点共享 `versionOfNodeId`，形成一组版本；
- 每个版本带 "A"、"B"、"C"… 的版本标签；
- 其中一个版本带 **primary（主版本）** 标志，**参与下游连线的就是它**；
- 重新生成成功后自动切换 primary。

## 日常操作

| 我想…… | 做法 |
|---|---|
| 回看某个版本 | 在画布上直接查看对应兄弟节点 |
| 切换主版本 | 在对比弹窗中「设为主版本」——只翻标志，不删节点 |
| 下游改用旧版本 | 每个版本都是独立节点，把连线指过去即可 |
| 沿用第一版 | 无需操作，切换 primary 即可 |

## 重试与重新生成的差别

这两个词在界面上不是一回事，别混：

| | 触发 | 计费 | 结果落点 |
|---|---|---|---|
| **重试** | 失败任务上的「重试」按钮 | 不额外计费（走幂等 id） | 同一个节点 |
| **重新生成** | 在节点上再次提交生成 | **按量计费**，可能弹「可能再次消耗积分」确认 | 新兄弟节点，组成版本族 |

重试会重建上下文：从最初生成的节点恢复引用；引用已丢失时会拒绝并提示。详见 [generate-images.md](generate-images.md)。

## 现在就能用的替代做法

版本族没验证，但下面这些**都已在 v1.6.14 上走查过**，能覆盖大部分「想回退 / 想对比」的需求：

| 你想做的事 | 用这个（已验证） |
|---|---|
| 回到之前的画布状态 | 顶栏「**版本记录**」→ 选一个历史版本恢复（恢复前会自动备份，恢复本身也可撤销） |
| 找回误删的项目 | 项目操作菜单 → 删除进**回收站** → 勾选恢复 |
| 误操作后反悔 | **⌘Z** 撤销 / **⇧⌘Z** 或 **⌘Y** 重做 |
| 复用以前生成的素材 | 底栏「**生成历史**」→ 从历史结果里重新插入 |
| 失败的生成再试一次 | 失败节点上的「**重试**」（不额外计费） |
| 任务卡住了想确认结果 | 任务详情 / 失败提示里的「复制排查信息」，见 [90-troubleshooting.md](../90-troubleshooting.md) |

以上操作见 [undo-history-versions.md](undo-history-versions.md) 与 [generate-images.md](generate-images.md)。
