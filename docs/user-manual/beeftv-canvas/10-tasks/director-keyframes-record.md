# 关键帧动画与白膜视频录制

> 适用角色：所有用户。

## 目标

用关键帧做镜头与对象动画，并把动画录制成白膜预览视频。

## 关键帧

- 拖动播放头到目标时间，调整对象/镜头属性，系统自动落关键帧（AutoKey 语义）；
- **双播放头设计**：取值与显示用「原始播放头」，写入用「帧格吸附值」——避免增量从错误起点计算产生漂移；
- 播放推进按帧格累积（帧率上限 120fps），不会随播放时长漂移；
- 撤销栈为 200 层快照，手势拖拽期间暂停记录。

## 骨骼动画

- 选中角色骨骼后可旋转摆姿势，姿势写入用吸附值；
- 骨骼控制器为屏幕恒定尺寸（选中 5px / 常态 3.5px，命中区更大），缩放时不变大变小。

## 白膜录制

见 [timeline-export.md](timeline-export.md) 的「白膜视频录制」一节：两次快照时效校验、首错即停、时长探针。

## 常见问题

- 关键帧怎么删？→ 选中关键帧后删除（无效果的操作不会进入历史、不触发保存）；
- 为什么动画和预览对不上？→ 确认没有在两个帧格之间记录关键帧——写入始终落在吸附值上。
