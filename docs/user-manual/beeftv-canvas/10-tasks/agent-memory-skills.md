# Agent 记忆与技能

> 适用角色：Agent 用户 ｜ 管理员可代管（不能代批）。

> **当前状态（v1.6.14 源码核查）**：「设置 → Agent 记忆」分区在当前版本**不存在**——设置页只有渠道 / 默认模型 / 提示词偏好 / RunningHub / 诊断五个分区。记忆与技能面板随旧桌面 Agent 一并退场，后端 API（`POST /agent/memories/compact` 等）仍保留。下面写的是**机制与后端契约**，不是你现在能点到的操作——请先看文末「现在能做什么」。

## Agent 记忆

- **写入**：Agent 用 remember_lesson 写入「待审」记忆；
- **审批**：你在「设置 → Agent 记忆」里自己批准/驳回；管理员可查看和删除，**不能代批**；
- **使用**：系统提示只带已批准记忆的索引（标题+适用场景），完整内容由 Agent 按关键词取用；
- **压缩**：可用自己的文本模型手动压缩相近条目，或按日/周/月自动压缩；压缩是异步任务（排队→运行→成功/失败）；
- **导入导出**：支持导出与导入记忆包；
- 只读模式下不能写记忆。

## 技能（Skills）

::: warning 这一节写的是**历史机制**，当前版本没有技能分区
下面三种安装方式（表单创建 / 上传 markdown·zip / GitHub 仓库）在 v1.6.16 的设置页里**都没有入口**——「设置 → Agent 记忆」整个分区不存在（页面顶部写明了依据）。**本节不是你现在能照做的操作。**
:::

1. 安装技能：表单创建 / 上传 markdown·zip / GitHub 仓库（支持自动同步）；
2. 使用：在提示词中 `@技能名`，或在面板勾选；
3. 预算：每轮最多 **4 个**技能、共 32k 字符、每个技能最多关联 3 个文件——超出会被截断并明示；
4. 技能包内的 SKILL.md 指向的参考文件会被按相关性自动带上。

## 现在能做什么

记忆/技能面板未开放，但这些**都已在 v1.6.14 上走查过**：

| 你想做的事 | 用这个（已验证） |
|---|---|
| 沉淀常用提示词 | 把常用提示词存成**文本节点**或复用 **提示词优化器**的候选变体，见 [提示词与 @mention](prompts-and-mentions.md) |
| 固定一套操作习惯 | 记下快捷键并用底部「画布快捷键」随时查，见 [快捷键与帮助中心](shortcuts-help.md) |
| 让操作更省事 | 选区工具条的**批量连接**、**对齐/分布**，见 [连线引用](connect-references.md) |
| 固定模型与渠道 | 设置页的**渠道 / 默认模型 / 提示词偏好**三个分区，见 [插件管理](plugins-management.md) |

分区开放后，本页会补上完整的操作步骤与截图。
