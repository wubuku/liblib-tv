## Agent 记忆

- **写入**：Agent 用 remember_lesson 写入「待审」记忆；
- **审批**：你在「设置 → Agent 记忆」里自己批准/驳回；管理员可查看和删除，**不能代批**；
- **使用**：系统提示只带已批准记忆的索引（标题+适用场景），完整内容由 Agent 按关键词取用；
- **压缩**：可用自己的文本模型手动压缩相近条目，或按日/周/月自动压缩；压缩是异步任务（排队→运行→成功/失败）；
- **导入导出**：支持导出与导入记忆包；
- 只读模式下不能写记忆。

## 技能（Skills）

1. 安装技能：表单创建 / 上传 markdown·zip / GitHub 仓库（支持自动同步）；
2. 使用：在提示词中 `@技能名`，或在面板勾选；
3. 预算：每轮最多 **4 个**技能、共 32k 字符、每个技能最多关联 3 个文件——超出会被截断并明示；
4. 技能包内的 SKILL.md 指向的参考文件会被按相关性自动带上。
