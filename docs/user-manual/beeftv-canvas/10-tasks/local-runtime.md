# 本地伴随进程（深度/线稿/姿态）

> 适用角色：需要本地 AI 推理的进阶用户。

## 目标

理解并接入 BeefTV 的本地伴随进程 framefield-local-runtime，用本机模型做深度图、线稿与姿态估计。

## 它是什么

一个运行在你自己电脑上的独立进程（`http://127.0.0.1:17371`），为媒体转换节点提供本地推理：Depth Anything V2 Small 深度图、ControlNet Aux 线稿与 OpenPose 姿态。**这些操作不会加载 Stable Diffusion 重绘管线**，也不经云端。

## 安全机制（系统自动执行）

- 只接受**精确回环地址** `http://127.0.0.1:17371`——配置其他地址会直接报错；
- 会话经**挑战-签名**交换建立（浏览器生成密钥对，向进程注册公钥）；挑战过期自动重建；
- 所有请求不带凭据、禁止重定向、禁用缓存；
- 响应体有大小上限（普通 64KB、深度 32MB），超限即失败。

## 自托管部署注意（v1.6.x 起）

后端新增 `depthruntime` 域：深度素材的服务端拉取与哈希校验由后端完成——自托管运营者在部署后端时需一并确认该域的网络出口与存储配置；桌面端用户的本地伴随进程使用方式不变。

## Windows 深度视频运行时（v1.6.12/13 新增）

桌面端在 Windows x64 上可**免手动装进程**：首次使用深度处理时自动下载官方签名的可选组件（可续传、校验，取消即停）——

- 固定 Small 模型；**CPU 推理已测试可用**（2 秒与 15 秒片段实测），但可能较慢且占用内存；
- NVIDIA CUDA 为**社区测试预览**：安装前用真实模型探针校验，设备故障自动回退 CPU 一次；
- 进程树级取消：取消任务会终止整棵处理进程；
- Apple Silicon Mac 的本地处理方式不变。

> 代理环境（v1.6.13 后新增）：组件下载与桌面更新共用同一代理选择规则——显式环境代理优先，否则读取 Windows/macOS 当前用户的**系统代理**（含排除地址规则）；修改系统代理后直接重试即可读到新配置，无需在 BeefTV 里重复填写。

Web 自托管模式仍走本机伴随进程 / 服务端 `depthruntime` 域，行为不变。

## 使用流程

1. 启动本地伴随进程；
2. 画布中创建「智能剪辑（媒体转换）」节点并连接图片/视频；
3. 选择转换类型（灰度 / Canny / AI 线稿 / 深度 / 姿态）执行；
4. 结果保存回当前节点的本地素材存储。

视频输入会先提取首帧再处理；姿态未检测到人物时会跳过并提示。
