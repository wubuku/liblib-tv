# 任务指南（How-to）

| 阶段 | 页面 |
|---|---|
| 画布基础 | create-nodes（建节点）· navigate-canvas（导航与视图）· upload-materials（上传素材）· connect-references（连线引用）· prompts-and-mentions（提示词与 @） |
| 生成 | generate-images（图片生成）· generate-video（视频生成）· media-versions（多版本对比） |
| 整理与历史 | organize-canvas（整理画布）· undo-history-versions（撤销与版本） |
| 时间线 | timeline-editing（轨道与片段）· subtitle-highlights（字幕与关键词高亮）· timeline-export（导出成片） |
| 导演台 | director-basics（场景与机位）· director-keyframes-record（关键帧与动画）· director-rig-bones（骨骼与姿态） |
| Agent 与运维 | cloud-agent（云端 Agent）· agent-memory-skills（记忆与技能）· plugins-management（插件管理）· local-runtime（本地伴随进程）· shortcuts-help（快捷键） |
