# 快速开始：从打开画布到第一组「素材 → 生成」

> 适用角色：所有用户 ｜ 预计耗时：约 2 分钟 ｜ 生成操作涉及按量计费，本页在付费边界前停止。

## 你将完成

在画布上放一个「文本」节点和一个**空的**「图片」节点，用连线把文本作为图片的生成参考——这是 BeefTV 一切创作流程的最小单元。

## 前置条件

- 已启动 BeefTV（Web 端自托管地址，或桌面客户端）。**本地部署不需要登录**——启动后工作区里已经有一个本地身份，不用注册也不用登录。
- **先有一个可用模型**。新装好的 BeefTV **默认一个可用模型都没有**（出厂配置里渠道是空的、也没有 API Key，源码注释写明「不能内置供应商模型」）。**不先配，第 6 步「发起生成」会直接被挡下来**，提示「当前没有可用模型，请联系管理员或检查模型配置」——**本地部署里没有管理员可找，模型是你自己配的**。配法见 [10-tasks/model-channels.md](10-tasks/model-channels.md)，一般只要填一个渠道的 Base URL、API Key，再选好默认模型。

## 步骤

1. **进入画布**。登录后从首页点击「新建画布创作」（或左侧「新建项目」）：

   ![BeefTV 首页：新建画布创作与七个创作能力入口](screenshots/01-home.png)

2. **打开「添加节点」菜单**。在画布空白处**双击**（空态也有「双击画布 · 自由生成节点」提示），或右键 → 「添加节点」，或点底部工具栏的「添加节点」按钮。菜单为列表形态、右上角可搜索，分「创作节点」与「导入资源」两段：

   ![添加节点菜单：创作节点与导入资源两段](screenshots/03-add-node-menu.png)

   创作节点：文本 / 图片 / 视频 / 音频，标「正在开发」的智能剪辑、逐帧拉片、脚本，以及**可用的「导演台」**（v1.6.7 起解禁，点击后进入镜头模板选择并创建镜头节点，见 [director-basics.md](10-tasks/director-basics.md)）；绘图、文件夹、批量创作表默认隐藏，搜索名称即可创建。导入资源：上传 / 从生成历史选择 / 素材库。
3. **放一个「文本」节点**。点击菜单中的「文本」，再在画布上点一下放置位置；节点标题可直接输入，留空会自动回退为默认名。
4. **放一个空的「图片」节点**。再次打开菜单点「图片」，在画布上点一下放置位置。**先别往里传图**——空着的图片节点是「生成器」，点它会打开提示词面板，这正是本教程要用的入口。
5. **连一条线**。把鼠标悬停在「文本」节点边缘，出现圆形「+」侧栏后按住拖出，拖到「图片」节点附近松手（有 56px 的圆形吸附范围，靠近即可吸上）。文本节点的内容会**自动**成为图片节点的参考。
6. **发起生成（涉及计费）**。点选刚建的图片节点，在提示词面板里写提示词、确认引用里出现了那条文本，然后点击生成。具体参数与费用见 [generate-images.md](10-tasks/generate-images.md)。

::: warning 别在第 4 步就上传图片
往图片节点里上传本地图片，会让它从「生成器」变成「**结果节点**」——之后点它弹出的是图片工具条（替换/裁剪/下载等），**不再是提示词面板**，第 6 步就走不通了。

想从自己的图片开始，请把它作为**参考素材**用：在提示词面板里用「参考内容」选择器或 @mention 引入，而不是覆盖节点本身。详见 [upload-materials.md](10-tasks/upload-materials.md) 与 [prompts-and-mentions.md](10-tasks/prompts-and-mentions.md)。
:::

## 你的空画布长什么样

创建后画布中间是空的，**上面写着「双击画布 · 自由生成节点」**——双击空白处就会打开「添加节点」菜单。这是你在 BeefTV 里建节点的常规入口。

**这个空画布的样子是固定的**：不管你建了几张画布，看到的都是同一句提示、同一套引导。源码里其实写了四种空画布形态（普通空画布 / 短剧引导 / 关联项目画布 / 非空），**而你实际只会遇到两种**——上面这种默认形态，以及画布真的关联着某个项目时的「项目画布为空」。**短剧引导那套虽然代码和界面都还在，却没有任何入口能让画布切过去**；普通空画布上原本还有四个快捷入口（故事脚本生成等），也被一个写死的开关关着。两种情况见 [create-nodes.md](10-tasks/create-nodes.md)。

## 如果你想换个起点

| 你手上有什么 | 怎么做 |
|---|---|
| 一张本地图片，想改造它 | 「添加节点」→ 导入资源 → **上传**，得到结果节点，用其工具条裁剪/替换 |
| 一段视频，想剪成片 | 上传视频后从其工具条「视频处理 → 视频剪辑」进入时间线 |
| 一段音频，想配字幕 | 上传音频后点「进入剪辑」，在时间线里配字幕（见 [subtitle-highlights.md](10-tasks/subtitle-highlights.md)） |
| 只有文字想法 | 就是上面这个流程：文本节点 + 空的图片节点 + 连线 |

## 本版没有的功能（别白找）

有些功能在别的介绍里见过，但**当前 v1.6.16 客户端里打不开**——这不是你操作错了：

| 找不到的入口 | 说明 |
|---|---|
| 短剧 / 小说转视频生产台 | 「导入小说」「章节进度」「分镜图」「动作预演」「镜头视频」这一整套界面在当前版本**不可达**。即使手动访问 `/projects/<项目ID>`，页面也会**自动跳回该项目的画布**。想直接上分镜，得先在画布里用导演台逐镜搭建（见 [director-basics.md](10-tasks/director-basics.md)） |
| 任务中心、技能广场、我的技能 | 这几个入口的路由都已退场，**点进去静默跳回首页**（不是 404，也不是故障）。任务状态看画布上该节点的状态徽章；退场路由的完整清单见 [20-reference.md](20-reference.md) |

## 成功判据

- 画布上有一个「文本」节点和一个「图片」节点；
- 两者之间有一条从文本指向图片的连线；
- 点击图片节点弹出的是**提示词面板**，引用里能看到那条文本；
- 点生成后，图片节点上出现结果。

## 取消与恢复

- 删除连线：点击连线选中后按 Delete（优先删除连线而不是节点）。
- 误删节点：Ctrl/Cmd+Z 撤销；更早的状态见版本历史与回收站（见 [undo-history-versions.md](10-tasks/undo-history-versions.md)）。
