### 本轮否证过的说法

这些是取证过程中被实测推翻的，保留下来免得下一位重犯：

| 曾经的判断 | 实测结论 |
|---|---|
| 底部「教程」按钮打开教程中心 | 实现是 `data-sidebar-btn="contact"`，点击无面板/无跳转/无新窗口 |
| 选中节点按 `Delete` 就能删 | 不生效；必须先点空白让焦点回画布，再 `⌘A` + `⌫` |
| 「复制画布」会把副本插到列表最前 | 插在**源画布正下方**，与「新建画布」规则不同 |
| 快捷键面板是「成组 G / 合并 ⌥G」（无 ⌘） | 面板上有 ⌘ 前缀，是**图形键帽没有文本**；只读 innerText 会整列丢失 |
| `⌘0` 是「重置缩放」 | 它是「适合屏幕」，节点少时会放大到 100% 以上 |
| 从「+」建节点可以自己选位置 | 一律落在同一锚点；要定位得用**双击画布**（面板锚在双击点） |
| 「项目」和「画布」是同一个东西 | 两层；且**一张画布 = 一个 projectId**，切换画布 URL 会变 |
| 空白处无修饰键左键拖 = 平移画布 | **不成立**。同一段鼠标位移 `(+220,+120)`：裸拖只换来 `(+16.3, 0)`；`Space`+拖 / 抓手工具+拖 / 中键拖 都是 `(+220,+120)` 严格 1:1 |
| 成组/解组/复制的键位「面板上写了就算数」 | 已全部实按：框选 2/2 → `⌘L` 0→1 → `⌘G` 组 0→1 → `⌘⇧G` 组 1→0 → `⌘D` 3→4 → `⌘Z` 4→3 → `⌘⇧Z` 3→4 |
| `⌘⌥G 合并分镜组` 是可用的 | 按了毫无反应。它对应组操作条上的「转分镜组」，而那枚按钮实测 `opacity: 0.45`（灰的），点击同样无反应 |
| 画布空了就说明节点没了 | **节点只在视口内才渲染**。连续 `Space` 拖远，页面里的节点数 `3→3→2→1→0`，归零那一刻才浮出「当前视窗没有节点」 |
| 导演台点进去就是一个 3D 场景 | **进得去，但 3D 视窗加载不出来**。站点先检测浏览器硬件加速，无头 Chromium 没有 GPU，直接弹「请开启浏览器硬件加速」并拒绝渲染 |
| 角色造型室只是个「全屏浮层，Esc 关不掉」 | 说得太糙。它有完整界面：两个库标签、三个筛选下拉、搜索、列表/卡片/网格三视图切换、角色横排 + 右侧翻页、空状态「创建新角色」 |
| 小地图在右下角 | 它的 class 确实写 `bottom right`，但**实测渲染在左下角**（`x≈145`），紧贴左工具条并压住右侧图标 |
| 「高级设置」是什么、点了会怎样 | 文本节点**没有**这一项。**Batch AV 定案：入口是参数条右侧那枚 32×32 的滑块图标按钮 `⚙`（SVG `M14 17H5M19 7h-9`），不是那行灰色的「高级设置」四个字 —— 点标题没反应。** `⚙` **是 toggle**：点开后容器 class 从 `grid-rows-[0fr]`（`grid-template-rows` 计算值 `0px`）变成 `grid-rows-[1fr]`（`157px`），视频面板高度 **246 → 411px**；再点一次收回。视频展开出 `联网搜索`/`自动校验素材`/`智能引用 AutoLink` **三个开关、默认全开**，其中后两个各带一个 `?` 说明图标；音频展开出 `语速`/`声调`/`音量` **三个 Mantine 滑杆（176×8）**，每条滑杆**右侧都跟一个数值框**（`1.00`/`0`/`1.0`，`aria-valuenow` 读作 `1`/`0`/`1`），范围 0–2 / 0–12 / 0–10。**此前「没有数字框」的说法会误导用户 —— 画面上就摆着三个数值框**（只是它们不是 `input[type=number]`，该选择器恒为 0） |
| 资产管理「更多操作」的四项都没点过、状态未知 | Batch Y/Z/AA/AB/AC **四项全部实按**。**重命名** = 抽屉行内就地编辑（`input[aria-label="节点名称"]` 自动聚焦、画布节点上不冒输入框），回车后两边同步、无提示。**复制** = 副本叫「原名 - 副本」落在原节点正下方；**复制完画布上可能一个节点都不多** —— 副本在视口外，`⌘0` 后立刻可见（立刻数 1 → `⌘0` 后 2 → 刷新 2）。**添加到Agent** = 右侧滑出 TV Director 抽屉，节点以附件 chip 挂进输入框、**不自动发送**，且**实测会挂两个完全相同的 chip**。**删除** = **无二次确认、`⌘Z` 也撤不回来** |
| 「删除节点」应该像删画布一样有二次确认 | **不成立。** 删整张画布有确认弹层，删单个节点没有。点完 200 毫秒全屏扫 `role="dialog"`，除了资产管理抽屉自己什么都没有；把焦点交回画布（`document.activeElement` → `BODY`）后按 `⌘Z` / `⌘⇧Z`，节点数纹丝不动 |
| 资产管理工具行是「🔍 / 筛选 / 管理」三枚控件 | 「画布」标签下是**四枚**：`搜索节点` / `筛选：全部` / `所有评级` / `展示设置`。**`筛选：全部` 按节点类型**（10 档：全部/文本/图片/视频/智能剪辑/导演台/逐帧拉片/音频/脚本/剧本），**`所有评级` 按星级**（6 档），是两个独立筛选器，当前档位写进 aria-label。搜索框**平时不存在**，点 🔍 才展开，是实时过滤 |
| 「☰ 是列表/卡片视图切换」 | 叫 `展示设置`，四项：列表展示 / **宫格展示**（3 列卡片，工具行图标同时变成 ⊞，可切回）/ 展开全部分组 / 收起全部分组。后两项**没测出效果** —— 菜单在、能点、点了不报错，但没有组就看不出差别，而这轮建组始终失败 |
| 资产管理「资产」标签的「管理」是个分类管理器 | 点开**没有浮层也没有任何可见变化**。「批量操作」倒是进勾选模式（底部变成「已选择 0 项」）。`筛选` 打开真面板：重置 + 六个预置标签胶囊（新建标签/角色/场景/物品/风格/音效）+ 取消/应用；`创建` 下拉是 新建文件夹 / 上传资产。建标签、传资产一个都没点（写账户数据） |
| 故事板的「对话」按钮只在视频列 | **图片列也有**，而且**平时 opacity 为 0、鼠标悬停到节点行上才显形**（`52×20` 胶囊）。全页按文字搜到 2 枚，坐标 `[888,107]` 与 `[1363,107]`。点开 = 右侧滑出 TV Director 抽屉 + 把该节点挂成**一个**附件 chip，**不自动发送**（欢迎页仍在）。与资产管理 `⋯→添加到Agent` 的机制相同，但**那边挂两个、这边挂一个** |
| 故事板视频列的「全部」是筛节点状态 | 筛的是**成片 / 片段**：菜单三项 `全部`（带 ✓）`成片` `片段`，选完列头文案跟着变。没生成过任何视频时选「成片」，视频列的节点行**整行消失** |
| 生成历史里的「时间倒序」是带下拉箭头的排序下拉 | **它没有下拉箭头，也不是下拉** —— 点一下直接在 `时间倒序`（`title="当前：最新优先"`）↔ `时间正序`（`title="当前：最早优先"`）之间切换，两态循环，连点三轮 `倒→正→倒→正`，全程无浮层。同排的 `所有评级 ▾` **才是**真下拉（`mantine-Popover-dropdown` 200×230，六档 `所有评级/1⭐…5⭐`，与资产管理抽屉那枚同一套） |
| 生成历史是全屏遮罩 | 它是**浮在画布上的居中面板**（`[72,80,1296×640]`），四周画布露着、右下角 TV Director 面板也露着。右上角 `×`（`[1315,107,28×28]`，纯图标无文字无 aria）关掉后画布原样回来 |
| 资产管理/生成历史里的分类标签文案就是「图片」 | 生成历史里是 **`图片 0`**、`视频 0`、`音频 0`，**带计数徽标**（`[286,172]` / `[350,172]` / `[414,172]`，各 48×32），所以 `getByText('图片', {exact:true})` 匹配不到 |
| 缩放菜单只能调到 50 / 100 / 800 三档 | 菜单**顶部是一个能敲数字的输入框** `input[aria-label="缩放比例"]`（`[181,491,146×20]`），填 `200` + `Enter` 后 `scale` 1→2，**菜单不关**，输入框与左下角标签同步变 `200%`。它是唯一能落到任意比例的入口。三档预设也逐个点过：`2.106`(211%) →`0.5`→`1`→`8`，三档 `hit: true` |
| 缩放菜单里那格 `%` 只是个单位装饰 | 那是输入框本身。菜单六行 = 输入框 / 放大 `⌘+` / 缩小 `⌘-` / 适合屏幕 `⌘0` /（分隔线）/ 缩放至50% / 100% / 800%。另外 `211%` 这种数字来自「适合屏幕」算出来的 `2.106`，**不是预设档位** |
| 画布行菜单每一行可能不一样 | **三行一样。** 同一张下拉里连点第 1/2/3 行的「更多操作」，三次读出的浮层**逐字一致**：`在新窗口打开 / 重命名画布 / 复制画布 / 删除画布`，只有这四项、无第五项、无图标无分组线，不随是否活动画布/是否已改名而变 |
| 「点开缩放菜单 → 逐项点一遍」这种脚本能一把过 | **不能。** AP 第一次跑，三档预设里 `缩放至50%` 和 `缩放至800%` 直接报「菜单里没有这一项；菜单=undefined」—— 因为点完第一档**菜单自己关了**，后两档是在关着的菜单里找行。必须每档之前**重新确认菜单开着**（AQ 改掉后三档全中）。这是 §15.6 记过的 toggle 坑，本轮又踩了一次 |
| 「在新窗口打开」大概就是当前页跳一下 | **它开的是新标签页。** 用 `ctx.on('page')` 接住 popup 实测：页签数 `1→2`，新页 URL 的 `projectId` 换成**那一行画布自己的** id（≠ 原页），标题变成 `画布 63 - LibTV - 专业视频创作工具`，`.react-flow` 已挂载；**原标签页 URL / 内容 / 节点数全没变**。它不是 `<a target="_blank">`（是 `BUTTON`，`href`/`target` 均为 null），也没有对话框 |
| 发布与分享是个居中弹窗 | 它是**挂在顶栏下方的 360×167 小浮层**（`mantine-Popover-dropdown`），画布照常可见可点。而且里面**只有 2 枚按钮**（`在LibTV上发布` / `分享链接`），枚举结果是**输入框 0 / 链接 0 / tab 0 / 开关 0** —— 旧手册的 alt 文案还把标题「在LibTV上发布」漏掉了 |
| 面板提示「按 ESC 退出」就说明 Esc 管用 | **不管用。** 两枚按钮的 hover 提示都写着「按 ESC 退出」，实按 `Esc` 后面板纹丝不动。证据不是一次读数：点开 → 在 → 按 Esc → **仍在** → 再点一次触发图标 → 关掉了（`closedByReclick: true`；若 Esc 已生效，再点会重新打开、此项该是 `false`）。Esc 前后 URL 和节点数都没动，按错无损失。**关它只能再点一次那枚图标** |
| 缩放改完就只在当前这次会话里有效 | **按画布持久化。** `0.5` → 点「缩放至800%」→ `8` → **连续 reload 两次都读到 `8`**。刷两次是为排除「只是浏览器缓存里留着上一次的状态」 |
| 工具箱卡片上的「使用」按钮是 `opacity: 0` 悬停变 1 | **不是。** 悬停前后量过：`opacity` 都是 `1`、`display` 都是 `flex`、`visibility` 都是 `visible`。它**一直存在**，只是**平时被预览图压在下面**，悬停才浮上来。所以拿「opacity 多少」判断它必然判错 —— 得用 `document.elementFromPoint` 或截图 |
| 底栏那一排是「一堆无名图标按钮」，只能按坐标找 | **十三枚全都有 `aria-label`**：`资产管理` / `整理画布，Option+Shift+F` / `切换小地图` / `隐藏节点连线` / `网格吸附` / 缩放选项 / `添加节点` / `移动` / `素材库` / `角色造型室` / `生成历史` / `快捷键` / `教程`。早期脚本筛「`innerText` 为空**且**无 `aria`」，条件写反，一枚都筛不出，还会抓到邻居（**把 `快捷键` 当成了 `+`**） |
| 素材库要从「+」→`素材库` 子菜单进去 | 底栏有**独立的** `素材库` 按钮（`[660,757,32×32]`），点它直接弹面板。而且这个面板**不是**「+」里的那一层，是**另一块**：`fixed z-20` `[556,516,235×225]`，三项 `风格库 / 特效库 / 打开工具箱` |
| 「用 class 白名单筛浮层」是通用做法 | **会静默漏掉一整类。** 素材库面板的 class 既不是 `Menu-dropdown` 也不是 `Popover-dropdown`，按白名单筛出来是空的 —— **而截图里它明明开着**。面板识别应该用 `fingerprint()`/`diffPanels()`（只看可见 + 面积 + 位置，不认 class） |
| `LibTV Plugin` 大概能打开插件市场 | **点了三遍都只出悬停提示。** 按钮进入高亮态、浮出写着「LibTV Plugin」的气泡，**没有新浮层 / 模态框 / 新页签 / 对话框**，URL 和节点数都不变。跟资产管理那枚「管理」是同一类 |
| 工具箱里那些是「平台预设」 | 平台自带的一张**都**带 `【预设】` 前缀（`【预设】左弧滑行`/`【预设】Live 2D`/`【预设】旅拍转场 zoom in`…），**没有前缀的就是自己建的**（本账户 `手册取证测试箱`）。这条比「看名字像不像」可靠 |
| 角色造型室是「列表 / 大卡片 / 网格三视图」，而且我的角色库是空的 | **两处都错。** 右上只有 **`多选` / `列表模式` / `宫格模式`** 三枚图标，**视图模式只有两种**。而且「我的角色库」**不空** —— DOM 里有 **23 张角色大图**（`alt` 全空，即角色卡没有文字），最左一张是线框人偶占位卡写着「创建新角色」 |
| 角色造型室按 `Esc` 能关 | **不能。** 全屏遮罩 `z-(--z-modal) fixed inset-0 … bg-black/60`，实测按 `Esc` **两次都没关掉**。**只能点它自己右上角那枚 `×`（`aria-label="关闭"`）**，点完 `maskAfterClose: false` |
| 风格库 / 特效库是「新增一个节点」的功能 | 是**两个素材市场**。风格广场有**十个分类标签**（推荐/摄影写真/电商营销/动漫游戏/风格插画/平面设计/建筑及室内设计/创意玩法/文创周边/小说推文）+ `仅看可商用` + `全部▾` 排序；特效广场同结构但只有 `推荐` 一个分类。每张卡 = 预览图 + `⋯` + 名称 + `商用` 徽标 + 作者 + **一个数字**。⚠️ **两个广场的数字量级完全不同**（风格 `532.0w`/`1.1w`，特效 `3500`/`549`），**不能当成同一个东西** |
| 工具箱「使用」按钮在卡片右上角 | **在右下角**（`50×24`）。而且 `?` 说明图标在**标题旁边**、不在右上角 |

| `input[type="text"]` 选不中 | React 只设了 `type` **属性**没设 attribute，得用 `aria-label="画布名称"` |
| 「看着像空白的地方」可能压在节点上 | 图片节点卡片宽 615px，一直铺到 x=1312。想在右上角起手拖，结果**把图片节点拖走了**，后面按旧坐标算的框选矩形全部错位 |
| 视口内读不到节点 ≠ 节点不存在 | 节点被虚拟化了，移出视口就从 DOM 消失。判断「画布上有没有节点」不能只看 `.react-flow__node` 计数，要用 `⌘F` 搜索面板交叉验证 |
| 组操作条不是 `<button>` | 成组后的六个动作全是 `div` / `span`，按 `getByRole('button')` 找永远返回空 |
| 自己写的 helper 会咬人 | `nodeCount(page)` 少传一个参数就是 `undefined.locator`，7 个步骤一路崩到底 —— 报出来的是**脚本崩了**，不是产品没反应 |
| 「页面上最大的元素」当面板 | **别这么判**。React Flow 的 `.react-flow__viewport` 带 transform，`getBoundingClientRect()` 永远巨大，于是每一次读到的都是画布本身。batchG 三个面板全部「读成画布」，而截图是对的 —— **只看截图会以为没问题**。必须用 DOM 差集法（`fingerprint` + `diffPanels`） |
| 写死坐标建节点 | 图片节点宽 622px 铺到 `x=1022`，把第二个节点写在 `x=1000` 就会落在它身上，双击打开的是编辑区不是「添加节点」面板。起手点要**程序化求解** |
| `querySelector('.selected')` 取第一个 | 画布上可能残留别的选中态，会把参数**读串到别的节点上**。要按节点标题精确定位 |
