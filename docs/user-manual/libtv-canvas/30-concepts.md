# 名词解释

这一页回答「这东西到底是什么」。操作步骤在 [10-tasks/](10-tasks/README.md)。

---

## 画布（Canvas）

你正在操作的那块无限大的区域。节点摆在上面，连线画在中间。

LibTV 里**一张画布就是一个独立的项目地址**（URL 里的 `projectId`），所以画布可以直接分享给别人。

## 项目（Project）

顶栏那个可编辑的名字（如「未命名工作区」），是所有画布的**容器**。

> 关键区别：项目名在所有画布下**显示同一个值**。改画布名不会改它，改它也不会改画布名。

## 节点（Node）

画布上的一张卡片，代表一步工作。标题格式是 `{类型}节点 {序号}`，比如 `图片节点 2`。

节点有**两种形态**：

- **折叠态**（默认）：只露出预览区和「尝试：」几个模式；
- **展开态**（点一下）：露出提示词框、顶部工具、底部参数条。

> ⭐ 展开态的卡片**右上角还有一枚 `⤢`**，点它会再开一层：
> 屏幕正中浮出一块 `800×600` 的**大编辑器**，四周画布被压暗。
> 这**不是第三种形态**，是同一个节点换了个更大的编辑界面。
> ⛔ 大编辑器**关不掉 `Esc`**，只能点外面的压暗遮罩或它右上角的收拢箭头。
> 见 [90-troubleshooting.md](90-troubleshooting.md)。

## 端口（Handle）

节点左右两侧的小圆环。**左进右出**：

- 左环 = 入口（target），接收上游产物；
- 右环 = 出口（source），送出本节点产物。

DOM 上分别是 `data-handleid="target"` / `data-handleid="source"`。

## 连线（Edge）

两个节点之间的连线，表达「上游的结果可以给下游用」。

**连线本身不会触发任何动作** —— 它只是建立关系。

## 「尝试：」

节点卡片上一排模式按钮。同一个节点换模式，等于换一种用法：

- 文本节点：`自己编写内容` / `文生视频` / `图片反推提示词` / `文字生音乐`
- 视频节点：`5分钟超长视频` / `首尾帧生成视频` / `首帧生成视频`

## 参考 / 上传

往节点里塞素材的**手动**通道（连线是自动通道）。

节点顶部常见的 `参考` 按钮。传进去的素材可以在提示词里用 `@` 引用。

## 规格串

底部参数条上那串点分文本：

```
16:9 · 720P · 5s · 1个
 └比例┘ └分辨率┘ └时长┘ └数量┘
```

不同节点段数不同（图片节点第二段是画质档，第三段才是分辨率）。点它可以逐项修改。

## 工作流 / 故事板

**同一批内容的两种排布方式**：

| | 工作流 | 故事板 |
|---|---|---|
| 画布上是 | 节点 + 连线 | 三列内容 |
| 回答 | 谁依赖谁 | 先播什么后播什么 |

切换**不会丢内容**。空画布切到故事板只有三列空状态，那是正常的。

## 智能引用 AutoLink

图片/视频/音频节点上的一个开关，默认开启。📖 具体行为本轮未验证。

## TV Director

右侧那个 Agent 抽屉。可以用自然语言让它替你操作画布。

> ⚠️ 它会**真的动画布**，并可能触发生成 —— 也就是可能扣积分。

## 积分

生成内容的消耗单位，面板上直接印在参数条末尾（图片 15、视频 135、音频 1）。

📖 本手册**不解释计费规则、不给充值指引**。

## TV 工具箱 / 工具箱

素材库面板里的「打开工具箱」通向更完整的素材管理。📖 内部未验证。

## Beta / NEW / SD 2.5

节点面板上的角标：

| 角标 | 含义 |
|---|---|
| `Beta` | 测试期功能，**可能变** |
| `NEW` | 新上线 |
| `SD 2.5` | 该节点绑定的模型版本 |

---

## 三个最容易误解的地方

1. **「新建项目」没有对话框** —— 点了就已经建好并跳转了。不是按钮坏了。
2. **「教程」按钮不是教程** —— 实测是联系入口，点击不打开任何面板。
3. **整理画布会问你一次** —— 「是否保留此次整理结果？」不点「保留」就等于没整理。
