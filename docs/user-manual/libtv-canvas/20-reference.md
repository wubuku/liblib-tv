| 元素 | 形态 |
|---|---|
| 分区标题 | `画布` |

| 活动行 | 左侧带 `✓` |

### 规格串的读法

`16:9 · 720P · 5s · 1个` = **比例 · 分辨率 · 时长 · 数量**（节点顺序不同，图片节点第二段是画质档）。
