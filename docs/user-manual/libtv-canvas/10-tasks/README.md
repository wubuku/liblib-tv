## 读之前先分清三层

本手册每一页都尽量标明了证据来源，三层的可信度不一样：

- **✅ 实跑** —— 在真实界面点过，DOM、网络、截图三者对得上；
- **⚠️ 面板实跑 / 未提交** —— 控件、文案、位置都是真的，但触发后的结果没验证（主要因为会扣积分）；
- **📖 按界面推断** —— 从控件命名和布局推出来的行为，**没有实测**，仅供理解，别当成保证。
