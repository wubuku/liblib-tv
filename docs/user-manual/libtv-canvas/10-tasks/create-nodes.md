# 创建节点：九类节点与它们各自能调什么

> 目标：知道该建哪种节点，建完之后每个旋钮是干什么的。
> 适用角色：普通创作者 · 验证状态：✅ 九类节点全部实跑建出；⚠️ **一次都没有提交过生成**

## 两种建节点的入口

| 入口 | 操作 | 节点落点 |
|---|---|---|
| 添加节点面板 | 点底部工具条最左的「+」 | 固定落在同一个位置 |
| 双击画布 | 在空白处**双击**，再选类型 | **锚在双击点** |

两种入口弹出的是**同一个面板**（下方那张图就是双击弹出的），只是锚点不同。想把节点摆到画布某个特定位置，用双击。

### 九类节点一览

| 节点 | 面板角标 | 点下去会发生什么 |
|---|---|---|
| 文本 | — | 直接建出文本节点 |
| 图片 | — | 直接建出图片节点 |
| 视频 | — | 直接建出视频节点 |
| 智能剪辑 | `Beta` | 直接建出智能剪辑节点 |
| 导演台 | `NEW` | 先在画布建一张卡片，卡片上只有「打开导演台」按钮 |
| 逐帧拉片 | `SD 2.5` | 直接建出逐帧拉片节点 |
| 音频 | — | 直接建出音频节点 |
| 脚本 | 右侧有 `›` | ⚠️ **只展开子菜单**，不建节点 |
| 素材库 | 右侧有 `›` | ⚠️ **只展开子菜单**，不建节点 |

### 两个带子菜单的入口

![脚本子菜单：脚本 NEW / 脚本（旧版）Beta](../screenshots/C-08-脚本子菜单.png)

![素材库子菜单：风格库 / 特效库](../screenshots/C-09-素材库子菜单.png)

`脚本` 展开后是 `脚本 NEW` 和 `脚本（旧版）Beta`；`素材库` 展开后是 `风格库` 和 `特效库`。

> 角标含义：`Beta` = 测试期功能，可能变；`NEW` = 新上线；`SD 2.5` = 该节点绑定的模型版本。

### 文本节点

![文本节点卡片](../screenshots/D-01-文本-节点特写.png)

**「尝试：」** 四个模式：`自己编写内容` · `文生视频` · `图片反推提示词` · `文字生音乐`

同一个文本节点能当四种活干，选哪个模式决定下方提示词框的提示语和模型。

![文本节点展开](../screenshots/F-01-文本节点-展开.png)

提示词框占位文案：`写下你想讲的故事、场景或角色设定。例如：一个来自未来的机器人，在城市屋顶看星星。`

底部显示模型 `GVLM 3.1` 和花费 `6`（积分）。

### 图片节点

![图片节点卡片](../screenshots/D-02-图片-节点特写.png)

**「尝试：」**：`图生图` · `图片高清`

![图片节点展开](../screenshots/F-02-图片节点-展开.png)

- 顶部工具：`参考` · `标记` · `风格`
- 提示词框占位：`可直接文字生图，或上传图片输入文字指令对图片进行编辑，如：将背景改为雪夜`
- 底部：`Lib Image 2.5 Pro` · `16:9 · 标准画质 · 2K · 1张` · `15`（积分）· `高级设置` · `智能引用 AutoLink`

`16:9 · 标准画质 · 2K · 1张` 是一串四段式读法：**比例 / 画质档 / 分辨率 / 张数**，点它可以改。

### 视频节点

![视频节点卡片](../screenshots/D-03-视频-节点特写.png)

**「尝试：」**：`5分钟超长视频` · `首尾帧生成视频` · `首帧生成视频`

![视频节点展开](../screenshots/F-03-视频节点-展开.png)

- 顶部工具：`参考` · `标记` · `特效` · `角色库` · `运镜`
- 提示词框占位：`描述你想要生成的画面内容，@引用素材`
- 底部：`2.0`（模型）· `文生视频` · `16:9 · 720P · 5s · 1个` · `135`（积分）
- 开关：`联网搜索` · `自动校验素材` · `智能引用 AutoLink`，以及 `高级设置`

视频节点是可选功能最多的一个：特效、角色库、运镜都挂在这。

### 智能剪辑节点

![智能剪辑节点卡片](../screenshots/D-04-智能剪辑-节点特写.png)

空状态文案很直白：**「空空如也，请连接视频节点后操作」** —— 它不是拿来凭空生成的，得先接视频。

**「尝试：」**：`讲解视频` · `批量广告` · `口播视频` · `素材混剪`

![导演台节点卡片](../screenshots/D-05-导演台-节点特写.png)

> 在3D空间中搭建场景并进行多视角截图

### 逐帧拉片节点

![逐帧拉片节点卡片](../screenshots/D-06-逐帧拉片-节点特写.png)

## 选中节点会发生什么

- **折叠态**：只露出预览区 + 「尝试：」几个模式；
- **选中态**：卡片**展开**，露出提示词框、顶部工具、底部参数条。

![视频节点展开后的完整编辑区](../screenshots/F-03-视频节点-展开.png)

点空白处或按 `Esc` 收起。

## 取消与恢复

- 建错类型：选中节点 → 让焦点回到画布 → `⌘A` 全选 → `⌫` 删除。
  ⚠️ **只选中单个节点时直接按删除键是没用的**，实测 `Delete` 和 `Backspace` 单独按都不生效；必须先点画布空白处让焦点离开输入框，再全选删除。
- 建多了想重来：直接删，不需要「回收站」。
