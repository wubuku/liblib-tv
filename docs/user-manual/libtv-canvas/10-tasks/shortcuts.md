# 快捷键

> 目标：知道四组快捷键分别管什么，以及哪些是本手册真的按过验证的。
> 适用角色：普通创作者 · 验证状态：⚠️ 面板原文 ✅；**部分实按** ⚠️

## 打开

底部工具条的「**快捷键**」（键盘图标）。面板自带关闭 `×`，但它**会挡住第四列**，关掉右侧的 TV Director 抽屉才看得全。

![快捷键面板四列：创作 / 缩放 / 移动画布 / 其他](../screenshots/p07b-shortcuts-4col.png)

> 面板是 **macOS 键位**。Windows 上 `⌘` → `Ctrl`，`⌥` → `Alt`，`⇧` → `Shift`。

## ✅ 实按验证过的

| 键 | 实测行为 |
|---|---|
| `⌘0` | 框住所有节点（**不是**重置到 100%） |
| `⌘+` / `⌘-` | 缩放生效，缩放菜单里的百分比同步变化 |
| `⌥⇧F` | 节点被铺开，并弹出「是否保留此次整理结果？」 |
| `⌘A` + `⌫` | 全选节点并删除 |

### ⚠️ 删除键的一个坑

面板写的是「删除 `⌫`」，但实测：

- 选中一个节点后**直接按 `Delete` 或 `Backspace`，都不生效**；
- **必须先点画布空白处让焦点离开节点的输入框**，再 `⌘A` 全选，再 `⌫` —— 这样才删得掉。

原因很直白：节点里有提示词输入框，焦点在框里时 `⌘A` 选中的是**框里的文字**。

## ⚠️ 未实按验证的键位

`⌘G` 成组 / `⌘⌥G` 合并分镜组 / `⌘⇧G` 解组 / `⌘L` 连线 / `⌘D` 复制节点和连线 / `Tab` 新建节点 / `⌘F` 节点搜索 / `Space` 临时平移 / `V` `H` 工具切换。

这些键位**逐字来自官方面板**，但本轮没有逐条实按。其中**成组/解组/复制**还需要先框选多个节点，而框选入口本轮没取得可靠读数，所以这几项在 [create-nodes.md](create-nodes.md) 里只给键位、不声称已验证。

---

## 「教程」按钮不是教程

底部工具条上那枚标着「**教程**」的按钮，实测实现上是 `data-sidebar-btn="contact"`（联系入口）。点下去：

- 没有弹出任何面板；
- 没有跳转；
- 没有新窗口；
- 只发出一条 `POST /log/ocpcagl` 埋点。

**不要指望它能打开教程中心。** 本手册实测范围内，LibTV 画布里**没有找到教程中心入口**。
