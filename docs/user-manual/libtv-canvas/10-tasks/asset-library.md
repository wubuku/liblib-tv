# 素材库：风格、特效与上传

> 目标：把统一的风格/特效沉淀成可复用的素材，并在节点里引用。
> 适用角色：普通创作者 · 验证状态：✅ 面板实跑（上传未执行）

---

## 两个入口，同一个面板

「素材库」在两处能打开，面板内容一致：

| 入口 | 位置 | 无障碍名 |
|---|---|---|
| **底部工具条** | 底栏中央的一枚独立按钮 | `素材库` |
| 添加节点面板 | `素材库 ›` 那一行 | — |

![点底部工具条「素材库」弹出的面板：风格库（副标题「新增风格节点」+ NEW）/ 特效库（副标题「新增特效节点」+ NEW）/ 打开工具箱](../screenshots/M-128-素材库面板.png)

> 💡 **走底栏那枚按钮更近** —— 它不是「+」里的子菜单，是独立的一枚。
> 添加节点面板里那一行右边也有 `›`，展开是同样三项。

面板里是三项，**其中两个是「广场」，不是普通列表**：

| 项 | 点进去是什么 |
|---|---|
| **风格库** `新增风格节点 NEW` | 风格广场 —— 一个**分类浏览的市场** |
| **特效库** `新增特效节点 NEW` | 特效广场 —— 同样结构 |
| **打开工具箱** | 镜头运动预设（见下） |

### ⭐ 一张风格卡由什么组成

![一张风格卡的完整解剖：预览图左上角一枚 `📊 Seedream 5.0` 的模型徽标；右上角一枚 ☆（收藏）、预览图右下角一枚对角箭头 ⤢（详情）—— 这两枚**鼠标移上去才显形**；预览图下方是名称 `Seedream 5.0 pro`，再下面一行左边是 `🔥 热点推荐官` 徽标、右边是一枚漏斗图标加数字 `533.1w`](../screenshots/M-231-风格卡片-悬停显形.png)

| 位置 | 是什么 | 实测 |
|---|---|---|
| 预览图**左上角** | **模型徽标**，一枚 `📊` 柱状图图标 + 模型名（这张是 `Seedream 5.0`） | 常驻。⭐ **它不是风格名** —— 同类的还有 `Qwen Image` / `Z Image` / `Lib Image`，**都是模型**，别当标题读 |
| 预览图**右上角** | ☆ **收藏**（`<button aria-label="收藏">`，`24×24`） | ⭐ **悬停才显形**：`opacity` 从 `0` 变 `1`，位置不动 |
| 预览图**右下角** | ⤢ **详情**（`<button aria-label="详情">`，`24×24`，图标是两支对角箭头） | ⭐ **同样悬停才显形**（`0 → 1`） |
| 预览图**下方** | 风格**名称** + `商用` 徽标 | `商用` 徽标**不是每张都有** |
| 名称下一行 | 作者头像 + 作者名 + **漏斗图标** + 数字 | 见下 |

⭐ **悬停显形是精确读到的**：同一张卡，悬停前后各读一次那两枚按钮的 `opacity`，
两次都是 `0 → 1`，而**矩形位置完全没动**（`[271,210,24,24]` / `[271,413,24,24]`）。

> 💡 **已收藏的卡上不出现 ☆。** 在「我的收藏」页里，卡片**没有收藏按钮** ——
> 没地方可再收藏了。所以「我的收藏」页看起来和「风格广场」页不一样，是正常的。

### ⭐ 点 ⤢「详情」会打开什么

![风格详情面板：标题「风格详情」，左边是整张大图；右栏依次是风格名「J_漫剧素材三视图+大头表情+姿势…」、作者「JM32」、一栏「首选推荐模型」和一枚 `General image V2` 的胶囊；底部左侧一枚 `★ 取消收藏`、右侧一枚白色的 `使用`；右上角还有一枚缩到最小化的图标](../screenshots/M-237-风格详情面板.png)

点卡上那枚 ⤢ **不会**建节点，它开的是**一个详情浮层**，逐字读出来是：

```
风格详情 │ <风格名> │ <作者> │ 首选推荐模型 │ <模型名> │ [★ 取消收藏] [使用]
```

| 元素 | 说明 | 实测 |
|---|---|---|
| **首选推荐模型** | ⭐ 每张风格都有一个**推荐模型**字段（`General image V2` / `Seedream 5.0` …），它就是卡面左上角那枚徽标的来源 | ✅ 读到 |
| **`★ 取消收藏`** | 收藏态下按钮写的是「**取消收藏**」而不是「**收藏**」—— 说明打开那一刻这张已经是收藏态 | ✅ 读到；点它弹「**取消收藏成功**」，本轮据此把收藏清回 0 张并**独立复核**过 |
| **`使用`** | ⭐ 「把风格用进画布」的入口 | ⛔ **本手册没点**（可能建节点或消耗）。点它会发生什么仍 📖 |
| 右上角 `⤡` | 缩到最小化 | 读到图标，按钮无文字 |

> ⚠️ **别把「点详情」和「点卡片」当成同一件事。** 本手册只验了前者。
> 直接点卡片本身会发生什么，仍然**没验** 📖。

| `动漫游戏` | `1912.5D写实人像` |
| `风格插画` | `赛璐璐光影` |
| `平面设计` | `Lib Image` |
| `建筑及室内设计` | `天宫东方传统美学超现实神话元素奇幻概念艺` |
| `创意玩法` | `中秋节主题场景月饼建筑海报` |
| `文创周边` | `一键输出IP文创周边设计样机` |

![切到「电商营销」分类之后：十个分类标签里「电商营销」高亮，卡片换成了电商题材，第一张是「一键全套电商主图主…」（作者「饭盒」）、后面是「3D电商渲染级KV」「创意电商…」「全品类促销海报模板」「工业设计产品设计…」等，每张右下角都带漏斗图标和数字（7800 / 5900 / 22.5w / 23.7w / 6600 / 14.8w）](../screenshots/M-240-风格广场-电商营销分类.png)

> 💡 **一眼能认出的规律：名字以「一键…」开头的，是成套模板。**
> `一键生成人物多视图`（摄影写真）、`一键全套版电商主图…`（电商营销）、
> `一键输出IP文创周边设计样机`（文创周边）都是这一类 ——
> 它们预览图左上角那枚徽标是**一整块文字**，而不是模型图标。
> 要成套的效果优先找它们，要单张的风格就找名字正常的那些。

> ⚠️ **「一共有多少张卡」别拿屏幕上数出来的当答案。** 广场是**滚动网格**，
> 视口里只渲染出前几行；本轮不同轮次分别读到过 **30** 枚收藏星和 **6** 枚详情按钮，
> **两个数不一致、原因没查清** 📖。要确认某张卡在不在，**用搜索框搜它的名字**。

### 那个数字和那两个没验的东西

> ⚠️ **卡片上那个数字的，单位本手册没有验证。**
> 风格广场这边读到的是 `532.0w` / `1.1w` / `279` / `5900` / `59` / `252` ——
> `w` 是「万」，所以**这一列更像使用量/热度，不是价格**。
> 而特效广场那边读到的是 `3500` / `1500` / `549` / `3100` / `138`，量级完全不同。
> **两个广场的数字不是同一个东西** 📖，具体含义请以界面上你看到的那一项为准。
>
> ⭐ **数字左侧那枚漏斗图标，两个广场都有**（本手册早期写成「特效广场特有」，是错的）。
> 风格广场这边是 `11×11` 的漏斗形图标（`path d="M.09 1.94A1.45 1.45 0 0 1 1.94.09…"`），
> 特写截图里也看得清清楚楚。
> **悬停这个数字不弹任何提示** —— 这条做过阳性对照（先往页面里塞一个假的
> `role="tooltip"`，确认读得到；拿掉，确认读不到），所以「没有浮层」是有效读数。

下面三处本手册**没验**：

- 卡面左上角那枚徽标**点下去**会发生什么 📖；
- `⋯` 那个三点按钮**点下去**菜单里有什么 📖 ——
  截图里看得见它，但按文字和 `aria` 都**没抓到**那个元素，所以既不能说它有用，也不能说它没有；
- `全部 ▾` 排序下拉里有哪些选项 📖 ——
  试过四种判据（按文字正则、按几何、按面板内新增叶子、点前点后比像素 sha256），**全都没读出来**。

「仅看可商用」勾选框**能切**，实测 `checked` 在 `false ↔ true` 之间来回变（本轮已改回）。

## 特效广场：同一套结构，数字不带「万」

![特效广场：同样的三个标签与搜索框（占位符「搜索特效名称、作者」）；第二排只有「推荐」一个标签和「全部」排序；下面是卡片网格，每张是预览图加名称、商用徽标、作者和一个带漏斗图标的数字（3500 / 1500 / 2800 / 549 / 525 / 544 …）](../screenshots/M-135-特效广场.png)

结构跟风格广场几乎一样，差别在：

| | 风格广场 | 特效广场 |
|---|---|---|
| 分类标签 | **10 个** | 只有 `推荐` 一个 |
| 数字量级 | `532.0w` / `1.1w` / `59`（**带 `w` = 万**） | `3500` / `1500` / `549` / `3100`（**纯整数**） |
| 卡片左上角 | 有模型徽标那一层 | 📖 没细看 |

特效广场的卡片上那个数字是**能直接看见的整数**，
本手册读到的几十个在 `41`（AI搬砖侠）到 `3500`（小蜜蜂运镜）之间。

> ⚠️ 是不是积分价格、点了要不要付，**本手册没点过任何一张卡片**，不做判断 📖。
> 但量级看起来不像使用量 —— 用之前请自己确认一次。

其他两处细节：

- 两个广场的卡片**悬停时右上角都会浮出一枚 ☆**（收藏），**预览图右下角都会浮出 ⤢（详情）** ——
  和上面「一张风格卡由什么组成」那张表是同一套机制；
- 两个广场的列表最底下都有一行 `没有更多了`；
- `我的收藏` 页**空的时候写的是「暂无素材」**（不是「暂无收藏」）—— 收藏和素材共用这一页。

## 「新增风格节点 / 新增特效节点」

面板上写的是这个副标题，所以**在广场里选中一张**，就会在**当前画布上建一个节点**，
把这份风格/特效固化下来，之后就能像普通节点一样连线复用。

> 📖 本手册**没有在广场里点过任何一张**（那会在画布上建节点），
> 「建出来的节点长什么样、能不能改」在 [create-nodes.md](create-nodes.md) 里也没有实测过。

### 「使用」按钮在右下角，而且平时看不见

每张卡片**右下角**都有一枚 `使用` 按钮（`50×24`），但**默认看不到** ——

## 把组存进工具箱

组操作条上还有一个「**添加到工具箱**」入口，方向和「打开工具箱」相反：
「打开工具箱」是**取用**平台预置的镜头运动预设，「添加到工具箱」是**存放**你自己做的组/节点，以后复用。

![「添加到工具箱」打开的弹窗：创建新工具箱 / 更新工具箱 两个标签，封面、名称、标签、备注，右下角「创建」](../screenshots/M-19-工具箱弹窗-创建新工具箱.png)

点它弹出的是一个**双标签**弹窗：

| 标签页 | 内容 |
|---|---|
| **创建新工具箱** | 封面（大图占位 + `更换封面` 按钮）、名称、标签（`0/5` + `添加标签`）、备注、右下角 `创建` |
| **更新工具箱** | 列出已建工具箱的卡片（封面缩略图 + 名称），右下角 `确认` |

各字段的实测细节：

- **名称**输入框的占位符是 `输入工具箱名称`，**默认值就是「工具箱」** —— 不改直接点创建会得到一个叫「工具箱」的箱子。
- **标签**上限 5 个，计数显示为 `0/5`。点 `添加标签` 本手册**没有观察到任何输入界面出现**，只多了两处 `标签` 文字 📖。
- **备注**是多行文本框，占位符「请描述您的工具箱，例如应用场景、使用步骤及使用技巧」。

填好名称、点 `创建` 之前的现场：

![名称里已经填了「手册取证测试箱」，标签 0/5，备注还是占位提示，右下角「创建」](../screenshots/M-12-工具箱弹窗-填写名称.png)

### ⚠️ 创建成功没有任何提示

填好名称点 `创建` 之后，**弹窗直接关闭，不弹 toast，页面上也看不到刚建的工具箱**。
第一反应一定是「没保存成功」。实际上**它是存上了** —— 验收方法：再点一次「添加到工具箱」，
切到「更新工具箱」页，已建的工具箱会列在那里。

下图是本手册连续两轮各建一个同名工具箱之后的样子，「更新工具箱」页里赫然是**两个一模一样的「手册取证测试箱」**：

![「更新工具箱」页的空状态：暂无工具箱 + 确认按钮](../screenshots/M-11a-工具箱弹窗-更新工具箱-空状态.png)

> 建议：建完工具箱**顺手切到「更新工具箱」页看一眼**，这是目前唯一能确认「真的存上了」的办法。

### 按钮文案会从「添加」变成「更新」

![点完创建之后，同一个组的操作条上那一项已经写成「更新工具箱」](../screenshots/M-13-工具箱弹窗-点创建之后.png)

这是最容易错过的一个信号：**同一个组存进工具箱之后，操作条上那一项的文案就从
「添加到工具箱」变成了「更新工具箱」**。

它同时也解释了为什么创建之后「什么都没发生」—— 不是没发生，是**画面上没有给你任何地方去看见它**，
唯一的变化就是这个按钮换了名字。

> ⚠️ **这轮真的建了工具箱**（在一次性测试账号里建了两个）。工具箱是账号级数据、不随画布删除，
> 你自己的正式账号上不会有本手册的测试残留。

## 添加资源

添加节点面板底部还有一个独立的「**添加资源**」分区：

![添加节点面板底部的「添加资源」分区：上传 / 从生成历史选择](../screenshots/B1-item-从生成历史选择.png)

| 入口 | 用途 |
|---|---|
| `上传` | 从本地传文件进画布 |
| `从生成历史选择` | 复用以前生成过的东西 |

「从生成历史选择」点开是一整块**选择弹窗**（不是一个小列表）：

![「从生成历史选择」弹窗：标题「选择图片」，顶部 LibTV / Lib生成器 / WebUI / ComfyUI / AI应用 五个来源，右上「已选 0/10 张」，下面是 图片/视频/音频 三个分类，主体空态「暂无数据」，右下「确定」](../screenshots/M-138-从生成历史选择-弹窗.png)

| 位置 | 实测内容 |
|---|---|
| 标题 | `选择图片`（选视频/音频时会跟着变） |
| **来源标签** | `LibTV` · `Lib生成器` · `WebUI` · `ComfyUI` · `AI应用` |
| 计数 | `已选 0/10 张` —— **一次最多选 10 个** |
| 主体 | 没生成过东西时是 `暂无数据` |
| 底部 | `确定` |

> 💡 **五个来源的分类标签并不一样**，点哪个决定你看到哪几类素材：

| 来源 | 分类标签 |
|---|---|
| `LibTV` | `图片` · `视频` · **`音频`** |
| `Lib生成器` | `图片` · `视频` |
| `WebUI` | `图片` · `视频` |
| `ComfyUI` | `图片` · **`音视频`** |
| `AI应用` | `图片` · **`音视频`** |

注意 `LibTV` 那档写的是 `音频`、`ComfyUI` 和 `AI应用` 那两档写的是 `音视频` ——
不是同一个东西。后两者把音频和视频合在一类里。

> ⚠️ 这里有个**手册之前没说、但很重要**的点：来源不止 LibTV 自己，
> **`WebUI` / `ComfyUI` / `AI应用` 说明你可以从外部工具把素材接进来**。
> 本手册只读了标签文案，**没点过任何一个来源** —— 各自怎么接、需不需要配 API Key，都不知道 📖。
> 五个来源本轮**全部显示「暂无数据」**（测试账号从没真正跑过生成）。
>
> 另一个实用推论：计数上限是 **10 张/次**，所以「一次把几十个素材搬进画布」这条路走不通，得分批。

> 📖 历史记录里到底有哪些东西、怎么筛选，本轮仍未展开验证（测试账号从没真正跑过生成），
> 见 [../20-reference.md](../20-reference.md) 的「资产页」。

## 在节点里怎么用

素材进入画布之后，用两种方式喂给节点：

1. **连线** —— 把素材节点的出口连到目标节点的入口，见 [connect-nodes.md](connect-nodes.md)；
2. **参考** —— 点节点顶部的 `参考` 按钮手动挑。

风格还有第三条路：图片和视频节点顶部各有一个 `风格` 按钮。

## 📖 没有验证的部分

- `上传` 支持的文件格式与体积上限；
- **直接点一张卡片**（不是点 ⤢ 详情）会发生什么，建出来的风格节点 / 特效节点长什么样；
  详情面板里那枚 **`使用`** 按钮点下去会发生什么 ⛔ 本手册**没点**（可能建节点或消耗）；
- 广场卡片上那个数字的**确切单位**（两个广场量级不同，见上文）；
- 那个 `⋯` 三点按钮的作用 —— 截图里看得见，但按文字和 `aria` 都没抓到那个元素 📖；
- 分类标签各有多少条内容（**屏幕上只渲染前几行，数不出总数**）；
- `全部 ▾` 排序下拉里有哪些选项（试了四种判据都没读出来）📖；
- 工具箱预设「使用」之后落在哪、能不能改。

> ⚠️ 关于格式限制：本手册**不编**。请以 `上传` 打开后的界面提示为准。
