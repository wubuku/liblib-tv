# 素材库：风格、特效与上传

> 目标：把统一的风格/特效沉淀成可复用的素材，并在节点里引用。
> 适用角色：普通创作者 · 验证状态：✅ 面板实跑（上传未执行）

---

## 两个入口，同一个面板

「素材库」在两处能打开，面板内容一致：

| 入口 | 位置 | 无障碍名 |
|---|---|---|
| **底部工具条** | 底栏中央的一枚独立按钮 | `素材库` |
| 添加节点面板 | `素材库 ›` 那一行 | — |

![点底部工具条「素材库」弹出的面板：风格库（副标题「新增风格节点」+ NEW）/ 特效库（副标题「新增特效节点」+ NEW）/ 打开工具箱](../screenshots/M-128-素材库面板.png)

> 💡 **走底栏那枚按钮更近** —— 它不是「+」里的子菜单，是独立的一枚。
> 添加节点面板里那一行右边也有 `›`，展开是同样三项。

面板里是三项，**其中两个是「广场」，不是普通列表**：

| 项 | 点进去是什么 |
|---|---|
| **风格库** `新增风格节点 NEW` | 风格广场 —— 一个**分类浏览的市场** |
| **特效库** `新增特效节点 NEW` | 特效广场 —— 同样结构 |
| **打开工具箱** | 镜头运动预设（见下） |

### ⭐ 一张风格卡由什么组成

![一张风格卡的完整解剖：预览图左上角一枚 `📊 Seedream 5.0` 的模型徽标；右上角一枚 ☆（收藏）、预览图右下角一枚对角箭头 ⤢（详情）—— 这两枚**鼠标移上去才显形**；预览图下方是名称 `Seedream 5.0 pro`，再下面一行左边是 `🔥 热点推荐官` 徽标、右边是一枚漏斗图标加数字 `533.1w`](../screenshots/M-231-风格卡片-悬停显形.png)

| 位置 | 是什么 | 实测 |
|---|---|---|
| 预览图**左上角** | 一枚 `24×24` 的图标按钮，**无文字**（模型名被 `24×24` 裁掉了看不见）。这张是**模型徽标** —— 一枚 `📊` 柱状图图标 + 模型名。⭐ **它不是风格名**，实测悬停读出的模型名有 `Seedream 5.0` / **`Seedream 4.5`**（往下滚才出现）/ `Qwen Image` / `Z Image` / `Lib Image` **五种**，**气泡逐字就是徽标里的模型名**。⚠️ **不是每张卡都长这样** —— 有的卡这个位置是**三个点 `•••`**（path `M2 0a2 2 0 1 1 0 4 2…`，6 个圆点），悬停**没有气泡** | 常驻（`opacity: 1`）。⭐ **模型徽标点了什么也不发生**：落点已用 `elementFromPoint` 验过**确实落在徽标自己身上**（`cursor: pointer`），点完 6 次采样 —— 节点数不变、积分 `20 → 20`、广场还开着、详情浮层没开。⭐ **点那枚 `•••` 同样不弹任何菜单**（见下） |
| 预览图**右上角** | ☆ **收藏**（`24×24`） | ⭐⭐ **`aria-label` 有两态**：没收藏时写 `收藏`，收藏后写 **`取消收藏`**。⭐ **悬停才显形**：`opacity` 从 `0` 变 `1`，位置不动 |
| 预览图**右下角** | ⤢ **详情**（`<button aria-label="详情">`，`24×24`，图标是两支对角箭头） | ⭐ **同样悬停才显形**（`0 → 1`）。⚠️ **只有风格广场有这一枚，特效广场一枚都没有**。⭐⭐⭐ **每张卡都有一枚** —— 滚动过程中三次采样，详情按钮数和收藏星数**始终相等**（`30/30` → `54/54` → `54/54`） |
| 预览图**下方** | 风格**名称** + `商用` 徽标 | `商用` 徽标**不是每张都有** |
| 名称下一行 | 作者头像 + 作者名 + **漏斗图标** + 数字 | 见下 |

![同一屏里两种卡面对比：左边这张左上角是 `•••`（名称「J_漫剧素材三视图三…」、作者 JM32、`1.1w`），右边那张左上角换成了一枚模型徽标（名称「【捌陆设计】短剧…」、作者 捌陆设计、`287`）—— 说明**卡面左上角那枚图标不是每张卡都长成 `•••` 那样**；两张卡右下角都有漏斗图标 + 数字](../screenshots/M-244-风格卡片-左上角两种徽标.png)

⭐ **悬停显形是精确读到的**：同一张卡，悬停前后各读一次那两枚按钮的 `opacity`，
两次都是 `0 → 1`，而**矩形位置完全没动**（`[271,210,24,24]` / `[271,413,24,24]`）。

#### ⭐ 那枚 `•••`：点它不弹任何菜单

这个按钮**抓了三次**才抓到 —— 值得记一下过程，因为它是个典型的「判据错了」：

| 判据 | 结果 |
|---|---|
| 按**文字**找（`⋯` / `...` / `…`） | 0 命中（它**根本没有文字**） |
| 按 `circle` **元素**数 ≥ 2 找 | 0 命中（⭐ 三个点**不是三个 `<circle>` 元素**，是同一个 `<path>` 里的三段圆弧） |
| 按 `d` 里的**圆弧段**数 ≥ 3 找 | ✅ **命中**（特效广场 **12/12 张卡**都有） |

**点它的结果：什么也没发生。** 判据两条 ——
面板内可见文字块数**点前 174 → 点后 174**（风格那边 124 → 123，反而少一个），
而且点击后的画面上**没有任何新出现的浮层**：

![点完那枚 `•••` 之后：卡片网格原样，没有任何菜单、浮层或提示；每张卡左上角的 `•••` 都还在，右下角仍是漏斗图标加数字（3500 / 1500）](../screenshots/M-245-特效卡片-点三点后无变化.png)

> ⚠️ 本轮有一处**差点被骗**：点前点后同一块像素的体积从 `147KB` 涨到 `579KB`，
> 看着像弹出了一张大图。**其实不是** —— 那是**图片懒加载完成**（点前截到还没加载的点阵图，
> 点后截到加载好的真图），前后**构图一模一样**。
> ⭐ **体积变化不等于出现了新东西**。

> 💡 **已收藏的卡上不出现 ☆。** 在「我的收藏」页里，卡片**没有收藏按钮** ——
> 没地方可再收藏了。所以「我的收藏」页看起来和「风格广场」页不一样，是正常的。

### ⭐ 点 ⤢「详情」会打开什么

![风格详情面板：标题「风格详情」，左边是整张大图；右栏依次是风格名「J_漫剧素材三视图+大头表情+姿势…」、作者「JM32」、一栏「首选推荐模型」和一枚 `General image V2` 的胶囊；底部左侧一枚 `★ 取消收藏`、右侧一枚白色的 `使用`；右上角还有一枚缩到最小化的图标](../screenshots/M-237-风格详情面板.png)

点卡上那枚 ⤢ **不会**建节点，它开的是**一个详情浮层**，逐字读出来是：

```
风格详情 │ <风格名> │ <作者> │ 首选推荐模型 │ <模型名> │ [★ 取消收藏] [使用]
```

| 元素 | 说明 | 实测 |
|---|---|---|
| **首选推荐模型** | ⭐ 每张风格都有一个**推荐模型**字段（`General image V2` / `Seedream 5.0` …），它就是卡面左上角那枚徽标的来源 | ✅ 读到 |
| **`★ 取消收藏`** | 收藏态下按钮写的是「**取消收藏**」而不是「**收藏**」—— 说明打开那一刻这张已经是收藏态 | ✅ 读到；点它弹「**取消收藏成功**」，本轮据此把收藏清回 0 张并**独立复核**过 |
| **`使用`** | ⭐ 「把风格用进画布」的入口 | ⭐ **点它 = 画布上加一个节点**，和「点卡片本体」**同一个后果**（见下）。**不扣积分**（实测 `20 → 20`） |
| 右上角 `⤡` | ⭐⭐ **不是「缩到最小化」，是「关掉这一层、回到下面那层」** | 按钮无文字，但**有 `aria-label="缩小"`**（`24×24`）。⭐ 实点过：点完**详情浮层连同它的压暗层一起消失**，**下面那层风格广场原样留在屏幕上**。⭐ **没有任何「还原」入口** —— 想再看那张卡，重新点一次卡上的 ⤢ 就行。⚠️ 这个「缩小」是从图标猜的名字，**猜错了**，已更正 |

> ⭐⭐ **它的图标和大编辑器右上角那枚「收拢箭头」是同一个**
> （path `M9.76 10.59c.28 0 .5.22.5.5v8a.4.4…`），
> 但**两处行为不一样**：大编辑器那枚点了直接回画布，详情浮层这枚点了回广场。
>
> ⚠️ **风格广场 / 特效广场自己**的右上角也有两枚 `40×40` 按钮：
> 一枚 `aria-label="minimize"`、一枚 `aria-label="close"`。
> ⭐ **全站的 `aria-label` 都是中文，只有广场这一层是英文** ——
> 靠「aria 是什么语言」就能认出这是广场，不是详情浮层。

> ⭐ **`使用` 按钮点下去 = 和「点卡片本体」一模一样的后果**（本轮结掉这个 📖）：
> 画布 `12 → 13`，新增 `m-0J5UTXY01T`，**积分 `20 → 20` 不扣**，
> 点完每 400ms 采一次共 8 次，`广场` 与 `详情浮层` 都**在第一次采样前就关了**。
> ⭐ 顺带把详情浮层的结构钉死了（祖先链逐层量出来的）：
> `使用` 按钮 `121×32`、class `bg-btn-invert-bg text-btn-invert-text`（白底深字的主按钮），
> 它在 `div.mantine-Modal-body` → `section.mantine-Modal-content` → `div.mantine-Modal-inner`
> 里，而 **`mantine-Modal-inner` 是 `1440×810`，铺满整个视口**；真正有内容的容器
> （含「风格详情」全文）是 `757×681` 那一层。
> ⇒ **详情浮层是全屏的**，但内容只占中间一块。
>
> ⚠️ **别把「点详情」「点卡片」「点收藏星」「点使用」当成同一件事**：
>
> | 动作 | 后果 |
> |---|---|
> | 点 `⤢ 详情` | 开一个**只读**详情浮层，**不动画布**（本轮又复核了一次：连点两次详情，节点数没变） |
> | 点 `收藏` | 切收藏态（弹「取消收藏成功」），不动画布 |
> | ⭐ **点卡片本身** | **往画布里加一个节点** —— ⭐ **两个广场都已实测**，见下两节 |
> | ⭐ **详情浮层里的 `使用`** | **同样是加一个节点**，与「点卡片本体」等价 |

### 那个数字和那两个没验的东西

> ⚠️ **卡片上那个数字的，单位本手册没有验证。**
> 风格广场这边读到的是 `532.0w` / `1.1w` / `279` / `5900` / `59` / `252` ——
> `w` 是「万」，所以**这一列更像使用量/热度，不是价格**。
> 而特效广场那边读到的是 `3500` / `1500` / `549` / `3100` / `138`，量级完全不同。
> **两个广场的数字不是同一个东西** 📖，具体含义请以界面上你看到的那一项为准。

| | 风格广场 | 特效广场 |
|---|---|---|
| 分类标签 | **10 个** | 只有 `推荐` 一个 |
| 数字量级 | `532.0w` / `1.1w` / `59`（**带 `w` = 万**） | `3500` / `1500` / `549` / `3100`（**纯整数**） |

### ⭐⭐⭐ 点一下卡片 = **这个特效立刻变成画布上的一个节点**

![点完一张特效卡片之后：左边资产管理抽屉最上面多出一行「素材·特效·小蜜蜂运镜」（带图片图标），左下角写着「共 12 节点」；画布中下部也出现了同名的新节点卡片，带着这张特效的预览图，右下角是 TV Director 的入口浮标](../screenshots/M-298-特效卡片-点一下就进了画布.png)

**没有第二次确认，点一下就生效。** 实测的完整读数：

| 读数 | 点之前 | 点之后 | 删掉那个节点之后 |
|---|---|---|---|
| 抽屉「共 N 节点」 | **11** | **12** | **11** |
| 抽屉第一行 | `文本节点 1` | **`素材·特效·小蜜蜂运镜`** | `文本节点 1` |
| 剩下的 11 行 | 与基线逐项相同 | — | **与基线逐项相同** |

| 现象 | 实测 |
|---|---|
| 节点名字 | 画面上写 **`素材·特效·小蜜蜂运镜`**（中间是**中点 `·`**）；无障碍名里写的是 **`素材-特效-小蜜蜂运镜`**（**连字符 `-`**）—— 同一件事，两处写法不一样 |
| 这个节点的 id | `m-EAvw5wpOcF` —— **`m-` 前缀**，是本手册见到的第六种节点前缀 |
| 广场 | **点完立刻关闭**（时间序列采样：点后 300ms 内就已关；另有一次采样读数说还开着，见下面的「读数打架」） |
| 提示 | 右下角弹一条 toast，文字是 `素材·特效·小蜜…` |
| 落在哪 | 新节点出现在**视口中央偏下**，不是拖出来的，**位置固定** |

> ⭐ **所以「点卡片」和「点详情」是两种完全不同的后果**：
> `⤢ 详情` 是只读浮层，`点卡片` 是**往画布里加东西**。
> 特效广场的卡上**只有两枚按钮** —— `•••`（无 `aria`，实测点它不弹任何菜单）和
> `收藏`（`aria="收藏"`）；**没有 `⤢ 详情`**。
> 也就是说，**在特效广场里，「点之前先看清一张卡是什么」这条路界面上没给**。

> ⛔ **本手册把点出来的节点原样删回去了**：按名字 `素材-特效-…` 认人
> （用户原有的 11 个节点里**一个都不带这个前缀**），悬停到那一行、点**同一行**的
> `更多操作` → `删除`，删完 11 个名字与基线**逐项相同**。
> 删节点**没有二次确认** —— 这也是为什么前面那套「先读名字再动手」的习惯值得留着。

#### ⭐ 卡面上那个数字，单位仍然没验出来 —— 但能确定它是**同一个指标**

| 已验 | 内容 |
|---|---|
| 它前面有一枚图标 | **纸飞机**形状，`viewBox="0 0 16 16"`，路径 `M.09 1.94A1.45 1.45 0 0 1 1.94.09l12.3 4.4…` |
| ⭐ **两个广场用的是同一枚** | 风格广场首卡和特效广场首卡取到的路径**逐字相同** |

| 详情浮层里 | **没有**这个数字，也没有任何关于它的说明 |
| 界面上 | **没有任何一处文字解释它是什么** |

所以能确定的只是：**风格广场的 `532.0w` 和特效广场的 `3500` 是同一个指标**，
只是量级写法不同（`w` = 万）。它的**单位至今 📖 没验出来** ——
本手册**不写**它是价格、点赞还是使用量。

### ⭐ 广场的卡片是**无限滚动**的

往下滚会**一直加载出新的卡片**，不是翻到头。实测三个时刻：

| 时刻 | 列表总高 `scrollHeight` | 容器可视高 | 详情按钮总数 | ⭐ **视口内**的详情按钮 |
|---|---|---|---|---|
| 刚进广场 | **2265** | 517 | 30 | **12** |
| 滚到中段 | **4462** | 517 | 54 | **12** |
| 滚到底 | **6659** | 517 | 54 | **12** |

⭐⭐ 两个可用的判据：

1. ⭐⭐ **每张卡都有一枚详情按钮** —— 三个时刻里「详情按钮总数」和「收藏星总数」
   **始终相等**（`30/30` → `54/54` → `54/54`）。
   ⚠️ 早先有「6 枚」和「1 枚」两个读数，**两个都不对**（一个是脚本只扫了
   `x > 700` 的三列，另一个是广场还没加载完就采了）。
2. ⭐ **DOM 里始终只保留视口附近的卡** —— 三个时刻**视口内的详情按钮都是 12 枚**
   （6 列 × 2 行），而总数一路涨到 54。

滚动容器是 `div.m_c0783ff9 mantine-ScrollArea-viewport`，
`[101,197,1238,517]`，`overflow-y: scroll`。

> 📖 另一处曾经出现过、但没能复现的东西：某一轮截图里，卡面上浮出过一块
> 「**全部适配模型**」面板，列着 `Seedance 2.0` / `Kling 3.0` / `Kling O3`。
> 随后 8 次采样（含「只悬停不点」和「点了之后」）**一次都没再看到**，
> 所以**不能**当成已验证的行为写在这儿。

> ⚠️ 有一处**读数打架**，如实记在这儿而不是挑一个信：
> 同一批实验里，一次采样说「点完广场还开着、适配模型面板浮出来了」，
> 另一次说「点完广场关了」。后来用**时间序列采样**（点完每 400ms 采一次、共 8 次）
> 定死为「**300ms 内广场就关**」。⭐ **单点采样不足以定性，要看时间线。**

> ⚠️ 有一处**差点被骗**，如实记在这儿：
> 早一轮想靠「点前点后同一块像素的 sha256」判断点 `•••` 有没有弹出菜单，
> 体积确实从 `147KB` 变成 `579KB` —— 但那**是图片懒加载完成**（前后构图一模一样），
> 不是弹层。⭐ **体积变化不等于出现了新东西。**

其他两处细节：

- 两个广场的卡片**悬停时右上角都会浮出一枚 ☆**（收藏）；
- 两个广场的列表最底下都有一行 `没有更多了`；
- `我的收藏` 页**空的时候写的是「暂无素材」**（不是「暂无收藏」）—— 收藏和素材共用这一页。

> 建议：建完工具箱**顺手切到「更新工具箱」页看一眼**，这是目前唯一能确认「真的存上了」的办法。

### 按钮文案会从「添加」变成「更新」

![点完创建之后，同一个组的操作条上那一项已经写成「更新工具箱」](../screenshots/M-13-工具箱弹窗-点创建之后.png)

这是最容易错过的一个信号：**同一个组存进工具箱之后，操作条上那一项的文案就从
「添加到工具箱」变成了「更新工具箱」**。

它同时也解释了为什么创建之后「什么都没发生」—— 不是没发生，是**画面上没有给你任何地方去看见它**，
唯一的变化就是这个按钮换了名字。

> ⚠️ **这轮真的建了工具箱**（在一次性测试账号里建了两个）。工具箱是账号级数据、不随画布删除，
> 你自己的正式账号上不会有本手册的测试残留。

## 添加资源

添加节点面板底部还有一个独立的「**添加资源**」分区：

![添加节点面板底部的「添加资源」分区：上传 / 从生成历史选择](../screenshots/B1-item-从生成历史选择.png)

| 入口 | 用途 |
|---|---|
| `上传` | 从本地传文件进画布 |
| `从生成历史选择` | 复用以前生成过的东西 |

「从生成历史选择」点开是一整块**选择弹窗**（不是一个小列表）：

![「从生成历史选择」弹窗：标题「选择图片」，顶部 LibTV / Lib生成器 / WebUI / ComfyUI / AI应用 五个来源，右上「已选 0/10 张」，下面是 图片/视频/音频 三个分类，主体空态「暂无数据」，右下「确定」](../screenshots/M-138-从生成历史选择-弹窗.png)

| 位置 | 实测内容 |
|---|---|
| 标题 | `选择图片`（选视频/音频时会跟着变） |
| **来源标签** | `LibTV` · `Lib生成器` · `WebUI` · `ComfyUI` · `AI应用` |
| 计数 | `已选 0/10 张` —— **一次最多选 10 个** |
| 主体 | 没生成过东西时是 `暂无数据` |
| 底部 | `确定` |

> 💡 **五个来源的分类标签并不一样**，点哪个决定你看到哪几类素材：

| 来源 | 分类标签 |
|---|---|
| `LibTV` | `图片` · `视频` · **`音频`** |
| `Lib生成器` | `图片` · `视频` |
| `WebUI` | `图片` · `视频` |
| `ComfyUI` | `图片` · **`音视频`** |
| `AI应用` | `图片` · **`音视频`** |

注意 `LibTV` 那档写的是 `音频`、`ComfyUI` 和 `AI应用` 那两档写的是 `音视频` ——
不是同一个东西。后两者把音频和视频合在一类里。

> ⚠️ 这里有个**手册之前没说、但很重要**的点：来源不止 LibTV 自己，
> **`WebUI` / `ComfyUI` / `AI应用` 说明你可以从外部工具把素材接进来**。
> 本手册只读了标签文案，**没点过任何一个来源** —— 各自怎么接、需不需要配 API Key，都不知道 📖。
> 五个来源本轮**全部显示「暂无数据」**（测试账号从没真正跑过生成）。
>
> 另一个实用推论：计数上限是 **10 张/次**，所以「一次把几十个素材搬进画布」这条路走不通，得分批。

> 📖 历史记录里到底有哪些东西、怎么筛选，本轮仍未展开验证（测试账号从没真正跑过生成），
> 见 [../20-reference.md](../20-reference.md) 的「资产页」。

## 在节点里怎么用

素材进入画布之后，用两种方式喂给节点：

1. **连线** —— 把素材节点的出口连到目标节点的入口，见 [connect-nodes.md](connect-nodes.md)；
2. **参考** —— 点节点顶部的 `参考` 按钮手动挑。

风格还有第三条路：图片和视频节点顶部各有一个 `风格` 按钮。

## ⚠️ 页面上有两个「上传」，它们不是同一个东西

LibTV 画布里有**两个都叫「上传」的入口**，去的地方完全不同：

| | 「上传」（本页 `添加资源` 分区） | 「上传资产」（资产管理抽屉） |
|---|---|---|
| 位置 | `添加节点` 面板底部 `添加资源` 分区 | 左下角 `资产管理` → `资产` 标签 → `+` → `上传资产` |
| 进去的东西 | **进画布**（变成可用的节点素材） | **进资产库**（变成可分类的资产文件） |
| 点下去立刻弹什么 | 📖 本手册没点 | **不是系统选文件框**，而是「上传资产」表单：先选**保存到哪个文件夹**，再在虚线框里放文件 |
| 格式限制写在哪 | 📖 没打开过 | ✅ **面板底部白纸黑字**：`支持的文件格式 🖼 jpg/jpeg/png ▶ mp4 🔊 mp3`、`单个文件大小不超过 20MB` |
| 必填项 | — | `保存位置 *`（带红星）—— 不填右下角 `保存` 是**禁用**的 |

> ⭐ **想知道上传支持哪些格式，去资产抽屉那个「上传资产」面板看底部那两行字。**
> 那是界面正文，不是推测。
>
> ⚠️ 反过来，**别拿资产库那套格式去推断画布节点的上传** ——
> 两个入口的约束不保证一致（📖 本手册没打开过节点那个）。

完整读数见 [整理画布 · 资产管理：左抽屉](organize-canvas.md#「资产」标签)。
