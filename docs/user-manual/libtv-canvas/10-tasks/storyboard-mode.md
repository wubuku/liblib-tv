# 故事板模式：按时间顺序看内容

> 目标：在「工作流」和「故事板」之间切换，知道两种视图各自适合做什么。
> 适用角色：普通创作者 · 验证状态：✅ 实跑

---

## 两个视图的区别

顶栏中间有一个切换开关：`工作流` | `故事板`。

| | 工作流 | 故事板 |
|---|---|---|
| 画布上是什么 | **节点和连线** | **三列内容** |
| 回答的问题 | 「谁依赖谁」 | 「先播什么后播什么」 |
| 适合 | 搭流程、调依赖 | 检查叙事顺序、交付给客户看 |

![工作流模式：画布上是节点和连线，中央提示「双击画布 自由生成节点」](../screenshots/A4a-mode-workflow.png)

![故事板模式：画布换成三列「文本 / 图片 / 视频」，每列各有自己的空态文案](../screenshots/A4b-mode-storyboard.png)

## 故事板的三列

切到故事板后，画布内容换成三列。**空画布**时每列是空状态：

| 列 | 空状态文案 |
|---|---|
| 文本 | 暂无文本 |
| 图片 | 暂无图片 |
| 视频 | 暂无视频 |

但**有内容时长什么样**，才是你真正会遇到的。建一个文本、一个图片、一个视频再切过来：

![故事板有内容时：文本列只有节点行，图片列和视频列各有一个「待确认后生成」的占位框和模型标签，视频列右上角还有「全部」筛选和节点行上的「对话」按钮](../screenshots/M-29-故事板模式-有内容.png)

| 列 | 有内容时 | 备注 |
|---|---|---|
| 文本 | 一行「文本节点 1」 | 纯文字，**没有预览框** |
| 图片 | 「图片节点 2」+ 灰色占位框，框内写 **待确认后生成** + 下面挂 `Lib Image 2.5 Pro` 模型标签 | 占位框右上角有 `⤢` |
| 视频 | 「视频节点 3」+ **右侧一枚「对话」按钮** + 占位框「待确认后生成」+ `2.0` 标签；列头右上角多一个 **「全部」筛选下拉** | |

> **「待确认后生成」是这几个节点的真实状态**：还没跑过生成，所以没有产物。
> 故事板这一列显示的就是「这一格将来要出什么」，而不是「现在出了什么」。
> 换句话说，**故事板是按产物类型分的待办清单**，正好用来检查「这一段该有图还是该有视频」。

> 切换**不会丢内容** —— 这是同一批内容的两种排布方式。切回工作流，节点和连线都还在。
> 实测：切过去再切回来，工作流态节点数 `3 → 3`，一个不少。

## 怎么切

点顶栏的「工作流」或「故事板」按钮即可，来回切没有代价，也没有确认框。

## 一个容易踩的坑

**空画布切到故事板，几乎什么都看不到** —— 只有三列空状态。所以别把「切过去一片空白」当成切换失败，它只是忠实地告诉你：你的画布里还没有内容。

## 切到故事板，TV Director 会跟着一起来

第一次实测这一页时撞上的意外：**点「故事板」的同时，右侧会滑出一个 TV Director 面板**。

![切到故事板时右侧滑出的 TV Director 面板，四个入口分别是感知画布开始创作 / 从爆款预设开始剧本原创 / 上传故事来改编 / 批量优化提示词，底部是「全能创作」和提交箭头](../screenshots/M-33-TV-Director-面板.png)

| 面板位置 | 实测 |
|---|---|
| 浮层框 | `[1024, 154, 400×640]`，class 是 `mantine-Drawer-inner` |
| 标题 | `让 TV Director 辅助你的无限创意` |
| 四个入口 | `感知画布开始创作` · `从爆款预设开始剧本原创` · `上传故事来改编` · `批量优化提示词` |
| 输入框底栏 | `+` · **`全能创作` ▾** · 立方体 · 文件夹 · 手掌 · 提交 `↑` |
| 底部状态条 | `故事板 正在跟随` · `取消ESC` · `按 ESC 退出` |

它右上角有一枚「—」，点一下就收起（实测收起后再读页面，浮层确实不在了）。

> ⚠️ **那四个入口本手册一个都没点。** 点它们会**给 TV Director 派发任务、进而可能触发生成**，
> 属于安全边界里「需要单独授权」那一类。所以这张图只证明「面板长这样」，
> 不证明「点下去会发生什么」。
>
> 另外注意「故事板 正在跟随」：切回工作流后状态条依然在，
> 说明**它跟的是整个画布，不只是故事板视图**。

## 取消与恢复

- 切错了：再点另一个按钮切回来。
- 故事板里想改内容：点具体的列去看，或者切回工作流改节点 —— 两个视图操作的是同一份数据。
