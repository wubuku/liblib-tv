# 整理画布：平移、缩放、整理、小地图

> 目标：节点多了也能一眼看清，找回看丢的东西。
> 适用角色：普通创作者 / 重度创作者 · 验证状态：✅ 实跑

---

## 缩放

### 三种方式

| 方式 | 操作 |
|---|---|
| 缩放菜单 | 点左下角的百分比（如 `100%`） |
| 键盘 | `⌘+` 放大 · `⌘-` 缩小 · `⌘0` 适合屏幕 |
| 菜单里直接给档位 | `缩放至50%` / `缩放至100%` / `缩放至800%` |

![缩放菜单：顶部百分比输入框，下面是放大 ⌘+ / 缩小 ⌘- / 适合屏幕 ⌘0，以及 缩放至50% / 100% / 800%](../screenshots/A6-zoom-menu.png)

### 「适合屏幕」不是「回到 100%」

`⌘0`（菜单里叫**适合屏幕**）是把**所有节点框进当前视口**，不是重置缩放比。节点少的时候它会**放大到超过 100%**，节点多的时候会缩得很小。

想要固定比例，用菜单里的 `缩放至50%` / `100%` / `800%`。

> 触摸板双指捏合也能缩放，无需按任何键。

## 平移

> ### ⚠️ 空白处直接拖，画布是拖不动的
>
> 这是本页最容易踩空的一条。本手册用**同一段鼠标位移 `(+220, +120)`** 分别试了四种操作，
> 量出各自的「视口实际位移」：
>
> | 操作 | 视口实际位移 | 跟手吗 |
> |---|---|---|
> | 空白处**无修饰键**左键拖 | `(+16.3, 0)` | ❌ 基本等于拖不动，纵向完全没反应 |
> | `Space` + 左键拖 | `(+220, +120)` | ✅ 严格 1:1 |
> | 抓手工具（`H`）+ 左键拖 | `(+220, +120)` | ✅ 严格 1:1 |
> | **中键**拖 | `(+220, +120)` | ✅ 严格 1:1 |
>
> 「抓手工具按 `H` 切到抓手，然后左键拖空白」这句话在面板上是这么写的，但**更省事的是直接 `Space`**：
> 不用切工具、随时能松手回到选择状态，中键拖也是同等的 1:1 且完全不用管工具。
>
> 抓手工具唯一多出来的东西是**光标**会变成 `grab`，适合长时间拖着看大片区域时用。

## 平移

| 方式 | 操作 |
|---|---|
| **临时平移（最省事）** | 按住 `Space`，再左键拖空白 |
| 中键 | 按住滚轮拖动（不用切工具） |
| 抓手工具 | 按 `H` 切到抓手（左键拖；光标变 `grab`），再按 `V` 切回选择 |
| 滚动 | 鼠标滚轮 / 触摸板双指滚动 |

底部中央工具条上那枚按钮就是抓手工具：默认显示「**移动**」，按 `H` 之后变成「**抓手工具**」，按 `V` 又变回「移动」。

## 整理画布

`⌥` + `⇧` + `F`，或点底部工具条上那个「整理画布」按钮（按钮的悬浮提示里就写着这个键）。

![整理画布：节点被按依赖关系铺成整齐的一行](../screenshots/D-98-整理画布后.png)

> ### ⚠️ 整理完一定会问你一次
>
> 左下角弹出「**是否保留此次整理结果？**」，两个按钮 `还原` / `保留`。
>
> - 点「**保留**」→ 这次布局落盘，刷新后还在；
> - 点「还原」→ 回到整理前的位置。
>
> **这是「以为整理没生效」的头号原因** —— 不点「保留」，下次打开就白整理了。

## 其他三个底部开关

| 按钮 | 作用 |
|---|---|
| 切换小地图 | 显示/隐藏右下角缩略图，节点多时用它定位 |
| 隐藏节点连线 | 连线太密、互相压着时先关掉 |
| 网格吸附 | 拖动节点时是否自动对齐网格 |

三个都是**开关型**，再点一次恢复。

## 找到「我刚才建的那张节点在哪」

- 先按 `⌘0` 框住全部节点；
- 实在太多，再点「切换小地图」用缩略图找；
- 节点在视口外，直接按 `⌘F` 搜名字（见 [create-nodes.md](create-nodes.md)）。

### ⚠️ 「当前视窗没有节点」不是画布空了

用 `Space` 把视口拖远，会拖到**一个节点都看不见**。这时候画面底部中央会弹出一条提示：

![把视口拖到所有节点之外后，底部弹出「当前视窗没有节点」和「返回节点」按钮](../screenshots/K-06-当前视窗没有节点.png)

**这不是画布被清空了。** 本手册量过一次完整的轨迹 —— 按住 `Space` 每轮向右拖 420px（视口每轮精确位移 420）：

| 轮次 | 画布 DOM 里的节点数 | 提示 |
|---|---|---|
| 1 | 3 | 无 |
| 2 | 2 | 无 |
| 3 | 1 | 无 |
| 4 | **0** | **「当前视窗没有节点」出现** |

也就是说：**只有落在视口内的节点才被渲染进页面**，拖远了它们就从页面上消失了（所以此刻按 `⌘A` + `⌫` 是危险的 —— 你以为在删节点，其实什么都没选中）。

两个按钮：

- **`返回节点`** → 把视口飞回有节点的地方。实测点完之后节点重新回到页面（DOM 节点数 0 → 3），提示自动消失 ✅
- **`✕`** → 关掉提示，视口留在原地。

**结论：看到这个提示，点「返回节点」，不要刷新。**

## 取消与恢复

- 缩放乱了：`⌘0` 或菜单里的 `缩放至100%`。
- 整理后悔了：在确认条上点「还原」，或者整理前先复制一张画布（见 [manage-canvases.md](manage-canvases.md)）。
