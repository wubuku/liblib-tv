# 快速开始：第一次打开 LibTV

> 目标：10 分钟内，你在 LibTV 里有一张自己的画布，上面摆了两个节点并连成一条线。
> 全程**不花任何积分** —— 只建节点和连线，不点生成。
> 适用角色：普通创作者。

## 你会得到什么

一张空画布，上面有一个图片节点、一个视频节点，两者之间连着一根线。这是 LibTV 里最小可用的工作单元，后面所有玩法都长在这个形状上。

![空画布：中央提示「双击画布 自由生成节点」，下方是五个快捷入口，底部是工具条，右侧是 TV Director 抽屉](screenshots/A3-canvas-empty.png)

## 动手之前

- 一个已登录的 LibTV 账号。取证时测试账户余额为 **20 积分**；
- 桌面浏览器。本手册所有截图取自 **1440×810** 视口。

> ⚠️ 下面第 5 步会弹出生成面板。**看完就关掉，不要点右下角的提交按钮** —— 那会扣积分。

---

## 第 1 步：从首页进画布

打开 `https://www.liblib.tv`，左侧栏从上到下是：首页、**新建项目**、LibTV Agent、LibTV 3D-BOX，然后是首页 / 项目 / 资产 / 插件与扩展。

![首页：左栏入口、主区「新建画布创作」与八个快捷生成按钮、下方最近项目列表](screenshots/A1-home-overview.png)

点左侧栏的「**新建项目**」。

![项目列表页：顶部「回收站」「新建文件夹」，下方是项目卡片列表](screenshots/A2-projects-list.png)

**注意**：这里没有弹出「请输入项目名称」的对话框。点下去的同时，一张名为「未命名工作区」的新画布已经建好，并且你已经站在它里面了 —— 顶栏显示「画布 1」。

> 这是 LibTV 和大多数工具不一样的地方。很多人第一次用会以为按钮没反应，然后又点一下，结果建了两张。

## 第 2 步：认识画布上有什么

刚进来时画布是空的，只有中间一行提示「双击画布 自由生成节点」和五个快捷入口：图片生成、视频生成、音频生成、剧本生成、智能剪辑。

| 位置 | 控件 | 作用 |
|---|---|---|
| 顶栏左 | 项目名 / 「画布 1」 | 改项目名；点「画布 1」管理多张画布 |
| 顶栏中 | 工作流 / 故事板 | 切换两种排布方式 |
| 顶栏右 | 发布与分享 / 积分超市 / 余额 | 发布、充值 |
| 底部中央 | `+` 移动 素材库 角色造型室 生成历史 快捷键 教程 | 添加节点与各类面板 |
| 底部左 | 资产管理 · 整理画布 · 小地图 · 隐藏连线 · 网格吸附 · 缩放 | 视野与整理 |
| 右侧 | TV Director 抽屉 | 让 Agent 替你操作画布 |

## 第 3 步：建第一个节点

点底部中央工具条最左边的「**+**」（无障碍名是「添加节点」），弹出一列节点类型。

![添加节点面板：文本、图片、视频、智能剪辑 Beta、导演台 NEW、逐帧拉片 SD 2.5、音频、脚本、素材库，下方「添加资源」分区有上传与从生成历史选择](screenshots/B1-add-node-panel.png)

点「**图片**」，画布上立刻出现一张图片节点卡片。

![图片节点卡片：标题「图片节点 1」，下方是「尝试：图生图 / 图片高清」](screenshots/D-02-图片-节点特写.png)

> 想把节点放在画布的特定位置，用**双击那个位置**再选节点类型 —— 面板会锚在双击点弹出来。用「+」建出来的节点总是落在同一个地方。

## 第 4 步：再建一个并连起来

再点一次「+」，选「**视频**」。现在两张卡片叠在一起了，这不影响，先往下走。

每张节点卡片左右各有一个圆形端口：

- **左边圆环**是入口（接收上游产物）
- **右边圆环**是出口（把产物送出去）

从图片节点右边的出口按住，拖到视频节点左边的入口，松手。

![连线：图片节点右侧出口拖到视频节点左侧入口，连线成立](screenshots/H-11-节点连线-完整.png)

连上之后，视频节点的入口旁边会多一个蓝色小加号，表示「这里已经接了上游」。

**成功判据**：两根节点卡片之间出现一条连线；视频节点不再提示缺少输入。

## 第 5 步：看一眼能调什么（然后关掉）

点一下视频节点，卡片会**展开**，露出完整的编辑区：

![视频节点展开：顶部参考/标记/特效/角色库/运镜，中间提示词输入区「描述你想要生成的画面内容，@引用素材」，底部是模型与参数条](screenshots/F-03-视频节点-展开.png)

底部参数条上能看到：模型（`2.0`）、生成方式（`文生视频`）、规格（`16:9 · 720P · 5s · 1个`）、以及**这次生成要花的积分（`135`）**。

> **到此为止，把面板关掉（点空白处或按 Esc）。**
> 右下角那个圆形上箭头是提交按钮，点了会真的扣 135 积分。本手册不会替你试这一步。

## 第 6 步：整理一下视野

节点多了容易乱。两个最常用的操作：

- **看全貌**：按 `⌘0`（菜单里叫「适合屏幕」）；
- **铺开**：`⌥` + `⇧` + `F`（底部工具条那个「整理画布」）。

> ⚠️ 整理完画布，左下角会弹出「**是否保留此次整理结果？**」。一定要点「**保留**」，点「还原」就等于这次整理没做。

![整理画布后，节点被按依赖关系铺开](screenshots/D-98-整理画布后.png)

## 取消与回退

- **建错节点**：点画布空白处，然后 `⌘A` 全选、`⌫` 删除。注意只选中一个节点时直接按删除键是**没用的**，必须先让焦点回到画布。
- **连线连错**：选中那根线删除即可，不会影响两个节点本身。
- **想推倒重来**：画布下拉 → 行级菜单「删除画布」，会有二次确认。
- **提交了不想要的生成**：本手册没有验证过生成结果的撤销（因为没提交过），见 [90-troubleshooting.md](90-troubleshooting.md)。
