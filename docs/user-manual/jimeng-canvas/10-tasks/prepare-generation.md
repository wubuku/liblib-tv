# 准备生成（发送前停止）

## 适用角色

已登录的即梦画布创作者。

## 目标

在生成面板中写好提示词、选好模型与参数、确认积分价格——完成点击 **生成** 前的
全部准备。**本手册不代替你点击生成**：点击即扣积分。

## 前置条件

- 已登录，面板可用。
- 空节点即可开始；也可先接入参考（见 [连接节点](connect-nodes.md)）。

## 入口

选中一个**空节点**（视频 / 图片 / 音频），节点下方弹出生成面板；面板随取消选中关闭。

- 面板 DOM 一律是 `[data-testid="node-toolbar"]`。
- 视频面板与图片面板实测同为 **680×208**（音频面板见
  [音频节点选音色](audio-node-voice.md)）。
- ⚠️ **面板可能超出视口**：节点在画布偏下时，面板底部会被视口切掉。把缩放拨到
  60% 左右即可完整看到（见 [浏览与缩放画布](navigate-canvas.md)）。

## 视频生成面板（2026-10-01 实测逐字）

- 容器 `[data-testid="node-toolbar"]` **680×208**，内含 12 个 svg。
- 占位提示：上传参考图、输入文字或 @ 主体，描述你想生成的视频
- 面板逐字全文：
  `上传参考图、输入文字或 @ 主体，描述你想生成的视频 ｜ 即梦 Seedance 2.0 VIP ｜ 16:9 · 720P · 1 ｜ 全能参考 ｜ 4s ｜ Current price 56. ｜ 56 ｜ 生成`
- 空提示词时 **生成 禁用**，面板右下角出现逐字提示「**请输入提示词**」。

### 参数行控件（文档序，共 8 个可交互控件）

| 逐字 aria | 类型 | 实测尺寸 | 说明 |
|---|---|---|---|
| `展开视频生成器` | button | 40×40 | 放大编辑区 |
| `添加参考` | button | 48×48 | 上传参考图/视频 |
| `提示词` | `role="combobox"` contenteditable | 646×28 | 输入区 |
| `引用参考` | button | 24×24 | 在提示词内引用画布素材 |
| `选择模型: 即梦 Seedance 2.0 VIP, Standard-only model` | button | 184×32 | 模型下拉 |
| `视频尺寸选项: 16:9 · 720P · 1, Standard-only model` | button | 129×32 | 比例/分辨率/数量 |
| `生成模式: 全能参考` | button | 80×32 | 模式（首尾帧 / 全能参考） |
| `选择视频生成时长: 4s` | button | 46×32 | 时长 |
| `引用参考` | button | 32×32 | **同名第二处**（底部工具条） |
| `生成` | `type="submit"` | 32×32 | 空提示词时 `aria-disabled="true"` |

- ⚠️ **`引用参考` 在面板里有两处**（24×24 在提示词内、32×32 在底部工具条），
  aria 逐字相同。自动化定位必须加尺寸或位置约束。
- 参数行四个下拉的按钮 **aria 都带 `, Standard-only model` 后缀**；图片面板的
  对应按钮**没有**这个后缀（见下）。

## 图片生成面板（2026-10-01 实测逐字）

- 容器同为 `[data-testid="node-toolbar"]` **680×208**，但只有 8 个 svg。
- 占位提示：上传参考图、输入文字或 @ 主体，描述你想生成的图片
- 面板逐字全文：
  `上传参考图、输入文字或 @ 主体，描述你想生成的图片 ｜ Seedream 5.0 Lite ｜ 1:1 · 2K · 1 ｜ Current price 3 / 张. ｜ 3 / 张 ｜ 生成`
- 控件 8 个：`展开图片生成器` 40×40 ｜ `添加参考` 48×48 ｜ `提示词` 646×28 ｜
  `引用参考` 24×24 ｜ `选择模型: Seedream 5.0 Lite` 146×32 ｜
  `图片尺寸选项: 1:1 · 2K · 1` 98×32 ｜ `引用参考` 32×32 ｜ `生成` 32×32
  （空提示词时 `aria-disabled="true"`）。

> 🔧 **订正一条旧结论**：本手册早前写「参数行：模型 ∨ ｜ 1:1 · 2K ｜ **1 ∨**」，
> 把「生成数量」当成一个独立下拉。**2026-10-01 实测不存在这个独立控件**——
> 数量是**并入 `图片尺寸选项` 的**（aria 逐字 `图片尺寸选项: 1:1 · 2K · 1`，
> 三个值用 `·` 连在一起）。

## 音频生成面板

- 说明：输入台词并描述声音，可上传参考音频，通过 引用多个音色，使用时间戳编排
  人声、音效与配乐。
- 参数行：创作类型 **音频生成** ｜ 模型 **SeedAudio 1.0**（New）｜ 模式 **全能配音** ｜
  音色 **音色库** ｜ **✦12**（原价 24，积分5折）｜ 生成 禁用
- 逐项 DOM 契约见 [音频节点选音色](audio-node-voice.md)。

## 尺寸弹层：视频与图片不一样（2026-10-01 实测）

两个弹层结构相同（`role="dialog"` + 内含三个 `role="listbox"`），**但选项数不同**，
而且**渲染位置相反**：

| | 视频 `视频尺寸选项` | 图片 `图片尺寸选项` |
|---|---|---|
| 容器 | 334×292，渲染在 `node-toolbar` **外部**（浮在画布上方） | 432×292，渲染在 `node-toolbar` **内部** |
| 比例 | 6 项 48×56：21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 | **8 项** 48×56：21:9 / 16:9 / **3:2** / 4:3 / 1:1 / 3:4 / **2:3** / 9:16 |
| 分辨率 | 3 项 98×36：720P / 1080P / 4K | **2 项** 197×36：2K / 4K |
| 数量 | 4 项 73×36：1 / 2 / 3 / 4 | **8 项** 48×36：1 … 8 |

- 三个 listbox 的 aria 逐字分别是 **`选择比例 options`**、**`选择分辨率 options`**、
  **`选择生成数量 options`**；当前值用 `aria-selected="true"` 标记。
- 比例项各带 1 个 svg（比例示意图），数量项无 svg。

## 视频参数行：四个下拉（2026-10-01 实测逐字）

### 1. 选模型 —— 九项，不是五项

容器 `role="listbox"`，aria 逐字 **`选择模型 options`**，实测 **400×384**，
标题行逐字「选择模型：即梦 Seedance 2.0 VIP by seed」。九个 `role="option"`
各 **388×64**，每项一行名称 + 一句能力说明：

| # | 名称 | 能力说明 | 状态 |
|---|---|---|---|
| 1 | 即梦 Seedance 2.5 (样片模式) | 节省预算，先生成480P样片，选择满意版本后直出高分辨率版本 | 可选 |
| 2 | 即梦 Seedance 2.5 | 最强模型，支持 50个参考，新增视频编辑、超长生成 | 可选 |
| 3 | 即梦 Seedance 2.0 mini | 极致性价比，相近的体验，比Fast更快的推理速度 | 可选 |
| 4 | 即梦 Seedance 2.0 Fast VIP | 极速推理，会员专属通道，音视文图均可参考（暂不支持真人人脸） | 可选 |
| 5 | **即梦 Seedance 2.0 VIP** | 全模态能力，会员专属通道，音视文图均可参考（暂不支持真人人脸） | **当前选中**（`aria-selected="true"`，右侧带 ✓） |
| 6 | 即梦 Seedance 1.0 Fast | Pro级表现，加量不加价 | **禁用**（`aria-disabled="true"`） |
| 7 | MiniMax H3 | 开源视频生成模型 | 可选 |
| 8 | HappyHorse 1.1 | 国产视频生成模型 | 可选 |
| 9 | Wan 3.0 | Wan系列最新视频模型 | 可选 |

> 🔧 **订正一条旧结论**：本手册早前写「模型菜单五项（2.5 样片模式 / 2.5 /
> 2.0 mini / 2.0 Fast VIP / 2.0 VIP）」。**2026-10-01 实测是九项**——
> 后面多出 **Seedance 1.0 Fast（禁用）**、**MiniMax H3**、**HappyHorse 1.1**、
> **Wan 3.0** 四项。

- 三种文字颜色区分状态：可选 `rgba(255,255,255,0.698)`、当前选中
  `rgb(255,255,255)`、禁用 `rgba(255,255,255,0.2)`。
- 只有第 6 项的 aria **没有** `, Standard-only model` 后缀——**缺后缀 ⇔ 禁用**，
  这是一条可脚本化的判据。
- 可视区只装得下约 5 项（内部滚动区 392×344），第 7–9 项需要向下滚动。

### 2. 生成模式 —— 两项，手册早前漏了「首尾帧」

容器 `role="listbox"`，aria 逐字 **`Reference mode options`**（**英文 aria**），
实测 200×84，两项各 **192×36**：`首尾帧`（1 个 svg）、`全能参考`
（`aria-selected="true"`，2 个 svg 含 ✓）。

### 3. 选时长

容器 `role="dialog"`，aria 逐字 **`Duration options`**（**英文 aria**），实测
**400×100**：

- 标题逐字「**选择视频生成时长**」。
- 刻度 **0 / 5 / 10 / 15** + 单位 `s`。
- 数字输入框 `type="number"`，**90×36**，`min="4"`、`max="15"`、`step="1"`、
  `value="4"`。
- ⚠️ **刻度从 0 起，但实际下限是 4**（`min="4"`）——拖到最左也是 4s，不是 0s。
- 弹层里另有一个隐藏 `type="text"` 输入框（0×0，值为 4），自动化按 `input` 定位
  会先撞上它。

## 核对价格

- 面板内有一句英文逐字 **`Current price 56.`**（图片面板是 `Current price 3 / 张.`），
  旁边跟着同样的大号数字。
- 2026-09-23 实测示例：无参考 4s 视频 ✦56；带 6s 参考 ✦140；图片 ✦3/张；
  音频 5 折 ✦12。**价格随参数实时变化，以面板显示为准**。
- 2026-10-01 只读复核：无参考 4s 视频仍是 `Current price 56.`，与旧记录一致。

## 原子步骤

1. **写提示词**：点击面板输入区，输入描述文字（支持 @ 引用主体/素材）。
   - 成功判据：空面板的「生成」由 `aria-disabled="true"` 变为可用（实测）。
2. **选模型**（视频）：点 `即梦 Seedance 2.0 VIP ∨` → 九项列表（见上表）。
3. **选比例/分辨率/数量**：点 `16:9 · 720P · 1` → 弹层里三段分别选择。
4. **选生成模式**：点 `全能参考 ∨` → `首尾帧` / `全能参考`。
5. **选时长**（视频）：点 `4s ∨` → 拖滑杆或在数字框输入 4–15 之间的秒数。
6. **（可选）接参考**：见 [连接节点](connect-nodes.md)。参考接入后面板顶部出现
   参考 chip，处理完成后即就绪；**有就绪参考时即使不写提示词，「生成」也可用**。
7. **核对价格**：读参数行尾部的 `Current price …`。
8. **停在发送前**：确认无误后，生成动作由你自行决定。

## 取消 / 恢复

- 放弃本次：点击画布空白处，面板关闭（已输入的提示词不保留在面板中，但节点配置
  会随画布保存）。
- 参考接错：点参考 chip 的移除钮（aria `Remove …`）。
- ⚠️ **在参数行下拉里按 Esc，会把整个生成面板一起关掉**（`node-toolbar` 从 1 变 0），
  不是只收起下拉。关掉后要重新点节点才能再打开。音频面板的音色库筛选器不是这个
  行为（Esc 只关筛选器），别把两处混为一谈。

## 常见错误与恢复

| 现象 | 原因 | 处理 |
|---|---|---|
| 「生成」灰色不可点 | 空提示词且无就绪参考 | 写提示词，或等参考处理完成 |
| 面板底部被切掉看不见 | 节点位置太靠下，面板超出视口 | 把缩放拨到 60% 左右 |
| 刚按 Esc 下拉就没了 | Esc 连整个面板一起关 | 重新点节点选中 |
| 价格比预期高 | 参数/时长/数量或参考变化 | 核对参数行；改小参数后价格实时回落 |
| 找不到第 7–9 个模型 | 列表需要向下滚动 | 在列表内继续滚动 |
