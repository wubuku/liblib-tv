## 适用角色

## 目标

创建音频节点，了解配音/音频生成的面板参数、音色库与价格显示，为台词配音做准备

### 连接手柄：音频节点**能**当连线的起点

音频节点**左右两侧的手柄都在**（`source` 31/31、`target` 31/31）——
这与**时间线节点形成对照**（时间线**没有**出边手柄，见[时间线节点](timeline-node.md)）。

⚠️ **有手柄 ≠ 能拖**。真正的可拖热区在**伪元素**上：

| 部位 | 读数 |
|---|---|
| 手柄元素本体 | `pointer-events: none`、`opacity: 0`、屏上 `14×28` |
| **`::before`** | **`pointer-events: auto`、`40px×80px`** ← **这才是热区** |
| `::after` | `20×20`，`opacity: 0`（圆形字形，**鼠标悬停或选中时**才显形） |

⇒ 想判断「这个节点能不能发起连线」，**要读 `getComputedStyle(手柄, '::before').pointerEvents`，
不是看元素本体在不在、看不看得到。**

### 批次 97 的复现尝试：试听时序为什么没测到

批次 32 记的是「0.9s 仍为 `Play`、3.4s 已为 `Pause`」。
批次 97 用**更硬的判据**重测：在点下之前先在页面里挂一个 `MutationObserver`
监听所有 `aria-label` 变化（**逐条记时间戳**），然后连采样 30 秒。

结果：**observer 记到 `0` 条**，轮询也只读到起手那一次 `Play`，
之后 30 秒一直是 `Play`，**`Pause` 一次都没出现**。

⚠️ 两条读数**互相矛盾**，本轮**判不了**是「播放功能变了」「这次没触发」还是「环境不允许播放」，
因此 **记 VOID、不下结论**（`VOlD` = 没法验证，不等于「不存在」）。

💡 但这轮留下一个**比轮询强得多的判据**，值得记住：
**「`Play`→`Pause` 有没有翻转」用 `MutationObserver` 判，不要用轮询判** ——
轮询间隔大于翻转耗时时会**整个漏掉**翻转，看起来就像「根本没播」。

⚠️ 另一处**本轮两轮读数矛盾、同样记 VOID**：未选中的空音频节点，
a 轮 31/31 读到 `Not selected.`，b 轮在锁定节点未选中时却读到该元素**不在 DOM 里**（`null`）。
只有「末句随选中态在 `Selected.` / `Not selected.` 之间变」这一条两轮都站得住。

## 原子步骤

1. 点击左栏 **音频** → 新建音频节点并打开面板（实测节点 **`320×320` canvas**，
   class `react-flow__node-audio`）。
   🔴 **订正（批次 79）**：此处原写 **240×240**。2026-10-02 用**两个独立节点**复核 ——
   画布上他人的「音频 1」与本轮自建的新音频节点，在 scale `0.6` / `0.574468` 下
   屏上都读到 `192×192`，折合 canvas **都是 `320×320`**。`240` 未复现。
2. 在提示词区输入台词/声音描述。
3. 按需切换 **创作类型**（音频生成 / 音乐生成）→ **选择模型** → **音频生成模式**。
4. 需要挑声音时，点 **音色库** → 用四个筛选器缩小范围 → 点 `Add <音色>` 选用。
5. 核对折扣后价格（示例 ✦12/原价 ✦24）。
6. **停在发送前**：是否点击 **生成** 由你决定（消耗积分）。

## 取消 / 恢复

- 放弃：点击空白关闭面板；节点可 **⌫** 删除（注意先让焦点离开输入框）。
- ⚠️ **Esc 在这里是「重操作」**：关掉下拉会**连整个面板一起关掉**。
  只想去掉下拉，**点面板外的空白处**。
