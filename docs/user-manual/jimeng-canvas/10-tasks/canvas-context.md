# 管理画布上下文（重命名、生成历史、搜索、保存）

## 适用角色

已登录的即梦画布创作者。

## 目标

识别顶栏各入口：重命名画布、查看生成历史、全局搜索节点、确认保存状态，
并理解「离线编辑」提示的处理方式。

## 前置条件

已打开画布。

## 顶栏一览（左→右）

返回首页 ｜ **画布标题**（单击重命名）｜ **项目**（项目切换器）｜ **节点 N**（类型汇总）｜
**已保存** 状态 ｜ 标记色 ｜ **搜索** ｜ **生成历史** ｜ **分享** ｜ **更多**（⋯）｜
积分徽标（✦数字 · 会员等级）｜ **用户菜单**

## 原子步骤

### 「项目」：切换到别的画布项目（2026-10-01 实测）

顶栏标题右侧那个窄按钮（`aria="项目"`，20×28）**不是装饰**，它是**项目切换器**。

1. 点击 **项目** → 左上角弹出面板
   （`data-testid="canvas-project-panel-popover"`，aria `Project panel`，实测 **240×200**）。
2. 面板分两块：
   - 标题行 **项目**；
   - 下方 `<nav aria="项目">` 列出**该账号下的其他画布项目**，每项 232×36，
     本次实测到三项：**测试项目**（当前所在）｜ **未命名项目** ｜ **视频创作**；
   - 底部 **新建画布项目**。
3. 点任一项目名即**切换到那个项目的画布**。

> ⚠️ **切换项目会离开当前画布**。本手册**没有执行过任何项目切换**，
> 也没有点过 **新建画布项目** —— 两者都会离开或改变你当前的工作上下文。
> 正文只记录面板结构。

![顶栏「项目」按钮展开的 240×200 面板出现在画布左上角：标题「项目」，下方依次列出三个项目条目「测试项目」「未命名项目」「视频创作」（各 232×36，当前所在的测试项目为高亮项），底部是「新建画布项目」；面板外可见顶栏的测试项目、节点 1、已保存、分享与积分 805 基础会员](../screenshots/56-project-switcher-panel.png)

### 「节点 N」：看这个画布里各有多少节点（2026-10-01 实测）

1. 点击顶栏 **节点 N**（`Canvas node summary: 节点 1`，26×28）。
2. 弹出小结面板（`role="dialog"`，实测 **200×92**），自上而下两行：
   - 每个节点类型一行（本次实测 192×36）：**视频 1** —— 名称加一个类型小标签
     （`视频`，26×20），aria 逐字 `Canvas node summary`；
   - 一行 **查看项目信息**（192×36），通往项目信息。
3. **Esc** 关闭。

![顶栏「节点 1」按钮展开的 200×92 小结对话框：第一行是「视频 1」并带一个类型小标签「视频」，第二行是「查看项目信息」；面板锚定在顶栏「节点 1」按钮正下方](../screenshots/57-node-summary-popover.png)

### 重命名画布（实测）

1. 单击顶栏**画布标题** → 标题原地变输入框（可编辑态）。
2. 输入新名 → **Enter** 提交；**Esc** 取消。
   - **2026-10-01 实测闭环**：改名 → Enter 提交成功，顶栏与画布标识同步更新
     （aria 由 `Canvas title: 测试项目` 变为新名）；再次点击进入编辑、
     改回原名 Enter 提交，**已成功还原为「测试项目」**。
   - 成功判据：顶栏标题文字变化 + 刷新后仍是新名。
   - 输入框里 `⌘A` 不能全选（会变成在光标处插入），改名前先手动清空。

### 查看生成历史（实测）

1. 点击顶栏 **生成历史**。
2. 弹出面板（`role="dialog"`，aria 逐字 `生成历史`，实测 **320×211**），分两层：
   - **一级页签两个**：**生成历史** ｜ **积分明细**；
   - **二级类型页签五个**（本次实测逐字）：**全部 ｜ 图片 ｜ 视频 ｜ 音频 ｜ 文本**。
3. 本画布无生成记录，列表区逐字显示 **「暂无生成历史」**。
4. **Esc** 关闭。

![生成历史下拉：全部/图片/视频/音频页签与暂无生成历史空态](../screenshots/20-canvas-context-generation-history.png)

### 搜索节点（实测）

1. 点击顶栏 **搜索**。
2. 浮层输入框占位「搜索节点...」，下方按类型筛选（全部/图片/视频/音频/文本/
   主体/时间线/组/其他，带数量），结果按编号列出。
3. **Esc** 关闭。

> 📖 搜索的**完整操作**（点结果会定位并选中节点、输入值跨面板保留等）
> 见[平移、缩放与控制画布视图](navigate-canvas.md#搜索节点2026-10-01-实测此前完全未记录)。

### 分享画布（2026-10-01 实测）

1. 点击顶栏 **分享** → 右上弹出面板，标题 **分享画布**。
2. 面板逐字（自上而下）：
   - 画布链接输入框 ＋ **复制链接**；
   - 🔒 **仅自己可访问 ∨**（权限下拉），说明「只有你可以通过此链接访问画布」；
   - ✦ **创建团队，与成员在画布实时协作** ＋ 右侧 **创建团队**。
3. ⚠️ **改权限 = 对外开放**。把「仅自己可访问」改成任何可分享的选项后，
   拿到链接的人就能打开并编辑你的画布。改之前想清楚。
4. **Esc** 或点面板外关闭。

> **未执行**：本手册没有点过 **复制链接**、没有改过权限、没有点 **创建团队**——
> 这三项都会把画布暴露到账号之外，属对外产出动作。

![分享画布面板：标题「分享画布」，上方为画布链接输入框与「复制链接」按钮；中间为带锁图标的权限下拉「仅自己可访问」及说明「只有你可以通过此链接访问画布」；下方为「创建团队，与成员在画布实时协作」与右侧「创建团队」按钮，橙色高亮框为面板范围](../screenshots/36-share-panel.png)

### 更多菜单（2026-10-01 实测）

1. 点击顶栏 **更多**（⋯，aria `更多`）→ 弹出两项小菜单（实测 200×84）：
   **项目信息** ｜ **复制项目**。
2. **项目信息**：查看/编辑画布所属项目的信息。
3. **复制项目**：把整个画布复制成一份新项目。
   - ⚠️ **未执行**：会新建一个项目副本，属对外产出动作。
4. **Esc** 或点菜单外关闭。

![更多菜单：点击顶栏「更多」后弹出的两项小菜单——「项目信息」与「复制项目」，浮层 200×84，出现在按钮正下方，橙色高亮框为菜单范围](../screenshots/37-more-menu.png)

### 确认保存状态

- 顶栏 **已保存** 常驻显示保存状态；改动后自动保存。
- **内容跨刷新持久**（实测）：刷新页面后节点与连线完好。

### 「发现离线编辑」提示（处理原则）

断网期间做过修改、恢复联网后重开页面时，可能出现「发现离线编辑」对话框
（正文：你在离线状态下对当前画布做了修改，这些修改尚未同步到服务器。）：
- **保留并同步**：把本地修改同步上去（一般选这个）；
- **丢弃修改**：放弃离线期间的本地修改（不可恢复，慎点）。
（对话框文案来自真实观察记录；两种选择的后果以产品实际行为为准，慎用丢弃。）

## 常见错误与恢复

| 现象 | 处理 |
|---|---|
| 找不到某个节点 | 顶栏 **搜索** → 输入名称/类型筛选 |
| 怀疑改动没保存 | 看顶栏「已保存」；必要时刷新核对（内容会持久） |
| 不小心把画布分享出去了 | 顶栏 **分享** → 把权限改回 **仅自己可访问** |
| 想知道画布属于哪个项目 | 顶栏 **更多**（⋯）→ **项目信息** |
