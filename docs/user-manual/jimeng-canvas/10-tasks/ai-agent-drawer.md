# 使用「与 AI 对话」智能体抽屉

## 适用角色

已登录的即梦画布创作者。

## 目标

打开画布右侧的 Agent 对话抽屉，了解技能入口与输入方式（发送消息可能触发
生成并消耗积分，本手册只讲到发送前）。

## 前置条件

已打开画布。

## 入口

画布右下角 **与 AI 对话** 按钮，或按 **⌘/**（**2026-10-01 实测两按两态**：
`关闭 → 打开 → 关闭`，确认可开关）。

## ⚠️ 抽屉会盖住画布右侧的节点

**这是本任务最需要先知道的一件事。** 抽屉不是把画布挤窄，而是**覆盖在画布之上**：
实测宽 **400**、从屏幕 **x=868** 起铺满右侧，与画布重叠。

后果是**画布右侧约三分之一被挡住，落在那一带的节点点不中**：

| 状态 | 同一坐标的命中 | 点下去的结果 |
|---|---|---|
| 抽屉展开 | 落到抽屉内部（标题、技能 chips 等） | **节点选不中**，选中数不变 |
| 抽屉收起 | 落到节点卡片 | **正常选中** |

2026-10-01 对照实测：把「视频 1」拖到右侧使其与抽屉重叠，点节点上 `(957, 218)`
这个位置 —— 抽屉打开时命中 `H2`（抽屉标题）且选中数仍为 0；点抽屉头部 **收起** 后，
同一坐标命中节点卡片、选中数变 1。**节点位置没变，变的只是抽屉开合。**

> 💡 **要么先把节点拖出来，要么点「收起」/ 按 ⌘/**，再操作节点。
> 被盖住的节点**可以用左侧露出的一条点中**（实测节点左侧 111px 仍可正常点选），
> 但看不到全貌时很容易以为节点「失灵了」。

## 🔴 抽屉只有**两态**：展开 与 折叠 —— 没有「关闭」态

（**2026-10-01 批次 62 实测，推翻本手册此前「点收起 = 关闭抽屉」的说法**）

| | 展开 | 折叠（点「收起」之后） |
|---|---|---|
| 尺寸 | `400×696` @`(868,12)` | `200×348` @`(1068,360)` |
| `pointer-events` | `auto` | **`none`** |
| 内部可见元素 | 49 个 | **0 个** |
| 内部 `canvas-agent-panel` | 在 | **不在** |
| 画面 | 完整抽屉 | **什么都看不见**（截图已验证：只剩画布网格） |

**「收起」是折叠，不是关闭。** 折叠后那个 `200×348` 的框仍留在页面上，
只是它**内部空无一物、并且 `pointer-events: none`**，因此：

- ✅ **不再遮挡画布** —— 但机制**不是**「它消失了」，而是**它不接收点击**。
  零成本对照实测：取侧栏内 5 个坐标，`elementFromPoint` 在展开态 **5/5** 命中侧栏内，
  折叠态 **0/5**。
- ⚠️ **别把「画布上什么都没有」当成「元素不存在」** —— 它一直在 DOM 里。
- ⌘/ 是**切换**：折叠态按 ⌘/ **直接重新展开**（不是先「打开」再「打开」）。

> 🔑 这条也是一条读数纪律：**「读数没变」既可能是产品没反应，
> 也可能是我的尺子量错了量程。** 本批一开始用「宽度 340–460」当「抽屉开着」的判据，
> 折叠态的 200 宽不满足 ⇒ 被判成「已关闭」——
> **和批次 58 给质量门做阳性对照是同一个错，只是这次尺子在我脑子里。**

💡 想彻底不占位置：点「收起」即可（视觉与命中都已恢复）。
想重新打开：点右下角 **与 AI 对话** 按钮，或按 **⌘/**。

## 抽屉结构（2026-09-23 实测逐字，2026-10-01 批次 62 补 DOM 契约）

- 头部：**新会话**（旁注「仅支持新建一个空会话」）+ 收起钮。
- 空态：「探索更多专业创作模式」+ 技能 chips：
  **/视频反解** ／ **/创作分镜** ／ **/全流程广告片导演** ／ **/剧本开发** ／
  **/剧情短片**
- 底部输入卡：占位「输入想法、剧本或上传参考，支持「/」使用技能，@添加主体，
  和 Agent 一起创作」+ **使用技能** 按钮。

**批次 62 补的定位契约**（稳定选择器，不必再靠几何猜）：

| 元素 | 契约 |
|---|---|
| 侧栏本体 | `ASIDE[data-testid="canvas-feature-sidecar"]`，aria 逐字 **`Agent`**，`z-index: 40`。**全文档唯一**（实测 `querySelectorAll` 只命中 1 个） |
| 抽屉内容 | `canvas-agent-panel` **398×694 @ (869,13)** |
| 空态标题 | `canvas-agent-session-heading` **338×27 @ (899,213)**，逐字「探索更多专业创作模式」 |
| 5 个推荐 chip 的容器 | `canvas-agent-session-modes` **338×140 @ (899,252)** |
| 输入卡 | `canvas-agent-session-composer` **390×164 @ (873,539)**；`prompt-composer` **357×84 @ (890,554)**，aria 逐字「说说你的想法或任务，上传参考、输入文字或」 |
| 底部操作行 | `canvas-agent-composer-action-row` **357×32 @ (890,654)**，四项：`从本地、画布或资产库添加` 32×32 / `使用技能` 90×32 / `引用参考` 32×32 / `发送消息` 32×32 |

### ⚠️ 输入框里有**两层**同尺寸的 DIV，`elementFromPoint` 命中的不是编辑器

```
prompt-composer 357×84@890,554
└ DIV (relative w-full …) 357×84@890,554
  └ DIV.contents 0×0@0,0
    ├ DIV.tiptap.ProseMirror              357×84@890,554   ← contenteditable=true，能打字的那层
    └ DIV.relative.col-start-1.row-start-1 357×84@890,554 ← 占位符层，叠在它**上面**
```

输入框内**任意**坐标，`elementFromPoint` 命中的都是**占位符层**。
⇒ 想确认「点到了输入框」，判据是**落点在 `canvas-agent-session-composer` 之内**，
**不是**「落点在 `[contenteditable]` 之内」—— 那是**兄弟关系**，永远不成立。

## 原子步骤

**已实测**：打开与折叠抽屉。

1. 点击画布右下 **与 AI 对话** → 右侧全高抽屉展开（实测）。
2. 浏览空态技能 chips（**/视频反解**、**/创作分镜** 等）与底部输入卡的占位文案
   （实测逐项读过结构）。
3. 点击头部 **收起** → 抽屉**折叠**成看不见的空壳，画布右侧恢复可点（见上）。

**已实测（批次 62，全程未发送、积分 805 → 805 不变）**：

4. **点空态的技能 chip** —— 不是「展开引导」，而是**把该技能插成输入框里的一个 chip**。
   点 `/ 视频反解` 后输入框内容变成 `视频反解`，编辑器 HTML 是
   `<p><span class="react-renderer node-composerChip …">`，可见 chip **84×20 @ (890,556)**。
   **抽屉面板本身一点没变**（仍 `400×696@868,12`）。
5. **点底部「使用技能」** —— 弹出**技能选择器对话框**（见下表）。
6. **在输入框按 `/`** —— 弹出**技能下拉菜单**。
7. **在输入框按 `@`** —— 弹出**「添加参考」菜单**。

**仍未执行（属扣费边界，永久不在本手册范围）**：

8. **发送**：发送给 Agent 的消息可能触发生成类任务并消耗积分。本手册不描述
   发送后的行为，请自行评估后再操作。

## 技能：两个入口、四种落点，别把它们当成同一个东西

（**批次 62 实测。🔑 最容易踩的坑：`/` 唤起的浮层与「使用技能」按钮弹的
对话框是**两个不同的元素**。** 拿后者当前者，会得到一个「`/` 什么都没弹出」的
**假阴性** —— 而且读数干干净净（`no` / `no` / `no`），看不出任何异常。）

| 入口 | 浮层 | 几何 | `role` | 在抽屉内？ |
|---|---|---|---|---|
| 空态 5 个推荐 chip | **不弹浮层**，技能插成输入框内的 chip | — | — | — |
| 底部 **使用技能** | `canvas-agent-skill-picker` | `360×372 @ (896,274)` | **`dialog`** | **否**（挂在侧栏之外） |
| 输入框按 **`/`** | `agent-skill-menu` | `360×361 @ (878,187)` | `listbox` | **否** |
| 输入框按 **`@`** | 「添加参考」菜单（**无 `data-testid`**） | `240×296 @ (770,252)` | `listbox` | **否**（且**向左溢出到抽屉之外**） |

### 💡 输入卡一旦有内容，空态推荐区整块消失

点过 chip、或者输入了 `/`、`@` 之后，「探索更多专业创作模式」标题与 5 个推荐 chip
**同时不在 DOM 里**了（面板高度不变，只是那块内容被输入内容顶掉）。

## 取消 / 恢复

- **折叠**抽屉不影响画布内容；「新会话」仅新建空会话。
- **折叠同时解除对画布右侧的遮挡** —— 机制是 `pointer-events: none`
  让点击穿透，**不是**因为它被关掉了（见「只有两态」一节）。
- 技能 chip 是插在输入框里的，**删掉它即可撤销**（清空输入卡）。
