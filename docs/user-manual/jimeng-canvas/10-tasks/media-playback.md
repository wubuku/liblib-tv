# 预览与播放视频节点

## 适用角色

已登录的即梦画布创作者。

## 目标

在画布内播放/暂停视频、控制声音、进入全屏观看，处理加载失败的媒体。

## 前置条件

画布中有带媒体的视频节点。

## 入口

单击视频卡片（选中即出现播放控件与加工工具条）。

## 卡片播放控件（2026-09-23 实测）

选中卡片后，卡片底部一行：

- **播放/暂停** 钮（aria 为「Pause/Play <节点名>」）；
- **时间** 「00:00 / 00:06」样式；
- **静音** 钮（aria 在 Unmute video ↔ Mute video 间翻转；卡片默认静音）；
- **浏览器全屏** 钮（aria「Enter browser full screen」）；
- 底部细进度条显示播放进度。

工具条尾部另有 **全屏**（播放器全屏）与 **下载**。

## 原子步骤

1. **选中即播**：单击卡片选中，视频自动开始播放（时间从 0 走动）。
2. **暂停**：点击播放/暂停钮；成功判据：时间读数停止走动。
3. **声音**：点击静音钮切换；成功判据：aria 在 Unmute video / Mute video 翻转。
4. **全屏观看**：点击卡片右下浏览器全屏钮，或工具条 **全屏**；按 **Esc** 退出。
5. **下载**：工具条 **下载** 保存文件（本地行为，不耗积分）。

## 媒体异常

- 资源过期/加载失败时卡片显示失败态（如「视频播放失败」+ 重试按钮）。
- **重试播放** 后：资源可恢复则正常播放；资源已彻底失效则进入无时长空载态
  （时间显示 00:00 / 00:00，无法播放）——此时需重新上传或替换素材。
  （异常态行为部分来自历史观察记录，遇到时以画布实际提示为准。）

## 取消 / 恢复

- 点击空白取消选中，播放停止。
