# 预览与播放视频节点

## 适用角色

已登录的即梦画布创作者。

## 目标

在画布内播放/暂停视频、控制声音、进入全屏观看，处理加载失败的媒体。

## 前置条件

画布中有带媒体的视频节点。

## 入口

单击视频卡片（选中即出现播放控件与加工工具条）。

## 卡片播放控件（2026-09-23 实测）

选中卡片后，卡片底部一行：

- **播放/暂停** 钮（aria 为「Pause <节点名>」）；
- **时间** 「00:00 / 00:06」样式；
- **静音** 钮（aria 在 Unmute video ↔ Mute video 间翻转；卡片默认静音）；
- **浏览器全屏** 钮（aria「Enter browser full screen」）；
- 底部细进度条显示播放进度。

工具条尾部另有 **全屏**（播放器全屏）与 **下载**。

> **读屏用户注意**：播放/暂停按钮的 aria 文案**实测不随播放状态翻转**（暂停后仍读作
> 「Pause …」）。判断当前是否在播放，**以时间读数是否走动为准**，不要依赖按钮文案。
> 静音按钮则确实会翻转（`Unmute video` ↔ `Mute video`）。

## 原子步骤

1. **选中即播**：单击卡片选中，视频自动开始播放（时间从 0 走动）。
2. **暂停**：点击播放/暂停钮；成功判据：**时间读数停止走动**（按钮文案不变，见上方
   读屏提示）。
3. **声音**：点击静音钮切换；成功判据：aria 在 Unmute video / Mute video 翻转。
   卡片默认静音，需先解除静音才有声音。
4. **全屏观看**：点击卡片右下浏览器全屏钮，或工具条 **全屏**；按 **Esc** 退出。
   - 全屏播放器的控制条与卡片内不同：为 播放/暂停 + 时间（如 `0:01/0:06`，
     无前导零格式）｜ **音量滑杆**（细线 + 圆点，拖动调音量）｜ 扬声器图标 ｜
     退出全屏；右上角另有 **X** 关闭钮。视频铺满画面，底部一条细进度线。
   - 注意：全屏态下静音/全屏钮会隐藏，改由控制条上的音量滑杆调节。
5. **下载**：工具条 **下载** 保存文件（本地行为，不耗积分）。

## 媒体异常

- 资源过期/加载失败时卡片显示失败态（如「视频播放失败」+ 重试按钮）。
- **重试播放** 后：资源可恢复则正常播放；资源已彻底失效则进入无时长空载态
  （时间显示 00:00 / 00:00，无法播放）——此时需重新上传或替换素材。
  （异常态行为部分来自历史观察记录，遇到时以画布实际提示为准。）
  ⚠️ **订正（批次 78）**：上面这条只适用于「**有素材但播不了**」。
  **空节点不是这个状态** —— 它连 `00:00 / 00:00` 都不显示，见下表。

🔴 **「空节点」和「资源失效」是两种不同状态，读数不一样**（批次 78 实测订正）：

| | 空视频节点（还没放素材） | 资源失效（有素材但播不了） |
|---|---|---|
| 播放 / 暂停 / 静音 / 全屏控件 | **一个都没有** | 有 |
| 时间读数 | **完全没有**（不是 `00:00 / 00:00`，是压根不显示） | `00:00 / 00:00` |
| 卡片中央 | 一个**占位图标**，看着像播放键 | 失败态提示 |

⇒ 看到卡片中央有个播放形的图标、但**点不动、也没有时间读数**，那是**空节点**，
不是「资源坏了」；后者才会带时间读数与失败提示。

## 空视频节点长什么样（2026-10-02 实测）

新建一个视频节点、什么都不放，**选中它**时卡片上只有这些（尺寸为 canvas 像素）：

- 标题行 `视频 2`（`102×56`）+ 改名钮 + 标签钮；
- 卡片本体 `569×320`（正好 16:9），里面**只有一个居中的 `24×24` 占位图标**；
- 左右各一个 ⊕ 连接按钮（`36×36` 屏上，见 [连接节点](connect-nodes.md)）；
- 角落里一句 `0 ready, 0 processing, 0 failed` 的资源状态。

📌 **那个像播放键的图标不是控件**，三条证据：

1. 它带 `aria-hidden="true"` —— 对读屏软件而言根本不存在；
2. 它的 `cursor` 是 **`grab`**（拖动节点用的那个光标），不是 `pointer`；
3. 它的父层就是节点卡片本身，**没有** `aria-label="播放"` 之类的语义。

📌 **「暂无视频」四个字你在画面上找不到，因为它是给读屏软件用的**：
它不是画出来的文字，而是卡片空态容器上的 `aria-label`（该容器的 `innerText` 逐字是 `""`）。
所以「看不到提示」不等于「没有提示」——它只是不画给人看。

## 取消 / 恢复

- 点击空白取消选中，播放停止。

## 已验证说明

**当日实测（2026-09-23）**：选中即播、暂停、静音翻转、时间读数、全屏/下载入口。

**复刻研究源站采样**：全屏播放器的控制条构成与音量滑杆（batch 218）。

**未验证 —— 因为没有带媒体的视频节点**（这一条此前只写了「未验证」没写理由，
2026-10-01 批次 62 补上）：双击重播、进度条点击跳转、拖动音量滑杆。
这三项都需要一个**能播的**视频节点；当前画布上只有空视频节点，
空节点上**没有播放控件、没有时间读数**（批次 78 已把这两点逐项实测，见上节），
**无从测起**。与「需授权」不同 ——
这是**素材限制**，条件一变（能拿到可播的视频）就该回来测。

> ⚠️ 订正：早期把「空节点上没有播放控件」归因为「资源已彻底失效」，不成立 ——
> 空节点是**还没有素材**，不是素材坏了；后者才有 `00:00 / 00:00` 与失败提示。
