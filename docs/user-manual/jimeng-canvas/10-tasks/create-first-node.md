# 创建节点（含本地上传）

## 适用角色

已登录的即梦画布创作者（普通会员即可，创建节点本身不消耗积分）。

## 目标

在画布中创建文本、图片、视频、音频节点，或从本地上传媒体文件作为节点。

## 前置条件

- 已登录并打开一个画布（`/ai-tool/ai-canvas/:projectId`）。
- 本地上传只使用你自己有权使用的文件。

## 入口

- **左栏**：**文本**/**图片**/**视频**/**音频**（另有时间线/主体/导演台/资产库/上传）。
  鼠标悬停左栏时整栏展开为图标+文字标签，便于识别。
- **节点边缘 + 手柄**：悬停已有节点，左右边缘中点出现 **+** 圆钮。
- **空白处右键 → 新建节点**（子菜单，含 从资产库添加/本地上传）。

## 原子步骤

### 方式 A：左栏插入（实测）

1. 点击左栏 **文本**。
2. 画布中央立即出现新节点「文本 1」，自动选中，顶栏节点计数加一。
3. 结果：选中文本节点上方出现工具条（**背景色**/**全屏**/**下载**）。
   - 成功判据：新节点带选中描边。
     ⚠️ **屏幕上看不到节点数**（🔴 批次 120 订正：画布状态行那句读数是读屏播报、屏上不可见）；
     **肉眼的判据就是「新节点带选中描边」**，要数字只能看顶栏「节点 N」。见 [界面速查](../20-reference.md)。
   - 每类节点建一个后，命名按「文本 1、文本 2…」递增。
4. **图片** 同法：创建「图片 1」并自动弹出图片生成面板（模型 Seedream 5.0 Lite、
   1:1 · 2K、价格 ✦3 / 张）。
5. **视频** 同法：创建空视频节点并弹出视频生成面板（默认 即梦 Seedance 2.0 VIP、
   16:9 · 720P、4s、✦56 起）。

### 方式 B：+ 手柄创建并连线（实测）

1. 悬停源节点，点击边缘 **+**（aria 为 `Create connected node after …`）。
2. 弹出「添加节点」菜单：文本/图片/视频/音频/时间线/主体/导演台。
3. 点击其中一项（如 **视频**）→ 新节点建在源节点旁，并**自动生成一条参考连线**。
   - 成功判据：节点数与连线数各加一（状态行 `…, 1 edge, …`）。
   - 注意：与源节点类型无法连接的项会标「无法连接这些节点」并禁用
     （例如从视频节点出发时，文本/图片/音频/导演台不可连）。
     📌 **本方式点的是 after ⊕**（aria 逐字 `… after …`），菜单标题是「**添加节点**」；
     点节点**左边**那个 ⊕ 弹的是「**添加上下文**」，可连项不同 ——
     两套逐项表见 [连接节点](connect-nodes.md)。

### 方式 C：空白右键（实测）

1. 在空白处点右键 → 菜单弹出（`role="menu"`，aria 逐字
   **`Canvas context menu`**，实测 **240×172**），四项各 232×36：

   | 逐字 | 快捷键 | 备注 |
   |---|---|---|
   | **新建节点** | — | 带子菜单 |
   | **粘贴** | ⌘V | aria 逐字 `粘贴` |
   | **重做** | ⌘⇧Z | 禁用时条目下方附「无需重做操作」 |
   | **撤销** | ⌘Z | 禁用时条目下方附「无需撤销操作」 |

   🔴 **订正（2026-10-02 批次 95）**：上表的「四项各 232×36」只对**对外可见的那四条**成立。
   DOM 里实际有 **13 个** `[role=menuitem]`：其中 4 条有文字、`innerText` 各 232×36（即上表），
   另外 **9 个 `innerText` 为空、尺寸 192×36** —— 那是「新建节点」的**子菜单项被内嵌在同一个容器里**
   （悬停「新建节点」时它们才显形）。⇒ **按 `[role=menuitem]` 计数会得到 13，不是 4。**
   与节点右键菜单（7 项、各 `192×36`、容器 `200×292`，见
   [编辑文本节点](edit-text-node.md)）**是同一个 `Canvas context menu` testid，但几何不同** ——
   空白处 240×172 / 232×36，节点上 200×292 / 192×36。

2. 悬停 **新建节点** 展开子菜单：文本/图片/视频/音频/时间线/主体/导演台 +
   **从资产库添加** + **本地上传**。
3. 点击子菜单项即在右键位置创建。
4. **Esc** 可关闭右键菜单（实测关闭成功）。

![画布空白处右键弹出的 240×172 菜单出现在右键点右下方：四项依次为 新建节点、粘贴 ⌘V、重做 ⌘⇧Z（条目下方附灰色小字「无需重做操作」）、撤销 ⌘Z（条目下方附灰色小字「无需撤销操作」）；菜单右侧已到视口边缘](../screenshots/58-canvas-context-menu.png)

### 方式 D：本地上传（2026-10-01 批次 64 全程实测，已关闭「上传流程待验证」）

1. 悬停左栏，点击 **上传**（左栏最后一个入口，`40×40`）。
2. **系统文件选择器打开**（实测触发 filechooser 事件，`isMultiple = true` ⇒ **支持多选**）。
3. 选好文件后**立刻**生成对应媒体节点，并**自动选中**它。

**实测细节**（传一张 PNG，全过程积分 805 → 805 **未变**）：

| 观察项 | 读数 |
|---|---|
| 节点类型 | `react-flow__node-image` |
| 节点 aria | 逐字 **`图片 node: b22-upload`** |
| 标题 | **`b22-upload`** —— 是**去掉扩展名**的文件名，不是完整文件名 |
| 卡片尺寸 | `341×192`（**这是 60% 缩放下的屏上读数**；canvas 为 `569×320`，批次 79 补注单位） |
| 状态行 | 上传完成即 `7 nodes, 0 edges, 1 selected.`（**自动选中**） |

| 时刻 | `img` 读数 |
|---|---|
| **t=0 … 2200ms** | `2560×1440`，`src=blob:…`（**本地 blob，原图**） |

- **视频 20 种**：mp4 / m4v / webm / mov / flv / mkv / avi / wmv / asf / rm / rmvb / 3gp /

## 移动节点（2026-10-01 实测，此前未单独记录）

1. **选择工具**模式下，按住节点卡片拖动即可移动（实测节点屏幕坐标随鼠标
   同步变化，方向与幅度一致）。
   - 拖动时节点**保持选中**，状态行的 `selected` 计数不变。
   - 成功判据：松手后节点停在新位置，且顶栏「已保存」点亮。
2. **⌘Z** 可**精确还原**位置：实测拖动后按一次 ⌘Z，节点坐标与拖动前
   **完全一致**（`dx=0 dy=0`）。
   - 与删除一样，**刷新页面后 ⌘Z 不再有效**（见[复制、删除与撤销](duplicate-delete-history.md)）。
3. ⚠️ 拖动要**按住卡片主体**。节点四角与四边中点有按钮（`Create connected node
   before/after …`、`Rename …`、`Edit tags: …`）和缩放把手，按到它们会触发
   按钮而不是拖动。
   - 文本节点**选中**时，卡片四周浮出**八个方向的缩放把手**：四角各一个，
     四条边中点各一个；右下角内侧另有一个小对角把手。
     **进编辑态后这八个把手全部消失**（见下节），此时拖动不会误触。
   - ⚠️ 本轮**没有**把缩放把手的尺寸钉成契约：跨缩放档多次读数互相矛盾
     （同一张 320×320 的文本卡片，60% 档量到角把手 24×24、23% 档量到 11×11），
     **机制未定**，此处只给「在哪里」不给「多大」。见
     [概念页](../30-concepts.md)对「读数纪律」的要求。
     🔑 **2026-10-03 批次 140 部分结清**：那些「互相矛盾」的读数其实是**换缩放时
     换掉了节点**（`320×0.234=75`，当年两个「60%/100%」档量的其实是 23% 的视口）。
     锁死同一节点重测后——**边中点把手**长度 **canvas 恒 296**、厚度**屏上恒 10**；
     **四角把手**在 60/100/200% **屏上恒 24×24**（与组卡片角把手机制相同），
     仅 40% 档读 `19.2` 仍未定案（已排除 CSS 裁剪与热区遮挡）。
     ⇒ 正文只把「边中点：长度 canvas 恒、厚度屏上恒」当参考，**角把手不给硬契约**。

### 两条路径创建的节点，**落点不同**（2026-10-02 批次 95 实测）

同一个画布、同一时刻，用两种方式各建一个文本节点：

| 路径 | 节点落在（画布坐标） | 自动选中 | 节点数 |
|---|---|---|---|
| 左栏点 **文本** | 画布中央附近 | 是 | +1 |
| 空白处右键 → 新建节点 → 文本 | **紧贴右键的那个点** | 是 | +1 |

⇒ 想把节点放在某个具体位置，**在那个位置右键**，比「先在左栏建、再拖过去」省一步。
⚠️ 落点会被**已有的节点**顶开：右键处如果正压在别的节点上，新节点会挤到旁边，
有时还会被完全盖住、点不中（实测有新建文本节点 10×10 采样点全部被别的节点占据）。



**媒体节点**（实测对视频节点）：**双击**与**单击**结果**完全相同** —— 只是选中节点并打开
节点工具条，**不进入全屏、不弹出对话框**。想要全屏预览，走工具条里的 **全屏** 按钮。
（文本节点有编辑态，见[编辑文本节点](edit-text-node.md)。）

**文本节点**（批次 95 受控复测，序列拆开量）：

| 序列 | 结果 |
|---|---|
| 未选中 + **单击** | 选中节点，出现缩放把手与工具条 |
| 未选中 + **纯双击** | **进入编辑态**（出现可输入的光标区） |
| **已选中** + 单击 | **同样进入编辑态**（不是「再点一次才编辑」） |

⇒ ⚠️ **「点两下同一个节点」是进入文本编辑的可靠办法** ——
不管第一下是单击选中还是双击的一部分，第二下都进编辑态。

📌 **进编辑态后画布上只剩一个裸文本框**：没有工具条、没有缩放把手、没有选中描边，
而且**右键菜单弹不出来**。想删这个节点或复制它，先按 **Esc** 退回选中态
（**Esc 一次退到选中、两次退到未选中**），再操作。详见
[使用节点工具条](use-node-toolbar.md) 的「文本节点三态」表。

## 取消 / 恢复

- 误建节点：选中按 **⌫**，或右键 → **删除 ⌫**；**⌘Z** 可撤销。
- 误移动节点：**⌘Z**（实测可精确还原位置）。
- 视图太乱：底部缩放按钮 → **适配画布 ⇧1**。
