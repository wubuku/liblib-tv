# 使用资产库并上传素材

## 适用角色

已登录的即梦画布创作者。

## 目标

从资产库选择素材插入画布，或把本地图片/音频/视频上传为节点。

## 前置条件

- 已登录并打开画布。
- 本地上传仅使用你自己的文件。

## 入口

- 左栏 **资产库**（悬停左栏可见文字标签）。
- 左栏 **上传**（悬停展开后可见）。
- 空白右键 → **新建节点** 子菜单 → **从资产库添加** / **本地上传**。

## 原子步骤

### 资产库（模态实测）

1. 点击左栏 **资产库**。
2. 居中模态「**Import assets**」打开：说明「Choose assets from Dreamina and
   import them into this canvas.」。
3. 顶部两级页签：第一级 **资产 ｜ 主体**；第二级（资产下）**图片 ｜ 视频 ｜ 音频
   ｜ 文档**。右侧另有两个小按钮：**时间**（28×28，按时间筛选）与 **筛选**（28×28）。
4. **搜索**：面板右上搜索框，aria 逐字 `Search Dreamina assets`，占位「搜索」（200×36）。
5. **筛选**：点漏斗图标展开右侧浮层，**四组**逐字为：
   - **操作** → **收藏**
   - **类型** → **超清**
   - **分辨率** → **1K ｜ 2K ｜ 4K ｜ 8K**
   - **比例** → **21:9**
6. 选择素材（底部显示「已选择 N 个素材」）→ 点击 **确认** 插入画布。
   - 成功判据：模态关闭，画布出现对应素材节点。
   - **空态是平行的一族**（2026-10-01 批次 52 逐个点过，四个逐字）
     **图片**「暂无图片素材」 ｜ **视频**「暂无视频素材」 ｜
     **音频**「暂无音频素材」 ｜ **文档**「暂无文档素材」。
   - ⚠️ **「主体」页签是另一套结构**：切过去后**第二级只剩「全部」一个页签**，
     空态逐字是「**没有可用主体**」（不是「暂无…素材」），
     而且**内容区不再有 `canvas-asset-library-viewport` 这个元素**。
7. **Esc** 关闭模态（实测，aria 为 `Close asset library` 的 ✕ 亦可，36×36@(981,74)）。

> 💡 **想知道一个按钮是不是禁用的，别看它灰不灰**（2026-10-01 批次 52 阳性对照）。
> 这个弹窗里未选素材时的 **「确认」** 就是真的禁用实例：
> `aria-disabled="true"` + `data-disabled="true"` + `cursor: not-allowed` +
> 文字色 `rgba(255,255,255,0.2)`；而 `opacity` **仍然是 1**、`disabled` **原生属性也没有**。
> 同一弹窗里的页签按钮则是 `cursor: pointer`、无 `aria-disabled`。
> —— 这张表就是判断「下载」之类按钮是否禁用的**基准**。

> ⚠️ **画布上的节点不会出现在资产库里**（2026-10-01 实测，可能与你预期不同）：
> 先用「上传」把一张 PNG 放进画布（画布变成 3 个节点、图片正常显示），
> 再打开资产库切到**图片**页 —— 依然逐字显示「**暂无图片素材**」，
> 底部「已选择 0 个素材」，**确认**按钮保持**灰色禁用**。
>
> 也就是说：**资产库 ≠ 画布节点清单**。从画布上已有的图片回用，
> 请走「右键 → 新建节点 → **从画布选择**」或时间线里的「**从画布选择**」，
> 不要指望资产库。
>
> 未选中任何素材时「确认」是禁用的，此时点击无任何反应（实测点了也不关面板），
> 不必反复尝试 —— 先选素材，或直接 **Esc** 退出。
>
> ⚠️ **而且你看不到那句原因**：「请先选择素材」是 `class="sr-only"` 的**隐藏文本**，
> 屏上实测只有 **1×1 像素 @ (263,628)**，住在**页脚**（`canvas-asset-library-footer`）里、
> 是「确认」按钮的**兄弟节点**而不是按钮的子节点。
> 也就是说：它读屏能播报，**肉眼看不着** —— 别指望从界面里读出「为什么灰着」。

### 本地上传（2026-10-01 完成态实测）

1. 点击左栏 **上传**（aria `上传`；或空白右键子菜单 **本地上传**）。
2. 系统文件选择器打开（支持一次多选）。
3. 选择文件 → 画布上**直接生成一个图片节点**并自动选中，节点标题取自
   **去掉扩展名后的文件名**（2026-10-01 批次 64 实测：`b22-upload.png` → 标题 `b22-upload`；
   过长时中间省略，如 `55dd39e3–5024–…971–4d35be848a65`）。
4. **完成态（实测逐字）**：状态串出现 `<文件名>.png: Upload complete`；
   顶栏「已保存」随后点亮。
   - 成功判据：节点数 +1；节点内图片正常渲染；状态串出现 `Upload complete`。
   - ⚠️ **「节点出现了」不等于「上传处理完了」**：前 2 秒多显示的是**本地原图**，
     之后才换成服务端缩略图（实测 t=0…2200ms 为 `2560×1440` 的 `blob:` 图，
     t≈3200ms 换 `360×203` 远程图，t≈4500ms 换 `720×405`）。
     判定「完成」要等 5 秒以上，详见[创建节点 · 方式 D](create-first-node.md)。
5. 提示：**上传本身免费**；上传后的 **智能改图 / 智能超清 / 智能打光** 等加工
   按钮才会扣积分，详见[使用节点工具条](use-node-toolbar.md)。

### 保存到主体库

- 媒体节点右键菜单含 **保存到主体库**（按节点类型出现），可把素材沉淀为可复用
  主体。（入口观察自菜单结构；保存动作未执行。）

## 取消 / 恢复

- 资产库误选：清空选择或直接 **Esc**，不产生画布变更。
- 上传的节点可 **⌫** 删除 / **⌘Z** 撤销。

## 常见错误与恢复

| 现象 | 处理 |
|---|---|
| 确认钮提示「请先选择素材」 | 先在网格中点选至少一个素材 |
| 上传后找不到节点 | 底部缩放按钮 → 适配画布 ⇧1；新节点在视口中央附近 |
| 状态串一直停在 `processing` | 等素材处理完；此时部分入口会提示「素材信息仍在加载中，请稍后重试。」 |
| 节点标题不是你想要的名字 | 标题取自**去掉扩展名后**的文件名，**不能改**；需要区分就在节点上 **Add tags** 打标记 |
