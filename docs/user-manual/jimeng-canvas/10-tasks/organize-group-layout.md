# 编组、排列与整理画布

## 适用角色

已登录的即梦画布创作者。

## 目标

把多个节点框选成组、解组、用布局功能把画布排整齐。

## 前置条件

画布中已有多个节点。

## 入口

- **框选**：空白处按住左键拖拽，框住目标节点。
- 多选后画布顶部出现的**多选工具条**。

## 三种状态，三套工具条

![从框选到编组的三种状态示意：①框选多个节点时是多选工具条（N 节点/编组/布局/下载，无背景色）；②点击编组后出现组卡片「编组 1」，工具条变为解除编组/布局/背景色/下载；③解除编组后成员恢复独立并保持选中，回到①的状态。](../screenshots/diagrams/group-vs-multiselect.svg)

最容易踩的一点：**多选工具条和组工具条不是同一套**。「背景色」只在真正编组
之后才出现——如果你框选了一堆节点却找不到「背景色」，说明你还在①多选状态，
还没有点 **编组**。

另一处容易记反的是「下载」：**①和②都有**，但它是两个不同的按钮
（多选态 `batch-download`、组态 `download`），别当成同一项。

## 原子步骤

### 框选多个节点（实测）

1. 在空白处按住左键拖出矩形，罩住要一起管理的节点。
2. 松开 → 全部选中，顶部出现**多选工具条**。2026-10-01 实测宽 **511×40**，
   四项逐字与尺寸：

   | 逐字 | 尺寸 | 状态 |
   |---|---|---|
   | **N 节点**（实测「2 节点」，DOM `selection-context-toolbar-count`） | 54×32 | 只读计数 |
   | **编组** | 62×32 | 可用 |
   | **布局** | 78×32 | 可用（带 ∨ 下拉） |
   | **下载**（图标） | 32×32 | **可用**（🔴 2026-10-01 批次 55 订正，见下） |

   - 成功判据：状态行 `…, N selected`；工具条计数等于选中数。
   - 🔧 **订正（批次 55）**：早前这里写多选工具条的「下载」**禁用**、条目内附
     「**没有可用的就绪资源**」—— **那其实是右键菜单里那一个下载**，不是工具条上的。
     批次 51/55 两次受控实测：多选工具条的「下载」（含选中集里有带内容的图片节点时）
     **没有** `aria-disabled`、**没有** `data-disabled`、`cursor: pointer`、
     也没有那句文案；而**右键菜单**的「下载」在节点**没有已就绪媒体资源**时
     才是 `aria-disabled="true"` + `cursor: not-allowed` + 那句 `sr-only` 文案。
     详见[右键菜单与画布浮层](canvas-context.md)。
   - ⚠️ **多选工具条里没有「Add tags」** —— 逐字核对工具条内容只有上表四项。
     `Add tags` 是**每个节点自己的**标记按钮（DOM `flow-node-selected-tag`），
     出现在节点标题行右侧，不属于顶部工具条。
   - ⚠️ **工具条宽度不是固定值**：同一天两次实测分别为 511×40（缩放 74%）与
     1298×40（缩放 100%），计数项也从 54×32 变成 256×40。**别拿宽度当判据，只数按钮。**
   - **框选仍是首选，但 Shift+点选也能用**（2026-10-01 批次 56 受控复测）：
     **⌘A 全选确实不存在**（前置断言「有 2 个已选」后按下，选中数不变）；
     **Shift+点选是标准 toggle** —— 点**未选中**的节点会**加选**（实测 2 → 3），
     点**已选中**的节点会**取消它**（实测 2 → 1）。
     🔧 早前写「Shift+点选反而会取消选中」是**只测了取消那一支就外推**，已订正。
     详见[帮助与快捷键](help-and-shortcuts.md)。

![在画布空白处拖出矩形选框罩住「视频 1」「视频 2」两个节点后的多选状态，顶部出现多选工具条，两节点带选中描边，左下角缩放读数 74%](../screenshots/52-multi-select-toolbar.png)

### 编组（实测）

1. 框选若干节点 → 点击工具条 **编组**；或直接按 **⌘G**（实测等价）。
2. 结果：出现组卡片「编组 1」（顶部标题），节点计数加一（组本身计入节点数）。
   - 实测：6 个节点按 ⌘G → 顶栏变 **7 节点**，状态行 `6 nodes, 0 edges, 1 selected`，
     组卡片四角各出现一个圆形控制点。
   - 2026-10-01 复测 2 个视频节点：框选后状态行 `2 nodes, 0 edges, 2 selected`，
     按 ⌘G → `3 nodes, 0 edges, 1 selected`，组卡片 aria 逐字
     **`组 node: 编组 1`**，实测尺寸 **1050×403**（正好罩住两个成员）。
   - 成功判据：状态行节点数 +1；组卡片随成员整体拖动。

> ⚠️ **框选的矩形要真的罩住节点**。实测两次失败都不是产品问题，是手势问题：
> ① 框选的**起点必须落在 `.react-flow__pane`（空白画布）**上，落在节点上会变成拖动节点；
> ② 终点要拖到包围盒的**对角外侧**。若终点算成「包围盒下边 +30」而起点本就在下方，
> 框就没罩到任何节点，松手后选中数为 0。

### 组工具条（实测）

选中组卡片，工具条变为四项：**解除编组 ｜ 布局 ｜ 背景色 ｜ 下载**。
- **背景色**：为组选底色（此项只在组工具条上，多选工具条没有）。
- **解除编组**：点击后组卡片消失，成员恢复独立并保持选中；或按 **⌘⇧G**
  （实测 7 节点 → 6 节点，6 个成员恢复选中）。
- 2026-10-01 批次 50 **做了控制变量**：只改「组内有没有媒体节点」这一个变量，
  同一会话两轮独立执行，结论稳定 ——
  **组工具条恒为四项，「下载」与组内成分、与缩放都无关。**

  | 组 | 缩放 | 工具条 | 逐字 |
  |---|---|---|---|
  | 3 个文本节点 | 60% | 336×40 | 解除编组 88×32 ｜ 布局 78×32 ｜ 背景色 75×32 ｜ 下载 32×32 |
  | 2 文本 + 1 空视频节点 | 60% | 367×40 | 同上，逐字相同 |
  | 3 个文本节点 | 47% | 296×40 | 同上，逐字相同 |
  | 2 文本 + 1 空视频节点 | 47% | 312×40 | 同上，逐字相同 |

  - 🔧 **订正两处旧结论**（本手册早前都写错过）：
    1. 「**组工具条只有三项、无「下载」**」—— **错**。这是 2026-10-01 批次 15
       那次 DOM 扫描漏掉了纯图标按钮（`aria-label="下载"`、无 innerText）造成的。
       当场复核两张**旧截图**（`16-organize-group-group-card.png` 2026-09-23、
       `27-group-keyboard.png` 2026-10-01），两张图里都拍到了**四项** ——
       **产品行为从未变过，是读数方法错了**。
    2. 「「下载」的出现条件是组内含媒体节点」—— **也错**。纯文本组同样有「下载」。
  - ✅ **真正有条件的只有一件事：组里有没有成员。** 0 成员的空组工具条逐字只有
    **解除编组 ｜ 背景色** 两项，**没有「布局」也没有「下载」**
    （没有可布局、也没有可下载的对象）。空组可用 **⌘⇧G** 直接清掉。
  - 四项的 `data-toolbar-value` 逐字：`ungroup` ｜ `batch-organize` ｜
    `group-color` ｜ `download`。⚠️ **多选工具条上的「下载」是另一个按钮**
    （`data-toolbar-value="batch-download"`），两者不要混为一谈。
  - 工具条**宽度跟随组卡片宽度**，不是固定值：实测 336×40、367×40、296×40、
    312×40 四种（同样 60%/47% 缩放下卡片宽度不同所致），高度恒为 40。
    **所以宽度不能当判据，只数按钮个数。**
  - 内层容器 DOM：`node-toolbar`（surface）→ `selection-context-toolbar`
    （aria 逐字 `Selection actions`，包住这四个动作）→ 各按钮。

> 可点的位置——2026-10-01 实测，**未选中时整张组卡片都不接收点击**：卡片主体与内部
> 空白都是 `pointer-events-none`，鼠标落点直接穿透到画布背景，怎么点都选不中组；
> 标题文字那**一小块**（实测 36×20）才收得到点击。

>   位于卡片上沿**之外**约 28px，不是画在卡片里面），标题右侧另有一个 24×24 的标签按钮。
> - ⚠️ 早前版本把这里记成「点标题那一行（`group-title-hit-area`，高 18px）」。

> - ⚠️ 若编组卡片顶边被**顶栏**遮住（卡片顶边 y<58、标题带 y=36–54），
>   标题就点不到；此时先**向下滚动画布**把标题移出顶栏再点。
> - 点组内的**成员节点**选中的是**成员自己**，工具条也是成员自己的（空视频节点会
>   展开生成面板），不会选中组。

### 布局整理（菜单 + 执行结果均实测）

1. 多选（或选中组）→ 点击 **布局∨**。
2. 弹出菜单两项：**宫格布局** ｜ **智能布局**（菜单浮层实测 180×88，两行各一项）。
3. 选择其一，节点按规则重新排列。
   - **实测「宫格布局」**：5 个节点（3 个 320×320 文本 + 2 个 569×320 媒体）被排成
     两行，行间距 400，同一行内等距留白，媒体节点保持原始尺寸不被拉齐。

> ⚠️ **布局不会自动缩放视口**。实测执行宫格布局后缩放**仍是 100%**，节点被排到
> 视野之外——右侧和下方的节点直接看不见，很容易误以为「节点丢了」。
> **找回方法**：按 **⌘0** 或 **⇧1**（适配画布）把所有节点收进视野；实测缩放从
> 100% 变为 62%，全部节点回到画面内。

- **智能布局**（菜单第二项，2026-10-01 已执行）：同样是「排成若干行」，
  5 个节点同样排成 2 行、行间距同样是 400，节点尺寸同样保持不变。
  与宫格布局的**肉眼差别很小**：两者排出的行都不左对齐到同一列起点
  （实测第二行起点比第一行右移约 120px）。
  想一次排齐就用它，不必纠结两者谁更整齐。

- 恢复：**⌘Z**（实测有效——宫格布局后按一次 ⌘Z，5 个节点的坐标逐一回到布局前的
  位置，与布局前快照完全一致）。

- ⚠️ **快捷键面板里的「宫格视图 G」按了没用**：实测按下会提示
  「此快捷键当前不可用」。要排整齐请用上面的 **布局 → 宫格布局** 菜单，
  不要指望 G 键。详见[帮助与快捷键](help-and-shortcuts.md)。

### 其他整理

- **节点颜色标记**：悬停节点标题行 → **Add tags** 钮，给节点打颜色标记分类。
  详见下方「节点颜色标记」。
- **显示连线**（dock）：连线太多看不清节点时，可临时关闭连线显示。

### 节点颜色标记（2026-10-01 实测）

1. 悬停节点，让标题行浮出来 → 点标题行右侧的 **Add tags**（标签图标）。
   - 节点**已选中**时该按钮的 aria 会带上当前色名，逐字形如
     **`Add tags`**（无标记）或 **`Edit tags: 青绿色`**（已有标记）。
2. 弹出一排**圆形色板**，实测 6 枚，每枚 28×28，**aria 逐字**如下
   （注意色名是「青绿」「靛蓝」这种两字全称，不是「青」「蓝」）：

   | 位置 | aria 逐字 | 取色 |
   |---|---|---|
   | 第 1 枚 | **全部清空** | 透明（清除全部标记） |
   | 第 2 枚 | **移除“青绿色”**（已标记时）/ 添加“青绿色” | `rgb(0, 202, 224)` |
   | 第 3 枚 | **添加“靛蓝色”** | `rgb(109, 124, 255)` |
   | 第 4 枚 | **添加“紫色”** | `rgb(190, 104, 255)` |
   | 第 5 枚 | **添加“橙色”** | `rgb(255, 146, 48)` |
   | 第 6 枚 | **添加“黄色”** | `rgb(255, 214, 0)` |

   - 引号是**中文全角引号** `“”`，不是直角引号。
   - 第 1 枚的逐字是**「全部清空」**（一次性清掉该节点的所有标记），
     不是「无标记」。
3. **可以叠加多个标记**（实测）：依次点青绿色和紫色后，节点标题行右侧
   **同时出现青绿、紫两个色点**——不是单选。
4. **已选中的颜色带白色圆环**，aria 从「添加“X”」变成「**移除“X”**」；
   点「全部清空」可一次清掉全部。
5. 色点显示在**节点标题行右侧**（在节点卡片上方，不在卡片里面）。
6. 顶栏的画布图标也会跟着变色——画布里有带标记的节点时，它显示这些颜色；
   该按钮的 aria 逐字形如 **`青绿色, 1 objects`**（颜色名 + 带标记的对象数）。

> 标记的用途是**分类**：把同一阶段的素材打同一种色，框选时一眼分辨。
> 标记不影响连线，也不改变节点内容。

## 取消 / 恢复

| 误操作 | 恢复方式 |
|---|---|
| 误编组 | 选中组 → **解除编组**（或 ⌘⇧G） |
| 误布局 | **⌘Z**（实测可完全还原） |
| 布局后找不到节点 | **⌘0 / ⇧1** 适配画布（布局不会自动缩放视口） |
| 误移动 | **⌘Z** |
| 误删除 | **⌘Z**（可撤销删除，但**必须没刷新过页面**，见[复制、删除与撤销](duplicate-delete-history.md)） |

两轮独立执行 —— 组工具条**恒为四项**（解除编组 / 布局 / 背景色 / 下载），
与组内成分、与缩放都无关；0 成员空组只有两项（无「布局」无「下载」）；
「布局」下拉 180×88 逐字「宫格布局 / 智能布局」；⌘⇧G 可直接清掉空组。
