# 打开帮助与使用快捷键

## 适用角色

已登录的即梦画布创作者。

## 目标

找到帮助入口，查看并使用画布快捷键。

## 前置条件

已打开画布。

## 入口

顶栏 **用户菜单**（右上角头像）→ 菜单：帮助中心 ｜ 使用手册 ｜ **快捷键** ｜
AI生成水印设置 ｜ 即梦CLI。

## 快捷键全表（面板逐字，2026-09-23）

### 通用操作

| 功能 | 快捷键 |
|---|---|
| 打开/关闭 Agent | ⌘/ |
| 撤销 | ⌘Z |
| 还原 | ⌘⇧Z 或 ⌘Y |
| 移动工具 | V |
| 全屏 | F |
| 创建编组 | ⌘G |
| 取消编组 | ⌘⇧G |

### 视图

| 功能 | 快捷键 |
|---|---|
| 放大视图 | ⌘+ |
| 缩小视图 | ⌘− |
| 适配画布 | ⇧1 或 ⌘0 |
| 缩放至 100% | ⌘1 |
| 缩放至选中项 | ⇧2 |
| 缩放画布 | ⌘ + 滚轮 |

### 时间线

| 功能 | 快捷键 |
|---|---|
| 分割片段 | ⌘B |
| 向左裁剪 | Q |
| 向右裁剪 | W |
| 缩放时间线 | ⌘ + 滚轮 |

### 文本编辑

| 功能 | 快捷键 |
|---|---|
| 加粗 | ⌘B |
| 倾斜 | ⌘I |
| 下划线 | ⌘U |
| 删除线 | ⌘⇧X |
| 一级/二级/三级标题 | ⌘⌥1 / ⌘⌥2 / ⌘⌥3 |
| 普通文本 | ⌘⌥0 |
| 无序列表 | ⌘⇧8 |
| 有序列表 | ⌘⇧7 |

### 实测生效清单（2026-09-23）

⌘D（复制副本）、⌘Z（撤销，多次）、⌫（删除节点/连线/清空提示词）、
Esc（关闭菜单/面板/取消选中）、Ctrl+滚轮缩放、滚轮平移、空白拖拽框选。

### 未独立验证清单

⌘V 粘贴（实测未生效）、⌘A 全选（实测未生效）、Shift+点选（实测未生效）、
⌘/、V、F、⌘G/⌘⇧G（编组经按钮实测，快捷键未按）、⇧1/⇧2/⌘0/⌘1
（对应菜单项已实测）、⌘+/⌘−、⌘Y、时间线与文本编辑组快捷键。
以上以快捷键面板声明为准，使用时若无效请改用菜单/按钮路径。

## 原子步骤

1. 点击 **用户菜单** → **快捷键** → 右侧面板分四组列出全表。
2. **Esc** 关闭面板。
3. 帮助中心 / 使用手册：跳转官方帮助页面（站外内容，不在本手册范围）。
