# 排障：按症状查找

按你在画布上看到的现象查找原因与恢复动作。

## 画布操作

### 空白处拖不动画布 / 一拖就选出一片

即梦画布的空白拖拽是**框选**，不平移。平移请用**滚轮**；缩放用 **Ctrl+滚轮**
或底部缩放菜单 **适配画布 ⇧1**。见 [平移缩放与视图](10-tasks/navigate-canvas.md)。

### 找不到某个节点

顶栏 **搜索** → 输入名称或按类型筛选；或底部缩放按钮 → **适配画布 ⇧1**。

### 左栏的「时间线」「主体」「导演台」点进去不知道该做什么

这三类入口在左栏可见，但**本手册尚未取证它们的内部流程**，因此没有对应的操作页。
已知边界见 [参考速查](20-reference.md)「左栏其余入口」一节：

- **主体**：资产库模态的 **主体** 页签可查看，空态显示「没有可用主体」；
  媒体节点右键 **保存到主体库** 可把素材存为主体。
- **时间线 / 导演台**：除快捷键面板列出的时间线快捷键外，其余行为请以界面实际
  显示为准；补全这两项需重新登录源站取证。

### ⌘A 全选 / Shift+点选 / ⌘V 粘贴没有反应

这三个手势在 2026-09-23 实测中未生效。替代路径：
- 多选：空白拖拽**框选**；
- 复制节点：右键 **复制副本 ⌘D**；
- 粘贴：暂无可靠手势，避免依赖。

### 按 ⌫ 删不掉节点

焦点还在输入框里（如生成面板提示词）。点击空白处，再选中节点按 **⌫**。

### 删错了东西

立即 **⌘Z**（可恢复节点、连线等多步操作）。**刷新后撤销失效**——历史不跨会话，
刷新前抓紧撤销。

## 菜单与生成

### + 菜单里想加的类型是灰的

源节点类型与目标类型不可连接（如视频→文本）。换可连类型或调整方向。见
[连接节点](10-tasks/connect-nodes.md)。

### 「生成」按钮是灰的

空提示词且没有就绪参考。写提示词；或等待参考 chip 从「正在处理上传内容…」
变为就绪。

### 价格（✦ 数字）比预期高

价格随模型/时长/数量/参考实时变化。核对参数行；调小参数价格即时回落。

### 误点了带 ✦ 的付费按钮

立即 **Esc**；若已弹出确认/任务面板，**不要确认**，直接关闭。已提交的付费任务
无法通过画布撤销，如需处理请联系官方客服渠道。

## 工具条与本地加工

### 工具条里找不到「视频修剪」/「截取帧」

这两个是**视频专属**项，只在带媒体的**视频**节点上出现。选中的是图片节点时，
工具条是图片那一套（智能改图/扩图/智能超清/抠图/多角度/工具）。见
[使用节点工具条](10-tasks/use-node-toolbar.md)。

### 点了视频修剪，工具条消失了

这是**正常的中间态**：修剪态下工具条暂时隐藏、标题行保持可见，节点下方出现
修剪条。在修剪条上拖两端把手调整范围，点 **确认** 提交，或按 **Esc** 退出。

### 截取帧的「确认」按钮点不动

自定义模式下**未截取时确认是置灰的**。先在帧条上点选目标帧，点 **📷 截取帧**
完成截取，确认钮才会变为可用。

### 截取帧选了首帧/尾帧却没出现选择条

首帧/尾帧**不打开选择条**，而是直接异步产出一个图片节点（标题形如 `…_首帧`）。
稍等片刻，或用底部 **适配画布 ⇧1** 找到新节点。

## 媒体

### 视频卡片显示播放失败

点击卡片上的重试按钮。能恢复则正常播放；时间变成 00:00 / 00:00 的空载态说明
源资源已失效，需重新上传或替换素材。

### 上传后找不到新节点

新节点通常出现在视口中央附近；底部缩放按钮 → 适配画布 ⇧1 查看全局。

## 保存与同步

### 出现「发现离线编辑」对话框

离线期间的修改未同步。一般选 **保留并同步**；**丢弃修改** 不可恢复，仅在确定
放弃离线改动时使用。

### 怀疑改动未保存

顶栏常驻「已保存」状态。刷新页面核对——内容跨刷新持久（实测）。

## 仍无法解决

- 顶栏 **用户菜单** → **帮助中心 / 使用手册**（官方站外资源）。
- 付费任务、账户与积分问题超出本手册范围，请通过官方渠道处理。
