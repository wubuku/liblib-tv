## 已知限制

1. **安全边界**：即梦是真实计费产品。手册所有生成类内容只写到「点击执行前一步」，
   最后一下由用户自己决定。已提交的付费任务无法通过画布撤销。
2. **撤销栈不跨刷新**：内容跨刷新持久，但 ⌘Z 历史不跨会话——刷新前没撤销的误操作
   刷新后即固定。
3. **证据分三层**：当日实测（2026-09-23 / **2026-10-01**）／复刻研究源站采样
   （SOURCE_FACT）／未验证。正文各页以「已验证说明」逐页标注，
   `20-reference.md` 顶部给出统一层级说明。
4. **易变数值**：价格、比例、时长、放大比例等为当日读数，源站改版后以界面
   实际显示为准。已确认源站在 09-21→09-23 发生过工具条改版。
5. **示意图非现场截图**：**4** 张 SVG 为依据台账事实手工绘制，manifest 中以独立
   「示意图」小节登记，`captured_at` 记录绘制时间、`verified_locator` 记录事实来源。
6. **发布前须脱敏**：截图中含测试素材（人物画面），对外发布前需按
   [`PUBLISH.md`](PUBLISH.md) 审查。
7. **台账曾与正文脱节**（2026-10-01 批次 9/13 两次发现并修复）：`PROGRESS.md` 一度
   与 `SOURCE_OBSERVATIONS.md` 就「边是否有 DOM」互相矛盾；`FINAL-REPORT.md` 长期
   未同步。**现已建立交叉审计脚本**（见 `AUDIT.md` 批次 13），逐条扫描
   「同一事实在多层是否说同一句话」。
