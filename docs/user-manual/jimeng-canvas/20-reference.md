# 参考：界面要素、菜单与参数速查

本页汇总即梦智能画布（`/ai-tool/ai-canvas/:projectId`）的界面要素与菜单文本。

**证据层级**（阅读时请据此判断可信度）：

- **2026-09-23 源站当日实测逐字**——绝大多数条目属此类；
- **复刻研究源站采样**（`docs/research/jimeng-canvas/README.md` 的 SOURCE_FACT，
  2026-09-12 起）——图片节点工具条、视频修剪条、截取帧细节、资产库主体页签等
  属此类，非当日重提，标注为「采样」；
- **不在范围**——导演台的 3D 工作台在画布之外，见下方专节与 [导演台节点](10-tasks/director-node.md)。

价格、尺寸等**易变**数值均为 2026-09-23 的读数，源站改版后请以界面实际显示为准。

| 区域 | 内容 |
|---|---|

| 底部 dock | **工具按钮（aria 即当前模式：`选择工具` ⇄ `抓手工具`；抓手下空白拖拽=平移，选择工具下=框选）**、小地图、显示连线（默认开）、缩放值按钮（**内嵌 `aria="Set zoom percentage"` 输入框**：点它**同时**弹出菜单与输入框并自动全选；可输入区间约 **8%–800%**，越界被钳位。⚠️ **没有取消路径 —— Enter / Esc / 失焦 都会提交**） |

> 状态行的英文会**按数量变形**：只有 1 个时用单数。实测 `1 node, 0 edges, 0 selected`、

## 进入「编辑模式」的付费功能（✦）

与上表不同，下面两个按钮会把节点切换成独立编辑模式：画布自动放大聚焦、工具条收起、
节点下方出现专属工具条与提示条。**进入不扣费，发送才扣费**：

| 功能 | 进入后出现 | 发送（扣费） | 退出 |
|---|---|---|---|
| **局部重拍✦** | 修剪条（圈定片段）+ 重拍面板（参考缩略图、片段芯片、占位「描述你如何调整这一片段」） | 提示词为空时禁用（`Prompt is required`） | **Esc** |
| **视频编辑✦** | 8 图标编辑药丸（选择/文字/擦除/撤销重做）+ 编辑提示条（占位「描述你如何调整视频」） | 提示词为空时禁用；价格签形如 `✦ 144 分/次` | **Esc** |

要点：进入/退出编辑模式**不入撤销栈**（⌘Z 无效）；放大比例每次可能不同，不要依赖
具体数值。详见 [使用节点工具条](10-tasks/use-node-toolbar.md)。

## 菜单速查

- **+ 手柄菜单**（「添加节点」，`canvas-context-menu` / `role="menu"`，
  实测 **200×316**）：七项 文本/图片/视频/音频/时间线/主体/导演台，
  每项下面附一句原因。**两个入口**：① 选中节点后点其左右 **36×36** 的 ⊕ 按钮
  （aria 逐字 `Create connected node before/after <节点名>`，
  testid `flow-node-target-connection-menu-button` /
  `flow-node-source-connection-menu-button`，**仅选中时出现**）；
  ② 从手柄拖到空白松手后再点。**Esc 可关。**
  - 🔍 **可用/禁用的 DOM 级判据**：文字颜色
    **可用 = `rgb(255, 255, 255)`**、**禁用 = `rgba(255, 255, 255, 0.2)`**。
  - ⚠️ 选中时 `.react-flow__handle` 的 `pointer-events` 是 **`none`** ——
    左右中点被那两个 ⊕ 按钮接管，**要点 ⊕ 才有菜单**。

## 「添加节点」菜单逐项可连性（2026-10-01 批次 28 实测，**订正旧结论**）

| 源节点 | 可用（白） | 禁用（`rgba(255,255,255,0.2)`）及其逐字原因 |
|---|---|---|
| **视频节点** | **仅 视频** | 文本 / 图片 / 音频 / 导演台 → 「无法连接这些节点」；时间线 → 「**素材信息仍在加载中，请稍后重试。**」；主体 → 「**没有可用的就绪资源**」 |
| **图片节点** | 图片 / 视频 / 音频 / 时间线 / 主体 | 文本、**导演台** → 「无法连接这些节点」 |

🔴 **本手册此前写「从视频节点出发：视频/时间线/主体可连」——实测时间线与主体当前也是灰的。**
它们与「无法连接」性质不同：原因文案是**临时状态**，过一会儿可能变可用。

💡 **看到灰项先读那行原因**：写「无法连接这些节点」= 永久不可连；
写「加载中 / 没有就绪资源」= 等一会儿再试。
⚠️ **可连项差异很大**（视频源只连视频，图片源能连五类）——
**别把「能连」当成节点类型的固有属性，它取决于当前这个源节点。**

## 视图锚点与找回内容

| 事实 | 说明 | 验证 |
|---|---|---|
| **缩放以视口中心为锚，不强制居中** | 节点中心偏移 `(−100,−40)` 时点「缩放至50%」→ 偏移变 `(−50,−20)`（**按比例减半**）；**只有按适配画布 ⇧1 才回到正中** `(640,360)` | 实测（2026-10-01 批次 25） |
| **缩放区间 ≈ `8%`–`800%`** | 输入 `5` → 钳到 `8%`；输入 `1000` → 钳到 `800%`（**填不出比 800% 更大的画面**） | 实测（同上） |
| **「适配画布」= 按内容包围盒重算，不是回到固定倍率** | 抓手把节点拖出部分视野后按 ⇧1 → 节点被摆回正中 `(640,360)` 而**缩放仍 100%**（单节点在 100% 下本就装得下）。倍数会变的情况：23% → **50%**；6 节点 100% → **62%** | 实测（2026-10-01 批次 26） |
| **缩放输入框没有取消路径** | **Enter / Esc / 点别处（失焦）三者都会提交**。实测 `77`→Esc→`77%`、`33`→失焦→`33%`，**两轮独立复现**。「不按 Enter 不生效」只在手指停在框内时成立 | 实测（2026-10-01 批次 26，**推翻批次 24 的「不按 Enter 视图不会变」**） |
| **「当前视窗没有内容 ｜ ⊕ 回到节点」** | **仅当视窗内一个节点都没有时**出现（抓手工具拖出视野即可；**与缩放无关** —— 缩到 8% 时节点仍与视口相交、不出现）。提示条 `back-to-content-overlay` **232×44**，按钮 aria 逐字 `回到节点` **72×20**。**点击 = 节点重新居中，缩放不变**。该元素**常驻 DOM 但平时 0×0** → **判据是尺寸，不是「在不在 DOM 里」** | 实测（同上，**推翻此前「出现条件未验证、不要依赖」**） |

## 状态与提示文本

### 保存与历史

- 「已保存」：顶栏保存状态；内容跨刷新持久，撤销历史不跨刷新。
- 「无需重做操作」/「无需撤销操作」：重做/撤销无可执行历史时的禁用提示。

### 连线被拒（批次 27 补全：同一句话有**三个**触发场景）

- 「**无法连接这些节点**」：**三处**会逐字出现同一句话，别只当成「类型不兼容」：
  1. **+ 菜单**里源-目标类型不可连（菜单项直接标这句、灰字）；
  2. **拖拽建线被拒** —— 自环 `A→A`、连回去成环、重复拖同一对
     （同时会画一条橙色临时线 `connection-failure:N`）。
- ⚠️ 这条提示在拖拽失败时是**顶部 toast**（360×44，固定顶部居中），
  **无 `role` / 无 `aria` / 无 `data-testid`**，按无障碍树或 testid 都抓不到。

### 其它

- 「素材信息仍在加载中，请稍后重试。」「没有可用的就绪资源」：时间线/主体临时状态。
- 「**当前视窗没有内容**」+「**回到节点**」：视窗内一个节点都没有时的顶部提示条
  （批次 25 实测，见下方「视图锚点与找回内容」）。
- 「发现离线编辑」：离线修改未同步的对话框（丢弃修改 / 保留并同步）。
