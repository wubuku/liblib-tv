# 参考：界面要素、菜单与参数速查

本页汇总即梦智能画布（`/ai-tool/ai-canvas/:projectId`）的界面要素与菜单文本，
全部为 2026-09-23 源站实测逐字记录。

## 画布布局

| 区域 | 内容 |
|---|---|
| 顶栏 | 返回首页、画布标题（点击重命名）、项目、节点 N 计数、已保存、搜索、生成历史、积分徽标（✦ · 会员等级）、用户菜单 |
| 左栏（悬停展开标签） | 文本、图片、视频、音频、时间线、主体、导演台（Beta）、资产库、上传 |
| 底部 dock | 选择工具、小地图、显示连线（默认开）、缩放值按钮 |
| 右下 | 与 AI 对话 |
| 画布状态行 | `N nodes, N edges, N selected. Editable. Room connected. 已保存.` |

## 节点类型

| 类型 | 新建形态 | 选中后 |
|---|---|---|
| 文本 | 320×320，「文本 N」 | 工具条：背景色/全屏/下载 |
| 图片 | 480 级方形，「图片 N」 | 图片生成面板（Seedream 5.0 Lite，1:1·2K，✦3/张） |
| 视频 | 569×320，「视频 N」 | 空节点=视频生成面板；带媒体=加工工具条 |
| 音频 | 222×222，「音频 N」 | 音频生成面板（SeedAudio 1.0，全能配音，音色库，✦12 原 24 五折） |
| 编组 | 覆盖成员的组卡片「编组 N」 | 组工具条：解除编组/布局/背景色/下载 |

## 菜单速查

- **+ 手柄菜单**（节点边缘）：添加节点：文本/图片/视频/音频/时间线/主体/导演台；
  不可连项标注「无法连接这些节点」；选择后**自动建连线**。
- **空白右键**：新建节点＞（子菜单含 从资产库添加/本地上传）、粘贴 ⌘V、
  重做 ⌘⇧Z、撤销 ⌘Z。
- **节点右键**：复制 ⌘C、复制副本 ⌘D、粘贴 ⌘V、下载、（媒体节点含
  保存到主体库）、重做 ⌘⇧Z、撤销 ⌘Z、删除 ⌫。
- **底部缩放菜单**：放大视图 ⌘+、缩小视图 ⌘−、适配画布 ⇧1、缩放至选中项 ⇧2、
  缩放至50%、缩放至100% ⌘1、缩放至200%。
- **多选工具条**：N 节点、编组、布局∨（宫格布局/智能布局）、下载、Add tags。
- **组工具条**：解除编组、布局、背景色、下载。
- **用户菜单**：帮助中心、使用手册、快捷键、AI生成水印设置、即梦CLI。

## 状态与提示文本

- 「已保存」：顶栏保存状态；内容跨刷新持久，撤销历史不跨刷新。
- 「无需重做操作」/「无需撤销操作」：重做/撤销无可执行历史时的禁用提示。
- 「无法连接这些节点」：+ 菜单中源-目标类型不可连。
- 「素材信息仍在加载中，请稍后重试。」「没有可用的就绪资源」：时间线/主体临时状态。
- 「发现离线编辑」：离线修改未同步的对话框（丢弃修改 / 保留并同步）。
