# 参考：界面要素、菜单与参数速查

本页汇总即梦智能画布（`/ai-tool/ai-canvas/:projectId`）的界面要素与菜单文本。

**证据层级**（阅读时请据此判断可信度）：

- **2026-09-23 源站当日实测逐字**——绝大多数条目属此类；
- **复刻研究源站采样**（`docs/research/jimeng-canvas/README.md` 的 SOURCE_FACT，
  2026-09-12 起）——图片节点工具条、视频修剪条、截取帧细节、资产库主体页签等
  属此类，非当日重提，标注为「采样」；
- **不在范围**——导演台的 3D 工作台在画布之外，见下方专节与 [导演台节点](10-tasks/director-node.md)。

价格、尺寸等**易变**数值均为 2026-09-23 的读数，源站改版后请以界面实际显示为准。

## 画布布局

| 区域 | 内容 |
|---|---|
| 顶栏 | 返回首页、画布标题（点击重命名）、**项目**（项目切换器，240×200 面板列出其他画布项目）、**节点 N**（类型汇总，200×92 面板 + 「查看项目信息」）、已保存、**标记色**、**搜索**（打开 `role="dialog"` 320×211 搜索面板：输入框占位「搜索节点...」+ 九个分类页签 全部/图片/视频/音频/文本/主体/时间线/组/其他；点结果会定位并选中该节点）、生成历史、分享、更多、积分徽标（✦ · 会员等级）、用户菜单 |
| 左栏（悬停展开标签） | 文本、图片、视频、音频、时间线、主体、导演台（Beta）、资产库、上传 |
| 底部 dock | **工具按钮（aria 即当前模式：`选择工具` ⇄ `抓手工具`；抓手下空白拖拽=平移，选择工具下=框选）**、小地图、显示连线（默认开）、缩放值按钮（内嵌 `aria="Set zoom percentage"` 输入框，可直接键入百分比） |
| 右下 | 与 AI 对话 |
| 画布状态行 | `N nodes, N edges, N selected. Editable. Room connected. 已保存.` |

> 状态行的英文会**按数量变形**：只有 1 个时用单数。实测 `1 node, 0 edges, 0 selected`、
> `1 node, 1 edge, 0 selected`；而 0 条连线仍写作 `0 edges`（0 用复数）。

|---|---|---|

| 视频（空） | 569×320，「视频 N」 | 视频生成面板 |

| 音频 | 222×222，「音频 N」 | 音频生成面板（SeedAudio 1.0，全能配音，音色库，✦12 原 24 五折） |

> 不出现在图片节点上；图片专属的抠图/多角度/扩图也不在视频节点上。

## 不耗积分的本地加工操作

以下操作只改本地素材，不提交生成任务，可放心执行：

| 操作 | 入口 | 要点 |
|---|---|---|
| 视频修剪 | 视频工具条 **视频修剪** | 节点下方内联修剪条；两端白色把手拖拽调整入/出点，条内显示选区时长（如 6.1s）；**确认** 胶囊钮提交，Esc 退出 |
| 截取帧（首帧/尾帧） | 视频工具条 **截取帧∨** | 不开选择条，直接异步产出图片节点（标题形如 `…_首帧`） |
| 截取帧（自定义） | **截取帧∨ → 自定义** | 帧条上选帧 → **📷 截取帧** → **确认**（未截取时置灰） |
| 静音切换 | 卡片右下静音钮 | `Unmute video` ↔ `Mute video` 翻转 |
| 下载 | 工具条尾部下载钮 | 保存媒体文件到本地 |

## 进入「编辑模式」的付费功能（✦）

与上表不同，下面两个按钮会把节点切换成独立编辑模式：画布自动放大聚焦、工具条收起、
节点下方出现专属工具条与提示条。**进入不扣费，发送才扣费**：

| 功能 | 进入后出现 | 发送（扣费） | 退出 |
|---|---|---|---|
| **局部重拍✦** | 修剪条（圈定片段）+ 重拍面板（参考缩略图、片段芯片、占位「描述你如何调整这一片段」） | 提示词为空时禁用（`Prompt is required`） | **Esc** |
| **视频编辑✦** | 8 图标编辑药丸（选择/文字/擦除/撤销重做）+ 编辑提示条（占位「描述你如何调整视频」） | 提示词为空时禁用；价格签形如 `✦ 144 分/次` | **Esc** |

要点：进入/退出编辑模式**不入撤销栈**（⌘Z 无效）；放大比例每次可能不同，不要依赖
具体数值。详见 [使用节点工具条](10-tasks/use-node-toolbar.md)。

## 菜单速查

- **+ 手柄菜单**（节点边缘）：添加节点：文本/图片/视频/音频/时间线/主体/导演台；
  不可连项标注「无法连接这些节点」；选择后**自动建连线**。
- **空白右键**：新建节点＞（子菜单含 从资产库添加/本地上传）、粘贴 ⌘V、
  重做 ⌘⇧Z、撤销 ⌘Z。
- **节点右键**：复制 ⌘C、复制副本 ⌘D、粘贴 ⌘V、下载、（媒体节点含
  保存到主体库）、重做 ⌘⇧Z、撤销 ⌘Z、删除 ⌫。
  「重做 / 撤销」条目下方会附**禁用原因副文案**「无需重做操作」/「无需撤销操作」，
  **该文案消失即表示该项当前可用**（2026-10-01 实测：⌘Z 后「无需重做操作」消失，
  此时 ⌘⇧Z 与 ⌘Y 均能重做）。
  **菜单尺寸随节点类型变化**：空视频节点 **200×292 七项**；
  **有资源的图片节点 200×372 九项**，多出 **复制为图片 ⌘⇧C** 与 **保存到主体库**
  （2026-10-01 实测，关闭了「保存到主体库是否只出现在有资源的媒体节点上」这一长期疑问：
  **空视频节点确实没有该项，图片节点有**）。
- **底部缩放菜单**：放大视图 ⌘+、缩小视图 ⌘−、适配画布 ⇧1、缩放至选中项 ⇧2、
  缩放至50%、缩放至100% ⌘1、缩放至200%。
- **多选工具条**：N 节点（计数，只读）、编组、布局∨（宫格布局/智能布局）、下载。
  2026-10-01 三轮实测**只有这四项，没有「Add tags」**——`Add tags` 是每个节点
  自己的标记按钮，不在顶部工具条。工具条宽度不固定（实测 511×40 与 1298×40 两种）。
- **组工具条**：解除编组、布局、背景色。2026-10-01 三轮实测**只有这三项，没有
  「下载」**；三个动作包在内层 `Selection actions` 容器里（实测 255×40），
  外层工具条宽度跟随组卡片宽度（实测 1378×40）。
- **用户菜单**（2026-10-01 实测 **六项**，此前长期只记了五项）：帮助中心、使用手册、
  快捷键、AI生成水印设置、即梦CLI、**新功能许愿**。菜单 `data-testid="canvas-user-menu"`，
  实测 **240×312**，出现在头像左下方；每项 232×36，顶部另有一块账号信息区
  （头像 + 昵称，**含个人信息，截图已脱敏**）。

## 状态与提示文本

- 「已保存」：顶栏保存状态；内容跨刷新持久，撤销历史不跨刷新。
- 「无需重做操作」/「无需撤销操作」：重做/撤销无可执行历史时的禁用提示。
- 「无法连接这些节点」：+ 菜单中源-目标类型不可连。
- 「素材信息仍在加载中，请稍后重试。」「没有可用的就绪资源」：时间线/主体临时状态。
- 「发现离线编辑」：离线修改未同步的对话框（丢弃修改 / 保留并同步）。
