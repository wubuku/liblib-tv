### 2.5 connect-nodes：参考连线全链路（2026-09-23，已执行）

- **连线创建**：从内容节点（sb_）右缘 Handle/+ 位置按下，拖到目标节点（视频 1）
  左缘 → 松开即生成连线（status 1 edge）。方向语义 = 参考 → 生成目标。
- **边有 DOM（纠正旧结论）**：今天 `.react-flow__edge` 存在，类
  `react-flow__edge react-flow__edge-reference`（类型 reference），选中加
  `.selected`；aria 逐字「Reference connection from 视频 node: sb_… to 视频 node:
  视频 1」。旧研究「边无 DOM、全 canvas 绘制」不再成立（canvas 层仍画线，
  DOM 同时存在可命中）。
- **选中与删除**：点击连线本体 → 选中该边（无节点选中而 status=1 selected）；
  **Backspace 删除选中连线**（1→0）；**⌘Z 撤销恢复连线**（0→1，键盘撤销实测）。
- **+ 菜单插入自动连线**：在节点 + 菜单点「视频」→ 新建「视频 2」（空视频节点，
