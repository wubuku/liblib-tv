# Archive

> Historical documents that are no longer maintained as current guidance.

Before moving a document here, apply the gates in
[`DOCUMENT_LIFECYCLE.md`](../DOCUMENT_LIFECYCLE.md). Historical Batch contracts
and evidence artifacts are not archive candidates merely because they are old.

## Archive Rules

1. Add a date prefix: `YYYY-MM-DD_<name>.md`.
2. Update all inbound links before moving a document.
3. Add an entry to this index with the reason for archival.
4. Do not archive source evidence or completed batch handoff records merely because they are old; those remain in `docs/research/` when they explain current code or provenance.

## Current Archive

No documents are currently archived. The project keeps research batches in place because they are durable implementation history and agent handoff context.
