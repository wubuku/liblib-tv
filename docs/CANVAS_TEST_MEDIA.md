## 使用边界（先读）

- ✅ 可以：把文件**上传**到画布作为本地上传节点、参考图、素材，用于探索上传、
  挂载、预览、连接、删除与历史恢复等不产生费用的功能。
- ❌ 禁止：**不要实际触发真实的视频生成和图片生成动作**——生成需要付费且
  价格较高；所有带 ✦/VIP/积分/生成/发送 字样的按钮一律只观察、不点击执行。
- 充值、订阅、积分购买页一律不进入；不读取 cookie/token。
- 部分文件名含用户作品语义（如 `S83·镜2.mp4`、咖啡馆角色图）：上传后节点标题
  会带文件名，相关截图必须遮蔽标题区，台账不得记录用户作品名。
- 字节数来自 2026-09-23 的只读 `stat` 核对；使用前若打开失败，先重新 `stat`
  确认文件仍在。
